# Vertical coordinate reference systems
<!-- id: sistemas-referencia-coordenadas-verticales -->
<!-- origen: 66855de5f35556adb66e38b119419129eac95655 -->

Vertical systems always represent elevation, height or depth. They have a single dimension, usually _Z_. Heights represented by these systems are always orthometric, never ellipsoidal.

The following types exist:

| Coordinate reference system | Dimensions |
| :--- | :--- |
| [Unknown or local](sistema-referencia-vertical-desconocido.md) | 1D or 2D |
| Engineering | Not applicable: Digi3D.AI does not support them. |
| Vertical | 1D |

Digi3D.AI only allows a vertical coordinate reference system to be selected as the vertical part of a [compound coordinate reference system](../sistemas-referencia-coordenadas-compuestos.md).

EGM08_REDNAP Península and EGM08_REDNAP Canarias are automatically replaced by the official EPSG systems _Alicante height_ and _Tenerife height_. See [EGM08_REDNAP becomes Alicante height and Tenerife height](/digi3d-ai/usuarios-de-versiones-anteriores/egm08-rednap-sustituido-por-alicante-height.md).
