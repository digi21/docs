# Compound coordinate reference systems
<!-- id: sistemas-referencia-coordenadas-compuestos -->
<!-- origen: 141358e68f67bb6fc26e94429e48915ba460e431 -->

Digi3D.AI only supports three-dimensional (_3D_) coordinate reference systems. To select a projected coordinate reference system, which has two dimensions (_2D_), you must combine it with a vertical system. Compound coordinate reference systems combine two systems: a horizontal (_2D_) system and a one-dimensional (_1D_) vertical system, producing a _3D_ coordinate reference system.

Digi3D.AI allows these compound coordinate reference systems:

1. _Unknown horizontal_ + _unknown vertical_.
2. _2D geographic_ + _unknown vertical_.
3. _2D geographic_ + _vertical_.
4. _Projected_ + _unknown vertical_.
5. _Projected_ + _vertical_.
