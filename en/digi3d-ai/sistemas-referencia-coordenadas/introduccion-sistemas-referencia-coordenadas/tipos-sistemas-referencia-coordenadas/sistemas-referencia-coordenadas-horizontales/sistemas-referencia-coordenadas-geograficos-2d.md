# 2D geographic coordinate reference systems
<!-- id: sistemas-referencia-coordenadas-geograficos-2d -->
<!-- origen: 1e4806b0d01c94a92ed9ef364ba145523aa0f0c5 -->

Represent points as polar coordinates, that is, angles. They have two dimensions: one for _Latitude_ and another for _Longitude_.

Units and axis order can vary. Most geographic coordinate reference systems use _Latitude, Longitude_ coordinate order, with degrees as their units.

Digi3D.AI does not allow users to select a two-dimensional (2D) geographic coordinate reference system directly; it can only be selected as part of a [compound coordinate reference system](../sistemas-referencia-coordenadas-compuestos.md).
