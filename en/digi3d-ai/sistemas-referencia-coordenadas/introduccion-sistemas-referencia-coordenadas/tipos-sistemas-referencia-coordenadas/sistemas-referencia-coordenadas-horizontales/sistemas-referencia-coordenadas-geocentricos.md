# Geocentric coordinate reference systems
<!-- id: sistemas-referencia-coordenadas-geocentricos -->
<!-- origen: e6704734d51cb0b2d256e706b03100ff37871ac8 -->

![Diagram showing geocentric and topocentric coordinate reference systems](../../../../../images/geocentrico-y-topocentrico.png)

Digi3D.AI sometimes needs to transform coordinates from one coordinate system to a geocentric coordinate system.

Geocentric coordinate systems are always Cartesian, with their origin at the Earth's center. Geocentric coordinate system units are always meters.

Digi3D.AI does not allow you to select a geocentric coordinate reference system, but uses these systems internally (for example, absolute orientation calculations sometimes take place in geocentric coordinates).

The geocentric system is shown in red in the image above.
