# Horizontal coordinate reference systems
<!-- id: sistemas-referencia-coordenadas-horizontales -->
<!-- origen: 2f76135254a9a800c571b709e9c8372d0f8d668a -->

Horizontal coordinate reference systems represent coordinates in two or three dimensions. Usually _X,Y_ or _Latitude,Longitude_, or _X,Y,Z_ and _Latitude,Longitude,Height_.

The following types exist:

| Coordinate reference system | Dimensions |
| :--- | :--- |
| [Unknown or local](/digi3d-ai/sistemas-referencia-coordenadas/introduccion-sistemas-referencia-coordenadas/tipos-sistemas-referencia-coordenadas/sistemas-referencia-coordenadas-horizontales/sistema-referencia-coordenadas-horizontal-desconocido.md) | 1D or 2D |
| Engineering | Not applicable: Digi3D.AI does not support them. |
| [Geocentric](sistemas-referencia-coordenadas-geocentricos.md) | 3D |
| [Topocentric](sistema-referencia-coordenadas-topocentricos.md) | 2D |
| [2D geographic](sistemas-referencia-coordenadas-geograficos-2d.md) | 2D |
| [3D geographic](sistema-referencia-coordenadas-geograficos-3d.md) | 3D |
| [Projected](sistema-referencia-coordenadas-proyectados.md) | 2D |

Digi3D.AI works with horizontal coordinate reference systems except _engineering_ systems, but only allows three-dimensional (_3D_) coordinate reference systems to be selected. A two-dimensional (_2D_) system can only be selected as the horizontal part of a compound coordinate reference system.
