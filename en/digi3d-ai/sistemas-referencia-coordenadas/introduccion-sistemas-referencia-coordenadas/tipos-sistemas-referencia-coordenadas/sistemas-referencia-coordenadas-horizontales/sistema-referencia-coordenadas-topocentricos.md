# Topocentric coordinate reference systems
<!-- id: sistema-referencia-coordenadas-topocentricos -->
<!-- origen: 8eb8675eb83d922eeb4495bcfe3a8a06089df746 -->

![Diagram showing geocentric and topocentric coordinate reference systems](../../../../../images/geocentrico-y-topocentrico.png)

Topocentric systems are Cartesian coordinate systems tangent to the ellipsoid (or spheroid) at a given point. Their axes are oriented so that _X_ increases _eastward_, _Y_ northward and _Z_ perpendicular to the tangent plane, increasing away from the ellipsoid's (or spheroid's) center. The topocentric system is shown in blue in the geocentric/topocentric coordinate reference system diagram.

As with [geocentric coordinate reference systems](/digi3d-ai/sistemas-referencia-coordenadas/introduccion-sistemas-referencia-coordenadas/tipos-sistemas-referencia-coordenadas/sistemas-referencia-coordenadas-horizontales/sistemas-referencia-coordenadas-geocentricos.md), Digi3D.AI needs to create topocentric coordinate reference systems but does not allow users to select a system of this type.
