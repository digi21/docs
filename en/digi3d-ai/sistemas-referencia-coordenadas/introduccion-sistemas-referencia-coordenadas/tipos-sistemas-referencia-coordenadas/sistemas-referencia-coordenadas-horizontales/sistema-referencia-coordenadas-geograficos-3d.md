3D geographic coordinate reference systems

Essentially [2D geographic coordinate reference systems](/digi3d-ai/sistemas-referencia-coordenadas/introduccion-sistemas-referencia-coordenadas/tipos-sistemas-referencia-coordenadas/sistemas-referencia-coordenadas-horizontales/sistemas-referencia-coordenadas-geograficos-2d.md) with an additional dimension for height, which is **always ellipsoidal.**

Digi3D.AI allows you to select every 3D geographic coordinate reference system available in the _EPSG_ database.
