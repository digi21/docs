# Digi3D.AI modules with their own coordinate reference system
<!-- id: implementacion-src-modulos-digi3d -->
<!-- origen: e2b5e1239df4de7a29a7840d52f742f7ac22dbf0 -->

Digi3D.AI consists of several interacting modules: the user interface (menus, toolbars), windows (photogrammetric and drawing windows), sensors (_ADS40/80, conic, satellite_), drawing files (_.bind, .bin, .shp_, ...) and configuration files (keys, code tables, ...).

This section explains which modules have an assigned coordinate reference system, how to change each module's system and when Digi3D.AI transforms coordinates into a module's coordinate reference system.
