# Assigning the drawing window's coordinate reference system
<!-- id: asignacion-src-ventana-dibujo -->
<!-- origen: b73402f7b380e63b7d1b3f7857e4777137a0fb9e -->

Digi3D.AI lets you specify the drawing window's coordinate reference system through **Drawing window's coordinate reference system**, in the **Coordinate Reference System** section of the Drawing file tab in [New project](/digi3d-ai/referencia/cuadros-de-dialogo/nuevo-proyecto/README.md).

Clicking the ellipsis button displays the **Coordinate reference system dialog**. Selecting **That of the drawing file** assigns the drawing window the system associated with the first drawing file you load (the file whose opening creates the drawing window).

Once the drawing window is created, its coordinate reference system **cannot be changed**. To view geometries in another coordinate reference system, close the drawing window and open a new one in that system.
