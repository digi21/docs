# Drawing files
<!-- id: archivos-de-dibujo -->
<!-- origen: e857890b7a61e8954ecec084f113d6f8fd801944 -->

Coordinates of geometries stored in loaded drawing files belong to a coordinate reference system.

When creating a drawing file, you can specify the coordinate reference system to assign to it. Once a system is assigned to a drawing file, **it cannot be changed**. To obtain a file in another coordinate reference system, [export](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/e/exportar.md) the file and create a new one in the other system.
