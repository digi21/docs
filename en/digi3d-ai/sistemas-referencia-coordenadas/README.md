# Coordinate reference systems
<!-- id: sistemas-referencia-coordenadas -->
<!-- origen: 4b2876cc8f8c35c5ceba8e3f57f062d29bd63cad -->

Digi3D.AI associates a coordinate reference system with each loaded file (photogrammetric model, drawing windows, ...) and can transform coordinates between different coordinate reference systems.

This topic explains the concept of a coordinate reference system and the systems Digi3D.AI accepts. It also describes how and where coordinates are transformed within the program and how to assign a coordinate reference system to each Digi3D.AI module.
