# Installing Digi3D.AI
<!-- id: instalacion-digi3d-ai -->
<!-- origen: b05656fa60546b80f7cd9c264c414340504b08b0 -->

To install Digi3D.AI, simply [download the installer](https://www.digi21.net/Digi3D/Download) from our website.

The installer is a _bootstrapper_, a program that runs the installers for the required components. The Digi3D.AI installer installs all the components the program needs \(licensing suite, dongle driver, geoid models, etc.\).

![Digi3D.AI installer](../../images/instalador-digi3d-ai.png)

The installer displays one row for each component: Digi3D.AI, the EGM2008 geoid model and the Licencias application suite. If a component is already installed on your computer, you can **Repair**, **Skip** or **Remove** it. Click **Next** to apply the actions you selected for each component.

Under **Other Digi21 applications**, the **Microsoft Store** button opens the store page used to install each application:

* **Reproject**: converts coordinates between reference systems.
* **Lot Of Points Studio**: generates point cloud pyramid levels and uploads them to Azure.

Once Digi3D.AI is installed, you need a license \(purchased, rented or trial\) to use it. See [About dongles](/acerca-llaves-proteccion/) for information on obtaining a license.
