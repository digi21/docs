# Information for users of versions 2005 and 2007
<!-- id: primeros-pasos-usuarios-versiones-anteriores -->
<!-- origen: 9b5d4d7036e981b9409d4452945045db128af4d1 -->

If you use Digi3D 2005 or Digi3D 2007, see the Digi3D.AI changes described in this section.

Digi3D.AI maintains compatibility with earlier versions wherever possible. Some changes reflect Windows 10 and Windows 11 security policies, while others modernize the formats of certain file types.
