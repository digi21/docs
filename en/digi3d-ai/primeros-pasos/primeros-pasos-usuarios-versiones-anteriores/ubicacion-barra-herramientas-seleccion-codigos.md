# Where is the code selection toolbar?
<!-- id: ubicacion-barra-herramientas-seleccion-codigos -->
<!-- origen: 84612f15a6672b950945bfee877e52ab75cb5735 -->

If you use _Digi3D.AI_ after working with earlier versions of _Digi3D_, you may not see the _Code_ toolbar, which lets you select the code used to digitize entities.

_Digi3D.AI_ does not display the _Code_ toolbar when configured in _multi-code_ mode (assigning multiple codes to an entity).

Change the code selection settings in [Code selection interface](/digi3d-ai/referencia/cuadros-de-dialogo/configuracion/diging/interfaz-para-seleccionar-codigo.md).
