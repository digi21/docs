# Code tables
<!-- id: tablas-de-codigos -->
<!-- origen: 7830e43de7e1b24514204e3bee566c8097e4e1c6 -->

Digi3D.AI cannot load multiple code tables simultaneously, so the former _Tools/Tables_ option has been removed.

Digi3D.AI lets you work without a code table or with a single code table.

To work with a code table, specify its location in the [Code table](/digi3d-ai/referencia/cuadros-de-dialogo/nuevo-proyecto/archivo-de-dibujo.md) field on the Drawing file tab of the _New project_ dialog.
