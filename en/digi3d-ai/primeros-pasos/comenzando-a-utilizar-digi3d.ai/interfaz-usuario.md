# Digi3D.AI user interface
<!-- id: interfaz-usuario -->
<!-- origen: 19a8a7fbc5f47f37e425dd75b39f5dcf7ddbedc8 -->

The Digi3D.AI user interface consists of the areas described below:

![Digi3D.AI user interface](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/interfaz-usuario.md)

| 1 | Menu bar | Contains menu options for running commands in Digi3D.AI. The menu bar changes depending on whether drawing files or photogrammetric windows are open and which window currently has focus. |
| - | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Toolbars | Contain buttons for quickly running commands in Digi3D. Buttons remain pressed while a command is running or the option represented by the button is active. |
| 3 | Photogrammetric window | Displays a photogrammetric model. This window displays one or two images depending on the type of model loaded (monoscopic or stereoscopic). For a stereoscopic model, it displays the images according to the Stereoscopy setting. |
| 4 | Drawing window | The area where you draw and edit entities. |
| 5 | Panels | Digi3D.AI provides multiple panels for interacting with different parts of the program. |
| 6 | Message bar | Digi3D.AI commands communicate with you through the message bar. |
