# Downloading examples and configuring Digi3D.AI for the tutorial
<!-- id: descargando-ejemplos -->
<!-- origen: 90fad22578fbb11df7dfa0cd1044d30659942bd9 -->

This topic explains how to use the basic features of _Digi3D.AI_.

The steps introduce the program's basic operation without exploring each topic in depth.

To follow these steps, you need to download two projects:

| Project name | Description |
| :--- | :--- |
| [Bronchales](http://digi21.blob.core.windows.net/ejemplos/Bronchales.zip) | Contains two analog frame camera models. The images are grayscale. The project lets you practice internal, relative and absolute orientation. |

Download and unzip the projects before continuing.

You also need to configure Digi3D.AI to use the key assignment file supplied by the installer. Follow these steps:

1. Select **Tools/Configure virtual keyboards...** from the menu. The [Configuration of virtual keyboards dialog](/digi3d-ai/referencia/cuadros-de-dialogo/configuracion-de-teclados-virtuales.md) appears.
2. If the **Key assignment files** list contains any entries, select one and click **Remove**. Repeat until the **Key assignment files** list is empty.
3. Click **Add...**. The **Open** dialog appears.
4. Enter _%Programdata%_ in the **File name** field. The contents of the %ProgramData% directory appear.
5. Select the **Digi3D.AI** directory. This is where Digi3D.AI's tables and settings are installed.
6. Select the **Tablas** directory.
7. Select **Teclas.keyboard.xml**. This is Digi3D.AI's standard key assignment file. The keys listed in this file match those explained in this tutorial.
8. Click **OK** in the **Configuration of virtual keyboards** dialog.
