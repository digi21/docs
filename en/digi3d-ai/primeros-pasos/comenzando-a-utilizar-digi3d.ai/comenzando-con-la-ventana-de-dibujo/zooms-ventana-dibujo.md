# Zooming in the drawing window
<!-- id: zooms-ventana-dibujo -->
<!-- origen: 57d57d73d06a7b6102d513f70a245aaed9b974e2 -->

Follow these steps to perform an [extended zoom](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/z/zoome.md):

1. Click **Extended zoom** on the [Zooms toolbar](/digi3d-ai/referencia/barras-de-herramientas/zooms.md). Digi3D.AI changes the drawing window's zoom factor to fit the entire model.

Follow these steps to perform an **extended zoom** from the **Zooms** menu:

1. Select **Zooms/Extended zoom** from the menu. Digi3D.AI changes the drawing window's zoom factor to fit the entire model.

Follow these steps to perform a [window zoom](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/z/zoomv.md):

1. Click **Window zoom** on the [Zooms toolbar](/digi3d-ai/referencia/barras-de-herramientas/zooms.md). The message bar's left pane shows that Digi3D.AI is running **ZOOMW**. The command asks you to digitize the window's first point.
2. Click the drawing window with the [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). The Window zoom command asks you to digitize the second point in the drawing window.
3. Click another part of the drawing window with the [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). Digi3D.AI changes the zoom factor to display the area bounded by the two points you digitized.

Follow these steps to perform a **window zoom** from the **Zooms** menu:

1. Select **Zooms/Zoom Window** from the menu. The message bar's left pane shows that Digi3D.AI is running **ZOOMW**. The command asks you to digitize the window's first point.
2. Click the drawing window with the [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). The Window zoom command asks you to digitize the second point in the drawing window.
3. Click another part of the drawing window with the data button. Digi3D.AI changes the zoom factor to display the area bounded by the two points you digitized.

Follow these steps to [zoom in](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/z/zoom-mas.md):

1. Click **Zoom +** on the [Zooms toolbar](/digi3d-ai/referencia/barras-de-herramientas/zooms.md). Each click zooms in on the drawing.

Follow these steps to **zoom in** from the **Zooms** menu:

1. Select **Zooms/Zoom +** from the menu. Each time you select this option, you zoom in on the drawing.

Follow these steps to [zoom out](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/z/zoom-menos.md):

1. Click **Zoom -** on the [Zooms toolbar](/digi3d-ai/referencia/barras-de-herramientas/zooms.md). Each click zooms out from the drawing.

Follow these steps to **zoom out** from the **Zooms** menu:

1. Select **Zooms/Zoom -** from the menu. Each time you select this option, you zoom out from the drawing.

Follow these steps to **zoom to an entity**:

1. Click [Zoom to entity](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/z/zoom-entidad.md) on the [Zooms toolbar](/digi3d-ai/referencia/barras-de-herramientas/zooms.md). The message bar's left pane shows that Digi3D.AI is running **ZOOM\_ENTITY**. The command asks you to select the entity to center on screen.
2. Select the entity with the middle mouse button.
3. Click the drawing window with the data button. Digi3D.AI centers the selected entity on screen.

Follow these steps to **zoom to an entity** from the **Zooms** menu:

1. Select **Zooms/Zoom to selected entities** from the menu. The message bar's left pane shows that Digi3D.AI is running **ZOOM\_ENTITY**. The command asks you to select the entity to center on screen.
2. Select the entity with the middle mouse button.
3. Click the drawing window with the data button. Digi3D.AI centers the selected entity on screen.
