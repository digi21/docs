# Deleting the last digitized entity
<!-- id: eliminando-ultima-entidad -->
<!-- origen: 0855e790f6955fd527de36c24c8504ab41eda39c -->

Follow these steps to delete entities:

1. Find the [Undo toolbar](/digi3d-ai/referencia/barras-de-herramientas/deshacer.md) in Digi3D.AI. If you cannot find it, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) for instructions.
2. Notice that its buttons are disabled.
3. Digitize an entity with the mouse, for example a [LINE](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/l/linea.md).
4. After drawing the line, check that [Undo](/digi3d-ai/referencia/barras-de-herramientas/deshacer.md) is enabled on the **Undo toolbar**, because there is an action you can undo. **Click** the button and check that the line disappears.
5. To restore the line, click **Redo**.

**Undo** only lets you undo the latest entities entered in your drawing file. You cannot use this button to delete entities drawn earlier. To delete those entities, follow these steps:

1. **Digitize** several [lines](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo\dibujando-primeras-lineas.md) in the drawing file.
2. **Close** Digi3D.AI by entering [END](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/f/fin.md) in the command bar.
3. Select **File/New/Open photogrammetric model or drawing file...** from the menu to open the file you are working on.
4. Find the [Delete and recover toolbar](/digi3d-ai/referencia/barras-de-herramientas/eliminar-y-recuperar.md). If you cannot find it, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) for instructions.
5. Click **Delete last entity**. This button deletes the last digitized entity, even if you drew it in an earlier session. Each click deletes the last entity remaining in the drawing.
