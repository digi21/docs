# Changing an entity's code
<!-- id: cambiando-codigo-entidad -->
<!-- origen: 6a280bb02c91fbe1c9251370109a96edd3bc4ab6 -->

Follow these steps to **change an entity's code**:

1. **Draw** a building with code _050146 EDIFICIO PRIVADO_.
2. **Display** the [Edit codes toolbar](/digi3d-ai/referencia/barras-de-herramientas/editar-codigos.md). If it is not active, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) to learn how to display it.
3. **Click** the first button on the [Edit codes toolbar](/digi3d-ai/referencia/barras-de-herramientas/editar-codigos.md). It runs [EDIT\_CODES](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/e/editar-cod.md).
4. **Select** the building whose code you want to edit with the mouse's [snap button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers) when **Digi3D.AI** asks for an entity.
5. **Confirm** the selection with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
6. **Click Delete** in the **Code editor** dialog to delete the entity's code.
7. **Click Add new** to add a new code.
8. **Find** _050150 EDIF. CONSTRUCCIÓN_ and **click Select**.
9. **Click OK** and check that the building's code has changed.
10. **Finish** [EDIT\_CODES](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/e/editar-cod.md) with the mouse.

Another way to **change an entity's code** is:

1. **Click** the second button on the [Edit codes toolbar](/digi3d-ai/referencia/barras-de-herramientas/editar-codigos.md). It runs [CHNG\_COD](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/c/camb-cod.md).
2. **Select** the building whose code you want to change with the mouse's [snap button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers) when **Digi3D.AI** asks for an entity.
3. **Confirm** the selection with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). Confirming automatically replaces the entity's code with the active code on the [Code toolbar](/digi3d-ai/referencia/barras-de-herramientas/codigo.md).
4. **Finish** [CHNG\_COD](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/c/camb-cod.md) with the mouse.
