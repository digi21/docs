# Deleting an entity graphically and making your first selection
<!-- id: eliminando-entidad-graficamente -->
<!-- origen: f1ef82c097a95fd9c76596964f9cb623546192c7 -->

Follow these steps to delete entities:

1. **Digitize** several linear entities in the drawing window.
2. Find the [Delete and recover toolbar](/digi3d-ai/referencia/barras-de-herramientas/eliminar-y-recuperar.md) in _Digi3D.AI_. If you cannot find it, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) for instructions.
3. **Click** the second button on the [Delete and recover toolbar](/digi3d-ai/referencia/barras-de-herramientas/eliminar-y-recuperar.md), which runs [DELETE\_E](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/b/borra-e.md).
4. **Select** search mode **0. Vertex or projection in XY**.
5. **Select** the entity to delete with the mouse's [snap button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). _Digi3D.AI_ displays an animation showing the direction in which the entity was drawn and its vertices.
6. If this is the entity you want to delete, **confirm** the selection by clicking the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
7. **Click** the mouse's [cancel button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers) or press **Escape** to cancel the command.
8. **Check** that _Digi3D.AI_ is in [ready mode](/digi3d-ai/referencia/ordenes/formas-de-ejecutar-una-orden/de-manera-automatica/modo-preparado.md) \(the message Ready should appear in the lower left corner\).

Follow these steps to cancel an entity selection:

1. **Click** the second button on the [Delete and recover toolbar](/digi3d-ai/referencia/barras-de-herramientas/eliminar-y-recuperar.md), which runs [DELETE\_E](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/b/borra-e.md).
2. **Select** any entity with the mouse's [snap button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
3. **Click** the mouse's [cancel button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers) when _Digi3D.AI_ asks for confirmation, to deselect the entity if it is not the one you want.
4. **Click** the mouse's [cancel button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers) again to finish the command and return _Digi3D.AI_ to [ready mode](/digi3d-ai/referencia/ordenes/formas-de-ejecutar-una-orden/de-manera-automatica/modo-preparado.md).
5. **Click** the second button on the [Delete and recover toolbar](/digi3d-ai/referencia/barras-de-herramientas/eliminar-y-recuperar.md), which runs [DELETE\_E](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/b/borra-e.md), to try canceling a selection with the keyboard.
6. **Select** any entity with the mouse's [snap button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
7. **Press Escape** when _Digi3D.AI_ asks for confirmation, to deselect the entity if it is not the one you want.
8. Press **Escape** again to finish the command and return _Digi3D.AI_ to [ready mode](/digi3d-ai/referencia/ordenes/formas-de-ejecutar-una-orden/de-manera-automatica/modo-preparado.md).
