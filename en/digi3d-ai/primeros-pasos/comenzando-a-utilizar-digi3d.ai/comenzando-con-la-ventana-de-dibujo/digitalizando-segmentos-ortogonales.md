# Digitizing segments orthogonal to the last segment of the current polyline
<!-- id: digitalizando-segmentos-ortogonales -->
<!-- origen: d87baa59331db0518708a26e8a4e23c604801ade -->

Follow these steps to digitize segments orthogonal to the last segment of the polyline you are digitizing:

1. Display the [Polyline restrictions toolbar](/digi3d-ai/referencia/barras-de-herramientas/restricciones-de-polilinea.md). If it is not active, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) to learn how to display it.
2. Start digitizing a polyline with several vertices by **clicking** the **drawing window** with the data button.
3. Click the first button on the [Polyline restrictions toolbar](/digi3d-ai/referencia/barras-de-herramientas/restricciones-de-polilinea.md), which corresponds to [ORTHO](/digi3d-ai/referencia/ventana-de-dibujo/variables/o/orto.md).
4. Continue digitizing the polyline by **clicking** the drawing window with the [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). Check that each new segment is now orthogonal to the previous one.
5. Click the first button on the [Polyline restrictions toolbar](/digi3d-ai/referencia/barras-de-herramientas/restricciones-de-polilinea.md) again to **turn off** orthogonality.
6. Continue digitizing the polyline and check that new segments are no longer constrained to be orthogonal.
7. **Turn orthogonality on or off** as often as you need while drawing the polyline.
8. Click the drawing window with the [cancel button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers) to **finish** the polyline.

You can start digitizing the polyline with [ORTHO](/digi3d-ai/referencia/ventana-de-dibujo/variables/o/orto.md) active. Follow these steps:

1. Click the first button on the [Polyline restrictions toolbar](/digi3d-ai/referencia/barras-de-herramientas/restricciones-de-polilinea.md), which corresponds to [ORTHO](/digi3d-ai/referencia/ventana-de-dibujo/variables/o/orto.md).
2. Digitize the first segment by clicking the drawing window with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). This segment defines the orientation of the orthogonal segments.
3. Draw as many segments as you want to see how the command works, turning orthogonality on and off on the [Polyline restrictions toolbar](/digi3d-ai/referencia/barras-de-herramientas/restricciones-de-polilinea.md).
4. Click the drawing window with the mouse's [cancel button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers) to finish digitizing the polyline.
