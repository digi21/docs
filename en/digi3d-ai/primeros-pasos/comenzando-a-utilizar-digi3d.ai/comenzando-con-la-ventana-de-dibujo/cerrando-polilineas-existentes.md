# Closing existing polylines
<!-- id: cerrando-polilineas-existentes -->
<!-- origen: fd13e0d48440fb32bfa18ced4ca3f329f563b12f -->

Follow these steps to **close existing polylines**:

1. **Draw** open entities by **clicking** the drawing window with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers), for example a triangle and a square, each missing one side.
2. **Display** the [Edit polyline toolbar](/digi3d-ai/referencia/barras-de-herramientas/editar-polilinea.md). If it is not active, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) to learn how to display it.
3. **Click** the first button, **Close polyline**, on the [Edit polyline toolbar](/digi3d-ai/referencia/barras-de-herramientas/editar-polilinea.md). In the lower left corner, **Digi3D.AI** indicates that [CLOSE](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/c/cierra.md) is running and asks you to select the entity to close.
4. **Click** the entity to close with the mouse's [snap button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). The entity closes automatically.
5. **Finish** the command by pressing **Esc** or clicking the mouse's [cancel button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
