# Introducing the basic toolbars
<!-- id: barras-herramientas-basicas -->
<!-- origen: f3ef35eda9662dd48a396fbeefd5acfc1adb6bef -->

All **toolbars** are visible when you start **Digi3D.AI**. Follow these steps to select the basic toolbars:

1. Click a toolbar with the mouse's [cancel button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers) to display a list of all the toolbars available in Digi3D.AI.
2. Turn off every toolbar by clicking each one with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
3. Select only the [Coordinates](/digi3d-ai/referencia/barras-de-herramientas/coordenadas.md) toolbar.

Follow the same procedure to turn on any other toolbar.
