# Digitizing closed lines
<!-- id: digitalizando-lineas-cerradas -->
<!-- origen: 5c88d378f219552663eef2a1a6dab53210376e4b -->

Follow these steps to digitize closed lines:

1. Display the [End of the polyline toolbar](/digi3d-ai/referencia/barras-de-herramientas/finalizacion-de-polilinea.md). If it is not visible, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) to learn how to display it. The toolbar's buttons remain disabled until [LINE](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/l/linea.md) is running.
2. **Digitize** a polyline by **clicking** the drawing window with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
3. **Click** the second button on the [End of the polyline toolbar](/digi3d-ai/referencia/barras-de-herramientas/finalizacion-de-polilinea.md), **Close line**. It finishes the line you are digitizing and closes it automatically.

You can also close linear entities as follows:

1. Display the [Action when ending line toolbar](/digi3d-ai/referencia/barras-de-herramientas/accion-al-finalizar-la-linea.md). If it is not active, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) to learn how to display it.
2. **Click** the first button on the [Action when ending line toolbar](/digi3d-ai/referencia/barras-de-herramientas/accion-al-finalizar-la-linea.md). This activates [C](/digi3d-ai/referencia/ventana-de-dibujo/variables/c/c.md), which tells **Digi3D.AI** to close digitized lines automatically.
3. **Draw** a polyline by **clicking** the drawing window with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). When you finish the polyline with the mouse's [cancel button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers), it closes automatically, regardless of how many vertices it has.
