# Deleting the last segments of the current polyline
<!-- id: eliminando-ultimos-segmentos -->
<!-- origen: 16a6af08c25d49ed83679ba379307d6a2f4756ad -->

Follow these steps to delete the last segments of the polyline you are digitizing:

1. Display the [End of the polyline toolbar](/digi3d-ai/referencia/barras-de-herramientas/finalizacion-de-polilinea.md). If it is not active, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) to learn how to display it.
2. Start drawing a polyline by **clicking** the drawing window with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
3. Click the **third button** on the [End of the polyline toolbar](/digi3d-ai/referencia/barras-de-herramientas/finalizacion-de-polilinea.md). This is **Back**, which deletes the last digitized vertex and the line's last segment.
4. Click **Back** to delete the polyline's vertices. When no segments remain to go back through, **Digi3D.AI** finishes [LINE](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/l/linea.md).

There is another way to delete the last segments of the polyline you are digitizing. Follow these steps:

1. Digitize a polyline with several segments by **clicking** the drawing window with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
2. Click the **last button** on the [End of the polyline toolbar](/digi3d-ai/referencia/barras-de-herramientas/finalizacion-de-polilinea.md) to activate it. This button runs [MU](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/u/um.md).
3. Select any segment by **clicking** it with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). **Digi3D.AI** displays the message "_Mark the segment from which to delete_". **Digi3D.AI** deletes the segments from the last one digitized back to the selected segment.
4. Continue digitizing the polyline by **clicking** the drawing window with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
5. **Finish** the polyline by **clicking** the drawing window with the mouse's [cancel button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers).
