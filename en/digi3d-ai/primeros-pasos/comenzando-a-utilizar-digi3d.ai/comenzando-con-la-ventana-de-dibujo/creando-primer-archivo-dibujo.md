## Procedure

Follow these steps to create your first **drawing file**:

1. Start **Digi3D.AI**. The [New project](/digi3d-ai/referencia/cuadros-de-dialogo/nuevo-proyecto/) dialog appears by default.
2. Select the **Drawing file** tab. Open the drop-down list to see the last 10 drawing files loaded.
3. To **open** a file or **create** a new one, click the ellipsis button. The **Open** dialog appears.
4. Enter the name of the file you want to create and click **Open**.
5. Configure the **Environment:** option in the drawing window's **Configuration parameters**:

   * Under **Code table**, click the ellipsis button, enter %Programdata% and select the **Digi3D.AI** directory. This is where Digi3D.AI's tables and settings are installed.
   * Select the **Tablas** directory.
   * Select **Digi.tab.xml**, the table file you will use throughout the course.
   * Under **Symbols directory**, use the ellipsis button to select **C:\ProgramData\Digi3D.NET\Símbolos**.

   Configure these paths once when opening a new file in Digi3D.AI, or whenever you change the code table.

6. Click **Accept**.
7. Leave the default value, **Unknown**, when Digi3D.AI asks you to select the file's coordinate reference system. It requests a coordinate reference system because the drawing file is new and has not yet been assigned one.
8. Click **OK** to create the drawing file.
