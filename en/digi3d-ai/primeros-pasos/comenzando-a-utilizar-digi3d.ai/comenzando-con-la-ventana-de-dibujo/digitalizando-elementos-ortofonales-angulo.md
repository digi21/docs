# Digitizing features orthogonal to a specified angle
<!-- id: digitalizando-elementos-ortofonales-angulo -->
<!-- origen: 83f469a60f97f5a7c8ada87b6bb4ba1e4aa2383f -->

Follow these steps to **digitize features orthogonal to a specified angle**:

1. **Display** the [Polyline restrictions toolbar](/digi3d-ai/referencia/barras-de-herramientas/restricciones-de-polilinea.md). If it is not active, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) to learn how to display it.
2. **Display** the [Active parameters toolbar](/digi3d-ai/referencia/barras-de-herramientas/parametros-activos.md). If it is not active, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) to learn how to display it.
3. **Click** the third button on the Active parameters toolbar, which corresponds to the [active angle](/digi3d-ai/referencia/ventana-de-dibujo/variables/a/aa.md), to run [AA](/digi3d-ai/referencia/ventana-de-dibujo/variables/a/aa.md).
4. **Enter** 45 (sexagesimal degrees) in the window at the lower right and press **Enter**. In the lower left corner, **Digi3D.AI** asks you to enter an active angle or digitize the first point.
5. **Click** the second button on the [Polyline restrictions toolbar](/digi3d-ai/referencia/barras-de-herramientas/restricciones-de-polilinea.md), [Orthogonal to the active angle](/digi3d-ai/referencia/ventana-de-dibujo/variables/o/orto-aa.md). When this button is active, digitized lines are orthogonal relative to the stored [active angle](/digi3d-ai/referencia/ventana-de-dibujo/variables/a/aa.md). The active angle of 45º is measured from the positive X axis.
6. **Draw** a line in the drawing window by **clicking** with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). The first segment forms an angle of 45º to the horizontal, and the remaining segments are orthogonal to each other.
7. **Turn off** [Orthogonal to the active angle](/digi3d-ai/referencia/ventana-de-dibujo/variables/o/orto-aa.md) and continue **digitizing** segments. You can now draw segments in any direction.
8. **Turn** [Orthogonal to the active angle](/digi3d-ai/referencia/ventana-de-dibujo/variables/o/orto-aa.md) **on or off** as often as needed while drawing an entity.

Follow these steps to **digitize features orthogonal to a specified alignment**:

1. **Display** the [Polyline restrictions toolbar](/digi3d-ai/referencia/barras-de-herramientas/restricciones-de-polilinea.md). If it is not active, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) to learn how to display it.
2. **Display** the [Active parameters toolbar](/digi3d-ai/referencia/barras-de-herramientas/parametros-activos.md). If it is not active, click [here](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md) to learn how to display it.
3. **Click** the third button on the Active parameters toolbar, which corresponds to the [active angle](/digi3d-ai/referencia/ventana-de-dibujo/variables/a/aa.md), to run [AA](/digi3d-ai/referencia/ventana-de-dibujo/variables/a/aa.md).
4. **Digitize** two points to define an **alignment**. In the lower left corner, **Digi3D.AI** asks you to enter an active angle or digitize the first alignment point. **Click** two points in the drawing window with the mouse's [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers). If you defined an alignment before running the command, use search mode **4. Nearest vertex in XYZ** to select its two vertices. Click [here](introduccion-modos-busqueda.md) for instructions on changing search modes.
5. **Turn on** [Orthogonal to the active angle](/digi3d-ai/referencia/ventana-de-dibujo/variables/o/orto-aa.md) on the [Polyline restrictions toolbar](/digi3d-ai/referencia/barras-de-herramientas/restricciones-de-polilinea.md).
6. Start **digitizing** a polyline. Its first segment uses the angle defined by the alignment, and the remaining segments are orthogonal to it and to each other.
7. **Turn** [Orthogonal to the active angle](/digi3d-ai/referencia/ventana-de-dibujo/variables/o/orto-aa.md) **on or off** as often as needed while drawing an entity.
