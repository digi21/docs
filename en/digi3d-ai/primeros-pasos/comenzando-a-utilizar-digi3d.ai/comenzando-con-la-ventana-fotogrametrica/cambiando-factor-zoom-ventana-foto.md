# Learning to change the zoom factor
<!-- id: cambiando-factor-zoom-ventana-foto -->
<!-- origen: 6aac086b47cf35599ef8decbc14eafba36739268 -->

There are several ways to change the photogrammetric window's zoom factor. Changing it lets you:

* Move around the model faster \(zoom out to navigate the images faster\).
* Digitize more accurately \(zoom in on the images\).

### Using the zoom factor drop-down list on the photogrammetric window's status bar

* Click the **zoom factor drop-down list** on the photogrammetric window's status bar and select an option.

The list offers as many options as the loaded images' zoom capabilities allow.  
Zoom factor labels consist of a number, a colon and another number, for example 128:1.  
The notation means \[image pixels\]:\[screen pixels\], so selecting 128:1 makes Digi3D display 128 image pixels in one screen pixel.

### Using the Photogrammetric window menu

1. Open **Photogrammetric window** and select **Extended zoom**. Digi3D calculates a zoom factor that fits the entire image on screen. Your coordinates do not change; only the zoom factor changes.
2. Open **Photogrammetric window** and select **1x1 Zoom**. Check that Digi3D displays each image pixel in one screen pixel. Use this ratio to see image detail without enlarging pixels. Zooming in further makes each image pixel occupy more than one screen pixel. Zooming out displays several image pixels in one screen pixel.
3. Open **Photogrammetric window** and select **Zoom with memory (last two zooms)**. Digi3D returns to the zoom factor used before step 1. This option remembers your last two zoom factors. You can assign this command to any topo-mouse button to switch between them.
4. Open **Photogrammetric window** and select **Zoom In**. Digi3D increases the zoom factor.
5. Open **Photogrammetric window** and select **Zoom Out**. Digi3D reduces the zoom factor.

### Using the keyboard

Changing the zoom factor with the mouse can be slow.

The following keys have commands assigned that change the zoom factor without opening the menu:

1. Press **F3**. Digi3D performs an extended zoom.
2. Press **F4**. Digi3D performs a 1x1 zoom.
3. Press **Page Down**. Digi3D zooms in.
4. Press **Page Up**. Digi3D zooms out.

To zoom in by two levels, simply press **Page Down** twice.

### Using the mouse wheel

If your mouse wheel is configured to change the zoom factor, you can use it while the mouse is captured.

1. **Click the photogrammetric window** or press the **spacebar** to capture the mouse in it.
2. Turn the mouse wheel. If it is configured to change the zoom factor, the photogrammetric window changes its zoom factor.
3. Press the **spacebar** to release the mouse.
