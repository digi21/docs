# Learning to navigate the photogrammetric window with the mouse
<!-- id: desplazando-ventana-foto-raton -->
<!-- origen: 6659c395862a084b340ac60c9de977c83b0e2028 -->

You can capture the Windows mouse in the photogrammetric window to move the view with it, whether or not you have a topo-mouse or handwheels.

### Capturing the mouse in the photogrammetric window

There are two ways to capture the mouse in the photogrammetric window:

1. Run [DIGI3D\_MOUSE](/digi3d-ai/referencia/ventana-fotogrametrica/ordenes/r/raton-digi3d.md).
2. Click the photogrammetric window \(if the program is configured to allow this\).

### Releasing the mouse from the photogrammetric window

There are four ways to release the mouse from the photogrammetric window:

1. Switch to another application \(press **Alt+Tab**\).
2. Run [DIGI3D\_MOUSE](/digi3d-ai/referencia/ventana-fotogrametrica/ordenes/r/raton-digi3d.md).
3. Press **Enter** to release the mouse.
4. Press \(and hold\) **Ctrl** to release the mouse temporarily. When you release _Ctrl_, Digi3D.AI automatically captures the mouse in the photogrammetric window again.
