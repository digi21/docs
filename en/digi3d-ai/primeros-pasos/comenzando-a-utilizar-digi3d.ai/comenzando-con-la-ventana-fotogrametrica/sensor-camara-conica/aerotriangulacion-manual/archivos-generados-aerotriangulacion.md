# Files generated when measuring aerotriangulation
<!-- id: archivos-generados-aerotriangulacion -->
<!-- origen: c2baa4fc6f59772363d0b70005702f7c709e1e1a -->

Accepting an aerotriangulation measurement creates a file in **Aerotriangulación**, named _left photo - right photo.mod_, containing the measured points' model coordinates for that model.

As with absolute orientation measurement, _.f_ files in [PatB](/digi3d-ai/referencia/ventana-fotogrametrica/sensores/camara-conica/extensiones/patb.md) format are also created in that folder, containing each photo's measured point photo coordinates.

Complete [Measuring aerotriangulation for model 107-108](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-fotogrametrica/sensor-camara-conica/aerotriangulacion-manual/midiendo-aetrotriangulacion-modelo-107-108.md) before following these steps to check the generated files:

1. Open **File Explorer** \(you can press **Windows + E**\).
2. Locate the **Bronchales** project.
3. Check that **107-108.abs.xml** has been created.
4. Check that **Aerotriangulación** has been created and contains **107.f** and **108.f**.
5. Check that **Instantáneas** has been created and contains thumbnails of the measured points.
