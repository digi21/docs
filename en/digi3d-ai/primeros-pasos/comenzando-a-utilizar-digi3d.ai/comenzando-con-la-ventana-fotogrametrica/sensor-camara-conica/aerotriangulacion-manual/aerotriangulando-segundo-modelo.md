# Aerial triangulating the second model
<!-- id: aerotriangulando-segundo-modelo -->
<!-- origen: 59f211527c002a31d10b2cc474aa8b00d32899a8 -->

As when performing a project's [second absolute orientation](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-fotogrametrica/sensor-camara-conica/orientacion-de-modelos-fotogrametricos/orientacion-absoluta/midiendo-segunda-orientacion-absoluta.md), Digi3D.AI does not let you change a point's location in a photo if it has already been measured there.

When a point to be measured in a model has already been measured in the previous model, the program prevents movement in _X,Y_ and allows movement only in _Z_, locking the image where the point was already measured. This prevents measuring the same point at two different locations.

Complete [Files generated when measuring aerotriangulation](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-fotogrametrica/sensor-camara-conica/aerotriangulacion-manual/archivos-generados-aerotriangulacion.md) before continuing.

1. Load model 108-109 from the [Photogrammetric project pane](/digi3d-ai/referencia/paneles/proyecto-fotogrametrico.md).
2. Click **T** on the photogrammetric window toolbar.
3. Measure point 1080 as requested. It was already measured in photo 108 of model 107-108, so Digi3D.AI prevents movement of the photogrammetric window in _X,Y_. Change _Z_ to position the pointer stereoscopically over point 1080 and measure it.
4. Measure every point specified by the schema.
5. Add control points 8 and 9. Remember their [locations](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-fotogrametrica/sensor-camara-conica/orientacion-de-modelos-fotogrametricos/orientacion-absoluta/midiendo-segunda-orientacion-absoluta.md).
6. Click OK.
