# Relative orientation
<!-- id: orientacion-relativa -->
<!-- origen: 29dfe5fdba574d88de5497e3a396cb2cc721acf9 -->

Relative orientation lets you navigate the model stereoscopically. Once a model's relative orientation is complete, changing Z changes the position of the images.

As with [Internal orientation](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-fotogrametrica/sensor-camara-conica/orientacion-de-modelos-fotogrametricos/orientacion-interna/), if the project has been aerial triangulated, the images' positions in space are already known. If you have no aerial triangulation calculation file, you must perform relative orientation manually.

You can tell whether the loaded model has relative orientation by checking the photogrammetric window toolbar. If **R** is pressed, **R**elative orientation has been performed and loaded. If **R** is not pressed, relative orientation has not been performed.
