# Photogrammetric project files

Accepting [Create photogrammetric project](/digi3d-ai/referencia/cuadros-de-dialogo/crear-proyecto-fotogrametrico.md) created a file with the .d3dprj extension.  
The _photogrammetric project_ file contains information about the project's strips and the models in each strip.

Complete [Creating a photogrammetric project for Bronchales](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-fotogrametrica/sensor-camara-conica/proyectos-de-proyecto-fotogrametrico/creando-proyecto-fotogrametrico-bronchales.md) before continuing.

1. Open File Explorer and locate the _Bronchales_ project folder.
2. Check that _Proyecto de Bronchales.d3dprj_ has been created.
3. Double-click the file to open it. If your computer asks which program to use, select _Notepad_.
4. Check that there is only one section for _strips_, containing a single _strip_ titled _Strip: 1_. This strip contains two files: _107-108.d3d_ and _108-109.d3d_.
