# Creating a photogrammetric project for Bronchales
<!-- id: creando-proyecto-fotogrametrico-bronchales -->
<!-- origen: dec08d3b65e0363813a90f210402b4ae9529a549 -->

[Create photogrammetric project](/digi3d-ai/referencia/cuadros-de-dialogo/crear-proyecto-fotogrametrico.md) lets you create both _photogrammetric project_ files and [.d3d](/digi3d-ai/referencia/cuadros-de-dialogo/nuevo-proyecto/sensores-fotogrametricos.md) project files.

In this example, you will create a _photogrammetric project_ file specifying a single _strip_ containing two models: _107-108_ and _108-109_.

Complete [Measuring the second absolute orientation](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-fotogrametrica/sensor-camara-conica/orientacion-de-modelos-fotogrametricos/orientacion-absoluta/midiendo-segunda-orientacion-absoluta.md) before continuing.

1. Display the [Photogrammetric project pane](/digi3d-ai/referencia/paneles/proyecto-fotogrametrico.md) by selecting **Window/Other windows/Photogrammetric project**.
2. Click the first button on the _Photogrammetric project pane_ toolbar. [Create photogrammetric project](/digi3d-ai/referencia/cuadros-de-dialogo/crear-proyecto-fotogrametrico.md) appears.
3. Click the ellipsis button to specify the file name to create. **Open** appears.
4. Locate the Bronchales project folder and enter a file name, for example _Proyecto de Bronchales_. Click **Open**.
5. Select **Conical (Stereoscopic)** in **Sensor**. It is selected by default.
6. Click **Create** under **Strips**. [Strip properties](/digi3d-ai/referencia/cuadros-de-dialogo/propiedades-de-la-pasada.md) appears. The strip's default name is _Strip: 1_. Click **OK**. Check that the new strip's name appears in **Strips**.
7. With _Strip: 1_ selected in **Strips**, click **Load** under **Models**. This adds [.d3d](/digi3d-ai/referencia/cuadros-de-dialogo/nuevo-proyecto/sensores-fotogrametricos.md) project files to **Models**. **Open** appears.
8. Locate and select _107-108.d3d_ and click **Open**. Model _107-108_ appears in **Models**.
9. Click **Load** again and load _108-109.d3d_.
10. Click **OK**. _Create photogrammetric project_ closes, and the project loads in **Photogrammetric project**.
11. Check that **Photogrammetric project** contains a section named _Strip: 1_. Expand it to see the two models, _107-108_ and _108-109_.
12. Click model 107-108. A photogrammetric window opens with model 107-108.
13. Click model 108-109. The model displayed in the photogrammetric window changes.
