# Photogrammetric window user interface
<!-- id: interfaz-usuario-ventana-fotogrametrica -->
<!-- origen: d056fcb8aa2ca4f0d97435506af36319018a482b -->

The Digi3D.AI user interface consists of the areas described below:

![Photogrammetric window user interface](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-fotogrametrica/interfaz-usuario-ventana-fotogrametrica.md)

| 1 | Toolbar | Contains buttons for actions in the photogrammetric window. The toolbar changes depending on the type of sensor displayed in the window. |
| - | ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Zoom factor drop-down list | Displays the current zoom factor and lets you change it by selecting an option from the list. |
| 3 | XY and Z speed factors | Displays the input device's current speed for XY and Z. |
| 4 | Coordinate display | Displays coordinates. The type of coordinates shown depends on the sensor loaded in the photogrammetric window. |
