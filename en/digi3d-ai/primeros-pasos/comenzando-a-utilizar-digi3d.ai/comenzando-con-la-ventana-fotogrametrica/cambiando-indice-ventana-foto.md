# Changing the pointer type in the photogrammetric window
<!-- id: cambiando-indice-ventana-foto -->
<!-- origen: f0ff2d73a94d1bdf57cdc8dede01e1fab9006a15 -->

You can change both the shape and color of the photogrammetric window's pointer.

Digi3D lets you choose from the following pointer shapes:

| Small index | A 1x1 screen pixel point in your chosen color, surrounded by a black ring. |
| :--- | :--- |
| Medium index | A 3x3 screen pixel point in your chosen color, surrounded by a black ring. |
| Large index | A 6x6 screen pixel point in your chosen color, surrounded by a black ring. |
| Blade | A large diagonal cross. Used for precise digitizing of diagonal cross-shaped fiducial marks during analog camera [internal orientation](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-fotogrametrica/sensor-camara-conica/orientacion-de-modelos-fotogrametricos/orientacion-interna/README.md). |
| Horizontal cross | A large cross. Used for precise digitizing of cross-shaped fiducial marks during analog camera internal orientation. |

Follow these steps to change the pointer type and color:

### Using the Photogrammetric window menu

1. Open **Photogrammetric window** and select **Cursor/Large index**. Digi3D changes the pointer's size.
2. Open **Photogrammetric window** and select **Cursor/Color**.
3. Select the desired color in **Color** and click **OK**. Digi3D changes the pointer's color.

If you have not selected a color, Digi3D defaults to **pure green**.

### Using the keyboard

**F2** has a command assigned that changes the pointer type each time you press it.

* Press **F2**.

Digi3D changes the pointer type, cycling repeatedly through the shapes \(small, medium, large, diagonal cross, cross\).
