# Information for Digi3D.NET users
<!-- id: usuarios-de-versiones-anteriores -->
<!-- origen: 216d0e15c14efbb6efe7877bcdc75c77bb1919de -->

This section describes changes that affect you when moving from Digi3D.NET to Digi3D.AI and explains how to adapt your files.

- [Update a code table's Python quality controls](actualizar-guiones-python.md): resolves `No module named 'digi3d.relations'` in code tables created for Digi3D.NET and the `NameError` and `AttributeError` errors that appear after replacing the Python environment, and lists renamed Python application programming interface (API) members.
- [Update Python selection and command expressions](actualizar-expresiones-python.md): translates expressions written for Digi3D.NET (`digi3DGeometry`, `Points.Count`, `Atr`, `g.codes[0].name`) to Digi3D.AI syntax.
- [EGM08_REDNAP becomes Alicante height and Tenerife height](egm08-rednap-sustituido-por-alicante-height.md): EGM08_REDNAP Península and EGM08_REDNAP Canarias vertical systems are replaced automatically by the official EPSG systems, with the same heights.
- [Migration to .NET 10](../programacion/.net/migracion-a-net-10.md): adapting .NET extensions.
