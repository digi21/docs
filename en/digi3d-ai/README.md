# Digi3D.AI

![Digi3D.AI icon](../images/digi3d-ai-icono.png)

Digi3D.AI is a complete _Digital Photogrammetric Workstation_ for capturing geographic entities from aerial imagery, analog and digital frame cameras, the Intergraph Digital Mapping Camera System, Vexcel UltraCamX, pushbroom sensors such as Leica ADS40/80, satellite sensors such as Ikonos and QuickBird, terrestrial photogrammetry, orthophotos with DTMs and/or DSMs, and dense point clouds.

**Digi3D.AI incorporates artificial intelligence (AI).** The program includes an AI assistant that you can ask, in natural language, to query and modify the active drawing \(for example, _“zoom to the first building”_ or _“delete the texts with code 050146”_\), without programming. The assistant works with cloud providers \(Claude, OpenAI, Azure OpenAI, Kimi, OpenRouter\) or a model running on your own computer with LM Studio or Ollama. See [AI assistant](/digi3d-ai/referencia/asistente-ia/README.md).

Digi3D.AI is also a computer-aided design (CAD) program and a geographic information system (GIS).

With Digi3D.AI, you can capture entities using commands designed for mapping.

Digi3D.AI lets you open drawing files in different formats, transform coordinates between reference systems, perform geometric and topological analyses, and search for entities.

You can also program Digi3D.AI with .NET technologies to add custom commands, utilities, exporters, search criteria and quality controls.
