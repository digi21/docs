# Entering coordinates
<!-- id: introduccion-de-coordenadas -->
<!-- origen: f7e3f63632e091b3492d1e5b344d036de0fbbb58 -->

Most [interactive commands](../ordenes/ordenes-interactivas.md) prompt you to digitize one or more points.

Digitize points in any of these ways:

* Point to them graphically with the pedal/button of the handwheels, mouse, or topomouse.
* Run [XY](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/x/xy.md).
* Run [XYZLINE](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/x/xyzlinea.md).
* Enter coordinates stored in a text file with [N](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/n/n.md).
