# REGENERATE
<!-- id: regenera -->
<!-- origen: 72078831aaa93c0910fdb7b70c02437f26bbf697 -->

Refresh the screen to update the drawing file display.

## Parameters

Does not accept parameters.

## Notes

Press Esc to stop a screen refresh or the screen redraw performed by zoom commands.
