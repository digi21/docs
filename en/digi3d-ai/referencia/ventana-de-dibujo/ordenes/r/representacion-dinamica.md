# DYNAMIC\_REPRESENTATION
<!-- id: representacion-dinamica -->
<!-- origen: d3fbdb1c89af15e1d6ba65058dae0577016cd2f0 -->

Assign the dynamic representation named by the parameter to the drawing document.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | Dynamic representation name | Yes |

## Notes

Without a parameter, the command disables the dynamic representation. If the code table has no dynamic representation with the specified name, the command plays an error sound and changes nothing.
