# RECARGAR\_ARCHIVOS\_REFERENCIA\_VISTA
<!-- id: recargar-archivos-referencia-vista -->
<!-- origen: bc8035a1f5c5004bc2e5eb56e36288762eab158f -->

Reload reference files supporting a region of interest with entities overlapping the current view.

## Parameters

Does not accept parameters.

## Notes

The command can run only when no other command is active; otherwise, it displays a message and ends. If no loaded drawing file supports partial loading, the command displays a message.
