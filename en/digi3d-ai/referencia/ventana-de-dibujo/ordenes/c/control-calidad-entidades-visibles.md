# QUALITY\_CONTROL\_VISIBLE\_ENTITIES
<!-- id: control-calidad-entidades-visibles -->
<!-- origen: 40fdd0e6cd4c28e613f96152cc3a6af697a1cb50 -->

Perform quality control analysis on visible entities.

## Parameters

Does not accept parameters.

## Notes

The command analyzes entities in the active drawing file that are not deleted, are visible, and are within the area of interest.
