# CHANGE\_KEYS\_MNU
<!-- id: cambia-teclas-mnu -->
<!-- origen: 84fed935f8d1e58b182a19265a3923dd3cc64990 -->

Change the key file.

## Parameters

Does not accept parameters.

## Notes

Each time you run this command, the application activates the next key file defined in _Configuration of virtual keyboards_ in Digi3D.

The active keyboard is displayed in the _Keyboards toolbar_.
