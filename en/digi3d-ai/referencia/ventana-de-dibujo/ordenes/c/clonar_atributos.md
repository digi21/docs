# CLONE\_ATTRIBUTES
<!-- id: clonar-atributos -->
<!-- origen: 3247c01c43f6c74d5908a49a1a17922e84b4e79b -->

Clone the attributes of the selected entity.

## Parameters

Does not accept parameters.

## Notes

Select an entity. The command replaces the contents of the Active attributes panel with the attributes of that entity.
