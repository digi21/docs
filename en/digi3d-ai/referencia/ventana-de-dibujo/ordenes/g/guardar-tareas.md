# SAVE\_TASKS
<!-- id: guardar-tareas -->

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Path of the file to create. If omitted, the program displays a dialog box for you to specify it | String | Yes |
