# SAVES\_LAYOUT
<!-- id: guarda-disposicion -->
<!-- origen: 84f76f72b4b3cc5a76c5c481162bb51fa51bf0e2 -->

Save the window and display layout of the DigiNG drawing file.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | Layout file name | No |

If you omit the parameter, the error sound plays and the command does not save anything.
