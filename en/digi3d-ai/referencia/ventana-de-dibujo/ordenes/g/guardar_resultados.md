# SAVE\_RESULTS
<!-- id: guardar-resultados -->
<!-- origen: c8b784f2d5ef83a54e3d7b7bab0c3a846650cacb -->

Save the contents of the results panel to a TXT file.

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Path of the file to create. If you omit the path, the application displays a dialog box for you to specify it | String | Yes |
