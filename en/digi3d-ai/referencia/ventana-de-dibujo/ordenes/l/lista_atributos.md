# LIST\_ATTRIBUTES
<!-- id: lista-atributos -->
<!-- origen: 287eb2d887e2e147046042e5805e2d79b97ac0e2 -->

Display the selected entity's attributes in the Results pane.

## Parameters

Does not accept parameters.

## Notes

The command prompts you to select an entity. After selection, it opens the Results pane if it is closed and displays the entity's attributes there.
