# LOCATE\_TASK
<!-- id: localizar-tarea -->
<!-- origen: 6b31b6d6dc9d0ddffa85615c2af9512e171fb868 -->

This command prompts you to digitize a point and, if there is a task at that point, locates and selects it.

## Parameters

Does not accept parameters.

## Notes

If there are no tasks, the command displays an error message and finishes. If there is no task icon at the digitized point, the command continues prompting for points until it locates a task or you cancel the command.
