# EXIT
<!-- id: salir -->
<!-- origen: 71559bf3c1aa0bdd3499d880a4045cf382f3b3dd -->

Save the active drawing file and close Digi3D.AI.

## Parameters

Does not accept parameters.

## Notes

The command saves the active drawing file and then closes the main window, using the same closing process as _File/Exit_.
