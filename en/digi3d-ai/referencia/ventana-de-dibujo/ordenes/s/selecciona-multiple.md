# SELECT\_MULTIPLE
<!-- id: selecciona-multiple -->
<!-- origen: 43a77c83abd90431c73fcbfc739705d89dca56da -->

Select and deselect multiple entities.

## Parameters

This command does not accept parameters.

## Notes

A command that supports multiple selection must already be running.

1. Point to each entity with the data button or the snap button. The command adds it to the selection and marks it.
2. Press `Esc` to remove the last entity added from the selection. When the selection is empty, `Esc` finishes the command.
3. Press the spacebar to pass the selected entities to the active command.
