# ZOOM-
<!-- id: zoom-menos -->
<!-- origen: e1d11643ca6f451c3b481b152a2ff4fa04edc513 -->

Decrease the zoom factor.

## Parameters

Does not accept parameters.

## Notes

The view zooms out. The command divides the visible area width and height by [Zoom wheel percentage](/digi3d-ai/referencia/cuadros-de-dialogo/configuracion/rueda-del-raton/porcentaje-de-zoom-rueda.md), the same value used by each mouse wheel step. If not configured, it uses 0.99. The view center does not change.
