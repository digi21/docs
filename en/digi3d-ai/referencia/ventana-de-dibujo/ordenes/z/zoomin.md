# ZOOMIN
<!-- id: zoomin -->
<!-- origen: 7d46496f4143440162bc5746ea33815085d4cf85 -->

Increase the zoom factor.

## Parameters

Does not accept parameters.

## Notes

The view zooms in. The command multiplies the visible area width and height by [Zoom wheel percentage](/digi3d-ai/referencia/cuadros-de-dialogo/configuracion/rueda-del-raton/porcentaje-de-zoom-rueda.md), the same value used by each mouse wheel step. If not configured, it uses 0.99.

Zooming is centered on the cursor position: that point becomes the view center and the cursor moves to the center.
