# ZOOM+
<!-- id: zoom-mas -->
<!-- origen: bf30055a341600fe630d262c2c26a323e61bd953 -->

Increase the zoom factor.

## Parameters

Does not accept parameters.

## Notes

The view zooms in. The command multiplies the visible area width and height by [Zoom wheel percentage](/digi3d-ai/referencia/cuadros-de-dialogo/configuracion/rueda-del-raton/porcentaje-de-zoom-rueda.md), the same value used by each mouse wheel step. If not configured, it uses 0.99. The view center does not change.
