# ZOOMTO
<!-- id: zooma -->
<!-- origen: c9f92bc05f20b03a4293dbd913b1fff8422fc501 -->

Center the view on the cursor/stereoplotter position.

## Parameters

Does not accept parameters.

## Notes

Entities retain the same zoom factor and appear at the same size as before running this command.
