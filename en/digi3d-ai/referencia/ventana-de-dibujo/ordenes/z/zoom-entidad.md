# ZOOM\_ENTITY
<!-- id: zoom-entidad -->
<!-- origen: 61f60d60be352dfb9281a92fc45f8b80bb0f9324 -->

Zoom to the selected entity.

## Parameters

Does not accept parameters.

## Notes

Select one or more entities. The command fits the view to the window enclosing the selected entities, then finishes.
