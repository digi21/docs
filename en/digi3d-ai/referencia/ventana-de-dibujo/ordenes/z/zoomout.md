# ZOOMOUT
<!-- id: zoomout -->
<!-- origen: 397798d0c0c9ff9635e692e45afcd2e4cbe26dc0 -->

Decrease the zoom factor.

## Parameters

Does not accept parameters.

## Notes

The view zooms out. The command divides the visible area width and height by [Zoom wheel percentage](/digi3d-ai/referencia/cuadros-de-dialogo/configuracion/rueda-del-raton/porcentaje-de-zoom-rueda.md), the same value used by each mouse wheel step. If not configured, it uses 0.99.

Zooming is centered on the cursor position: that point becomes the view center and the cursor moves to the center.
