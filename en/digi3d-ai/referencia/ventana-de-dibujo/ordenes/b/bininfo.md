# BININFO
<!-- id: bininfo -->
<!-- origen: 08b4bf9715d456ab8ffac746b89bdaa3a923e512 -->

Display information about entities in loaded drawing files.

## Parameters

Does not accept parameters.

## Notes

Open the **Results** dockable window and write the drawing window's coordinate reference system (name and WKT) and number of loaded drawing files. Then write this information for each loaded file:

* File coordinate reference system (name and WKT)
* Entity count for each type (lines, points, texts, complex entities, point-based complex entities, polygons, and bitmaps or raster images), showing total, undeleted, and deleted counts
* Total undeleted entities, deleted entities, and overall total
* Maximum and minimum coordinates
* Known codes
* Unknown codes: codes absent from the code table (see [Code table editor](/digi3d-ai/referencia/editor-de-tablas-de-codigos/)).
