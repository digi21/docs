# DELETE\_LAST
<!-- id: borra-ultimo -->
<!-- origen: 85a5a34fc5d80b4f1df4ee189d5ead87cadc70bb -->

Delete the last entity recorded in the drawing file.

## Parameters

Does not accept parameters.

## Notes

Each time you run this command, the application deletes the last nondeleted entity in the active drawing file. The command does not ask for confirmation.
