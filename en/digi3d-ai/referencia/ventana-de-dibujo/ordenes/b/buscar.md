# SEARCH
<!-- id: buscar -->
<!-- origen: 466a63372fc7d24814b271c077305538c2a228f7 -->

Specify entity search criteria.

## Parameters

Does not accept parameters.

## Notes

The command opens the search pane and finishes. In the pane, choose one of these search criteria:

* Search by Python expression
* Complex by code
* Entities with null attribute
* Entities with null attribute by field
* Lines with an odd number of vertex
* Lines crossing other lines
* Poligons by code
* Points by code
* Text by string
* Text by code
* Text by code and string
* All entities
* All entities by code
* All lines
* All lines by criteria
* All complex
* All polygons
* All points
* All texts

Refine the search by specifying any parameters supported by the command.
