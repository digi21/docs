# LEAVE\_TOP
<!-- id: dejar-top -->
<!-- origen: 7d5ce0c43beedea1d9b177585b63a9c3dabaf923 -->

Unload one of the topology files generated by [BINTOP](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/b/bintop.md) that are loaded when the command runs.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | Full path of the topology file to unload | Yes |

## Notes

With a parameter, the command unloads that topology without displaying a dialog box. Enclose paths containing spaces in double quotes.

Without a parameter:

- If no topology is loaded, the command displays an error message and ends.
- If only one topology is loaded, the command unloads it directly.
- If multiple topologies are loaded, the command displays a dialog box for selecting which to unload. It works like the [LEAVE](dejar.md#leave-dialog-box) dialog box: clicking a topology selects or deselects it without holding Ctrl or Shift; **\* All** unloads all loaded topologies, **OK** unloads selected topologies, and **Cancel** closes the dialog box without unloading any.

## Example

`leave_top=C:\Bronchales\aste.top`
