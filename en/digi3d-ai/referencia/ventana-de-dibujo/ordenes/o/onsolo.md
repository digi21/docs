# ONONLY
<!-- id: onsolo -->
<!-- origen: 211a74e711ae3993b68d3812b02d38646ebc07cd -->

Enable only the specified codes in the drawing and photogrammetric windows.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | One or more codes, separated by spaces | Yes |

## Notes

The command disables all codes and then enables those specified. A parameter starting with `#` represents all codes in the code table assigned that tag.

Without parameters, the command displays a dialog box listing codes to show.
