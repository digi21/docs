# ORDER\_BY\_CODE
<!-- id: ordena-por-codigo -->
<!-- origen: b22cb2cd5037df9578b24a3cb2d26d2694a1e729 -->

Sort the entities in a file by code, grouping them in the file by the code they belong to.

## Parameters

Does not accept parameters.

## Notes

The command operates on the active drawing file and sorts alphabetically by each entity's first code.

If quality control rejects the modified entity, the original entity is preserved unchanged.
