# OFFS
<!-- id: offs -->
<!-- origen: 04488394a7f68ccd5d1f14739ce0c1b4643d9a5a -->

Disable codes in the photogrammetric window.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | One or more codes, separated by spaces | Yes |

## Notes

The command only affects the photogrammetric window. A parameter starting with `#` represents all codes in the code table assigned that tag.

Without parameters, the command displays a dialog box listing codes to hide.
