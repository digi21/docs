# OFF\_ALL
<!-- id: off-todo -->
<!-- origen: e6852ab4835b49d509b599257d2e1230a014969a -->

Hide all entities.

## Parameters

Does not accept parameters.

## Notes

This command operates on entities rather than codes. When an entity is marked as hidden, it is not drawn until the hidden flag is cleared, regardless of whether its codes are enabled. The command acts on all loaded drawing files. To show hidden entities again, run [ON\_PYTHON\_EXPRESSION](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/o/on_expresion_python.md).
