# SEE\_ONLY\_ENTITIES\_WITHOUT\_BBDD\_LINK
<!-- id: ver-solo-entidades-sin-enlace-bbdd -->
<!-- origen: bdc59d62d8f96b9e49d6e5878fe0ef07f6354a64 -->

Show only entities with no codes linked to a database.

## Parameters

Does not accept parameters.

## Notes

A code has a database link if it has a table assigned. The command hides entities with any code with an assigned table. To also show entities combining codes with assigned tables and codes without assigned tables, use [SEE\_ONLY\_WITHOUT\_BBDD\_LINK](ver-solo-sin-enlace-bbdd.md).
