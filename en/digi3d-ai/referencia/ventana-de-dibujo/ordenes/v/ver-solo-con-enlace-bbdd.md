# SEE\_ONLY\_WITH\_BBDD\_LINK
<!-- id: ver-solo-con-enlace-bbdd -->
<!-- origen: 07bdd691fd0e339090cce7f012638176b753f8ac -->

Show only entities with at least one database link.

## Parameters

Does not accept parameters.

## Notes

A code has a database link if it has a table assigned. The command leaves entities with at least one code with an assigned table visible and hides the rest.
