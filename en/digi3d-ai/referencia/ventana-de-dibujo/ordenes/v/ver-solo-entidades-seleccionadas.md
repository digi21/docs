# SEE\_ONLY\_SELECTED\_ENTITIES
<!-- id: ver-solo-entidades-seleccionadas -->
<!-- origen: 7dbf3bd2244ad8f1d5625864887eab27b6e1d669 -->

Hide all entities except those selected.

## Parameters

Does not accept parameters.

## Notes

Select one or more entities. The command hides all other entities in all drawing files. Code states do not change. Run [SEE\_ALL\_ENTITIES](ver-todas-entidades.md) to show all entities again.
