# SEE\_ONLY\_TAGS\_SELECTED\_ENTITY
<!-- id: ver-solo-etiquetas-entidad-seleccionada -->
<!-- origen: 2aad24977174a7b76179c35bb9239f003cc0b38b -->

Enable only codes sharing a tag with the selected entity's codes.

## Parameters

Does not accept parameters.

## Notes

Select one or more entities. The command disables all codes and enables codes assigned the selected entities' tags, in the drawing and stereoscopic views.
