# SEE\_ONLY\_CODES\_SELECTED\_ENTITY
<!-- id: var-solo-codigos-entidad-seleccionada -->
<!-- origen: 782d2125a222162c77be71431244f140b2d31795 -->

Leave only the selected entity's codes enabled on screen, disabling all others.

## Parameters

Does not accept parameters.

## Notes

Select one or more entities. The command disables all codes and enables only those of the selected entities, in the drawing and stereoscopic views.
