# SEE\_ONLY\_ENTITIES\_WITH\_BBDD\_LINK
<!-- id: ver-solo-entidades-con-enlace-bbdd -->
<!-- origen: 9a71a363e441e74d9118c39aaafb33dbe155bc47 -->

Show only entities in which every code has a database link.

## Parameters

Does not accept parameters.

## Notes

A code has a database link if it has a table assigned. The command hides entities with any code without an assigned table. To also show entities combining codes with assigned tables and codes without assigned tables, use [SEE\_ONLY\_WITH\_BBDD\_LINK](ver-solo-con-enlace-bbdd.md).
