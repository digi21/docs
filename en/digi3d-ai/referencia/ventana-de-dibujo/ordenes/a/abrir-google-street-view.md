# OPEN\_GOOGLE\_STREET\_VIEW
<!-- id: abrir-google-street-view -->
<!-- origen: 50e68eecb8d70c6cdc2fafe5eb0701910252f7b7 -->

Specify a point and open a Google Street View window at its coordinates.

## Parameters

Does not accept parameters.

## Notes

The command transforms the point's X and Y coordinates from the drawing file coordinate reference system to WGS84 (EPSG:4326) and opens Google Street View in the default browser. If multiple transformations are possible, it displays a dialog box for selecting one.
