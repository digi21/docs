# EXHAUSTIVE\_AUTOSMODE
<!-- id: automodob-exhaustivo -->
<!-- origen: 22b7176f3c7d56bceb27253fb7780cebed8683e9 -->

Enable or disable exhaustive search mode, which prevents snapping to an entity whose code is not specified in the search table.

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Exhaustive search mode | Without a parameter, the Boolean variable toggles between Enabled and Disabled.<br>**0**: Disable it.<br>**1**: Enable it.<br>**?**: Display a balloon showing whether it is enabled or disabled. | Yes |
