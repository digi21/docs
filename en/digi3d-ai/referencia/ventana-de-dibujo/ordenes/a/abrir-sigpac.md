# OPEN\_SIGPAC
<!-- id: abrir-sigpac -->
<!-- origen: 2f2232db974f4363491a49a6ceb7cb0e444628bb -->

Specify a point and open the SIGPAC viewer at its coordinates.

## Parameters

Does not accept parameters.

## Notes

The command transforms the point's X and Y coordinates from the drawing file coordinate reference system to WGS84 (EPSG:4326) and opens the SIGPAC viewer in the default browser. If multiple transformations are possible, it displays a dialog box for selecting one.
