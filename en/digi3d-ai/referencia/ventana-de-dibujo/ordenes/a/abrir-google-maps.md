# OPEN\_GOOGLE\_MAPS
<!-- id: abrir-google-maps -->
<!-- origen: e2646e355758b515202fce1e231bc3e7c983acc8 -->

Specify a point and open a Google Maps window centered on its coordinates.

## Parameters

Does not accept parameters.

## Notes

The command transforms the point's X and Y coordinates from the drawing file coordinate reference system to WGS84 (EPSG:4326) and opens Google Maps in the default browser at zoom level 20. If multiple transformations are possible, it displays a dialog box for selecting one.
