# HELP
<!-- id: ayuda -->
<!-- origen: 2dee3eec566debce6f01f6158c053716a280fd10 -->

Open Digi3D.AI help.

## Parameters

Does not accept parameters.

## Notes

HELP opens the active command's help page in the default browser. If no command is active, or the active command has no help page, open the Digi3D.AI help home page (`https://www.digi21.net/en/Ayuda/digi3d-ai`). HELP does not interrupt the active command.

### Run with F1

If the key file assigns no command to _F1_, pressing it in the drawing window runs this command. Assigning HELP to _F1_ with [KEY](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/t/tecla.md) has the same effect. If other commands are assigned to _F1_, run those instead of HELP.

In the photogrammetric window, _F1_ without an assignment, or assigned only HELP, opens the help home page: commands in that window have no help pages. In dialog boxes, _F1_ does not run this command: it opens the dialog box page or, if none exists, the current command's page.
