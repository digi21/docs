# ASSIGN\_ATTRIBUTE
<!-- id: asigna-atributo -->
<!-- origen: 9b586c2895ee96969b16f63f3cdb564775ca3054 -->

Assign a value to an attribute in the active attribute list in the database dockable pane.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | Code | No |
| 2 | Field name | No |
| 3 | Value | No |
| 4 |Is the field visible? (0 or 1<br>default: 1)| Yes |
