# OPEN\_OPEN\_STREET\_MAP
<!-- id: abrir-open-street-map -->
<!-- origen: 64dd53832a4574c9409a5cb3f1a82b1637e7c56f -->

Specify a point and open an Open Street Map window at its coordinates.

## Parameters

Does not accept parameters.

## Notes

The command transforms the point's X and Y coordinates from the drawing file coordinate reference system to WGS84 (EPSG:4326) and opens Open Street Map in the default browser at zoom level 19. If multiple transformations are possible, it displays a dialog box for selecting one.
