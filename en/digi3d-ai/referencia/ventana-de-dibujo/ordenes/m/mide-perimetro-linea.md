# MEASURE\_LINE\_PERIMETER
<!-- id: mide-perimetro-linea -->
<!-- origen: 303878cf4e7d6e436ec64266b6d6e0ce6002ce66 -->

Measure the perimeter of the selected line \(in plan view\).

## Parameters

Does not accept parameters.

## Notes

Only lines are accepted; selecting another entity type causes an error tone. The command displays the perimeter in a balloon. If you run MEASURE\_LINE\_PERIMETER while another command is waiting for a distance, MEASURE\_LINE\_PERIMETER passes the perimeter to that command instead of displaying it in a balloon.
