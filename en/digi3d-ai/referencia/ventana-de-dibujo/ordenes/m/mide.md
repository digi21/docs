# MEASURE
<!-- id: mide -->
<!-- origen: 8db368215d6678848b1f240afe67a50e975e4ea8 -->

Calculate and display the distance between two points.

## Parameters

Does not accept parameters.

## Notes

Select points with the mouse or enter their coordinates with [XY](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/x/xy.md).

After selecting the first point, as you move the cursor, the command displays the plan distance, X, Y, and Z coordinate increments (DX, DY, and DZ), 3D distance, azimuth, and trigonometric angle in the status bar \(azimuth and trigonometric angle are in degrees\). When you select the second point, it displays these values in a balloon.

If you run MEASURE while another command is waiting for a distance, that command receives the plan distance.
