# MENU
<!-- id: menu -->
<!-- origen: 6b2911a489a97f085a95ae7c5db7cd301ddaced2 -->

Display a Digi3D user menu by its number.

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Menu number | Integer starting at 0. If no menu number is specified, or no menu has the specified number, the command displays the last menu shown | Yes |

## Notes

The command displays the menu as a context menu with 25 options. If no user menus are loaded, it displays an error message.
