# MEASURE\_LINE\_XYZ\_PERIMETER
<!-- id: mide-perimetro-linea-xyz -->
<!-- origen: 8d9ead2c782f904dbe7ad7212cbd18167992ee58 -->

Measure the perimeter of the selected line \(in 3D space, including Z\).

## Parameters

Does not accept parameters.

## Notes

Only lines are accepted; selecting another entity type causes an error tone. The command displays the perimeter in a balloon. If you run MEASURE\_LINE\_XYZ\_PERIMETER while another command is waiting for a distance, MEASURE\_LINE\_XYZ\_PERIMETER passes the perimeter to that command instead of displaying it in a balloon.
