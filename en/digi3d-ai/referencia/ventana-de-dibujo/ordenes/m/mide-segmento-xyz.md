# MEASURE\_SEGMENT\_XYZ
<!-- id: mide-segmento-xyz -->
<!-- origen: 1055c57bbdf57a1a0783db3ddbf7692312f76044 -->

Measure the selected segment of the selected line \(in 3D space, including Z\).

## Parameters

Does not accept parameters.

## Notes

Only lines are accepted; selecting another entity type causes an error tone. The command displays the length in a balloon. If you run MEASURE\_SEGMENT\_XYZ while another command is waiting for a distance, MEASURE\_SEGMENT\_XYZ passes the length to that command instead of displaying it in a balloon.
