# DTM\_MOVES\_DIGI3D
<!-- id: mdt-mueve-digi3d -->
<!-- origen: 0c8824723ab6057265d54450f4b8e50ca6a2a51d -->

Set whether loaded digital terrain models change the Digi3D Z coordinate.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | 0 disables the option and 1 enables it (? queries the value). Without a parameter, the command toggles the option between enabled and disabled | Yes |
