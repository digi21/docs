# MEASURE\_SEGMENT
<!-- id: mide-segmento -->
<!-- origen: 455400e14388f30cc51c718745fda4b6cb666a9b -->

Measure the selected segment of the selected line \(in plan view\).

## Parameters

Does not accept parameters.

## Notes

Only lines are accepted; selecting another entity type causes an error tone. The command displays the length in a balloon. If you run MEASURE\_SEGMENT while another command is waiting for a distance, MEASURE\_SEGMENT passes the length to that command instead of displaying it in a balloon.
