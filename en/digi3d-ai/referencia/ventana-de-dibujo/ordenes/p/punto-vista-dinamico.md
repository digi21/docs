# DYNAMIC\_VIEWPOINT
<!-- id: punto-vista-dinamico -->
<!-- origen: a653a4c944c21869f1f068cc86d7e2bc62e5fe26 -->

Rotate the orthographic window viewpoint dynamically using a rotation sphere.

## Parameters

Does not accept parameters.

## Notes

The command draws a circle in the window. Press and hold the data button, then move the cursor: the model rotates according to the cursor movement relative to the circle center. Release the button to repeat the rotation from another point. Press Esc to finish the command.
