# PROGRAM
<!-- id: programa -->
<!-- origen: ee9000c8f04c1aa28e9ea21eb8897e2fbbcf50bf -->

Run an external application or open a file with its associated application.

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Path of the application or file to open | — | No |

## Notes

If the path contains spaces, enclose it in double quotation marks. The command does not pass arguments to the application: it only uses the first parameter.
