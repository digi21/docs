# VIEWPOINT
<!-- id: punto-vista -->
<!-- origen: e7552e5e15c86edfd12a4e6bce1206583fa77b45 -->

Set the orthographic window viewpoint to one of the predefined views.

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Viewpoint number | 1 = Upper<br>2 = Lower<br>3 = Left<br>4 = Right<br>5 = Front<br>6 = Rear<br>7 = SW Isometric<br>8 = SE Isometric<br>9 = NE Isometric<br>10 = NW Isometric | Yes |

## Notes

If you omit the parameter or its value is outside the range 1 to 10, the command prompts for two points: the camera position first, then the point the camera looks at.
