# POINT
<!-- id: punto -->
<!-- origen: 23774e86b5ab06a42afbc256411ba7d249dedb2e -->

Draw a point in the current file.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 … N | Point code or codes. If omitted, the point is stored with the active code | Yes |

## Notes

Press the mouse [data button](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#mouse-button-numbers) to draw the point at the cursor coordinates. The point's rotation is the [active angle](/digi3d-ai/referencia/ventana-de-dibujo/variables/a/aa.md).
