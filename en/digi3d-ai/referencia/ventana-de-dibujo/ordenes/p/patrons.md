# SPATTERN
<!-- id: patrons -->
<!-- origen: 900310dbb2ce98941fe641940bcf2198b153caf8 -->

Enable or disable line pattern display in the stereoscopic view.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | 0 disables display and 1 enables it (? queries the state). Without a parameter, the command toggles the current state | Yes |
