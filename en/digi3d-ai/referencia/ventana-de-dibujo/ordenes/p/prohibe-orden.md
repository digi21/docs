# PROHIBIT\_COMMAND
<!-- id: prohibe-orden -->
<!-- origen: db8f70e2407d9bddef54fd2491fc2c4a7d315527 -->

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | Command or commands to prohibit (one or more) | No |
