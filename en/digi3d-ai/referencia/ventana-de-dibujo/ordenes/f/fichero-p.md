# P\_FILE
<!-- id: fichero-p -->
<!-- origen: fc081bb461494c1d25ffec6a201521e2d2b884f9 -->

Set or change the point file used by DigiNG without leaving the work session and returning to the application start screen.

## Parameters

Does not accept parameters.

## Notes

The command displays a dialog box for selecting the point file. If you cancel the dialog box, the point file does not change.
