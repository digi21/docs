# ENTER\_SPHERE
<!-- id: entrar-en-esfera -->
<!-- origen: 04a43b921ffaf566065eb5b9d15f9b96dbe8c79e -->

Enter a sphere by selecting a point on the screen.

## Parameters

Does not accept parameters.

## Notes

The command requires a loaded spherical image file; otherwise, it displays a warning and finishes. Digitize a point inside a sphere to enter it. If the point is not inside any sphere, the command plays an error sound and continues waiting for a point.
