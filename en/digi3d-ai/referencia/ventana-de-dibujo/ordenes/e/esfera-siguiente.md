# NEXT\_SPHERE
<!-- id: esfera-siguiente -->
<!-- origen: 06e7fb6d03d083da625ca499b15e496370370147 -->

Enter the next sphere.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | Number of spheres to move forward. Defaults to 1 if omitted | Yes |

## Notes

The command requires a loaded spherical image file and a selected sphere. It selects the sphere whose index is the current sphere index plus the parameter; if the result is out of range, it selects the first or last sphere.
