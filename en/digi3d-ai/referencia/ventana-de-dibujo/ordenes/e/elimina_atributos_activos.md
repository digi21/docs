# DELETE\_ACTIVE\_ATTRIBUTES
<!-- id: elimina-atributos-activos -->
<!-- origen: 47be5c97cd960b5de2aaa591f9d4c7d7e575c8c9 -->

Remove all attributes from the [Active attributes](../../../paneles/atributos-activos.md) pane.

## Parameters

Does not accept parameters.

## Notes

The command empties the active attribute list and ends. It does not modify entities already stored in the drawing file.
