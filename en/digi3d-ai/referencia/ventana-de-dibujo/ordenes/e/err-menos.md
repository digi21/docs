# ERR-
<!-- id: err-menos -->
<!-- origen: 41d3e1960493d3b7459989a0b1818576c52b080b -->

Display and center the view on the previous error in the drawing file generated with [BINTRAM](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/b/bintram.md), if that file is loaded as a reference for the working file.

## Parameters

Does not accept parameters.

## Notes

_BINTRAM_ and _BINTOP_ generate a .bin file with symbols at detected error positions. Load it as a reference for the working file.
