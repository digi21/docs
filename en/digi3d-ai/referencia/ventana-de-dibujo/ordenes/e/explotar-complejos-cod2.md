# EXPLOIT\_COMPLEXES\_COD2
<!-- id: explotar-complejos-cod2 -->
<!-- origen: 4e7e0357a771142333427cb368268603226b3966 -->

Break down complex entities bearing the specified codes and replace their constituent entities' codes with the complex entity's codes.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 … N | Code or codes of complex entities to explode | Yes |

## Notes

Assign the complex element's codes to the exploded entities.

Without parameters, display a dialog box for selecting codes. Explode complex entities in the active drawing file that are visible, within the area of interest, and bear any specified code.
