# ERR+
<!-- id: err-mas -->
<!-- origen: d6b3170a8fbf5a595446d7e0e5dba4b966f58507 -->

Display and center the view on the next error in the drawing file generated with [BINTRAM](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/b/bintram.md), if that file is loaded as a reference for the working file.

## Parameters

Does not accept parameters.

## Notes

_BINTRAM_ and _BINTOP_ generate a .bin file with symbols at detected error positions. Load it as a reference for the working file.
