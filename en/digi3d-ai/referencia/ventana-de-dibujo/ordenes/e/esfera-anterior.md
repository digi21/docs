# PREVIOUS\_SPHERE
<!-- id: esfera-anterior -->
<!-- origen: 7a9ab93090fd71c98a083ef954896d091b408464 -->

Enter the previous sphere.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | Number of spheres to move back. Defaults to 1 if omitted | Yes |

## Notes

The command requires a loaded spherical image file and a selected sphere. It selects the sphere whose index is the current sphere index minus the parameter; if the result is out of range, it selects the first or last sphere.
