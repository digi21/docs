# L
<!-- id: u-2 -->
<!-- origen: c3b50ca75bd49516b1bdf3d9224aed311b999a88 -->

Delete the last vertex of the entity being recorded when you run the command.

## Parameters

Does not accept parameters.

## Notes

L deletes a vertex if the entity has at least one vertex and has not been finished, while a drawing command that supports deleting vertices, such as [LINE](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/l/linea.md), is active. If no command is active, L plays an error sound.
