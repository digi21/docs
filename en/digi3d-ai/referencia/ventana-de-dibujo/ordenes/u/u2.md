# U2
<!-- id: u2 -->
<!-- origen: 7af820548ae744d256a5e2f59aa062e2200cdafb -->

Delete the last drawn segment of a linear entity without moving the cursor.

## Parameters

Does not accept parameters.

## Notes

Run this command before finishing the linear entity you are digitizing.
