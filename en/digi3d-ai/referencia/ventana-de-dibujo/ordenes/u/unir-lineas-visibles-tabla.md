# JOIN\_VISIBLE\_LINE\_TABLE
<!-- id: unir-lineas-visibles-tabla -->
<!-- origen: 15d9584a0e66e83c3c780b913de1d87ee4888972 -->

Join visible lines with the same code and geometric continuity, provided no more than two entities with that code meet at the node.

## Parameters

Does not accept parameters.

If Digi3D.AI rejects any new line, no lines are joined and all originals are preserved.
