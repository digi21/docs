# JOIN\_VISIBLE\_LINES
<!-- id: unir-lineas-visibles -->
<!-- origen: 35ef81036a6c80dc6591a0628d41b3f5ee9acaf6 -->

Join visible lines that have the same code and geometric continuity.

## Parameters

Does not accept parameters.

If Digi3D.AI rejects any new line, no lines are joined and all originals are preserved.
