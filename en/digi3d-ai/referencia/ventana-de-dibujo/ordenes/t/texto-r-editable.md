# EDITABLE\_TEXT\_R
<!-- id: texto-r-editable -->
<!-- origen: 1f28228896c8bead3ed8559a605bd48c836e0858 -->

Works like [TEXT\_R](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/t/texto-r.md), but does not hide the edit control when you supply parameters.

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Text proposed in the message bar. Everything after the command name forms the text, including spaces | Text | Yes |
