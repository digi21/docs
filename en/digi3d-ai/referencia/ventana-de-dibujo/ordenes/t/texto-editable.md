# EDITABLE\_TEXT
<!-- id: texto-editable -->
<!-- origen: 1ad988a220dd8b08ad6050779dd0eb61460da9fe -->

Works like [TEXT](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/t/texto.md), but does not hide the edit control when you supply parameters.

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Text proposed in the message bar. Everything after the command name forms the text, including spaces | Text | Yes |
