# Topology
<!-- id: topologia -->
<!-- origen: 6728dac9791a10563c19c9676556336db56323e3 -->

The Topology menu provides operations on [topologies](/digi3d-ai/referencia/editor-de-tablas-de-codigos/pestanas/topologias/) configured in the active code table.

## Groups

The menu has three groups:

### Creating, viewing, and unloading topologies

* **Create topologies**: create topologies from existing entities. This dynamic menu lists the topologies defined by the active code table \(provided the drawing file contains entities with codes belonging to the topology\).
* **View**: show or hide topologies made with **Create topologies**.
* **Unload topologies**: unload topologies made with **Create topologies**.

### Topology centroid tools

* **Search for centroid**: center the drawing window on the centroid of the selected topological polygon.
* **Create centroids automatically...**: create centroids for polygons without one in the selected topology.

### Converting topologies to polygons

* **Transform into polygon**: create a drawing file polygon for each topological polygon in the selected topology.
* **Export polygons to file**: create a file containing the topological polygons of the selected topology.
