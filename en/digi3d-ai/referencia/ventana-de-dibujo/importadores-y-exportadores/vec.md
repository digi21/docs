# Latino VEC files
<!-- id: vec -->
<!-- origen: 39f1d6ec596d17a25e71d55466b9d5bfb0309662 -->

Importer and exporter for **Latino VEC files**.

## Parameters

This extension accepts no command line parameters.

## Import/export engine parameters

This format adds no properties to the **Import/export engine** category in dialogs that import or export files in this format.

### Coordinate reference system

The format does not save the reference system, and Digi3D.AI does not request it: the file takes the photogrammetric window system, if one is open, or the drawing window system.

### Configuration options

The Configuration dialog has more options for this format in [Importer/Exporter of Latino's VEC file format](../../cuadros-de-dialogo/configuracion/importador-exportador-de-formato-vec-de-latino/README.md).

## Importer/exporter characteristics

| | |
| :--- | :--- |
| Extensions | `.vec` |
| Import ([IMPORT](../ordenes/i/importar.md) command) | Yes |
| Export ([EXPORT](../ordenes/e/exportar.md) command) | Yes |
| A drawing window can be opened with this format | No |
