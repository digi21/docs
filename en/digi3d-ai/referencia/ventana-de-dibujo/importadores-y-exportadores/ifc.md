# IFC files
<!-- id: ifc -->
<!-- origen: ff9fd224061d66b0cc06488091c627c0c4bf0576 -->

Importer and exporter for **IFC files**.

## Parameters

This extension accepts no command-line parameters.

## Import/export engine parameters

This format adds no properties to **Import/export engine** in dialogs that import or export it.

## Importer/exporter characteristics

| | |
| :--- | :--- |
| Extensions | `.ifc` |
| Import ([IMPORT](../ordenes/i/importar.md) command) | Yes |
| Export ([EXPORT](../ordenes/e/exportar.md) command) | Yes |
| Can open a drawing window with this format | No |
