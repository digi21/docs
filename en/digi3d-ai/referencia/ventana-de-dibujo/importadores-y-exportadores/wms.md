Importer for **WMS (Web Map Service)**.

## Parameters

This extension accepts no command-line parameters.

## See also

* [Connecting to a WMS server](/digi3d-ai/procedimientos/conectar-servidor-wms.md): create the connection file, load it, and choose layers.

| | |
| :--- | :--- |
| Extensions | `.wmsconnection` |
| Import ([IMPORT](../ordenes/i/importar.md) command) | Yes |
| Export ([EXPORT](../ordenes/e/exportar.md) command) | No |
| Can open a drawing window with this format | Yes |
