# GOTO\_SNAP
<!-- id: ir-tentativo -->
<!-- origen: 056e817faa3e1669f14999a417d9bc93fdcf7b85 -->

Set whether the stereoplotter moves to the snapped coordinates when snapping \(attaching the cursor\) to an entity.

## Parameters

See [Boolean variable parameters](/digi3d-ai/referencia/ordenes/variables/variables-booleanas.md).

## Notes

When this variable is enabled, snapping to an entity automatically moves the stereoplotter to the snapped position. When disabled, snapping calculates the coordinates, but the stereoplotter does not move to them.

This variable is enabled by default.
