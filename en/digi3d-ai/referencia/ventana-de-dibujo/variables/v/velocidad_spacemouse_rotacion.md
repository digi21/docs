# SPACEMOUSE\_SPEED\_ROTATION
<!-- id: velocidad-spacemouse-rotacion -->
<!-- origen: 53e31b6a2c33a81f112f1a11a85513596dcbb983 -->

Set the _SpaceMouse_ rotation speed factor in the drawing window.

## Parameters

Run this command with or without parameters.

### With parameters

| Parameter number | Description | Values | Optional |
| --- | --- | --- | --- |
| 1 | Speed to assign | Real number | Yes |

### Without parameters

Without parameters, the status bar displays a text box for entering the value. The command accepts only a typed value: digitizing a point plays an error sound and continues waiting for the value.

The factor is 0.001 when Digi3D.AI starts.

## Examples

Run the following command to set the rotation speed factor to 0.001:

```
SPACEMOUSE_SPEED_ROTATION=0.001
```
