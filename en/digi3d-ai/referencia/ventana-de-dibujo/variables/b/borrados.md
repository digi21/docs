# DELETED
<!-- id: borrados -->
<!-- origen: 67ce13dfe38f860a2ad4c3b2378610b65f5a8447 -->

Enable or disable display of entities deleted since the last file compression.

## Parameters

See [Boolean variable parameters](../../../ordenes/variables/variables-booleanas.md).

## Notes

DELETED displays deleted entities without restoring them. Run [RECOVER](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/r/recupera.md) to restore deleted entities.
