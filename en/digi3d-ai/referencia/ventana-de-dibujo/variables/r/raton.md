# RATON
<!-- id: raton -->
<!-- origen: 0206fa13e6303ebfa2a5b6121b80daf48c504593 -->

Set the mouse as the application input device.

## Parameters

Does not accept parameters.

## Notes

Run RATON to use the computer mouse as the input device when operating Digi3D with handwheels and foot pedals.
