# C
<!-- id: c-3 -->
<!-- origen: d267f70bf17a3fee8717c494d72f6a0c451d485a -->

Set whether _Digi3D.AI_ automatically closes the line you are digitizing when you finish it.

## Parameters

See [Boolean variable parameters](../../../ordenes/variables/variables-booleanas.md).

## Notes

Finish a line with the right mouse button or the handwheels _Reset_ pedal, which runs [FIN\_ENT](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/f/fin-ent.md).

If the Boolean variable **C** is enabled, finishing the line with the _Reset_ button or _FIN\_ENT_ automatically closes it as if _CLOSE\_ENT_ had been run.
