# Numeric variables
<!-- origen: ec5d16cdca0a654e446046cd68b9272f0d9f80a9 -->

These variables can store an integer \(a number without decimal places\).

### Parameters

These commands accept the value to assign as a parameter. If the parameter is **?**, they display the current value in a balloon.

When run without parameters, most of these commands display a dialog box for entering the value. See the page for each variable.

### Examples

The numeric variable command [NDEC](n/ndec.md) sets the number of decimal places displayed by the application in the coordinates toolbar and elsewhere.

Run the command to display two decimal places:

```text
NDEC=2
```
