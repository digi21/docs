# FIXXY
<!-- id: fijaxy -->
<!-- origen: 96adfacd71bbda954ff7f111341970fd6ecd00c8 -->

Enable or disable the option that restricts changes in planimetric coordinates to multiples of the contour interval.

## Parameters

See [Boolean variable parameters](../../../ordenes/variables/variables-booleanas.md).

## Examples

Run the following commands to move the cursor in the drawing window in increments of 100 drawing units along the X and Y axes:

```text
EQUIDISTANCE=100
FIXXY=1
```
