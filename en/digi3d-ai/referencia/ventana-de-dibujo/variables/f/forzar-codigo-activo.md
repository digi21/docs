# FORCE\_ACTIVE\_CODE
<!-- id: forzar-codigo-activo -->
<!-- origen: 40f04eb3dd9d8103b4de5587788fcf10e1fb91ee -->

If FORCE_ACTIVE_CODE is enabled, during both stereoplotting and editing, all entities generated by any command, such as [COPY](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/c/copiar.md), are stored with the _active codes_ in effect when each command runs.

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Value specifying whether to force the active code |If no parameter is specified, the Boolean variable toggles from *Enabled* to *Disabled* or from *Disabled* to *Enabled*.<br>**0**: Disable the Boolean variable.<br>**1**: Enable the Boolean variable.<br>**?**: Display the value of the Boolean variable in a balloon showing whether it is enabled or disabled.| Yes |

## Notes

Set the _active code_ before running the command.

Disabled by default.
