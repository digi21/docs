# FORCE\_ACTIVE\_JT
<!-- id: forzar-jt-activa -->
<!-- origen: b058437ead085bf4d18e49aa5a31c2a25436f0e5 -->

If FORCE_ACTIVE_JT is enabled, both during stereoplotting and editing, all text created by any command, such as [COPY](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/c/copiar.md), is stored with the active text justification set when that command runs.

## Parameters


| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Whether to enforce the active text justification |If no parameter is specified, the Boolean variable toggles from *Enabled* to *Disabled* or from *Disabled* to *Enabled*.<br>**0**: Disable the Boolean variable.<br>**1**: Enable the Boolean variable.<br>**?**: Display the value of the Boolean variable in a balloon showing whether it is enabled or disabled.| Yes |


## Notes

Before running the command, set the active text justification.

Disabled by default.
