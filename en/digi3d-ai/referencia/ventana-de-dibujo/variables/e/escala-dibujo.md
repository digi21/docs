# SCALE\_DRAWING
<!-- id: escala-dibujo -->
<!-- origen: 762befb6824c92767377ef4820cb9639983d1657 -->

Set the scale used to display the pattern on the screen.

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Numeric value | Real number | Yes |

### Examples

`SCALE_DRAWING=1000`

Set the drawing scale to 1000.

`SCALE_DRAWING=?`

Display the current drawing scale.
