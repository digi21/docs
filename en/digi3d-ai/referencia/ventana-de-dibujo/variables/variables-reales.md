# Real variables
<!-- origen: d7ea58e342eca7bcdc76aa6ba60292956ca0223e -->

These variables store real numbers \(with decimal places\).

### Parameters

These commands take the value to assign as a parameter. If the parameter is **?**, they show the current value in a balloon.

When run without parameters, most of these commands show a text box in the status bar where you can enter a value. See each variable's page.

### Examples

The real variable command [TH](a/at.md) sets the height of text to be drawn with the [TEXT](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/t/texto.md) command.

Run the following command to set a height of 1.25 drawing working length units:

```text
TH=1.25
```
