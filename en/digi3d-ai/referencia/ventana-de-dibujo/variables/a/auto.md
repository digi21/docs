# AUTO
<!-- id: auto -->
<!-- origen: f34e807605980a92bdc60724df5cd17363a7c95e -->

Enable or disable automatic centering of the drawing window when the photogrammetric window is the input device.

When AUTO is enabled, moving the cursor beyond the drawing window boundaries continuously recenters the drawing window to keep the cursor visible.

Use [AUTO_MOUSE](auto-raton.md) when the mouse is the input device.
