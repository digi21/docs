# AUTO_MOUSE
<!-- id: auto-raton -->
<!-- origen: 81ce4c36638be7982b88f8a7307a9b6b4a7f8894 -->

Enable or disable automatic centering of the drawing window when the mouse is the input device.

## Parameters

See [Boolean variable parameters](../../../ordenes/variables/variables-booleanas.md).

## Notes

If enabled, Digi3D.AI captures the mouse and prevents you from using it outside the drawing window.

While AUTO_MOUSE is enabled, the drawing window follows the cursor as you move it through the drawing with the system mouse. The cursor cannot leave the drawing window. Disable AUTO_MOUSE to release the mouse.
