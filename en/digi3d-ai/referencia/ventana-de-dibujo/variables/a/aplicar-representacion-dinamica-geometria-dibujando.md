# APPLY\_DYNAMIC\_REPRESENTATION\_DRAWING\_GEOMETRY
<!-- id: aplicar-representacion-dinamica-geometria-dibujando -->
<!-- origen: d40508a02f9f4086c14764063f6791fbc59287e3 -->

If enabled, dynamic representations are applied to the geometry being drawn.

## Parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Whether to apply dynamic representations to the geometry being drawn |If no parameter is specified, the Boolean variable toggles from *Enabled* to *Disabled* or from *Disabled* to *Enabled*.<br>**0**: Disable the Boolean variable.<br>**1**: Enable the Boolean variable.<br>**?**: Display the value of the Boolean variable in a balloon showing whether it is enabled or disabled.| Yes |

## Notes

Disabled by default.
