# AUTOMATIC
<!-- id: automatico -->
<!-- origen: 7c7662b9c4140287f9f1db299f8bf14e14808caa -->

Set whether _Digi3D.AI_ automatically runs a command when you digitize a point in ready mode (when no command is running).

## Parameters

See [Boolean variable parameters](../../../ordenes/variables/variables-booleanas.md).

## Notes

See [Running commands automatically](../../../ordenes/formas-de-ejecutar-una-orden/de-manera-automatica/) for instructions.

## Command characteristics

| Variable type                                 | [Boolean](../../../ordenes/variables/variables-booleanas.md) |
| ------------------------------------------------ | ------------------------------------------------------------- |
| Repeats automatically                           | No                                                            |
| Menu option           | Immediate/Flags/Automatic mode                 |
| Toolbar | Automatic commands                                           |
| Extension                                        | DigiNG.OrdenesStandard.dll                                    |
| Implementation | Native |
| Related variables                           | No related variables                               |
