# TH
<!-- id: at -->
<!-- origen: c7c961fb3078597bc932fcf245844fef4a6f51ea -->

Set the text height.

## Parameters

You can run this command with or without parameters.

### With parameters

| Parameter number | Description | Values | Optional |
| :--- | :--- | :--- | :--- |
| 1 | Numeric value | Real number, or **?** to display the current value in a balloon | Yes |

### Without parameters

If you run this command without parameters, it prompts you in the status bar to type the text height or digitize two points. If you digitize two points, it sets the text height to the distance between them.

## Notes

The default value is 1.5.

## Examples

Run the following command to set the text height to 10.5 drawing length units:

```text
TH=10.5
```
