# Left
<!-- id: left -->
<!-- origen: dbdb7a9c1068e75cdef79e826772d8ed60943dd2 -->

Returns the first _cantidad_ characters of the macro on which this function runs.

```csharp
 $(nombre_de_la_macro).Left(cantidad)
```

## Parameters

`cantidad`\
Number of characters to return.

## Returns

The first _cantidad_ characters generated by the macro.

## Example

For example, if `$(CodigoCentroide)` expands to 020400:

Use `$(CodigoCentroide).Left(3)` to obtain 020.
