# Right
<!-- id: right -->
<!-- origen: dbd15710c70df4082d8237b6f1e6d4ea2bd33642 -->

Returns the last _cantidad_ characters of the macro on which this function runs.

```csharp
 $(nombre_de_la_macro).Right(cantidad)
```

## Parameters

`cantidad`\
Number of characters to return.

## Returns

The last _cantidad_ characters generated by the macro.

## Example

For example, if `$(CodigoCentroide)` expands to 020400:

Use `$(CodigoCentroide).Right(3)` to obtain 400.
