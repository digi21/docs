# Menus

The code table editor menu bar contains:

* [File](archivo/README.md): create, open, and save code tables, and create packages.
* **Colors**: import and restore the palette. See the [Colors](../pestanas/colores.md) tab.
* [Symbols](simbolos/README.md): import MicroStation symbols.
* [Database](base-de-datos/README.md): import schemas and modify fields in all tables.
* **Macroinstructions**: import macroinstructions from a folder. See the [Macroinstructions](../pestanas/macroinstrucciones.md) tab.
* [Codes](codigos/README.md): import codes and modify multiple codes together.
* [Tools](herramientas/README.md): checks and configuration.
