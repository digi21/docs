# Codes

These options act on the [Codes](../../pestanas/codigos/README.md) list.

## Import

| Option | Action |
| :--- | :--- |
| **Import ASCII file codes [code] [description]...** | Adds one code per text line containing code and description. |
| **Import ASCII resources file codes exported with Erdas PRO600...** | Adds codes from PRO600 resources. |
| **Import MGCP characteristics catalog file codes...** | Adds MGCP feature catalog codes. |
| **Import .dgn file codes...** | Opens [Import .dgn file codes](importar-codigos-dgn.md). |
| **Import NGIX catalog...** | Opens [Import NGIX catalog](importar-catalogo-ngix.md). |
| **Import BINDXF codes...** | Adds BINDXF translation table codes. |
| **Import codes from ArcGIS workspace definition file...** | Adds ArcGIS workspace XML codes. After file selection, requests [ArcGIS version](../version-de-arcgis.md) and their style in [Select style](../../pestanas/selecciona-el-estilo.md). |
| **Import codes from a .CSV file[code][level][color][style][weight][cell][description]...** | Adds codes and DGN translation parameters from CSV. |
| **Complete import/export parameters** | Calculates missing code import/export parameters. |
| **Replace import/export parameters with automatically calculated parameters** | Replaces code import/export parameters with calculated ones. |
| **Delete duplicate codes** | Removes duplicates. |

## Tags

| Option | Action |
| :--- | :--- |
| **Add tag to multiple codes...** | Opens [Add tag to multiple codes](anadir-etiqueta-a-multiples-codigos.md). |
| **Add tag to multiple codes by table...** | Opens **Add tag to multiple codes by table**, entering codes one per line instead of selecting them in a list. |
| **Remove tags from multiple codes...** | Opens **Remove tags**, removing a tag from selected codes. |
| **Rename tags...** | Opens [Rename tags](renombrar-etiquetas.md). |

## Sort

**Sort by code** and **Sort by description** reorder codes alphabetically or numerically, ascending or descending.
