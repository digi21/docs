# Topological polygons
<!-- id: poligonos-topologicos -->
<!-- origen: efca11af41aa888b1b89238aade2acf97f7ef47b -->

A topological polygon is a relationship between lines which form a closed polygon when joined in a particular order.

> These are relationships between drawing file lines, rather than polygons stored in the file. For example, lines _A_, _B_ and _C_ form a topological polygon if joining them in that order closes a polygon.

Topological polygons normally require an internal [centroid](centroide.md).
