# Tabs
<!-- id: pestanas -->
<!-- origen: 78a16c1add8c48fe8deb2f63f8ca0ba35222c023 -->

The code table editor organizes the table into these tabs, in this order:

* [Colors](colores.md): 256-color palette and background color.
* [Database](base-de-datos/README.md): database tables and fields.
* [Styles](estilos.md): line and symbol styles.
* [Commands](ordenes.md): commands when opening the drawing window and selecting any code.
* [Macroinstructions](macroinstrucciones.md): named command lists.
* [Dynamic representations](representaciones-dinamicas.md): lists of dynamic representation rules.
* [Python environment](entorno-python.md): Python code in the table.
* [Expressions](selecciones.md): named selections defined by Python expressions.
* [Speech recognition](reconocimiento-de-voz.md): phrases for speech recognition.
* [Toolbox](cuadro-de-herramientas.md): Toolbox pane content.
* [Topologies](topologias/README.md): topologies and their centroids.
* [Codes](codigos/README.md): codes and their representations.
