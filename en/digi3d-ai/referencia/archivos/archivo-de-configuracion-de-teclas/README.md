# Key configuration file
<!-- id: archivo-de-configuracion-de-teclas -->
<!-- origen: 5081d2ca8d2a4837a13eeebfe95e5066746a4425 -->

The key configuration file is an .xml file storing command sequences run when a key is pressed. These files use the _.keyboard.xml_ extension.

The Digi3D.AI installer places the default `Teclas.keyboard.xml` in `C:\ProgramData\Digi3D.NET\Tablas`.

* Select a file to load in [Configuration of virtual keyboards](/digi3d-ai/referencia/cuadros-de-dialogo/configuracion-de-teclados-virtuales.md).
* Select the active key configuration file with [CHANGE\_KEYS\_MNU](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/c/cambia-teclas-mnu.md).
* Assign commands to the active key configuration file with [KEY](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/t/tecla.md).
