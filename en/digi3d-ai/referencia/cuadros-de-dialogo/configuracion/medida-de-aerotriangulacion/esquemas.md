# Schemas
<!-- id: esquemas -->
<!-- origen: b98a717fc666c03f8d4efed810c89d0ffd2a711e -->

Specifies the path of the aerial triangulation measurement schemes file (_.aerotrischeme.xml_).

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\Extensiones\Digi3D.ConicSensor\AerotriangulationMeasurement` |
| :--- | :--- |
| Value | `Esquema` |
| Type | `REG_SZ` |
| Default value | (empty) |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
