# RPCBA adjustment parameters
<!-- id: parametros-del-ajuste-rpcba -->
<!-- origen: 5d33326eb56a15f9b5d7467d8d9048f05dc52de4 -->

Configures the a priori accuracies for RPC coefficient block adjustment \(RPCBA\) for the [RPC Satellite](/digi3d-ai/referencia/ventana-fotogrametrica/sensores/rpc/README.md) sensor. The adjustment is performed in the [RPC Block Adjustment](/digi3d-ai/referencia/ventana-fotogrametrica/sensores/rpc/ajuste-en-bloque-de-rpcs.md) pane.

This category only appears if the RPC Satellite sensor extension is installed.

Configure these options in the **[Configuration](../README.md)** dialog.
