# Width for the coordinates window
<!-- id: ancho-de-la-ventana-de-coordenadas -->
<!-- origen: f7a56df30137efc83efaf232f50ff205d3c639f7 -->

Specifies the width of the window displaying coordinates in the **Coordinates** and **Snap** toolbars.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration\BarrasHerramientas\BarraHerramientasTentativo` |
| :--- | :--- |
| Value | `TamanoControlCoordenadas` |
| Type | `REG_DWORD` |
| Default value | 200 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
