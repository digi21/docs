# Seconds to be shown by the selected entity
<!-- id: segundos-a-mostrar-la-entidad-seleccionada -->
<!-- origen: cf45183c5255299167bf0c7351fb71769ba87795 -->

Specifies how many seconds Digi3D.AI highlights the selected entity when you double-click it in the Search results pane.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\Configuration\FindResults` |
| :--- | :--- |
| Value | `SegundosMostrarEntidadSeleccionada` |
| Type | `REG_DWORD` |
| Default value | 2 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
