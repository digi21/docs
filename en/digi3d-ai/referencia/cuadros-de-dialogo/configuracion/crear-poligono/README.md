# CREATE\_POLYGON

Configures what the [CREATE\_POLYGON](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/c/crear-poligono.md) command does with the lines it uses to form the polygon.

Configure these options in the **[Configuration](../README.md)** dialog.
