# Reference files
<!-- id: archivos-de-referencia-2 -->
<!-- origen: 61a72ee9e29b61ad9396f76eb71dcb37c37e4cfc -->

Configures what Digi3D.AI saves in the [reference files file](../../../archivos/archivo-de-archivos-de-referencia.md) of each drawing file: the reference files and the path of the photogrammetric project or photogrammetric model file associated with the drawing file.

Configure these options in the **[Configuration](../README.md)** dialog.
