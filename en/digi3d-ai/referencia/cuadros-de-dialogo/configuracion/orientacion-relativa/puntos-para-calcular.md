# Points to calculate
<!-- id: puntos-para-calcular -->
<!-- origen: 2be8a5fb62099f236b6d1a70f1f46100f0462e8a -->

Specifies the number of points used to calculate relative orientation.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\Extensiones\Digi3D.ConicSensor\RelativeOrientation` |
| :--- | :--- |
| Value | `PuntosParaCalcularRelativa` |
| Type | `REG_DWORD` |
| Default value | 5 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
