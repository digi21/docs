# Zoom wheel animations
<!-- id: animaciones-zoom-rueda -->
<!-- origen: c252555f93b9d01207d231848673ce5025782bdb -->

Specifies the number of animations when zooming with the mouse wheel.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\DigiNG\Configuration` |
| :--- | :--- |
| Value | `AnimacionesZoom` |
| Type | `REG_DWORD` |
| Default value | 5. If the value does not exist, the **Configuration** dialog displays 0 and saves it when you click **Accept**. |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
