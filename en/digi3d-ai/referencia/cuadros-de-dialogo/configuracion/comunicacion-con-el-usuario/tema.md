# Theme
<!-- id: tema -->
<!-- origen: aa0b72f4155e106f0134efcc59b215884a5dc398 -->

Configures the program visual theme.

## Possible values

* **Light**. Digi3D.AI displays menus, panes, and dialogs with a light theme.
* **Dark**. Digi3D.AI displays menus, panes, and dialogs with a dark theme.
* **Blue**. Digi3D.AI displays menus, panes, and dialogs with a blue theme.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Value | `Tema` |
| Type | `REG_DWORD` |
| Default value | 1 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
