# Sampling time for acceleration
<!-- id: tiempo-de-muestreo-para-aceleracion -->
<!-- origen: bcda3b10491a532dc91b975a960388e47d4abd2a -->

Specifies the time, in milliseconds, used for acceleration calculations. During this interval, pulses generated by the handwheels are counted to decide whether to enable acceleration.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\IO` |
| :--- | :--- |
| Value | `TiempoMuestreoAceleracion` |
| Type | `REG_DWORD` |
| Default value | 100 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
