# Multiplication factor
<!-- id: factor-de-multiplicacion -->
<!-- origen: 4061b07c2a77a852dfe1d2c41dcecf597fdb7831 -->

Specifies the value by which the current movement speed is multiplied when the condition for triggering image acceleration is met.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\IO` |
| :--- | :--- |
| Value | `FactorVelocidadAceleracion` |
| Type | `REG_DWORD` |
| Default value | 5 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
