# Inpho
<!-- id: inpho-3 -->
<!-- origen: c2cebe143f11d804e8bed92b3002e7a2b55ae500 -->

Configures the Trimble Inpho camera, model, and project importer. Heads in a multicamera project are identified by the `$CAMERA_ID` of each photo, without configuration.

> **See also:** the extension [Inpho](../../../ventana-fotogrametrica/sensores/camara-conica/extensiones/inpho.md) for the Conical sensor.
