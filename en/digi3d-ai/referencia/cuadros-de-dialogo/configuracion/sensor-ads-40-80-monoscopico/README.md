# ADS (Monoscopic)
<!-- id: sensor-ads-40-80-monoscopico -->
<!-- origen: 4f3492b86c612388917832925e15ae0572acec1b -->

Configures exterior orientation calculation and point correlation for the [ADS](/digi3d-ai/referencia/ventana-fotogrametrica/sensores/ads.md) sensor.

This category only appears if the ADS sensor extension is installed.

Configure these options in the **[Configuration](../README.md)** dialog.
