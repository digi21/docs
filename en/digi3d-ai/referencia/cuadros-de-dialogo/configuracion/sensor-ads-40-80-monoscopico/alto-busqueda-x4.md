# Search height x4
<!-- id: alto-busqueda-x4 -->
<!-- origen: 9441c12ca21ba8b134be3b25d7af912df85b1f14 -->

Specifies the search window height when correlating a point at pyramid level x4.

The default value is 600.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\Extensiones\Digi3D.ADS40Sensor` |
| :--- | :--- |
| Value | `nAltoBusquedaCorrelarPuntox4` |
| Type | `REG_DWORD` |
| Default value | 600 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
