# Subpixel interpolation
<!-- id: interpolacion-de-subpixel -->
<!-- origen: 986cbc5b10f18ef66dae933f9807e653c7aa4cbe -->

Configures whether Digi3D.AI uses subpixel interpolation in calculations, when supported by the sensor. Calculations using subpixel interpolation are more precise and may require more processing time than those without it.

Configure these options in the **[Configuration](../README.md)** dialog.
