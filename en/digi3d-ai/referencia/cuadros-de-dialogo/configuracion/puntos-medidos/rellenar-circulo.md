# Fill circle
<!-- id: rellenar-circulo -->
<!-- origen: 30d1a7e30893dd8c23f88a156487471b48edd435 -->

Specifies whether the circle marking measured points is filled.

## Possible values

* **Yes**. The circle is filled.
* **No**. Only the circle outline is drawn.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Value | `CirculosPuntosRelleno` |
| Type | `REG_DWORD` |
| Default value | 1 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
