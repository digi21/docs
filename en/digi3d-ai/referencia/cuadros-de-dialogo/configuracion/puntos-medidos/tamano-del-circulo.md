# Size of circle
<!-- id: tamano-del-circulo -->
<!-- origen: 8e4b0ecf5f1420bde18116d9a2e20480bfd51876 -->

Specifies the size, in pixels, of the circle marking where a point was measured (during absolute orientation or aerial triangulation measurement).

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Value | `TamanoCirculosPuntosMedidosv2` |
| Type | `REG_DWORD` |
| Default value | 5 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
