# Relative directory
<!-- id: directorio-relativo-2 -->
<!-- origen: 144c0faec509f9133934736e0f4eea80a5837552 -->

Specifies the subdirectory where measured points will be stored.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Value | `DirectorioPuntosMedidos` |
| Type | `REG_SZ` |
| Default value | `Aerotriangulación` (the text depends on the Digi3D.AI language) |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
