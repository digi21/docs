# Control points
<!-- id: puntos-de-apoyo -->
<!-- origen: 7f8a43f2b93be82e2e48d2a226e9a7106bc6a167 -->

Specifies the color used to draw ground control point markers (measured during absolute orientation or aerial triangulation measurement).

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Value | `ColorPuntosApoyo2` |
| Type | `REG_SZ` |
| Default value | `#FFFFFF77` |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
