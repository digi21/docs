# Opacity for entities not in the zone of interest
<!-- id: opacidad-para-entidades-no-de-interes -->
<!-- origen: 50b6b27cb9758677f031b338911e6383e8edc819 -->

Specifies the opacity percentage (from 0 to 100) used to display geometries that are not of interest.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\DigiNG\Configuration` |
| :--- | :--- |
| Value | `PorcentajeOpacidadEntidadesNoDeInteres` |
| Type | `REG_DWORD` |
| Default value | 25 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
