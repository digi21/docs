# Macro directory
<!-- id: directorio-de-macroinstrucciones -->
<!-- origen: b3f9cde2869d6894f6bd89b1a9207cd652fa03e8 -->

Specify the directory containing macroinstruction files.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Value | `DirectorioTablas` |
| Type | `REG_SZ` |
| Default value | (empty) |

This is a per-user _Windows_ value: it is not in Digi3DNET.db, and SQL statements in [Advanced configuration](../../configuracion-avanzada.md) do not modify it.

</details>
