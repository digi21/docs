# Resource files
<!-- id: archivos-de-recursos -->
<!-- origen: c7b23112490233e0c63649b7d45a45cff51a6726 -->

Specifies the path of MicroStation resource files (_.rsc_) in which to find fonts, custom line styles, etc.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\DigiNG\IO\Digi21.Io.Dgn` |
| :--- | :--- |
| Value | `ArchivosRecursos` |
| Type | `REG_SZ` |
| Default value | (empty) |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
