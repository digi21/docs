# Number of recent files
<!-- id: numero-de-recientes -->
<!-- origen: 974294e11e331c11ff1d88a9aee4022bb9b2c324 -->

Specifies the number of files stored in the recent files list.

<details>
<summary>Where it is stored</summary>

| Registry | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\DigiNG\Configuration` |
| :--- | :--- |
| Value | `NumberOfFilesRecentList` |
| Type | `REG_DWORD` |
| Default value | 10 |

This is a per-user _Windows_ value: it is not in the Digi3DNET.db file, and SQL statements in the [Advanced configuration](../../configuracion-avanzada.md) dialog do not modify it.

</details>
