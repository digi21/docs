# RPC Satellite extensions
<!-- id: extensiones-2 -->
<!-- origen: b09c9a7ebf63798afb5ff85074d6b6a1f834caaf -->

The RPC Satellite sensor can read satellite image RPC coefficients from these file formats:

* [Ikonos](ikonos.md)
* [Inpho](inpho.md)
* [ISD](isd.md)
* [LPS](lps.md)
* [NITF](nitf.md)
* [Pléiades](pleiades.md)
* [SocetSet](socetset.md)
* [SummitEvolution](summitevolution.md)
* [Vingeo](vingeo.md)
