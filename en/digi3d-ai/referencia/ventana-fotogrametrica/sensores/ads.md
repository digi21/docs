# ADS
<!-- id: ads -->
<!-- origen: 4fd8e8296887644aba5e6916433020928a082c36 -->

The ADS sensor supports images from Leica ADS airborne pushbroom cameras.

## Sensor properties

* **Backward support files.**, **Nadir support files.**, and **Forward support files.**: `.sup` files for the three images.
* **Paths to replace**: path pairs used to replace paths read from support files. **...** opens [Replacers](../../cuadros-de-dialogo/sustituidores.md).
* **Working Coordinate Reference System**: model coordinate reference system.
