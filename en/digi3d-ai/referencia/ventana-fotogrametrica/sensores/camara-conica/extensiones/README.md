* [Access](access.md)
* [AeroOffice](aerooffice.md)
* [ContextCapture](contextcapture.md)
* [Digi3D](digi3d.md)
* [DVP](dvp.md)
* [EspaKernel](espakernel.md)
* [IMU](imu.md)
* [Inpho](inpho.md)
* [Intergraph](intergraph.md)

* [OpenCV](opencv.md)
* [PatB](patb.md)

* [Pix4D](pix4d.md)

* [Summit](summit.md)
* [Vexcel](vexcel.md)

## Format overview

For each orientation-reading extension, the table shows the file selected as **Aerial triangulation file**, whether it contains camera calibration and where the coordinate reference system comes from. “Dialog” means [Would you like to assign one?](../sistema-de-referencia-del-modelo.md#horizontal-coordinate-reference-system), shown when none of the listed sources provides a system. If the file does not contain the camera, specify a camera file in the model (see [Camera](../README.md#camera)).

| Format | Aerial triangulation file | Camera in file | Reference system |
| --- | --- | --- | --- |
| [Access](access.md) | `.mdb`, `.accdb` | No | Associated `.prj` → dialog |
| [AeroOffice](aerooffice.md) | `.exp` | No | Associated `.prj` → dialog |
| [ContextCapture](contextcapture.md) | `.xml` (*BlocksExchange*) | Yes | File's `SpatialReferenceSystems/SRS/Definition` |
| [Digi3D](digi3d.md) | None: reads `.rel.xml`, `.rel` or `.orientation.xml` from the work directory | No: `.cam` or `.orientation.xml` | Local system |
| [DVP](dvp.md) | None: reads each image's `.par` | Yes, in `.par` | Left image's `.prj` → dialog |
| [EspaKernel](espakernel.md) | `.els` | Yes | Associated `.prj` → dialog |
| [IMU](imu.md) | `.eo`, `.imu` | No | Associated `.prj` → file's `EPSG_CODE` → dialog |
| [Inpho](inpho.md) | Inpho project `.prj` | Yes | File's `$COORDINATE_SYSTEM` or `$DELIVERABLES_COORD_SYSTEM`; local system if unreadable |
| [Intergraph](intergraph.md) | `project` | Yes | `project.prj` → dialog |
| [LPS](lps.md) | `.blk` | Yes | Associated `.prj` → dialog |
| [PatB](patb.md) | `.ori` | No | Associated `.prj` → dialog |
| [PhotoScan](photoscan.md) | `.xml` | Yes | `<reference>` node → associated `.prj` → dialog |
| [Pix4D](pix4d.md) | `*_calibrated_external_camera_parameters.txt` | No: `*_pix4d_calibrated_internal_camera_parameters.cam` | Associated `.prj` → dialog |
| [Summit](summit.md) | `.smtxml` | Yes | Associated `.prj` → dialog |

The associated `.prj` is the `.prj` file with the same name and folder as the aerial triangulation file.

Only IMU, Inpho and PhotoScan display [Unknown vertical coordinate system](../sistema-de-referencia-del-modelo.md#vertical-coordinate-reference-system) when the system has no vertical component. Only PhotoScan provides absolute orientation.

These extensions provide only the camera:

| Format | File |
| --- | --- |
| [OpenCV](opencv.md) | `.cocv` |
| [RapidCal](rapidcal.md) | `.cal` |
| [Vexcel](vexcel.md) | The UltraCam TIFF image itself |

EspaKernel (`.esp`), Inpho (`.prj`), Intergraph (`project`), PhotoScan (`.xml`) and Summit (`.smtxml`) also open projects in [Photogrammetric project](../../../../paneles/proyecto-fotogrametrico.md).
