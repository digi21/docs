# SHOW\_STEREO
<!-- id: mostrar-stereo -->
<!-- origen: b59602a7f734c8a357721891aa9f828b1c57b42f -->

Chooses what the photogrammetric window displays: the raster image, the overlay, or both.

## Parameters

| Parameter | Description |
| :--- | :--- |
| No parameter | Cycles from displaying everything to the raster image only, then the overlay only, then everything again |
| 0 | Displays the overlay only |
| 1 | Displays the raster image only |
| 2 | Displays everything |

### Example:

`SHOW_STEREO=1`
