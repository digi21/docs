# STREAM\_MODE
<!-- id: modo-stream -->
<!-- origen: 9eba8e41983902946f97990f8eaa42197a45f537 -->

Enables or disables continuous digitizing (*stream mode*) in the photogrammetric window. When enabled, pressing the data button or pedal starts sending coordinates continuously until you press it again.

## Parameters

| Parameter number | Description | Optional |
| :--- | :--- | :--- |
| 1 | `0` disables stream mode; any other number enables it | Yes |

## Notes

With no parameters, toggles stream mode on or off.
