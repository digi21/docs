# SEE\_COORDINATES
<!-- id: ver-coordenadas -->
<!-- origen: 49d49e0d70ccf026826b14a483c23e201fdcaa39 -->

Displays coordinates in the photogrammetric window's message bar.

## Parameters

| Parameter | Command behavior |
| :--- | :--- |
| None | Cycles through no coordinates, pixel coordinates, fiducial coordinates, photo coordinates, model coordinates and ground coordinates |
| 0 | Displays no coordinates |
| 1 | Displays pixel coordinates |
| 2 | Displays photo coordinates |
| 3 | Displays model coordinates |
| 4 | Displays ground coordinates |
