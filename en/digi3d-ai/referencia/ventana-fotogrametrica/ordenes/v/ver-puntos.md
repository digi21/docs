# SEE\_MARKS
<!-- id: ver-puntos -->
<!-- origen: b955ef85621241f0e2c089d25255a7fc6f1c72ce -->

Chooses which measured points appear over each image in the photogrammetric window.

## Parameters

| Parameter | Command behavior |
| :--- | :--- |
| No parameter | Cycles through 0, 1, 2, then back to 0 |
| 0 | Hides measured points |
| 1 | Displays all measured points |
| 2 | Displays common points only: points with a mark bearing the same description in both images |

### Example:

`SEE_MARKS=2`
