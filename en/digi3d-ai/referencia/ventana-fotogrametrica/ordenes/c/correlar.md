# CORRELATE
<!-- id: correlar -->
<!-- origen: b2d37f27713136cfffe3cf04cf97d0825f1fdc41 -->

Adjusts the plotter's Z coordinate by finding the corresponding point for the point at the cursor center in the left image.

## Parameters

| Parameter | Description |
| :--- | :--- |
| 0 \(or no parameter\) | Adjusts Z while keeping the left image fixed |
| 1 | Adjusts Z while keeping the right image fixed |

## Notes

Running the command displays a balloon in the lower-right corner with the correlation factor and the points' parallax.
