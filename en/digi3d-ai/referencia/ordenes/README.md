# Commands
<!-- id: ordenes -->
<!-- origen: e7b0ed81494d5238320874e8d10a0c0870ae3bcb -->

Digi3D.AI implements all its functionality through commands.

Some commands run in the drawing window, others in the photogrammetric window. Photogrammetric window commands vary with the active sensor.

There are three command types:

* [Variables](/digi3d-ai/referencia/ventana-de-dibujo/variables/).
* [Non-interactive commands](/digi3d-ai/referencia/ordenes/ordenes-no-interactivas.md).
* [Interactive commands](/digi3d-ai/referencia/ordenes/ordenes-interactivas.md).

Learn how to run commands in [Ways to run a command](/digi3d-ai/referencia/ordenes/formas-de-ejecutar-una-orden/).
Learn how to end commands in [Ways to cancel a command](/digi3d-ai/referencia/ordenes/formas-de-cancelar-una-orden.md).

The Digi3D.AI command stack lets you interrupt the active command, run another, and resume the interrupted command when the second ends. See [Pushing and popping commands](/digi3d-ai/referencia/ordenes/apilar-y-desapilar-ordenes.md).
