# Real variables
<!-- id: variables-reales -->
<!-- origen: 250122fa454adf136419e03c360da3931713dc3a -->

These variables can store a real number \(a number with decimal places\).

## Parameters

Pass the value as a command parameter to assign a value to these variables.

## Examples

The real variable command [ TH](../../ventana-de-dibujo/variables/a/at.md) sets the height of text drawn with [TEXT](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/t/texto.md).

Run the following command to set a height of 1.25 drawing length units:

```text
TH=1.25
```
