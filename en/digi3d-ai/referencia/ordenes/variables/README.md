# Variables
<!-- id: variables -->
<!-- origen: ce8307ac7f7a85c722a7fe6527be8e1354c896b5 -->

Variables are commands that store values without performing any other action. Other commands use the stored values.

For example: [TEXT](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/t/texto.md).

Because variables are commands, run them through menu options, toolbar buttons, or the command line, as described in [Commands](/digi3d-ai/referencia/editor-de-tablas-de-codigos/pestanas/ordenes.md).

There are four variable types, depending on the information stored:

* [Boolean](variables-booleanas.md).
* [Numeric](variables-numericas.md).
* [Real](variables-reales.md).
* [Text](variables-de-tipo-texto.md).
