# Numeric variables
<!-- id: variables-numericas -->
<!-- origen: f9b61f821e14eb6ff982420d063290c169d123ba -->

These variables can store an integer \(a number without decimal places\).

## Parameters

Pass the value as a command parameter to assign a value to these variables.

## Examples

The numeric variable command [NDEC](../../ventana-de-dibujo/variables/n/ndec.md) sets the number of decimal places displayed by the application in the coordinates toolbar and elsewhere.

Run the command to display two decimal places:

```text
NDEC=2
```
