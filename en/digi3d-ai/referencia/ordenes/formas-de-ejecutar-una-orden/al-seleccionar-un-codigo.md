# When selecting a code
<!-- id: al-seleccionar-un-codigo -->
<!-- origen: 65c7018ca14c48ab4f570261838149765e2c1b2d -->

Changing the active code with [COD](../../ventana-de-dibujo/ordenes/c/cod.md), or selecting a code in any application window that supports code changes, such as the [Code toolbar](../../barras-de-herramientas/codigo.md), automatically runs:

* Commands in [Commands to execute when selecting any code](/digi3d-ai/referencia/editor-de-tablas-de-codigos/pestanas/ordenes.md) on the **Commands** tab of the [Code table editor](/digi3d-ai/referencia/editor-de-tablas-de-codigos/).
* Commands assigned to the selected code in [Command (selecting code)](/digi3d-ai/referencia/editor-de-tablas-de-codigos/pestanas/codigos/propiedades-del-codigo.md).
