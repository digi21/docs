## Explicitly by the user

* [Automatically when the application is ready](/digi3d-ai/referencia/ordenes/formas-de-ejecutar-una-orden/de-manera-automatica/).
* Select a menu option.
* Click a toolbar button.
* [From the command line](ejecutar-una-orden-desde-la-linea-de-comandos/).
* [In a macroinstruction](ejecutar-una-orden-desde-la-linea-de-comandos/macroinstrucciones.md).
* [By voice](../../ventana-de-dibujo/variables/r/reconocer-voz.md).
* Press a key assigned to the command.

## Implicitly by the application

* [When opening the drawing window](al-abrir-una-ventana-de-dibujo.md).
* [When selecting a code](/digi3d-ai/referencia/ordenes/formas-de-ejecutar-una-orden/al-seleccionar-un-codigo.md).
* Automatically repeat the last command.
