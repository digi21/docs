# Ways to cancel a command
<!-- id: formas-de-cancelar-una-orden -->
<!-- origen: 1773eea6568d14c379fbf4007a03497dea1aa9c6 -->

Cancel the running command in these ways:

* Press **Escape**.
* Press the **right mouse button** or the **Cancel** pedal \(if using handwheels\).
* Run [CANCEL\_COMMANDS](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/a/anula-ordenes.md).
