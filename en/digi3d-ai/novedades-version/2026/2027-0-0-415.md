## Fixes

* Systematic stability review: importers, exporters, sensors, commands, panels and background processes show the error instead of closing or hanging the program
* Fixed read and write errors in the BIN, BinDouble, ASCII, DGN, DWG, DXF, Shapefile, GeoPackage, FileGDB, PostGIS, Geomedia, GeoJSON, KML, VEC and IFC formats
* Fixed errors in sensors and photogrammetric project loaders, including Inpho, PhotoScan, Metashape, ContextCapture, Pix4D, RPC and ADS40
* Fixed results of editing, topology, digital elevation model, orthophoto and measurement commands
* Fixed memory leaks and hangs when loading images, tiles and point clouds, and when closing windows
* Fixed errors in the code table, the database, macros and input devices
* Fixed untranslated, unreadable or truncated texts in dialogs, menus and messages
* Fixed errors in Inpho, RapidCal, OpenCV, PhotoScan, Metashape and ContextCapture cameras, and in .cam files with a distortion table or with the polynomial in camera coordinates
* Inpho projects with analog cameras are loaded
* The Find button of the command editor opened with Enter is enabled again
* [Fixed the search modes on complexes, nested complexes, holes of polygons and multipoints; modes 2, 6, 10 and 19 to 22 snap to the endpoint or to the vertex of extreme Z closest to the cursor](https://www.digi21.net/Ayuda/p/modob)
* The snap message shows the name of the code of the geometry even if it is not in the code table
* DISPLACE\_ORIGIN, SPR, SPR\_PLANE and TRIM work on the hole when the snap falls on the first vertex or the first segment of the first hole of a polygon
* Fixed the selection of CREATE\_POLYGON after choosing the outer boundary, which treated as a polygon any geometry that was not a line
* Texts created with the angle, height or justification forced store the corners that match those values
* COPY\_R also rotates point complexes
* The GeoJSON exporter writes the rotation attribute of points in degrees
* The Geomedia exporter writes the orientation of texts with the correct angle
* When reading BIN files, the creation time of points no longer comes from their rotation
* The Rotation column of the results panel shows degrees for points, texts and point complexes
* The conic, RPC and orthophoto sensors draw rotated TrueType texts, and Digi font texts with a height other than 1, in their place and with their size
* The stereoscopic orthophoto reads the \#RRGGBBAA stereo color of codes
* Fixed drawing errors of TrueType texts in the drawing window and in the photogrammetric window
* The inter\_axis command with a closed line and the Z computation on a polygon no longer close the program with repeated or collinear vertices
* [ToString of .NET geometries writes real tabs and line breaks, and the one of lines writes their vertices](https://www.digi21.net/Ayuda/p/readonlyline)
