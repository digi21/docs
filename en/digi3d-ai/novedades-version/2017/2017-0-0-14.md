# Digi3D.AI 2017.0.0.14

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 1/28/2017.

## New features

* Added an option to the replace database dialog box to replace any value with a particular one.
* Updated dependency on the Glew component to its latest version
* Changes to copyright dates to include 2017
* Improved algorithm to check if two vectors are aligned with accuracies less than 1e-15
* Now when pre-storing a polygon type geometry, double dots are eliminated automatically as it has always been done with lines
* The COMPRESS command now has no parameters.
* Now the exporter of Geomedia does not allow to store as two different coordinates whose difference is less than the active sigma
* Created the command DELETE\_DOUBLE\_POINTS
* Now in 64-bit installations the title of the "Code Tables Editor" program becomes "x64 Code Tables Editor"
* Now in 64-bit installations the "Pyramid Level Generator" program title changes to "Pyramid Level Generator x64"
* New command EXPORT\_SELECTED\_ENTITIES
* New command DETECT\_LOOPS
* New command DETECT\_SHORT\_SEGMENTS
* Modified Database Settings Change dialog box to be displayed with the active topic

## Fixes

* The program unexpectedly terminates loading DWG files that generate error messages.
* With double-precision sigmas, such as 1e-15, the attempts do not attempt at the correct projection
* If a geoid undulation is specified manually, the program does not display vectors in its Z coordinate
* If EGM2008 is selected as the vertical coordinate reference system, the geoid undulation calculated in negative coordinates very close to latitude 0 is incorrect
* The geoid ripple input dialog box allows you to enter a value without specifying previously that you want to enter a manual value.
