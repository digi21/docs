# Digi3D.AI 2017.0.0.46

Released on 8/29/2017.

## New features

* Added support for loading Inpho's PRJ files of version 7.1.0 in which they have changed the names of some variable like $CAMERA\_DEFINITION instead of $CAMERA and $ID instead of $TYPE
* Added support to the Code Table Editor program for importing database schemas and codes from a Added support to the Code Table Editor program for importing database schemas and codes from an ArcGIS workspace definition file
* Added support to the Code Table Editor program to create codes from a CSV file with DGN translation data

## Fixes

* Selecting the MicroStation Symbols / Import File Symbols menu option in the Code Table Editor does not take any action
* If the dongle has multiple activations of a computer, Digi3D.NET is not able to locate the most modern one and therefore indicates that the computer is not activated
* The program does not locate digital camera orientations in Inpho PRJ files since support for loading analog camera orientations was added
* Fixed problem caused in the version 2017.0.0.0.41 when activating the option to auto insert vertices in the intersections of new geometries: When drawing a new geometry it was not stored.
