# Digi3D.AI 2017.0.67.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 12/18/2017.

## New features

* Add the command ADD\_CODES
* Now when you import schemas from ArcGIS, an unconditional code is created whose name matches the name of the database table.
* Added prefixes to the imported codes of an ArcGIS work schema to differentiate between line, point, polygon type codes...
* Added option to change a field to "Not comparable" in all tables where it appears in the Code Tables Editor program.
* Added option to remove duplicate codes to the Code Table Editor program
* The code table editor now displays the table associated with each code.
* [New "Code table" docking panel](https://blog.digi21.net/2018/01/16/nuevo-panel-tabla-de-codigos/)
* Now if you are working on a Shapefile and you are drawing an open line in a polygon layer, the program shows the closed line in the drawing window.
* Eliminated the "rotate fiducial system"configuration option, as it was only needed for Inpho projects. Now if the photogrammetric project being loaded is from Inpho, this calculation is applied automatically
* You can now create. pg files (Files with PostGIS connection parameters) from the New Project dialog box.

## Fixes

* ArcInfo schema code importer generates duplicate codes if such codes already exist in the code table at the time of import
* Sometimes code is not correctly selected when loading a shapefile file. Now selecting the code for a loaded geometry of a shapefile file with a code table with multiple codes for the same table, locating the table without restrictions instead of assigning the code to this table ensures that there are no more restricted codes pointing to the same table.
* Sometimes when you synchronize zooms between the photogrammetric and drawing windows, they are not fully synchronized.
