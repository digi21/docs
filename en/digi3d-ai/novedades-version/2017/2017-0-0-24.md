## New features

* Now when performing an absolute orientation in a Leica ADS camera model you can indicate the coordinate reference system of the control points

## Fixes

* Improved performance with files with tens of thousands of entities
* When loading a model of an Inpho PRJ file with camera calibration with distortion polynomial is not correcting for the tangential increment in the Y-coordinate of the image
* Tangential distortion with PhotoScan files is not being corrected correctly. The value p1 is being applied by p2 and vice versa. This problem could cause models generated with much tangential distortion between models to see the geometries in different coordinates.
