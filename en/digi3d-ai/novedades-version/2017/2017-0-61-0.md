# Digi3D.AI 2017.0.61.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 11/23/2017.

## New features

* Now ArcGIS Workspace Scheme Importer can import multiple workspaces simultaneously
* Now the command COPY\_ATRIBUTO\_BBDD\_ENTIDAD\_EN\_ENTIDAD does not allow to try entities that do not have the attributes indicated in the command line.
* Now read shapefile entity types when importing codes from an ArcGIS workspace file
* Added support for multipoint and multipath in ArcGIS workspace importer.
* Significantly improved the speed of the Shapefile file code selection algorithm

## Fixes

* ArcGIS workspace schematics importer does not correctly import double type fields
* When executing the UNDO order with importers using the Digi3D\_Eliminated tables, the program gives an error message.
* The program unexpectedly ends when comparing database attributes if one of the geometries is not assigned the attribute being compared (i. e. has a null value)
