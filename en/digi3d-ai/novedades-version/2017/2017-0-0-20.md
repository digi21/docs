# Digi3D.AI 2017.0.0.20

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 3/16/2017.

## New features

* The TrueType font of codes that have an assigned TrueType font is not loaded
* Updated the DWG and DGN libraries to version 4.2.2
* [New command CREATE\_DATABASE\_VIEW](https://blog.digi21.net/2017/03/21/vistas-de-base-de-datos/)
* Fixed issue when connecting to WMS services returning Unicode strings
* Now when creating a WMS connection file, if we have a open drawing window, the WMS connection file we just created will be automatically loaded

## Fixes

* Fixed a problem in the English menu of the Code Tables Editor program. File option did not appear
* When you click the Clean button in the Change Database Settings dialog box, the program terminates unexpectedly
* Fixed a problem in the Web Map Service client that could cause the program to terminate unexpectedly when attempting to store errors in the Windows log
