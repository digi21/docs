# Digi3D.AI 2017.0.66.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 12/13/2017.

## New features

* Fixed problem that in PhotoScan you have to multiply the speed by -1 and you have to do the trick of inverting the angles of the epipolars.
* Changes in the leveling matrix. Now you can have an oblique levelling matrix. The satellite sensor now has no problem that sometimes the axes go in the wrong direction.
* Added the command EDIT\_CODES\_R

## Fixes

* Photogrammetric window command to create a leveling matrix from three points does not receive the pedal press event
* The epipolar calculus was swapping the angle of phi and omega.
