# Digi3D.AI 2017.0.0.41

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 6/29/2017.

## New features

* Added SQLite (3.19.3) engine with program installation
* Modified the behavior of the command auto\_insert\_vertex\_intersection\_when\_finishing\_linea. Lines are now created or modified by any command
* The BINDXF table importer now modifies the import/export parameters for existing codes instead of creating duplicate codes.
* The inpho loader now allows you to load strings whose name has a space specified as "\\".
* Added the extension method UtilidadesSecuenciaEntity.QueNoTenganAlgúnCódigo
* Added a new format (.csv) for loading photogrammetric projects of conical sensor type. The format of the file is:

\[Left\] \[path to the left photo\] \[path to the right photo\] \[path to the orientation file\]
* The CAMB\_AA command now transforms points if they are selected with multiple selection
* The PhotoScan Orientation Importer now reads the "reference" node to know about a point in the model.

## Fixes

* When loading an encrypted code table, the program indicates that the password is incorrect
* Now the SHOW\_HELP\_AYUDA command allows you to indicate URL paths located on web servers
* If a quality control indicates that a Point type entity has an error, double clicking on the task the drawing window displays an undetermined zoom
* When loading certain models of PhotoStan the epipolar is calculated in reverse and the movement of the images is the inverse of the expected. The conical camera sensor now takes into account whether the source point is above the projection center of the left camera. If so, we would be working with the symmetry, so that the direction of the nivelation matrix is changed and the epipols are calculated in reverse.
* If the user cancels the coordinate reference system selection dialog box when loading a photogrammetric project file, the program terminates unexpectedly
