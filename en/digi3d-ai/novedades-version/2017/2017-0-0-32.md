# Digi3D.AI 2017.0.0.32

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 6/2/2017.

## New features

* Because the vast majority of users have a single monitor, now the default setting for new installations is for a single monitor
* Because the feature of capturing the mouse in the photogrammetric window when clicking can be annoying for new users, now in new installations this option is disabled by default
* Because REST4 type cranks are no longer manufactured, now in new installations the default input device is None
* Now in new installations the default value for Epipolar Rectification by Default is set to on
* Now in new installations the option to rotate the images according to the fiducial system is disabled by default
* Now in new installations the option of Multi-coding Interface is disabled by default
* Modified the behavior of the UNDO command. It is not allowed to execute now if an order is being executed. It can only be executed when the program is in READY mode
* Modified the installer's bootstrapper so that it does not hide any of the components that the program installs

## Fixes

* Fixed an issue where no geometries stored inside folders in a KML file were loaded. Only geometries that were not inside a folder were loaded.
* Fixed a problem in the DigiNG.DrawingFile property that could create an unnecessarily Digi21.DigiNG.DrawingFile object. If an entity was obtained via snap when attempted to delete that entity (always before accessing the DigiNG.DrawingFile property), accessing the DigiNG.DrawingFile property created a new Digi21.DigiNG.DrawingFile object instead of using the qlready generated for the Entity.Owner property.
* The macros $(Time) and $(TimeUnderscore) are been substituted by date and not time
* When creating DGN file backups, the program unexpectedly terminates unexpectedly
