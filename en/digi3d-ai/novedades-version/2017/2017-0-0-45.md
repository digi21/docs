# Digi3D.AI 2017.0.0.45

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 8/28/2017.

## New features

* Modified the program to allow creating malformed TIFF files created with Erdas Imagine version 1.10.1.9.1.9.2.11
* Added support for loading Inpho .PRJ files with analog cameras
* [Added options to change the Brightness / Contrast / Gamma in the orthophotos loaded in the drawing window](http://blog.digi21.net/2017/08/28/cambia-el-brillo-contraste-o-gamma-en-las-ortofotos-cargadas-en-la-ventana-de-dibujo)

## Fixes

* If managed exceptions are detected when loading models from the photogrammetric project panel, the program ends unexpectedly
* Distortions in Inpho .PRJ files are not correctly corrected with cameras with radio-value distortions
* On new equipment with REST4 type handwheels, the input device dialog box shows movement on the handwheels but the photogrammetric window does not move when moving the handwheels
* Sometimes when you close a drawing window, the program does not allow you to reopen the drawing file. You need to restart the program. This problem is caused by the use of smart pointers and happened following the next sequence: open the drawing file, open the photogrammetric window, close the drawing file.

From this point on, the drawing window could no longer be opened with the same drawing file.
