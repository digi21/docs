# Digi3D.AI 2017.0.0.60

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 11/17/2017.

## New features

* Improvements in quality control notifications. If a geometry does not pass X tests, these X tests will be displayed in the error window.
* Modifications to the GeometricRelationException type. The type now contains a nullable type with the coordinates at which the error was detected.
* Added support for schemes to PostGIS importer
* Now if PostGIS importer creates a new code, it will assign a custom style to that code.
* Added support for removal and recovery of entities in PostGIS
* PostGIS importer can now download data from the database
* You can now change database fields in PostGIS connections
* Added support for compressing files on PostGIS connections
* The program now loads SLD representations located in the layer\_styles table of PostGIS databases.
* Now the PostGIS connector is reconnected in case of loss of connection to the server
* PostGIS importer now allows to load regions of interest
* Added support for point, multilinestring and multi-polygon geometries in PostGIS connections
* Improved GEN order performance. Entities that have not become generalized are no longer stored.
* Added support for UTF8 on PostGIS connections
* Added the commands VER\_SOLO\_ENTIDADES\_CON\_ENLACE\_BBDD and VER\_SOLO\_ENTIDADES\_SIN\_ENLACE\_BBDD
* Added the command FORCE\_STORAGE\_GEOMETRIAS\_SIN\_LINK\_BBDD. If active, all geometries will be stored without database link parameters.
* Now the GEN command can generalize polygon and complex entities.
* Added new search engines to facilitate the work with MSLINK type data models. The following searchs have been added:

Find entities with table and record links.
Search for entities with database links.
Find entities with table and record.
Search for entities without database links.

## Fixes

* The program terminates unexpectedly when loading files. LAS with points with a classification number greater than 32
