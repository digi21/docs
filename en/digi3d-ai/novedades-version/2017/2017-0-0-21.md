# Digi3D.AI 2017.0.0.21

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 3/23/2017.

## New features

* If the -diging parameter is indicated from the command line, the program does not keep the drawing window open and it auto-closed when create the drawing window

## Fixes

* Can not connect to WMS servers that are not on port 80
* The drawing window indicates that the WMS connection does not have any layer compatible with the coordinate reference system (CRS) of the drawing window when in fact there are sublayers that do have a compatible CRS. Program logic has been modified to allow subcapas to be found that provide CRS childs from non-CRS-providing layers
* When you press the snapr button when you are selecting a geometry to select another, there may be traces of the previous selection
* The program does not correctly load KML files generated in the namespace http://www.opengis.net/kml/2.2. The KML importer was developed before the KML format was an OpenGis standard and the namespace was expected to be http://earth.google.com/kml/2.2 and not http://www.opengis.net /kml/2.2
* The Pyramid Level Builder program does not transform 4-channel TIFF files
* The INSR and INS\_AA commands do not rotate texts or points that the inserted block may have
* If you select the "Import blocks" from the loaded DWG drawing file, the importer does not import anything
