# Digi3D.AI 2017.0.0.59

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 11/3/2017.

## New features

* [Added the DigiNG.Wkt property and added the DigiNG.SendInputDeviceEvent method to send events to the drawing window.](https://blog.digi21.net/2017/09/09/utiliza-tu-gps-como-dispositivo-de-entrada-en-digi3d-net/)
* Added separators to the menus to allow extensions. NET to create submenus in the Window menu.
* [Added a layer selection dialog box to load drawing files in Geomedia Datawarehouse format](https://blog.digi21.net/2017/09/10/mejoras-al-cargar-archivos-de-dibujo-de-geomedia-y-en-formato-shapefile/)
* [Added a layer selection dialog box to upload drawing files in Shapefile format](https://blog.digi21.net/2017/09/10/mejoras-al-cargar-archivos-de-dibujo-de-geomedia-y-en-formato-shapefile/)
* [Added partial load support for drawing files in Shapefile format](https://blog.digi21.net/2017/09/26/carga-archivos-por-regiones-de-interes/)
* [PROJECT\_DEM command now creates TIFF files](https://blog.digi21.net/2017/09/27/novedades-en-la-orden-proyecta_dem/)
* New option to pre-configure import/export parameters for drawing files
* Updated Gemalto driver to version 20.0.1.70827
* [Import/export parameters can now be configured for the different drawing file formats supported in project configurations](https://blog.digi21.net/2017/10/03/novedades-en-la-configuracion-de-proyectos/)
* Modified the loading logic of. BLK files to allow uploading images whose extension does not match the extension indicated in the. BLK file.
* Added support for uploading related orientations into. BLK files with satellite sensor orientations
* Added support for uploading files. BLK with satellite orientation with UTM projection
* Improvements in semantic error notifications. Now if a semantic model engine detects that a geometry does not pass the test, and the engine provides the coordinates at which the error was detected and the user indicates to store the entity, the drawing window focuses on the coordinates of the error.
* Improvements in semantic error notifications. Now if X semantic errors are detected when registering an entity, the user is asked if to store the entity for each of the errors detected. If the user decides not to store the entity in any of the questions, no new questions are still displayed.

## Fixes

* If an ArcMAP BBDD schema is imported into the Code Tables Editor, the program does not prompt you to Save the code table when closing it.
* If a code has spaces in its name, the code selection toolbar does not allow you to select it.
* When creating a. DGN file with shared cells the program displays an error message
* The importer/exporter of Shapefiles uses the value selected in Code Page only for export and not for import.
* If the auto-insert vertex flag is activated, when working with drawing files in Geomedia format, if any modification of an existing geometry is made, an error message appears and the entity is duplicated
* The program does not locate orientations in certain files. PRH. When loading an Inpho PRJ file in which the names of the photos that appear in the $PHOTO\_NUM variable do not match the names of the photos that appear in the $PHOTO\_FILE variable, the program is not able to locate the orientations of the photos.
* If the FIXZ flag is enabled and the code is changed by cloning an existing geometry, the FIXZ flag is not disabled.
* When executing the commands UPPER\_Z and LOWER\_Z, the Z is blocked in the photogrammetric window regardless of the status of the FIXZ flag.
* The program requests the import parameters even though they have already been filled in in the Open dialog box.
* The HORIZON order never ends if it is executed in a file with some deleted geometry.
* If you are digitizing points with a certain code and you change the code without cancelling the order before, the first digitized point is stored with the previous code.
* Buttons on the Z-coordinate toolbar do not have the icons that correspond to them
* Changing the code using the CLONE command does not disable the FIX\_Z option if it is enabled.
* The program does not load the auto-search files correctly
* Sometimes when exporting to DGN and DWG the program ends unexpectedly
* In the latest versions the program does not extract the internal orientation parameters of Vexcel cameras.
