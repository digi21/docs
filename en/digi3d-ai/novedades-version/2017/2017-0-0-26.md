## Fixes

* The INSR and INS\_AA commands do not correct the rotation of the texts and points that are part of the block
* .orientation.xml files do not store the internal orientation in case this is an analog
* The drawing window is not opening correctly image files of type ECW and JPEG 2000
* When you load a Shapefile file whose database schema does not match that of the code table, the program terminates unexpectedly
* When running the command DISPLAZE\_ORIGIN the program crashed
* When executing the Camera to Google Earth commend in the drawing window an error message appears indicating that the coordinate reference systems do not have the same number of axes
* Fixed an issue where the INTERSECTION, JOIN and JOIN\_Z commands failed if the file had deleted entities
* Fixed a problem displaying the names of the measured points in the photogrammetric window. They were not shown correctly because Digi3D.NET was sending to OpenGL Unicode strings when it waited for ANSII strings
