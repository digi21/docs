# Digi3D.AI 2017.0.0.8

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 12/20/2016.

## New features

* Now the CHANGE\_VALUES\_DATABASE command allows you to assign a GUID (generated for each record) to a field
* Now the CHANGE\_VALUES\_DATABASE command allows you to work with multiple codes simultaneously
* Now the items added in the Tasks panel can have a contextual menu to perform quick actions
* New command ASSIGN\_DATABASE\_ATTRIBUTE\_TO\_ENTITY to replace the value that had in a given field of BBDD a certain existing geometry
* Enhancements to the Common Code Search Dialog Box
* The "Delete By Window" dialog box can now be resized to accommodate the last modification of the Multiple Code Selection dialog box
* The erase enclosure dialog box can now resize to suit the new implementation of the multiple code selection dialog box
* Now the BINTRAM and BINTOP commands allow you to select codes from the active code list instead of working with table files
* Implemented the command LOAD\_RASTER
* Added support for loading Portable Network Graphics file format in the drawing window
* New commands INS\_PHOTO\_2P\_AA and INS\_PHOTO\_3P
* You can now specify the size of the coordinate window in the Coordinate and Attempt toolbars

## Fixes

* The MOVE command does not move geometries of type Bitmap
* Transparencies are not shown in bitmaps loaded in the drawing window
