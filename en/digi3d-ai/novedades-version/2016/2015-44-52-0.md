## New features

* [Now the program indicates that it is lost compatibility with Windows XP](https://blog.digi21.net/2016/06/19/sayonara-xp/). Digi3D.NET now indicates that the next version to be released will not be compatible with Windows XP.

This message appears only if the computer on which the application is running as a Windows XP operating system.
* [Now the program indicates if license is not available to run an update available for download](https://blog.digi21.net/2016/06/19/sayonara-xp/). If a new version of the program is detected but the subscription of technical support has completed, the software will indicate it to the user to prevent that him download and install a version that is not going to be able to use. Also invites the user to update the subscription to technical support.
