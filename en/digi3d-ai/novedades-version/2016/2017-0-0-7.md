# Digi3D.AI 2017.0.0.7

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 12/12/2016.

## New features

* Improved significantly the load speed of DEM files contained in tiled TIFF files
* Added support to create stereoscopic models from orthophotos with alpha channel
* Updated license suite built into installer
* Added support for the command INS\_PHOTO
* Libitiff's warning and error messages are now issued as debugging strings
* The BININFO command now displays the coordinate range for drawing files that do not provide gometries, such as DTMs
* Added support for Adobe Deflate compression to TIFF files
* Updated version of the third-party LibTIFF component to version 4.0.6.2
* Updated version of the third-party ZLib component to version 1.2.8.8.
* Updated version of the third-party LibJPeg component to version 9.2.0.1
* Added support for RapidCAL camera calibration model
* Modified the PhotoScan's camera calibration formulas as indicated in the user manual of that program
* Now the purposed error file name for the commands BINTRAM and BINTOP has .BIND extension
* Added the possibility of load .PNG files with the command LOAD\_RASTER

## Fixes

* When creating a stereo pair from an orthophoto the generated model is inverted
* Untitled
* Sometimes the order assigned to a button on the input device
* If you load a drawing file with entities of type Bitmap as main drawing file, bitmaps are not shown, but if you load it as reference file, bitmaps are shown
* If an .xml file other than a code table is selected as the code table file, the program terminates unexpectedly
* The external program Code Tables Editor shows messages in spanish
* If the photogrammetric project panel activates the model autochange button and there is no project loaded the program ends unexpectedly
* The Drawing Files panel displays the active drawing file in black if the active theme is dark, so the file name is not clear
* By disabling the "Show images" option in the "Display properties" panel of the photogrammetric window, the vectors are displaced and static
* If the BINTRAM or BINTOP command is executed by specifying to create an error file that is currently loaded as a reference file, the program terminates unexpectedly
