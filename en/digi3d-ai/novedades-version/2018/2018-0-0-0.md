# Digi3D.AI 2018.0.0.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 1/19/2018.

## New features

* Multiple keys can now be entered simultaneously when creating an encrypted table packet in the code table editor
* Added a toolbar to the code table panel with a button to search for the active code and another to clone.
* Now you can import files with multiple ArcGIS workspace schematics
* The program now asks for the ArcGIS version number when importing files, as ArcGIS definition files change the namespace of XML nodes depending on the version.
* Now when you add a code in the code table editor, you are assigned fill colors with transparency by default.
* You can now enable/disable layer display in the drawing file panel for Shapefile files

## Fixes

* The program terminates unexpectedly when loading. BIN files with texts with zero characters.
* Fixed problem when compressing Shapefiles, if later the program failed because the data of last modification was corrupted.
* Solved the problem that the "Color" option does not appear in the code table editor in the Fill Type dropdown box.
* Fixed a bug in the MOD\_MULTIPLE command. The order ended unexpectedly if a multiple selection order was executed on it
