# Digi3D.AI 2018.11.0.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 6/8/2018.

## New features

* You no longer need to be an administrator to change program settings. We've simplified the configuration dialog that now has a single button to accept and we've also removed the administrator elevation requirement from all other dialog boxes that required it.
* The Digi21.DigiNG.Topology.ClosedLoop type now has a Polygon property. The Polygon property of Digi21.DigiNG.Topology.ClosedLoopWithHoles has been removed
* Added Digi3D.IO.IBox extension. Deleted from CommonDevices Softmouse and can now be configured as a mouse or handwheels in IBox.
* Now the command EXPORT\_TOPOLOGY does not export enclosures whose centroid is an asterisk.
* The command EXPORT\_TOPOLOGY now takes the field conditions into account
* Improved error communication in Shapefile
* Added support for timestamp in Postgis connections and added all types of STRING supported by PostGIS and now it is analyzed if all fields are supported when connecting to a database.
* Now the EXPORT command shows an error if a code links to a table and the table schema is not located in the active code table.
* Now before storing a geometry the importer/exporter is asked if it can be stored (depending on the type of gometry and the layer, it could fail as for example in shapefiles).
* Added support for polygons and linestring in PostGIS
* Digi21.DigiNG.IO.IReadOnlyDrawingFile now provides the DatabaseAttributes property
* Now the default FILL flag is disabled.
* Now fill in by default is disabled in the photogrammetric window
* New command REST\_REFILL
* The BININFO command now displays the WKT string of the coordinate reference system.
* Now you can specify in the file properties in the Drawing Files pane the width of the region of interest for PostGIS type files.
* You can now store the table combination in the PostGIS table selection dialog box
* You can now store the table combination in the Geomedia table selection dialog box
* The combination of tables can now be stored in the Shapefile table selection dialog box
* Now when the information is displayed in the photogrammetric window the complete WKT string is displayed
* Reference Assemblies for programming in Digi3D.NET have been removed. Now the references are obtained through NuGet packages hosted at https://nuget.org
* Now if the number of records in the associated SHP and DBF does not match, the program displays an error message and does not allow loading the Shapefile.
* Added a service to send the Minidump files created when the program unexpectedly ends to the Digi21 servers to solve the problem.
* Deleted from the configuration dialog box the MiniDumps directory option and the option to send the MiniDumps over the internet
* Deleted from the configuration dialog box the MiniDumps directory option and the option to send the MiniDumps over the internet

## Fixes

* Fixed a memory leak in the LINE command. A memory leak was generated when starting a line, digitizing a single vertex and ending it.
* Fixed a problem that could cause the program to terminate unexpectedly when trying to load non-existent assemblies
* Fixed a problem where the resources of the.NET assemblies were not located due to the version number.
* Fixed a problem when transforming from Unicode to UTF8 with Windows 7 that does not work correctly with MB\_COMPOSITE and WC\_COMPOSITECHECK flags
* Fixed problem caused on 19/4/2018 when added the functionality to take into account the geometries that are off with OFF in the AUTO\_INSERT\_VERTICES\_AL\_FINALIZE\_LINE.
* Fixed a problem in the Digi21.DigiNG.Topology.TopologyAnalyzer.AnalyzeCentroids method that was not reporting duplicate centroids correctly.
* Fixed a memory leak in the database panel
* Changing the Fill flag in the photogrammetric window does nothing
* The Code Tables Editor crashes when importing MGCP configuration file database schemas
* When the pattern is activated, symbols whose number is a multiple of 256 such as 0, 256, 512 are not displayed.
* If the program ends unexpectedly and you say you are going to create a Minidump file, it does not create the MiniDump file.
* When loading null data from PostGIS databases the program does not display them as null but as empty character strings.
* When working with a drone project with thousands of models and with automatic model change, the program sometimes ends unexpectedly.
