# Digi3D.AI 2018.0.7.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 2/16/2018.

## New features

* [Added support for encoding in. DBF files](https://blog.digi21.net/2018/02/19/anadido-soporte-para-codificacion-encoding-en-los-archivos-dbf-asociados-con-shapefiles/). The program now stores in the header of the. DBF file an identifier to indicate the coding of the texts stored in the file. The program now displays a larger coding list.
* Fixed memory leaks that could cause the program to consume available memory when loading JPG files or changing photogrammetric model

## Fixes

* Cannot select codes by alias. This problem caused by an optimization to increase the speed implemented in the previous version of the program has been solved.
