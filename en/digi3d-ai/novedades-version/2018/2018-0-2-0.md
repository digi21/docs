Released on 2/1/2018.

## New features

* Fixed a problem when projecting using. LAS files. There was no assurance that the triangle formed surrounded the point at which the Z coordinate was to be obtained and that it was not guaranteed to be as equilateral as possible. In addition, the search algorithm has been improved by more accurately delimiting the mean distance between points in LAS.

## Fixes

* Fixed a problem in Geomedia with the flag auto\_intersectar\_vértices\_to\_end\_entity enabled. Fixed the problem that if the auto\_intersect\_vertices\_when\_entity\_complete\_is enabled, if the command that is storing the entity then deletes some entity and this is one of the ones that this algorithm has modified, with certain drawing files such as Geomedia, gives an error because it tries to delete a geometry that is already deleted. This modification does not store a new entity if the number of new proposed vertexes is not greater than it already had.
