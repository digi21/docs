Released on 10/26/2018.

## New features

* Now the drawing window centers the selected geometry in the database editor on Shapefile files
* The Database Editor panel now supports the application's dark theme.
* Quality control script loader now allows loading assemblies with full name or with path
* Database editor now allows you to edit databases associated with Shapefile files
* Now the database editor allows to edit databases with JET engine connection.

## Fixes

* The program ends unexpectedly when trying to load TIFF files with description if this is not a Vexcel calibration. We've solved the problem. Now the program only interprets that the orientation is of type Vexcel if the first word of the description is the word "Vexcel".
