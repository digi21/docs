# Digi3D.AI 2015.31.39.0

Released on 9/2/2015.

## New features

* Updated user interface library to prepare the program to be developed with Visual Studio 2015. Updated the user interface library Codejock to its latest version to support Visual Studio 2015 because Digi3D.NET will start to be developed in Visual Studio 2015 to be able to use the latest trends in programming such as asynchronous methods that will improve the user experience.
* Modified option Help/Share my desktop. Now the TeamViewer client is not installed anymore. When you select this menu option, a browser will be open to download from the TeamViewer servers the latest version of the client.
* Changes in the deployment of the TeamViewer client. Now the option from the menu Tools/Share my desktop opens a browser to download the TeamViewer client to make sure that the client has the latest version.
* Improved the calculation of the matrix of leveling in the satellite sensors. Now the satellite image's rotation is calculated automatically and the application can load satellite with epipolar images.

The calculation of the size of the pixel, was also improved so that now, an increase of one unit in input (mouse or topomouse) device is equivalent to an increase of a pixel in the photogrammetric window.
* [Added compatibility with Summit Evolution satellite projects](http://blog.digi21.net/2015/09/01/carga-de-proyectos-satelitales-de-summit-evolution/). It is now possible to load Summit Evolution's .SMTXML project files with satellital orientations.
* [The 64-bit version of Digi3D can now communicate with Google Earth](http://desarrollodigi3d.digi21.net/2015/09/01/haciendo-que-digi3d-x64-pueda-controlar-google-earth/)
* [Now the image properties panel memorises the parameters](Now the image properties panel memorises the parameters)
* [Added new conditions for actions when storing an entity](http://blog.digi21.net/2015/09/01/nuevas-condiciones-para-los-desencadenadores-de-digi3d-net-para-el-control-de-calidad-de-la-cartografia/)

## Fixes

* Select dongle or activate computer in the english version of the program is not running. If you execute Digi3D.NET and the protection key is not localized or the key is not activated, the program invites to press buttons to run the program Select Dongle or Activate Computer. If you are running the English version of the program, that buttons doesn't run because Digi3D.NET was trying to run the programs named in Spanish instead of English.
* When doing an absolute orientation with a known vertical coordinate systems, the program displays an error message indicating that you do not have permissions
