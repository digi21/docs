# Digi3D.AI 2015.34.42.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 9/9/2015.

## New features

* Increased the speed of the sensor stereo orthophoto. Now the orthophoto stereoscopic sensor uses all cores of CPU so that the images are generated much faster.
* Changed the installer to display Digi3D.NET and licenses in Add / Remove programs. Until now, the unified Installer (Bootstrapper) hides the components Digi3D.NET and Licences in Add / Remove programs.

This made that if Digi3D.NET was updated automatically appeared a second installer in Add / Remove programs.

Now the behaviour is the opposite. The Bootstrapper hides himself and the components Licenses and Digi3D.NET are not hidden.

## Fixes

* The configuration memory on-demand consumption parameter does not alter the behavior of the program. The parameter with an incorrect name was stored in the registry.
* Fixed a bug that made that excessive consumption of hard drive be made to load images in the photogrammetric window. This problem originated in the 2015.24.27.0 version and is due to legacy code from previous versions.
* Fixed a bug in the order MOD\_MULTIPLE. When executing this command the program ended unexpectedly.
