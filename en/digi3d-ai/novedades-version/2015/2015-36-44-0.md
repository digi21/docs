# Digi3D.AI 2015.36.44.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 10/8/2015.

## New features

* [Added commands to run when pressing the DATA button](http://blog.digi21.net/2015/10/07/ejecutar-ordenes-al-pulsar-el-boton-de-dato/). Added an option to the codes in the code table that allows you to indicate a series of commands to run if the data button has been pressed and the program is in ready mode and active code is the code which adds commands to run.
* Improvements in codes with conditions in Geomedia. Now in the case that several codes link to the same table, one of the codes can be withouth conditions, so this code will be the repository of geometries that do not meet conditions for that table.
* [New trigger: detect a point near another point](http://blog.digi21.net/2015/10/08/nuevos-desencadenadores-en-tiempo-real/)
* [New trigger: detect a geometry within a polygon, or area](http://blog.digi21.net/2015/10/08/nuevos-desencadenadores-en-tiempo-real/)
* When loading a model of conical camera without relative orientation the program displays coordinates infinite if the option of automatic epipolar rectification is active

## Fixes

* Not detected correctly polygons within polygons with virtual topologies without gaps. The algorithm of localization of polygons within polygons has been modified. Now, if the polygon have not holes, the algorithm continues seeking other polygons that are within this polygon and the search is ordered by area.
* The Image Properties Pane does not change the brightness/contrast in the image. Fixed this problem with a fragment shader that is generated dynamically at run time.
* Changing the option to rotate images depending on the fiducial system does not affect the representation of the images to load a model. Fixed this problem consisting in that the value is stored in the registry with an incorrect variable name.
* The command ASSIGN\_ATTRIBUTE forces to put the field's title and not it's name. This behavior has been changed. Now the first parameter of the order must be the name of the field, and not the title that the user sees.
