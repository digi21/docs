# Digi3D.AI 2015.35.43.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 9/12/2015.

## New features

* Improved the performance of the sensor Stereoscopic Orthophoto. Now the program uses all cores from the main processor to calculate the synthetic image.
* [New command SELECT\_EVERYTHING\_CURSOR](http://blog.digi21.net/2015/09/12/nueva-orden-selecciona_todo_en_cursor/). This command selects all entities that are within the scope of the cursor.
* The MOD\_MULTIPLE and MOD\_Z\_MULTIPLE commands now appear on the Edit menu. These commands have been added to the menu as well as toolbar Modify
* [New command GENERATE\_TOPOLOGY\_WITHOUT\_HOLES](http://blog.digi21.net/2015/09/12/nueva-orden-generar_topologias_sin_islas/). This command allows you to generate topologies for flood without taking into account the parent/child, between polygon/hollow relationship.

## Fixes

* Quotes appear in some coordinate reference systems. Fixed a problem of presentation, making quotation marks to appear in some coordinate reference systems.
* Coordinate reference systems selection dialog box appears in English. Fixed this problem caused because resource assemblies were not properly installed in the WinSxS folder to the Digi21.Epsg.dll assembly
* Windows XP has problems when selecting an unknown or local coordinate reference system. This problem was caused because Windows XP was not able to locate the resource from the Digi21.Epsg.dll assembly
* Not marked on the left side of the dialog box for selecting the type of system selected coordinate reference system. This problem was caused by a bug in the user Codejock interface library.
* When running the commands MOD\_MULTIPLE and MOD\_Z\_MULTIPLE program ends unexpectedly
