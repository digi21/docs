Released on 10/30/2015.

## Fixes

* Fixed a bug when displaying dialog boxes to select CRS. This problem appeared after the publication of version 2015.35.43.0 with the amendment correcting that coordinate reference systems selection dialog boxes appeared in English in Spanish version of Digi3D.NET
* Fixed a problem of representation of vectors when selecting the option Interchange eyes in the photogrammetric window. Vectors were not is projected correctly to enable the option of exchanging eyes.
* Fixed a bug when calculating the matrix of leveling in the photogrammetric window with models with absolute orientation files with a distinct SRC if one of the two has an axis ordered as Y,X or Latitude,Longitude. If you have a file of absolute orientation in a different coordinate reference system of the one in the photogrammetric model, such as the SRC of the WGS84 (geographical) model and the WGS84 absolute orientation file / UTM Zone 14N, and one of the two systems has the order of the axis as Latitude,Longitude or Y,X the program exchanged axis incorrectly making leveling matrix had a reverse axis.
* The close window in the photogrammetric window button is not activated when you close the order absolute orientation dialog box
