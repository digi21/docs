# Digi3D.AI 2015.33.41.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Released on 9/5/2015.

## New features

* Added an option in the menu to activate / disable the display of entities with unknown code. Added the option in the menu Window/Viewing parameters which runs the VIEW\_UNKNOWNS command.
* Modified the position of the menu option that enables the photogrammetric project's panel. Now the option is in Window menu
* [Not listed the systems of reference for coordinates Rednap (peninsula and Canary Islands) in the vertical coordinate reference systems.](http://desarrollodigi3d.digi21.net/2013/11/26/implementando-egm08_rednap-en-digi3d-net/) This problem is because the database with coordinate reference systems is now SQL Server Compact 4.0. When it was updated from version 3.5 to 4.0 DB was used as a template a database that did not have these additional systems.

## Fixes

* An error with little information is shown when making a transformation that involves an EGM2008 vertical coordinate reference system. This was due to an exception with internal information and external exception information was displayed. The program has been modified where exceptions have an inner exception, to display to the user the contents of the inner exception.
* When you load a project photogrammetric having images in TIFF with JPEG compression and 12-bit of color depth, the program ends unexpectedly. The program has been modified to catch errors when creating images.
* English dialog box which goes on export when do not match the SRC, shows in white. Corrected this problem caused by an bad-formed XML file.
* When exporting to a file. BIND indicating that there is connection with DB but with an invalid connection string, the program terminates unexpectedly. This problem has been fixed. An error message is now shown with information for the user.
