# Programming
<!-- id: programacion -->
<!-- origen: e33bdcf7ed4dfbc08b1e63a840b7835af84616fa -->

Digi3D.AI publishes assemblies for creating applications and extensions. Applications can access the import/export engine, topology engine and other components. Extensions let you add options to the search pane, create commands and create quality controls that run when geometries are stored or at your request.

Digi3D.AI also includes the IronPython engine, which lets you program in Python and access all the types published by Digi3D.AI assemblies.
