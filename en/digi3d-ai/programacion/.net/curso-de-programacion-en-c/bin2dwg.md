The examples repository contains a program for converting `.bind` files to the AutoCAD drawing format (DWG). The conversion program is explained in the [BindADwg](../ejemplos/bind-a-dwg.md) example. The `Digi21.DigiNG.IO.Dwg` assembly has no NuGet package, so the example references that assembly from the Digi3D.AI installation folder.
