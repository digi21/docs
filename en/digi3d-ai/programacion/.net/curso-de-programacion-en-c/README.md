In this course, you will learn to use the types exposed by Digi3D.AI.

When these videos were recorded, the Digi3D.AI installer copied assemblies to the _Windows_ _Reference Assemblies_ folder. To create an application or extension, you had to add references to the assemblies installed in _Reference Assemblies_ before compiling.

Assemblies are no longer published in the _Windows_ _Reference Assemblies_ folder. To add assembly references, use the [NuGet](https://www.nuget.org/profiles/Digi21) packages.
