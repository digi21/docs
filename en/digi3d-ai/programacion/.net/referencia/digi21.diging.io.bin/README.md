# Digi21.DigiNG.IO.Bin
<!-- id: digi21.diging.io.bin -->

This [NuGet](https://www.nuget.org/packages/Digi21.DigiNG.IO.Bin/) package provides an importer/exporter for classic Digi3D.AI binary files.

### Package manager
```bash
Install-Package Digi21.DigiNG.IO.Bin -Version 26.0.0
```

### .NET CLI
```
dotnet add package Digi21.DigiNG.IO.Bin --version 26.0.0
```

### Package reference
```markup
<PackageReference Include="Digi21.DigiNG.IO.Bin" Version="26.0.0" />
```

## Types

| Type | Description |
| :--- | :--- |
| [Bin](bin.md) | Drawing file in the classic binary format (`.bin`). Reads and writes lines, points, text, polygons and complexes. |

For `.bind` files with double-precision floating-point coordinates, use the [Digi21.DigiNG.IO.BinDouble](/digi3d-ai/programacion/.net/referencia/digi21.diging.io.bindouble/) package.
