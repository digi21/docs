# Digi21.Digi3D

Assembly: [Digi21.DigiNG.Plugin](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/)

Types for using Digi3D.AI's main window from an extension: results window, task panel, status bar, docking panes, sounds and notification balloons. The entry point is the static `Digi3D` class.
