# MenuItemGroup

Drawing window menu position where [CommandInMenuAttribute](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.diging.plugin.menu/atributos/commandinmenuattribute.md) adds an item.

```csharp
public enum MenuItemGroup
```

The drawing window menu has a hidden marker at each position. When the user opens a submenu containing a marker, Digi3D.AI inserts an item at the marker's position for each command registered with that group. The value's name indicates the menu and group: `EditGroup9Group15` is group 15 in the submenu containing group 9 of **Edit**. Names do not follow menu order: the table shows where each group is located.

In the table, **Menu** is the submenu path in the English interface and **Position** identifies the item or submenu preceding the inserted items. "The list of..." refers to a list of items generated by Digi3D.AI when opening the submenu, for example the tag or topology list. If the marker follows a separator, the first inserted item starts a new menu group.
