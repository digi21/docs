Loads a code table from a file.

```csharp
public static DigiTab Load(string path)
```

## Parameters

| Parameter | Description |
| :--- | :--- |
| `path` | Code table file path. |

The format is selected by the extension of `path`:

- `.xml` extension (for example `tabla.tab.xml`): code table XML file.
- Any other extension: ZIP file containing a `Digi.tab.xml` entry, the format generated by [Write](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.digitab/clases/digitab/metodos/write.md) with an extension other than `.xml`.

## Returns

A modifiable [DigiTab](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.digitab/clases/digitab/), with `Path` equal to `path`. Call `Dispose` (or use `using`) when you no longer need the table.

## Exceptions

| Exception | When |
| :--- | :--- |
| `ArgumentNullException` | `path` is `null`. |
| `FileNotFoundException` | The file `path` does not exist. |
| `Exception` | The file cannot be read, the XML has errors (the message indicates the line and column), the ZIP does not contain `Digi.tab.xml`, or the code table is encrypted (the ZIP contains `Digi.tab.xml.encrypted`). The message describes the error. |

## Example

```csharp
try
{
    using var tabla = DigiTab.Load(@"C:\Tablas\tabla.tab.xml");
    Console.WriteLine($"{tabla.Codes.Count()} códigos en {tabla.Path}");
}
catch (FileNotFoundException e)
{
    Console.WriteLine(e.Message);
}
```
