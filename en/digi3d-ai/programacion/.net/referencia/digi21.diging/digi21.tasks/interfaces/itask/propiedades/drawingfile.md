Path of the drawing file to which the task refers.

```csharp
string DrawingFile { get; }
```

## Property value

`string`: drawing file path. The Tasks pane displays it in the file column. Tasks generated by drawing files ([Bin](/digi3d-ai/programacion/.net/referencia/digi21.diging.io.bin/bin.md) and the other [IDrawingFile](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.io/interfaces/idrawingfile/) implementations) carry the path of the file that generated them in this property.
