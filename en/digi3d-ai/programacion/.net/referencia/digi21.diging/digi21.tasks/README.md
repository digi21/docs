# Digi21.Tasks
<!-- id: digi21.tasks -->
<!-- origen: f7f56ceabe2038035123e9b9ba4ce9201f478358 -->

Namespace in the [Digi21.DigiNG](/digi3d-ai/programacion/.net/referencia/digi21.diging/) assembly containing task, results and progress types.

A task is an error, warning or message generated by an extension or drawing file. Digi3D.AI displays tasks in the [Tasks pane](/digi3d-ai/referencia/paneles/tareas.md); an extension adds them using [Tasks.Add](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.digi3d/clases/tasks.md). Drawing files ([Bin](/digi3d-ai/programacion/.net/referencia/digi21.diging.io.bin/bin.md), [BinDouble](/digi3d-ai/programacion/.net/referencia/digi21.diging.io.bindouble/bindouble.md), [Shp](/digi3d-ai/programacion/.net/referencia/digi21.diging.io.shp/shp.md), [Geomedia](/digi3d-ai/programacion/.net/referencia/digi21.diging.io.geomedia/geomedia.md)) report tasks, results and progress through the `TaskAdded`, `ResultsAdded` and `ProgressChanged` events, which use this namespace's delegates.
