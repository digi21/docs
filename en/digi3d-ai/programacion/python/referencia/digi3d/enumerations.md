Module: `digi3d`

## InputDevice

Input device for the drawing window (the
[`DrawingView.input_device`](drawing-view.md#other-options) property).

| Value | Description |
|---|---|
| `Mouse` | The mouse. |
| `PhotogrammetricWindow` | The photogrammetric window. |

## MusicType

Standard Digi3D.AI sounds (the [`music`](functions.md#messages-and-notifications) function).

| Value | Description |
|---|---|
| `Beep` | Beep. |
| `End` | End of command. |
| `Error` | Error. |
| `In` | Enter. |
| `Out` | Exit. |

## BallonType

Information balloon icon (the [`show_ballon`](functions.md#messages-and-notifications) function).

| Value | Description |
|---|---|
| `None` | No icon. |
| `Info` | Information. |
| `Warning` | Warning. |
| `Error` | Error. |

## TaskType

Type of a [task](tasks.md).

| Value | Description |
|---|---|
| `Info` | Informational message. |
| `Warning` | Warning. |
| `Error` | Error. |

## FillType

Fill type of a [Representation](representation.md).

| Value | Description |
|---|---|
| `None` | No fill. |
| `Color` | Color fill. |
| `Bitmap` | Bitmap fill. |
