Send questions, problems and feature requests for _Digi3D.AI_ as technical support tickets through the Digi21 website: [https://www.digi21.net/Soporte](https://www.digi21.net/Soporte).

Each ticket is a conversation with the technical support team. Write messages and attach files of any size. The website emails you whenever technical support replies.

You need an account on [www.digi21.net](https://www.digi21.net). Accounts have no password: each sign-in is confirmed with an emailed code.

Pages in this section:

* [Create an account and send your first technical support ticket](/soporte-tecnico/creando-cuenta-soporte-tecnico.md): create an account, sign in, create a ticket and reply.
* [Technical support rules](/soporte-tecnico/reglas-soporte-tecnico.md): write a ticket that support can resolve without requesting more information.
* [Attach files to a technical support ticket](/soporte-tecnico/adjuntando-archivos-grandes-soporte-tecnico.md): upload files when creating or replying to a ticket and download them in a ZIP.
* [Close a technical support ticket](/soporte-tecnico/cerrando-ticket-soporte-tecnico.md): ticket states, closing and reopening.
