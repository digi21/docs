# Raster to Vector
<!-- id: vectorizar -->

[Compute](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-imagen/imagen-calcular.md)

This tool extracts a vector file containing areas occupied by pixels of a particular color. The dialog requests:

* **Color**: components of the target RGB color.
* **Threshold**: permitted difference between the target color and the color stored in the image.
* **Boundary codes**: code of generated linear entities.
* **Computed areas**: minimum area each generated boundary must have to be stored in the output document.
