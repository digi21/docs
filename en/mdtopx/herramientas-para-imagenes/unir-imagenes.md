[Compute](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-imagen/imagen-calcular.md)

This tool joins any number of images to the current image. All images must be georeferenced. Joining can add new pixels directly or calculate seam lines in overlapping areas.
