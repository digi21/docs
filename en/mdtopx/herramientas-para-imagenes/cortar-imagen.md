[Edit image](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-imagen/editar-imagen.md)

This tool crops an image using coordinates or boundaries stored in a vector file.

The following parameters are required:

* **Selection of the boundaries**: two options are available:
* **By coordinates**: maximum and minimum coordinates for cropping.
* **Load boundaries from file**: vector geometry file containing closed entities.
* **Where erase**: two options are available:
* **Inside limits**: deletes pixels inside the specified boundaries.
* **Outside limits**: deletes pixels outside the specified boundaries.
