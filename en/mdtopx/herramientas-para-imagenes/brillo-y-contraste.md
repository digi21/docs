# Brightness and contrast
<!-- id: brillo-y-contraste -->
<!-- origen: ba89855825dc8a69c17cad485259484916e6a315 -->

[Edit image](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-imagen/editar-imagen.md)

This tool evaluates image color distribution across the entire spectrum. Brightness/contrast makes simple tonal range adjustments and corrects the histogram by changing image brightness or contrast.

The dialog contains these fields:

* **Histogram**: bar chart showing the number of pixels with each value. X shows possible values and Y shows pixel counts. Moving the mouse displays both axis values at the bottom.
* **Brightness**: moving the slider right increases tonal values and expands highlights; moving it left decreases values and expands shadows. The slider selects a negative \(darker) or positive \(lighter) brightness value, reducing or increasing tonal brightness.
* **Contrast**: increases or decreases the image's overall tonal range.
* **Automatic adjustment**: adjusts image contrast automatically. Because channels are not adjusted individually, no color casts are added or removed. It clips shadow and highlight values and maps the remaining brightest pixels to pure white \(level 255) and darkest pixels to pure black \(level 0), making highlights lighter and shadows darker.
