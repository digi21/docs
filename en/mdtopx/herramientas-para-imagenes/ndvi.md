# NDVI
<!-- id: ndvi -->
<!-- origen: f0a6d0947b96f71067b3f99706b814a066f9656d -->

[Compute](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-imagen/imagen-calcular.md)

This tool calculates NDVI from infrared values. The image must store near-infrared and red values in its parameters. The result is a grayscale image with the original georeferencing; values closer to 256 indicate higher NDVI. The dialog selects the bands containing infrared and red values.
