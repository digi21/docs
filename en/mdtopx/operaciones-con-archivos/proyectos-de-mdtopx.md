# MDTopX projects
<!-- id: proyectos-de-mdtopx -->
<!-- origen: 1c2fd7be1e6f1cc1af28805082f67278acd59b57 -->

[MDTopX button](/mdtopx/introduccion/boton-de-mdtopx.md)

MDTopX projects reference files belonging to the same job, grouping them in one workspace. Files are referenced rather than duplicated on disk and can be located in any folder. The project view displays file boundaries or the files themselves. Additional tools enable batch processing of the included files.

When a project file is active, its own [tool tab](../fichas-de-herramientas/ficha-de-herramientas-proyecto/) appears with specific commands.
