# Read Shape files
<!-- id: leer-archivos-shape -->
<!-- origen: 13cbbe094ce46fd7dec70db9044f1552846b250f -->

[Open file](/mdtopx/operaciones-con-archivos/abrir-archivo.md)

These files may store elevations in their geometry or in an accompanying database. When reading a file, the program asks whether to extract elevations from a database field. To retain the elevations read from the geometry file instead, click **Exit**.

The program then asks whether to generate a centroid for every surface read. A dialog requests the field to use for text inside each surface and lets you specify the text height. Click **Exit** if you do not want to generate centroids.
