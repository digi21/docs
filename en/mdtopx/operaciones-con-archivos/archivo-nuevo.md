# New file
<!-- id: archivo-nuevo -->
<!-- origen: e9319b9aa1082dc5d7ba92f9261e1950947235ac -->

[MDTopX button](../introduccion/boton-de-mdtopx.md)

This command creates an empty document of one of these types:

* **Project**: a file linking multiple files of different types. Useful when files are too large or numerous and you want to group them in one working file.
* **Drawing file**: stores vector mapping as point clouds, linear entities and text.
* **Roads file**: stores the geometry of linear infrastructure projects, such as roads or pipelines. The command creates an empty document. To start designing roads, you need a workspace and ground coordinates. Load a DTM with Load on the [Roads tab](../fichas-de-herramientas/ficha-de-herramientas-viales/), or load a mapping file as a reference with [Open reference files](/mdtopx/operaciones-con-archivos/abrir-archivos-de-referencia.md).
* **DEM grid digital model**: a digital model based on evenly distributed elevations forming a grid of rectangular cells.
