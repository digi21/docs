# Import images
<!-- id: importar-imagenes -->
<!-- origen: 483948d4440cb2e4e67bada6f2b1d244727ceaa3 -->

[Import file](/mdtopx/operaciones-con-archivos/importar/importar-archivo.md)

This dialog converts an image before reading it, changing its components or reading only part of it. It contains:

* Source information:
  * Software: application that generated the image.
  * Height: image height in pixels.
  * Width: image width in pixels.
  * Bytes per pixel: number of bytes per pixel.
  * Samples per pixel: number of components per pixel.
  * Georeference: whether georeferencing information is present.
* Target information:
  * Min col: column at which to start reading. Defaults to zero.
  * Max col: column at which to stop reading. Defaults to image width.
  * Min row: row at which to start reading. Defaults to zero.
  * Max row: row at which to stop reading. Defaults to image height.
  * Component 1: component saved first. Defaults to red.
  * Component 2: component saved second. Defaults to green.
  * Component 3: component saved third. Defaults to blue.
