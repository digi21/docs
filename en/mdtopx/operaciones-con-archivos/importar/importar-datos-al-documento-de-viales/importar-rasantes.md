# Import grade lines
<!-- id: importar-rasantes -->
<!-- origen: c514be953a111cf142ca3a7fca15cb87b9ca9ce7 -->

[Roads module](../../../modulo-viales/)

When importing grade line files from other programs, a dialog assigns the imported grade lines to existing horizontal alignments.

The left list shows imported grade lines; the right list shows existing horizontal alignments. Both lists include lengths to help identify elements. The lower list shows associated elements: add associations with **Add** and remove them with **Delete**.
