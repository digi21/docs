# Export BIN, DXF or DGN files
<!-- id: exportar-archivos-bin-dxf-o-dgn -->
<!-- origen: cfa07fd7cd492ce1fabcb55b576d50b7765345f1 -->

The application exports digital models as drawing files for DIGI, AutoCad or MicroStation. Export converts the information into drawing entities, so the result can no longer be used for digital model calculations; it is only a drawing.

Windows file selection opens with additional options below. Specify the file name, folder and information to export:

* **Vertexes**: saves digital model points as point entities.
* **Triangles**: for DIGI or MicroStation, saves triangles as closed four-point entities. For AutoCad, saves them as 3DFACE entities.
* **Limit**: saves inner or outer boundaries as entities.
* **Breaklines**: saves the breaklines retained when the digital model was created as entities.
