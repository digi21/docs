# Export SGE, ArcView or Socet Set files
<!-- id: exportar-archivos-sge-arcview-o-socet-set -->
<!-- origen: 2cff742c198ea13879827578d03fa4efc8de9f9d -->

The application exports digital terrain models in SGE format for the Servicio Geográfico del Ejército, or in formats for ArcView or Socet Set.

Windows file selection specifies the file name and folder. Additional digital model information is required:

* **Grid boundaries**: rectangular grid boundaries in meters.
* **Grid frequency**: grid point increment in meters.
