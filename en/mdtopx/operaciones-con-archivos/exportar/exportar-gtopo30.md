# Export GTOPO30
<!-- id: exportar-gtopo30 -->
<!-- origen: 40a8b0b035fcb80667332719d8f35f42f719bb00 -->

The program exports the generated digital model to USGS GTOPO30 format. Windows file selection specifies the file name and folder, with two additional fields for grid spacing and point elevation units:

![Export to GTOPO30 dialog](../../../images/dialogo-exportar-gtopo30.jpg)

Two files are generated: the point grid and a header containing information about the generated digital model.
