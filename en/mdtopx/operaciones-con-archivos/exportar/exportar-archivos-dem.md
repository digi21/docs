# Export DEM files
<!-- id: exportar-archivos-dem -->
<!-- origen: 8ae97f1b10d6e2cb4cc9ebc89ba8e27f9a6d187b -->

The application exports digital terrain models as DEM digital models, VirtuaLand's native format.

Windows file selection specifies the file name and folder. Additional digital model information is required:

* **Grid boundaries**: rectangular grid boundaries in meters.
* **Grid frequency**: grid point increments along X and Y, in meters.
* **Breaklines**: enable this checkbox to export breaklines and form a hybrid model recognized by VirtuaLand. It combines a regular grid with breaklines that can assist later calculations.
