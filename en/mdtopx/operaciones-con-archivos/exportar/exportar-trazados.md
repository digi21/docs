# Export horizontal alignments
<!-- id: exportar-trazados -->
<!-- origen: 7a23e034deed0373aff6df38af8e7dd15b488b97 -->

[Roads module](/mdtopx/modulo-viales/)

When exporting a roads document with the horizontal alignment view active, a dialog associates exported horizontal alignments with vertical alignments, using the latter to assign elevations to the exported drawing entities.

The upper left list shows horizontal alignments; the lower left list shows their vertical alignments. If there are none, _&lt;No height&gt;_ appears. Select it to export the horizontal alignment at zero elevation. The right list shows associated elements: add associations with **Add** and remove them with **Delete**.
