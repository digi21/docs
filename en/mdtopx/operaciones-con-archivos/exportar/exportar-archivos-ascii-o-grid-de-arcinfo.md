# Export ASCII or ArcInfo grid files
<!-- id: exportar-archivos-ascii-o-grid-de-arcinfo -->
<!-- origen: 42cce48e90a3ddf85c6d70783e74deebb0a46919 -->

The application exports digital terrain models as ASCII, an easily readable text file, or GRID for ArcInfo.

Windows file selection specifies the file name and folder. Additional digital model information is required:

* **Grid boundaries**: rectangular grid boundaries in meters.
* **Grid frequency**: grid point increments along X and Y, in meters.
