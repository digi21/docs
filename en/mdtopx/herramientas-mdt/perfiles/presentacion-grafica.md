# Graphic presentation
<!-- id: presentacion-grafica -->
<!-- origen: 51f424825dd2e740b1d57112955847f106a747cb -->

![Graphic presentation dialog](../../../images/image-55.png)

This dialog specifies how to display calculated profiles, setting their spacing and arrangement with these fields:

* **Profile arrangement**: aligns profiles by rows or columns.
* **Number**: profiles per row or column.
* **Separation X/Y**: spacing between profiles on each axis, in meters.
