# Fit to elevation range
<!-- id: ajustar-a-rango-de-altitudes -->
<!-- origen: 7f6bb521626be9251aab5671bda518c93afbc391 -->

[Hypsometric tint map dialog](./)

![Fit to elevation range dialog](../../../images/image-64.png)

This dialog sets a color range's elevation limits. It retains the selected range's colors while proportionally redistributing its divisions between the specified limits. The program initially displays the current digital model's elevation limits, but you can change the maximum and minimum elevations in the dialog.
