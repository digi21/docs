# Codes by elevation difference
<!-- id: codigos-segun-diferencia-de-cota -->
<!-- origen: 85e72214128f413fb952f2d066f733bf4db20841 -->

![Codes by elevation difference dialog](../../../images/image-151.png)

This dialog creates a list linking elevation differences with particular codes, making entities with certain differences easy to identify.

Select a list item to **Delete** or **Edit** it with the corresponding buttons.

Complete **Difference** and **Code** to **Add** new list items.
