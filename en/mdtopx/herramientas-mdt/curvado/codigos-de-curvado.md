# Contour codes

[Contours dialog](./)

![Contour codes dialog](../../../images/image-47.png)

This dialog sets codes for the entities making up the contours:

* **Normal contours**: minor contour code.
* **Index contours**: index contour code.
* **Normal depression contours**: minor depression contour code. These are closed contours around hollows or sinkholes.
* **Index depression contours**: index depression contour code.
* **Contour numbers**: code for index contour label texts.
