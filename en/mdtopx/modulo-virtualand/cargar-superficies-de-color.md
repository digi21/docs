# Load colored surfaces
<!-- id: cargar-superficies-de-color -->
<!-- origen: 173484709460736b7080cdfeaeb409287a25ee62 -->

[VirtuaLand Load](../fichas-de-herramientas/ficha-de-herramientas-virtualand/virtualand-cargar.md)

The program loads colored surfaces onto the digital model, overlaying its triangles or cells. Surfaces must be closed linear entities stored in drawing files \(DIGI, AutoCad or MicroStation format). This dialog specifies their fill color.

The tool displays a dialog for loading new surfaces or unloading current ones, with a list of current surface files. Click **Load...** to load new files. To unload current files, first select them in the list with the left mouse button, using \[Ctrl] and \[Shift] for multiple selection if needed, then click **Download**.

If a file changes after loading, click **Reload** to load it again.

Assign a color to each surface file by selecting it in the list and clicking **Color** to open a color selection dialog.
