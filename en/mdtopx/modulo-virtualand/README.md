# VirtuaLand module
<!-- id: modulo-virtualand -->

[What is MDTopX?](../introduccion/mdtopx.md)

The optional VirtuaLand module provides tools for processing and displaying grid-based digital terrain models \(DEM). These tools serve two purposes:

* Processing digital models to obtain better terrain data and representations. The module includes a smoothing algorithm that produces high-quality subsequent contours. It also automatically extracts breaklines from a point set.
* Displaying models with millions of points very quickly through its visualization engine. Tools drape raster images over the digital model, place trees and buildings on it, and generate AVI videos travelling over it.

The module has its own [tab](../fichas-de-herramientas/ficha-de-herramientas-virtualand/) on the ribbon containing these tools.
