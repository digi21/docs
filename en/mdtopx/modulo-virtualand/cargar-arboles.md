# Load trees
<!-- id: cargar-arboles -->
<!-- origen: 0f1c242af83d5fdeb274cbf61104f24efb42790d -->

[VirtuaLand Load](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-virtualand/virtualand-cargar.md)

The program loads trees onto the digital model as objects fixed to the terrain. These must be point entities stored in drawing files \(DIGI, AutoCad or MicroStation format). The program projects them onto the digital model and replaces them with objects shaped like the selected tree type.

The tool displays a dialog with the following fields:

* **Input file**: drawing file \(BIN, DXF or DGN) storing tree positions. Use the button to the right to open Windows Explorer and find the file.
* **Size of the trees**: tree height in meters.
* **Type of tree**: choose a conifer \(conical crown) or an orange tree \(round crown).
* **Add to current group of trees**: adds to previously loaded trees or replaces them with the newly read trees.
