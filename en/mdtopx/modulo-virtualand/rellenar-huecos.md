# Fill gaps

[VirtuaLand Edit](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-virtualand/virtualand-editar.md)

This tool fills interior grid gaps by interpolating neighboring points. Useful when a grid interpolated from irregular data has areas where the general density was not maintained, creating unwanted gaps.

![Fill gaps dialog](../../images/image-114.png)

The dialog contains two fields:

* **Maximum gap**: maximum gap distance the program should fill by interpolation.
* **Cell size**: current grid cell size, shown to help specify the maximum gap size.

Changes apply to the current document.
