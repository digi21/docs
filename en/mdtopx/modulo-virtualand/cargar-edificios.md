# Load buildings
<!-- id: cargar-edificios -->
<!-- origen: d6c7f8bf0f9ae4de126193f5d5802129d2b4e0e9 -->

[VirtuaLand Load](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-virtualand/virtualand-cargar.md)

The program loads buildings onto the digital model as prisms fixed to the terrain. Buildings must be closed linear entities stored in drawing files \(DIGI, AutoCad or MicroStation format), with elevations at their roof ridge. The program projects them onto the digital model and automatically generates prisms. This dialog also sets their wall and roof colors.

The tool displays a dialog for loading new buildings or unloading current ones, with a list of current building files. Click **Load...** to load new files. To unload current files, first select them in the list with the left mouse button, using \[Ctrl] and \[Shift] for multiple selection if needed, then click **Download**.

If a file changes after loading, click **Reload** to load it again.

Assign wall and roof colors to each building file by selecting it in the list and clicking **Wall color...** or **Roof color...**, respectively, to open a color selection dialog.
