# System requirements
<!-- id: requisitos-del-sistema -->
<!-- origen: 24f9c22bad44fb4d65d0021820963a82c1141605 -->

MDTopX runs on Microsoft Windows \(Vista, 7, 8, 10 or 11), in 32 or 64 bits.

Installing and starting to use MDTopX requires the following hardware and software:

* A processor capable of running 32-bit or 64-bit Windows. A 64-bit processor is recommended to make better use of installed RAM. Multiple cores or processors are also recommended, because the program uses all of them in calculations where appropriate.
* Enough RAM to meet the operating system's requirements. More RAM reduces virtual memory file usage with large files. For LiDAR files, at least 16 GB is recommended, preferably 32 GB.
* 100 MB of available disk space.
* A color monitor supporting 1024 x 768 pixels and 16-bit color with thousands of colors \(millions of colors recommended).
* An OpenGL-compatible video card. 1 GB of video memory is recommended to navigate larger amounts of information.
* A USB port for a hardware dongle.
* A three-button mouse.
* Optionally, a six-degree-of-freedom motion device such as [SpaceMouse \(R)](https://3dconnexion.com/es/spacemouse/). These devices allow translation along all three coordinates and rotation about all three axes.
* An Internet connection is recommended for downloading new versions and accessing help.
