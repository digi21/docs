# Starting the program
<!-- id: inicio-del-programa -->
<!-- origen: 3508f1ddda76a7058eddb49126e3e33b94085c47 -->

The installer creates a shortcut on the Windows desktop and a folder in the Windows Start menu's Programs list.

To start MDTopX:

* Double-click the desktop icon.
* Select Start -&gt; Programs -&gt; Digi21.net -&gt; MDTopX.
