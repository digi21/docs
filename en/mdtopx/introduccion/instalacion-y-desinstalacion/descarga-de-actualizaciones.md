# Downloading updates
<!-- id: descarga-de-actualizaciones -->
<!-- origen: fc853c6911fb6b6678f083b07f2d0ac05a524982 -->

The Digi21.net development team periodically releases new versions with new tools, available to download from its website.

MDTopX users can download new versions from [www.digi21.net/mdtopx](http://www.digi21.net/mdtopx).

An update is a Windows installation file with the .msi extension. Save it to your hard disk or run it directly to update, then follow the installer's instructions.

If your computer has an Internet connection and new version checking is enabled, MDTopX checks for newer versions at startup and offers to download any it finds. Enable or disable checking in [Options](../../otras-herramientas/opciones.md).

You do not need to uninstall the previous version.
