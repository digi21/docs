# Uninstallation
<!-- id: desinstalacion -->
<!-- origen: 3e4634c62195ade1b29249ef0626365172344409 -->

To uninstall MDTopX, use Add or Remove Programs in Windows Control Panel as follows:

* Select Start -&gt; Control Panel.
* Double-click Add or Remove Programs.
* Select MDTopX from the list of removable programs.
* Click Add/Remove.
* Follow the installer's instructions.

Alternatively, use the uninstall shortcut created during installation: Start -&gt; Programs -&gt; Digi21.net -&gt; Uninstall MDTopX.
