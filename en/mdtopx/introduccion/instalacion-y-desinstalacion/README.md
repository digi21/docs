# Installation and uninstallation
<!-- id: instalacion-y-desinstalacion -->
<!-- origen: 4bf5c98b3c6a87b8aaa1ecf79101ab0ed5826f93 -->

For a first installation, there are three steps:

* [Install MDTopX](instalacion-del-programa.md).
* [Install the licensing suite](/mdtopx/introduccion/instalacion-y-desinstalacion/instalacion-de-los-driver.md).
* Run the newly installed **Select dongle for MDTopX** tool to specify which dongle the program should use.

If the application is already installed and you only want a newer version, only the first step is required.
