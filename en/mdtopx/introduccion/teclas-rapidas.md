# Keyboard shortcuts and associated operations
<!-- id: teclas-rapidas -->
<!-- origen: 9ee7ba330f72cc681b728a4f87cfed2dd228b9d5 -->

MDTopX assigns keyboard shortcuts to operations by default. Change assignments in [Options](../otras-herramientas/opciones.md).

The default shortcuts are:

| Key | Associated operation |
| :--- | :--- |
| Ctrl + A | [Open file](../operaciones-con-archivos/abrir-archivo.md) |
| Ctrl + B | [Volume calculation](/mdtopx/desde-linea-de-comando/linea-de-comando-cubicacion.md) |
| Ctrl + C | [Contouring](/mdtopx/desde-linea-de-comando/linea-de-comando-curvado.md) |
| Ctrl + E | [Aspect map](/mdtopx/como/como-mapa-de-orientaciones.md) |
| Ctrl + G | Save document |
| Ctrl + H | [Hypsometric tints](../como/como-mapa-de-tintas-hipsometricas.md) |
| Ctrl + I | Print document |
| Ctrl + L | [Platforms](/mdtopx/herramientas-mdt/plataformas.md) |
| Ctrl + M | [Slope map](/mdtopx/como/como-mapa-de-pendientes.md) |
| Ctrl + O | [Check elevations](../como/como-comprobar-mdt.md) |
| Ctrl + P | [Profiles](/mdtopx/desde-linea-de-comando/linea-de-comando-perfiles.md) |
| Ctrl + R | [Grid](/mdtopx/desde-linea-de-comando/linea-de-comando-rejilla.md) |
| Ctrl + S | [Shading](/mdtopx/desde-linea-de-comando/linea-de-comando-sombreado.md) |
| Ctrl + T | [Triangulation](/mdtopx/desde-linea-de-comando/linea-de-comando-triangulacion.md) |
| Ctrl + U | [Projection](../como/como-proyeccion-sobre-mdt.md) |
| Ctr + Y | Redo |
| Ctrl + Z | Undo |
| F1 | Help |
| F3 | Switch between horizontal and vertical alignment views in a roads document |
| Ctrl + F4 | Close document |
| Alt + F4 | Exit application |
| F4 | Increase vertical exaggeration |
| F5 | Reduce vertical exaggeration |
| F6 | Next document |
| Shift + F6 | Previous document |
| F7 | Increase thickness |
| F8 | Reduce thickness |
| F10 | Access ribbon tabs using the keyboard |
| F11 | Increase movement speed |
| F12 | Reduce movement speed |
| Spacebar | Move view |
| Ctrl | Zoom |
| Space + Ctrl | Rotate view |
| ←↑→↓ | Move the view sideways |
| Shift + ← or → | Change the view's X angle |
| Shift + ↑ or ↓ | Change the view's Y angle |
| Shift + Page Down or Page Up | Change the view's Z angle |
| Esc | Cancel the current command |
| Page Down | Zoom In |
| Page Up | Zoom Out |
| Delete | Delete elements |
| Insert | Insert new DTM vertices |
