# LiDAR pane
<!-- id: panel-lidar -->
<!-- origen: f94da8efd25e7f372923cff29156cbe90de9eb7b -->

[Application panes](/mdtopx/introduccion/paneles-de-la-aplicacion/)

This pane provides quick tools for LiDAR point cloud documents. They are limited to the main LiDAR classes: No classification, Bare ground, Low vegetation, Medium vegetation, Height vegetation and Buildings.

Each class provides:

* **Show**: shows or hides points of that class.
* **Color**: quickly changes the class's display color.
* **Assign**: assigns selected points to the class.
* **Delete**: deletes selected points belonging to the class.

A final button creates a view containing the currently selected points. This tool is also available in [LiDAR File Tools](../../fichas-de-herramientas/ficha-de-herramientas-archivos-lidar/).
