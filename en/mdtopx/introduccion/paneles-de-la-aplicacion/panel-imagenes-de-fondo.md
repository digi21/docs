# Background images pane
<!-- id: panel-imagenes-de-fondo -->
<!-- origen: e59abc6dafba9f7ec3e8dc1bb44a86d3d7948b1f -->

[Application panes](/mdtopx/introduccion/paneles-de-la-aplicacion/)

This pane displays images from a project loaded as the background for a point cloud.

This is usually done from a point cloud when you want to view it together with 360-degree images recorded by a Mobile Mapping device.

There are two ways to load the image project:

* Use **Load** in this pane.
* Use **Background image** on the [LiDAR Files Edit](../../fichas-de-herramientas/ficha-de-herramientas-archivos-lidar/editar-puntos-en-archivos-lidar.md) ribbon.

After loading the project, the program finds the image most centered in the current point cloud. Navigate between loaded images by:

* Using **Previous** and **Next** in this pane.
* Using **Prev image** and **Next image** on the [MMS Background image](../../modulo-mms/imagen-de-fondo.md) ribbon.
* Double-clicking the desired image in the pane's list with the left mouse button.
