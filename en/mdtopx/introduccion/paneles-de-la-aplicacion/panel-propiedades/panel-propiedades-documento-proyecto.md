# Project document Properties pane
<!-- id: panel-propiedades-documento-proyecto -->
<!-- origen: 78f29e87ba95b6e0b3448b40f1addf72270f88b0 -->

[Properties pane](/mdtopx/introduccion/paneles-de-la-aplicacion/panel-propiedades/)

This pane displays information about the current project:

* **Name**: project name.
* **Description**: project information.
* **Path**: folder containing the project.
* **TIN**: number of TIN digital models in the project.
* **DEM**: number of grid digital models in the project.
* **Drawings**: number of vector mapping files in the project.
* **Images**: number of raster documents in the project.
* **Roads**: number of roads documents in the project.
* **File list**: names of project files, grouped by type.
* **Boundaries**: codes of the boundaries representing each file type, and the text identifying each file's name.

Click **+** on the pane's toolbar to add new files to the project.
