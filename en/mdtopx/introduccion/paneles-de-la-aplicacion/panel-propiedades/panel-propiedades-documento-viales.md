# Roads document Properties pane
<!-- id: panel-propiedades-documento-viales -->
<!-- origen: f54a345b66dd7ebaa855c1820d089b14bccd022b -->

[Properties pane](/mdtopx/introduccion/paneles-de-la-aplicacion/panel-propiedades/)

This pane displays information about the current roads document:

* **Roads**: number of roads stored in the file.
* **Boundaries**: maximum and minimum coordinates bounding the document.
* **Road list**: shows the following information for each stored road:
* **Name**: road name.
* **Start**: initial road chainage.
* **Vertical**: number of vertical alignments stored for this horizontal alignment.
