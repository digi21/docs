# Drawing document Properties pane
<!-- id: panel-propiedades-documento-dibujo -->
<!-- origen: 57d3a6f5407baddef558b5276bfa4b85d9c3ae28 -->

[Properties pane](/mdtopx/introduccion/paneles-de-la-aplicacion/panel-propiedades/)

This pane displays information about the current drawing:

* **Lines**: number of linear entities in the file. A linear entity is a sequence of more than one point.
* **Points**: number of point entities, consisting of a single point.
* **Texts**: number of text entities, the map labels.
* **Total**: total number of entities in the file.
* **Erased**: number of deleted elements. Use Compress on the [Edit tools](../../../fichas-de-herramientas/ficha-de-herramientas-editar/) ribbon to remove this information completely.
* **Boundaries**: maximum and minimum coordinates bounding the file.
* **Code list**: lists the file's entity codes, divided into existing and nonexistent codes according to whether they are in the program's [code list](../../../otras-herramientas/lista-de-codigos/). Each code has a name and type \(Line or Text). Click X on the pane's upper toolbar to delete every entity with a given code. If a code is absent from the program's display code list, add it by clicking + on the same toolbar.
