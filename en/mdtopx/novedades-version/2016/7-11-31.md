# MDTopX 7.11.31

Released on 1/31/2016.

## New features

* New tool to delete selected attributes of entities on screen
* New dialog box for editing attributes from the Entity Info
* Possibility of creating a new empty vector drawing document
* Add more information on the dialog box DTM object information
* New tool to generate centroids with the floors of a building, according to their height and projection on DTM
* Possibility of including the slope as link to project surfaces on a point cloud

## Fixes

* Fixed bug when exporting files to Shape file format
* Fixed bug when reducing the size of orthophotos at the time of calculation
