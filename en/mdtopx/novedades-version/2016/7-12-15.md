Released on 2/15/2016.

## New features

* Improved reading / writing files from ESRI ASCII Grid. Before to this enhancement, these files must be imported or exported into digital models based on grid DEM format. Now, you can open and save as a format more
* Posibility to export TIN files to STL format (binary and ASCII). New option in the Export dialog box
* Possibility to export DEM files to STL binary format
* New tool to erase points of DEM files based on their height. The tool is in the toolbar VirtuaLand
* New tool to erase points of DEM files selecting on screen. The tool is in the toolbar VirtuaLand
* New tool to erase points of DEM files from limits stored in a vector file. The tool is in the toolbar VirtuaLand
