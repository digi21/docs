## New features

* New Drawing Comparison Tool
* Possibility of attaching a plan to a wall
* New possibility in plane/wall statistics to delete points outside projection limits
* Separate the Elevation Plan Editing toolbar so that it is only displayed when editing
* Improvements in the calculation of profiles from point clouds
* Possibility to view building plans with unique color and shadows
* New tool for entering points in the maximum and minimum areas of a contour
* Advances in tree detection and feature extraction
* Finished tool to calculate the transformation between two vector files that look alike
* New option to import triangles stored in a DIGI file as a TIN
* New tool to export a point cloud of a 3D TIN
* Global Source Mapping in Case the . E57 has no "pose"
* New options for calling cloud filtering and targeting from the command line
* Rearranged icons
* New possibility to contemplate the file limits stored in a project to speed up sheet cutting
* New Ability to Generate a Leaf Chart from a Project
* Ground Detection Improvements: Adjust maximum distance to point density
* Ability to upload reference vial files
* Possibility to view vial files in projects
* Ability to view plan/wall features in the properties window
* New function to fit a line to a polynomial
* Fixed bug when asking for 3D TIN point info so that dimension cannot be edited
* Added Save Script button in Python window
* Added Empty Python Script button
* Improvements to asphalt and sidewalk detection in MMS files from urban environments
* Improved trunk calculation tool
* Trees and Trunk Tools from Project
