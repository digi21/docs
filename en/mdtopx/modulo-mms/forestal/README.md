# Forestry

[MMS tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-mms.md)

This section groups the tools for point clouds captured in forest environments. They are on the **Forestry** panel of the [LiDAR classification](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-clasificar-lidar.md) tab:

* [**Trees**](clasificar-arboles.md)
* [**Trunks**](clasificar-troncos.md)
* [**Forest inventory**](inventario-forestal.md): the trees of the cloud with their stem, DBH, height and crown, the class of their points, a vector drawing with the trees' attribute table, a DTM with objects and a report with the stand parameters. Works with terrestrial clouds, drone clouds or both. It will replace **Trees** and **Trunks**, which remain available while it is being validated.
