# Delete triangles by slope
<!-- id: borrar-triangulos-por-pendientes -->
<!-- origen: 5c398bb12e77717aa2c44e3a78e956bc2f7dbd0e -->

[Delete TIN triangles](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-edicion-tin/borrar-triangulos-del-tin.md)

This tool removes [digital model](../como/como-triangulacion.md) triangles outside the slope range specified by the user. Specify a minimum slope below which triangles can be removed and a maximum slope above which triangles will also be removed.

![Delete triangles by slope dialog](../../images/image-81.png)

The tool displays a dialog requesting the maximum and minimum slopes. To retain all triangles in flat areas, set Minimum slope to 0. To retain all triangles on steep slopes, set Maximum slope to 90.

Slope values are entered in degrees.
