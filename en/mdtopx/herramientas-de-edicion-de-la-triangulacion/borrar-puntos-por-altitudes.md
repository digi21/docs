# Delete points by elevation
<!-- id: borrar-puntos-por-altitudes -->
<!-- origen: c1dcc9a1afce01bf933d4ea88ee205e6dac6594d -->

[Delete TIN vertices](../fichas-de-herramientas/ficha-de-herramientas-edicion-tin/borra-vertices-del-tin.md)

This tool removes digital model points outside a specified elevation range. Specify the range in the model's elevation units, usually meters.

The tool displays a dialog requesting the maximum and minimum elevations. The program removes points outside this range and retriangulates the affected areas.
