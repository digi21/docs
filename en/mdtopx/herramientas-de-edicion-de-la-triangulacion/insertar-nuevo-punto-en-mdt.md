# Insert a new point in the DTM
<!-- id: insertar-nuevo-punto-en-mdt -->
<!-- origen: 3b0a02f413f8fe741aebfd3c7f7ff0954b9a3f9f -->

This tool inserts a new point in the digital model. Specify the new point's plan position; the application displays a dialog with its elevation interpolated on the triangulation:

![Insert a new point in the DTM dialog](../../images/dialogo-insertar-punto-mdt.jpg)

You can change these values before inserting the point into the triangulation.
