# Projection onto a DTM
<!-- id: como-proyeccion-sobre-mdt -->
<!-- origen: d1afdf24a797f2df2d57ce900dfb8d3a44dbe33e -->

[DTM tools Civil products](../fichas-de-herramientas/ficha-de-herramientas-mdt/productos-civil.md)

This tool assigns elevations to entities without them or compares entity elevations with projected elevations, optionally marking potential errors.

A generated digital model must be the active document, and a drawing file must contain the entities to project.

Run the tool by:

* Clicking Project on the [DTM tools](/mdtopx/herramientas-mdt/) tab.
* Pressing \[CTRL] + \[U].

A [dialog](../herramientas-mdt/proyeccion-sobre-mdt/) requests projection options. Click OK to project the specified file and display a new document. Save it later as DIGI, DXF, DGN or Shape.

This tool also runs from the [command line](../desde-linea-de-comando/linea-de-comando-proyectar-sobre-mdt.md).
