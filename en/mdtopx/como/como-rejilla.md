# Grid
<!-- id: como-rejilla -->
<!-- origen: a01d67f34b6798e3330495f8b683a02dbc62bff6 -->

[DTM tools Raster products](../fichas-de-herramientas/ficha-de-herramientas-mdt/productos-raster.md)

This tool generates regular grids of points projected onto the digital model and creates a new drawing document containing projected points or lines. Another way to extract a DTM point grid is to export to a supported format listed under Export in [File](../introduccion/boton-de-mdtopx.md).

Run the tool by:

* Clicking Grid on the [DTM tools](/mdtopx/herramientas-mdt/) tab.
* Pressing \[CTRL] + \[R].

A [dialog](../herramientas-mdt/rejilla/) configures the grid. Click OK to calculate it and display a new document. Save it later as DIGI, DXF, DGN or Shape.

This tool also runs from the [command line](../desde-linea-de-comando/linea-de-comando-rejilla.md).
