# Aspect map
<!-- id: como-mapa-de-orientaciones -->
<!-- origen: 29e982e571c91693c4c0fb63ee5e3f0e7c2f549f -->

[DTM tools Raster products](../fichas-de-herramientas/ficha-de-herramientas-mdt/)

This tool generates a map with different tones according to the direction each slope faces, helping you understand the relief.

Assign different colors according to the azimuth of the surface's characteristic vector in centesimal degrees.

The map can also be combined with oblique shading to help interpretation.

Aspect maps can be generated only from a digital terrain model, so a digital model document must be active to run the tool.

Run the tool by:

* Clicking Orientations on the [DTM tools](/mdtopx/herramientas-mdt/) tab.
* Pressing \[CTRL] + \[E].

A [dialog](../herramientas-mdt/mapa-de-orientaciones.md) requests aspect map options. Click OK to calculate the DTM aspect map. Save the document later as TIF, BMP or JPEG. Saving also creates an ASCII file with the same name and the ORT extension, containing image georeferencing: upper left corner coordinates and pixel size in meters.
