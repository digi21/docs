# Slope map
<!-- id: como-mapa-de-pendientes -->
<!-- origen: 17e3703500f693d21979329d530fa06516d10446 -->

[DTM tools Raster products](../fichas-de-herramientas/ficha-de-herramientas-mdt/)

This tool generates a map with different tones according to each area's slope, helping you understand the relief.

Assign different colors according to slope values in sexagesimal degrees.

The map can also be combined with oblique shading to help interpretation.

Slope maps can be generated only from a digital terrain model, so a digital model document must be active to run the tool.

Run the tool by:

* Clicking Slopes on the [DTM tools](/mdtopx/herramientas-mdt/) tab.
* Pressing \[CTRL] + \[M].

A [dialog](../herramientas-mdt/mapa-de-pendientes.md) requests slope map options. Click OK to calculate the DTM slope map. Save the document later as TIF, BMP or JPEG. Saving also creates an ASCII file with the same name and the ORT extension, containing image georeferencing: upper left corner coordinates and pixel size in meters.
