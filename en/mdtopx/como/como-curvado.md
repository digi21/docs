# Contouring
<!-- id: como-curvado -->
<!-- origen: 5e21128f2be6e40af22f437c10852577aec2684a -->

[DTM tools Civil products](../fichas-de-herramientas/ficha-de-herramientas-mdt/productos-civil.md)

Contouring produces a map of isolines representing terrain. Contour lines are classified as intermediate or index contours according to elevation.

Contours can be generated only from a digital terrain model, so a digital model document must be active to run the tool.

The tool creates a new drawing document containing contour lines. To view contours with the triangulation for DTM editing or analysis, instead enable Contours on the [DTM tools](../fichas-de-herramientas/ficha-de-herramientas-mdt/) tab while the DTM is active. This previews contouring so you can modify the DTM if necessary. Contours displayed this way are basic, without smoothing or contour path optimization.

Run the tool by:

* Clicking Contours on the [DTM tools](/mdtopx/herramientas-mdt/) tab.
* Pressing \[CTRL] + \[C].

A [dialog](../herramientas-mdt/curvado/) requests contouring options. Click OK to calculate contours and display the resulting document. Save it later as DIGI, DXF, DGN or Shape.

This tool also runs from the [command line](../desde-linea-de-comando/linea-de-comando-curvado.md).

See [Example 1: Contouring from a point cloud](/mdtopx/ejemplos/ejemplo1.md) for an example.
