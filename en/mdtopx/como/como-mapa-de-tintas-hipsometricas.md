# Hypsometric tint map
<!-- id: como-mapa-de-tintas-hipsometricas -->
<!-- origen: a29d18ee6edd33aa780edb014f28e9dd627ffbb5 -->

[DTM tools Raster products](../fichas-de-herramientas/ficha-de-herramientas-mdt/)

A hypsometric tint map represents terrain relief with areas colored according to elevation. A configurable table relates colors to elevation ranges.

Run the tool by:

* Clicking Hypsometric on the [DTM tools](/mdtopx/herramientas-mdt/) tab.
* Pressing \[CTRL] + \[H].

A [dialog](../herramientas-mdt/mapa-de-tintas-hipsometricas/) requests tint map options. Click OK to calculate the map. Save the document later as TIF, BMP or JPEG. Saving also creates an ASCII file with the same name and the ORT extension, containing map georeferencing: upper left corner coordinates and pixel size in meters.

This map can be generated only from a digital terrain model, so a digital model document must be active to run the tool.

This tool also runs from the [command line](../desde-linea-de-comando/linea-de-comando-mapa-de-tintas-hipsometricas.md).

See [Example 4: Obtain a hypsometric tint map](/mdtopx/ejemplos/ejemplo4.md) for an example.
