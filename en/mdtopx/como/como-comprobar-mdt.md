# Check DTM
<!-- id: como-comprobar-mdt -->
<!-- origen: c33f800886b7894f77939e195c0e995ebbce2a9c -->

[DTM tools Civil products](../fichas-de-herramientas/ficha-de-herramientas-mdt/productos-civil.md)

This tool checks for missing contours and elevation errors within a contour or at a spot height. First triangulate a file containing only elevation mapping elements, treating every constant-elevation entity, such as a contour, as a breakline.

Run the tool by:

* Clicking Check on the [DTM tools](/mdtopx/herramientas-mdt/) tab.
* Pressing \[CTRL] + \[O].

A [dialog](/mdtopx/herramientas-mdt/comprobar-mdt.md) requests checking options. The tool does not generate a document, but creates a drawing file containing the errors found.

This tool also runs from the [command line](../desde-linea-de-comando/linea-de-comando-comprobar-mdt.md).
