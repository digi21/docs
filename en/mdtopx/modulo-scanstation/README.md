# ScanStation module
<!-- id: modulo-scanstation -->
<!-- origen: 7faab8bd90530826dbd15a14a084c0d4e4842fe6 -->

[What is MDTopX?](../introduccion/mdtopx.md)

The ScanStation module connects to Leica ScanStation scanners, allowing scanning and data downloads directly from MDTopX.

Its tools include three-dimensional monitoring at a specified interval to track the dimensions of a structure or scene.

Module tools are on the [ScanStation tab](../fichas-de-herramientas/ficha-de-herramientas-scanstation.md).

* [Start Scan](escanear.md)
* [Scanner data](datos-escaner.md)
* [Comparison 3D](comparacion-3d.md)
* [Scan Auto](escaneado-auto.md)
* [Image 360](imagen-360.md)
