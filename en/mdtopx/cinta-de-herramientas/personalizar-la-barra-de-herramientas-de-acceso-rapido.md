# Customize the Quick Access Toolbar
<!-- id: personalizar-la-barra-de-herramientas-de-acceso-rapido -->
<!-- origen: e6cd0f6ab89e0fde0159b36218abc73d97a52924 -->

[Ribbon](/mdtopx/cinta-de-herramientas/)

The customizable Quick Access Toolbar contains commands independent of the displayed tab. Add command buttons and [move it](mover-la-barra-de-herramientas-de-acceso-rapido.md) between two locations.

Add a command from the command list in [Options](../otras-herramientas/opciones.md). Open that dialog in either way:

* Through the [MDTopX button](../introduccion/boton-de-mdtopx.md):
  * Click the [MDTopX button](../introduccion/boton-de-mdtopx.md), then [Options](../otras-herramientas/opciones.md).
  * Click Customize.
* Through the Quick Access Toolbar:
  * Click Customize Quick Access Toolbar.
  * Click More Commands... in the list.

In the dialog, select the commands to make available on the toolbar:

* Choose a command category from the available command list.
* Select a command in that category and click Add.
* After adding the desired commands, click OK.

You can also add commands directly from the ribbon:

* Click the appropriate tab or group to display the desired command.
* Right-click the command and select Add to Quick Access Toolbar.
