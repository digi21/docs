# Ribbon
<!-- id: cinta-de-herramientas -->
<!-- origen: b494dfecad1762680fffa9cf1c01ef130ab92247 -->

[User interface](../introduccion/interfaz-de-usuario.md)

The ribbon replaces toolbars and user menus. It helps you quickly find the commands needed for a task, organizing them into logical groups on tabs.

Available tabs are:

* [Home](../fichas-de-herramientas/ficha-de-herramientas-inicio/): general program functions and viewing commands.
* [Edit](/mdtopx/modulo-laser/editar/): general editing of the current document's data.
* [DTM tools](/mdtopx/herramientas-mdt/): viewing and using digital terrain model documents.
* [Roads](../fichas-de-herramientas/ficha-de-herramientas-viales/): [Roads module](../modulo-viales/) functions.
* [VirtuaLand](../fichas-de-herramientas/ficha-de-herramientas-virtualand/): [VirtuaLand module](../modulo-virtualand/) functions.
* [LiDAR Files](../fichas-de-herramientas/ficha-de-herramientas-archivos-lidar/): general Laser module functions for terrestrial and airborne files.
* [LiDAR points](../fichas-de-herramientas/ficha-de-herramientas-puntos-lidar/): [Laser module](../modulo-laser/) functions specific to airborne data.
* [LiDAR classification](../fichas-de-herramientas/ficha-de-herramientas-clasificar-lidar.md): [Laser module](../modulo-laser/) point classification functions.
* [MMS](../fichas-de-herramientas/ficha-de-herramientas-mms.md): [MMS module](../modulo-mms/) functions.
* [MMI](../fichas-de-herramientas/ficha-de-herramientas-mmi.md): [MMI module](../modulo-mmi/) functions.
* [Buildings](../fichas-de-herramientas/ficha-de-herramientas-edificios.md): [Buildings module](../modulo-edificios/) functions.
* [ScanStation](../fichas-de-herramientas/ficha-de-herramientas-scanstation.md): [ScanStation module](../modulo-scanstation/) functions.
* [Image](../fichas-de-herramientas/ficha-de-herramientas-imagen/): raster image editing.
* [TIN edition](../fichas-de-herramientas/ficha-de-herramientas-edicion-tin/): TIN digital model editing. Appears only when a TIN document is active.
* [3D TIN edition](../fichas-de-herramientas/ficha-de-herramientas-edicion-tin-3d/): three-dimensional TIN model editing. Appears only when a 3D TIN document is active.
* [Project](../fichas-de-herramientas/ficha-de-herramientas-proyecto/): MDTopX project editing. Appears only when a project is active.
* [Horizontal](/mdtopx/modulo-mms/trazado/): horizontal alignment design. Appears only for a roads file in horizontal alignment view.
* [Vertical](/mdtopx/modulo-viales/alzado/): vertical alignment design. Appears only for a roads file in vertical alignment view.

The ribbon also includes a [Quick Access Toolbar](barra-de-herramientas-de-acceso-rapido.md), which is always present and can be configured with the commands you find most useful.

The ribbon does not support:

* Adding or rearranging commands.
* Changing or removing a command or group.
* Adding tabs.
* Switching to earlier MDTop versions' toolbars and menus.

You can:

* [Minimize the ribbon](minimizar-la-cinta-de-herramientas.md) to free screen space.
* [Move the Quick Access Toolbar](mover-la-barra-de-herramientas-de-acceso-rapido.md) above or below the ribbon.
* [Customize the Quick Access Toolbar](personalizar-la-barra-de-herramientas-de-acceso-rapido.md) with buttons for frequently used commands.
* [Use the ribbon with the keyboard](/mdtopx/cinta-de-herramientas/utilizar-la-cinta-de-herramientas-mediante-teclado.md).
