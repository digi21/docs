# Move the Quick Access Toolbar
<!-- id: mover-la-barra-de-herramientas-de-acceso-rapido -->
<!-- origen: c1d0e0dbc02b5e99633dc91d9943cb49f7a62477 -->

[Ribbon](/mdtopx/cinta-de-herramientas/)

The Quick Access Toolbar is customizable and contains commands independent of the currently displayed tab.

It can appear in either location:

* In the upper left corner beside the [MDTopX button](../introduccion/boton-de-mdtopx.md) (default).

![Quick Access Toolbar](../../images/barra-de-herramientas-de-acceso-rapido.jpg)

* Below the ribbon.

![Quick Access Toolbar below the ribbon](../../images/barra-de-herramientas-de-acceso-rapido-debajo.jpg)

Move it to the other location if the current one is inconvenient. If its default location beside the [MDTopX button](../introduccion/boton-de-mdtopx.md) is too far from the workspace, moving it below the ribbon brings it closer. However, that location occupies workspace; keep the default location to maximize working space.

To change the location:

* Click [Customize Quick Access Toolbar](personalizar-la-barra-de-herramientas-de-acceso-rapido.md).
* Click Show Below the Ribbon in the list.
