# Orthophoto module
<!-- id: modulo-ortofoto -->
<!-- origen: e5265875e8a0cbcd3f6eaeae907ea91e75f214ee -->

[What is MDTopX?](../introduccion/mdtopx.md)

The Orthophoto module calculates rectified orthophotographs from georeferenced perspective images and a digital terrain model. Its tools are distributed across the [DTM tools](../fichas-de-herramientas/ficha-de-herramientas-mdt/) and [Image](../fichas-de-herramientas/ficha-de-herramientas-imagen/) tabs, mainly:

* [**Orthophoto**](calculo-de-ortofoto.md): calculates orthorectified images. Available on the [DTM tools tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-mdt/).
* [**Seam Lines**](lineas-de-union.md): calculates seam lines between adjacent orthophotos. Available on the [Image tab](../fichas-de-herramientas/ficha-de-herramientas-imagen/).
* [**Image Mosaic**](mosaico-ortos.md): calculates mosaic sheets covering different adjacent orthophotos. Available on the [Image tab](../fichas-de-herramientas/ficha-de-herramientas-imagen/).
