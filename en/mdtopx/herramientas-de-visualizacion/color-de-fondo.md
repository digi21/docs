# Background color
<!-- id: color-de-fondo -->
<!-- origen: 97fff9ae94b4b57f5c21e4c75a169aedb888fda6 -->

[Home tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-inicio/)

![Background color dialog](../../images/image-77.png)

This dialog selects the background and DTM colors. It also lets you select a background image when a digital model is open.

It contains the following fields:

* **Background color**: selects the background color of open documents. You can also use the Background color command on the [Home tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-inicio/).
* **DTM color**: selects the background color of open documents. You can also use the DTM color command in the [Surface](vista-de-superficie-de-mdt.md) menu on the [DTM tools tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-mdt/).
* **Background image in DTM**: optionally selects a raster background image for open digital model documents.
