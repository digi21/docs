# Switch on/off DTM objects
<!-- id: encender-apagar-objetos-del-mdt -->
<!-- origen: a09645255e48510f927628ab88c60c64271f7a60 -->

[DTM tools: DTM view](../fichas-de-herramientas/ficha-de-herramientas-mdt/vista-de-mdt.md)

![Switch on/off DTM objects dialog](../../images/image-72.png)

This dialog shows or hides objects recorded on the current digital model. It requires a triangulated digital model document containing objects.

The dialog lists the contained objects with the following information:

* **View**: checkbox to show or hide objects of this type.
* **Code**: object type description, taken from the [LiDAR classification list](../modulo-laser/vista/lista-de-clasificaciones.md).
* **Type**: numeric object type code.
* **Number**: number of objects of this type found.
