# Cut by sheets
<!-- id: cortar-por-hojas -->
<!-- origen: 0cfa468f37baf6fbeb02085890d0ecb8f69ddf18 -->

[Edit file](../fichas-de-herramientas/ficha-de-herramientas-editar/editar-archivo.md)

This tool cuts a document using a sheet boundary file, generating one file per boundary. Supply a drawing file \(DIGI, AutoCad or MicroStation format) containing closed sheet boundary entities, each with an interior text naming the new sheet file.

Optionally fit triangles precisely to the boundaries. This generates a document matching the sheet boundaries exactly but requires more calculation and processing time.
