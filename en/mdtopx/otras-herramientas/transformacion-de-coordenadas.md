# Coordinate transformation

This tool transforms a document's coordinates using several transformation types. Its dialog selects the transformation and its parameters.

Fields:

* **Type of transformation**:
  * 2D Helmert
  * 3D Helmert
  * 2D affine
* **Way of introduction of data**:
  * By means of transformation parameters
  * By means of tension
  * By means of data stored in file
  * Using NTV2 grid
  * Using geoid model
  * Selecting points to define the XY plane
  * Transformation by patches based on two sets of points
* **Data**: requested data depends on preceding choices:
  * 2D Helmert by transformation parameters: X and Y translations, rotation angle in grads and scale factor.
  * 2D Helmert by tensor: elements of the 2x2 transformation matrix.
  * 3D Helmert by transformation parameters: X, Y and Z translations, rotation angles in grads and scale factors for each axis.
  * 3D Helmert by tensor: elements of the 3x3 transformation matrix.
  * 2D affine by transformation parameters: X and Y translations, rotation angles in grads and scale factors for each axis.
  * 2D affine by tensor: elements of the 2x2 transformation matrix.
  * Data stored in a file: transformation data in an ASCII file, possibly generated by another program such as TopCal.
  * NTV2 grid: uses an NTV2 grid file. The NTV2 format, developed by Canada's Geodetic Survey Division of Geomatics, is used by IGN for datum transformations such as ED50 to ETRS89 and the reverse. Each grid point defines longitude and latitude shifts between systems. The program interpolates each point's shift and applies it to obtain target coordinates. Specify transformation direction, UTM zone and hemisphere.
  * Geoid model: transforms ellipsoidal heights to orthometric heights. Specify UTM zone and hemisphere.
  * Points defining the target XY plane: graphically selects points defining a plane, transforming the rest of the file onto it. Useful for rotating a plane such as a vertical facade point cloud to coincide with XY. The program opens a [dialog](calcular-plano.md) for managing plane definition points.
  * Piecewise transformation from two point sets: calculates transformations in patches from corresponding points in two files. Supply two point sets with different coordinates in ASCII files with four columns: point number, X, Y, Z. Point numbers identify correspondences. The program triangulates them and calculates a 3D Helmert transformation for each triangle, then transforms current document points using the transformation of the triangle containing each point.
