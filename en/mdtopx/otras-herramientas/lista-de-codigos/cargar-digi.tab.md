# Load DIGI.TAB
<!-- id: cargar-digi.tab -->
<!-- origen: 10aee51b4564c8a86d0a2481876a4603aef6ebda -->

[Code list](/mdtopx/otras-herramientas/lista-de-codigos/)

Load DIGI display codes by specifying DIGI.TAB and DIGI.PAL, which defines colors.

DIGI.TAB stores mapping codes and symbology; DIGI.PAL stores the color palette. Both belong to DIGI.

This displays DIGI files with the same symbology as inside DIGI itself.

If DIGI.PAL is missing or unspecified, the program assigns the standard Ms-DOS operating system colors.
