# New code

[Code list](/mdtopx/otras-herramientas/lista-de-codigos/)

This dialog creates or edits an entity code. Codes distinguish geographic entities, each with its own symbology. Complete these fields:

* **Code name**: new code name or existing code to edit, identifying the cartographic entity type.
* **Entity Type**: line \(C) or text \(T). Line also includes point entities. Hidden when entering a new LiDAR type or return.
* **Width**: line thickness from 0 to 10.
* **Line style**: _Solid_, _Dash_, _Dot_, _Dash-Dot_ or _Dash-Dot-Dot_. Hidden when entering a new LiDAR type or return.
* **Colour...**: color from the Windows palette.
* **Description**: optional explanatory text or description for the new code.
* **Total echoes**: total recorded returns when entering a new LiDAR return.
