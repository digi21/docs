# Code list
<!-- id: lista-de-codigos -->
<!-- origen: 43df4f32e200ecdc14a3bb60712c1f526e349eec -->

This dialog lists codes used to draw entities on screen. Codes absent from the list are displayed in gray with default thickness.

Codes apply to texts or lines, with configurable thickness, color and line style.

Save or load the list as a text file.

Add codes or edit and delete existing ones. **New...** and **Edit...** open a [dialog](codigo-nuevo.md) configuring code display characteristics.

Load codes from the DIGI program's DIGI.TAB table with [Load Digi...](cargar-digi.tab.md).

Changes take effect only when you click **OK** to exit.
