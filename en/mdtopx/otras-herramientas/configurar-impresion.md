# Print setup
<!-- id: configurar-impresion -->
<!-- origen: e260f38c82dcfa1221878298bd4b1a3bf74b7b5f -->

Configure printing for the current document by selecting a print scale or fitting the document to the page. Select its rotation angle as well; the program calculates output dimensions from these settings.

Preview printing with the specified parameters and selected printer. Choose a printer with **Printer**.
