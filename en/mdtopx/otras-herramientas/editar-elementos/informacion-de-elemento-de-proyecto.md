# Project element information
<!-- id: informacion-de-elemento-de-proyecto -->
<!-- origen: ffc7c3707d09e092b7a17ec595b1959f7eee217a -->

[Project pane](/mdtopx/introduccion/paneles-de-la-aplicacion/panel-proyecto.md)

This dialog displays information about a project element:

* Name
* Folder
* Type: TIN, DEM, Drawing, Image or Roads.

**Open file** displays it in the program's main window.

For files containing LiDAR points, [**Info LiDAR**](../../modulo-laser/vista/propiedades-documento-laser.md) displays information about those points.
