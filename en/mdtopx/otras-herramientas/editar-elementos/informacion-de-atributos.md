# Attribute information
<!-- id: informacion-de-atributos -->
<!-- origen: 51eac9ff95d2d883051ee79d59f70490a5219f4d -->

[Elements](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-editar/editar-elementos.md)

This dialog displays attributes of linear or text entities. Attributes link external databases or contain alphanumeric information additional to the graphical representation. Each has three fields:

* **Table**: table index; 1 indicates an internal table.
* **Record**: position in the database.
* **Information**: additional alphanumeric information.

Use **Insert link** to add attributes or **Delete link** to remove them.
