# Laser point information
<!-- id: informacion-de-punto-laser -->
<!-- origen: 6b2a0e941e837c1e811b6280dca60b76354eaec9 -->

[Elements](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-editar/editar-elementos.md)

Requesting information about a LiDAR cloud point displays these properties:

* XYZ position.
* LiDAR intensity.
* Return number.
* Color: click to display as RGB or HSV.
* LiDAR class or type.
* Scan angle at measurement.
* Measurement source point identifier.
* GPS time.
