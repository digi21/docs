# Change code
<!-- id: cambia-codigo -->
<!-- origen: e132bd04155389d07d6e674680c235615632f032 -->

[Edit elements](../../fichas-de-herramientas/ficha-de-herramientas-editar/editar-elementos.md)

This tool replaces an entity code in bulk, in a drawing document or a digital model where entities are breaklines.

Enter the current code and new code names in their fields.

Digital models allow only line changes. Drawing documents allow linear and/or text entities, selected with Entity type.
