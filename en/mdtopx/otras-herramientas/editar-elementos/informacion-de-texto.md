# Text information
<!-- id: informacion-de-texto -->
<!-- origen: 9da98b7e615321db843e1be2532eace82b31f753 -->

[Elements](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-editar/editar-elementos.md)

This dialog displays information about the selected text entity:

* Recording code, which can be changed.
* Text insertion point coordinates \(lower-left corner).
* Editable text content.
* Text orientation, in degrees.
* Text height, in meters.
* Attribute count: edit attributes with **View links**.
