# Line information
<!-- id: informacion-de-linea -->
<!-- origen: b04d99b25aad15a3fec4cb4bd5dfb104be955db0 -->

[Elements](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-editar/editar-elementos.md)

This dialog displays information about the selected linear entity:

* **Code** used to record it, which can be changed.
* **Number of dots** in the line.
* **Number of links**: database links or alphanumeric information. [**View links**](informacion-de-atributos.md) opens a dialog for actions such as inserting or deleting them.
* **Length**
* **Area**, for a closed line. If first and last points differ, click Close to close it.
* **Point list** defining the line. Options:
  * [Edit](informacion-de-punto.md) points by double-clicking them.
  * Add points with [**Insert point**](informacion-de-punto.md).
  * Remove points with **Delete point**.
  * Reverse point order with **Invert direct.**
  * Change all line point elevations with **Change height**. A dialog offers _Maximum elevation_, _Minimum elevation_, _Mean elevation_, _Zero elevation_ or _User-defined_.

For closed entities, [More info...](informacion-adicional-de-linea.md) displays additional shape parameters.
