# Additional line information
<!-- id: informacion-adicional-de-linea -->

[Line information](/mdtopx/otras-herramientas/editar-elementos/informacion-de-linea.md)

This dialog displays additional information about closed linear entities:

* **Shape index**: similarity to a square, from 1 to infinity. An ideal square has value 1; less compact shapes have higher values.
* **Fractal dimension**: polygon complexity expressed through a perimeter-to-area ratio.
* **Compactness**: area/perimeter ratio. Since a circle is most compact, the preceding index can be modified to give circular shapes 1. Compactness ranges from 0 for a linear object to 1 for a circular object.
* **Max inner circle Area**: area of the largest circle fitting inside the shape. For compact objects it approaches actual object area; less compact objects have smaller values.
