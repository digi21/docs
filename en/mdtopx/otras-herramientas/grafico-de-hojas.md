# Sheet layout
<!-- id: grafico-de-hojas -->

[Edit file](../fichas-de-herramientas/ficha-de-herramientas-editar/editar-archivo.md)

This tool creates a new document showing sheets based on the current document's dimensions and these dialog settings:

* **Limits**: current document boundaries.
* **Origin**: generated sheet origin, the layout's lower-left corner.
* **Division format**: sheet cutting criterion: By sheet dimensions.
* **By sheet dimensions**: calculates sheet row and column counts.
* **By number of rows and columns**: calculates each generated sheet's dimensions.
* **Texts**: centroid text inside each sheet, with fixed and variable parts. The variable part contains any number of \# characters, replaced by sheet numbers assigned first by columns, then rows, starting at the lower-left corner.
