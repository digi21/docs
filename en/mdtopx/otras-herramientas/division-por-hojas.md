# Split into sheets
<!-- id: division-por-hojas -->
<!-- origen: 4622646c25f18a1b6416c8305946b6ea2afd67d8 -->

[Edit file](../fichas-de-herramientas/ficha-de-herramientas-editar/editar-archivo.md)

This dialog splits the current vector drawing or grid digital model into sheets.

Fields:

* **Limits**: current document's maximum and minimum coordinates.
* **Origin**: sheet origin, which can differ from the document's minimum coordinates.
* **Division format**: two options:
* **By sheet dimensions**: maximum sheet height and width, in meters.
* **By number of rows and columns**: row and column counts for subdividing the file.
* **Include each sheet frame**: adds a frame around each sheet according to its dimensions.
* **Data output**: resulting sheet names.
* **Name**: characters appended to the original name, with hash signs marking generated file index positions.
* **Format**: output sheet file format. Available formats depend on whether the file is a grid digital model, generic vector file or point cloud.
* **Destination**: folder storing resulting sheets.
