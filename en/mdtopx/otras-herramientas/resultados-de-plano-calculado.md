# Computed plane results
<!-- id: resultados-de-plano-calculado -->
<!-- origen: 9ab7d4789cb83051c6c08c5b5cc7ec948bfae707 -->

[Compute plane dialog](calcular-plano.md)

After accepting the points defining a plane, the program displays final results and asks what to do with them. Plane data can be edited: its normal vector components and position.

Save measured points in an ASCII file for reuse in another calculation.

Also save transformation parameters in an ASCII file read by [Coordinate transformation](transformacion-de-coordenadas.md).
