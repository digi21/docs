# Active using limits
<!-- id: activar-segun-limites -->

[Project limits](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-proyecto/limites-proyecto.md)

This tool enables or disables the display of files included in a project. Select file boundaries on screen. Left-click inside a file's boundary to enable it, or right-click to disable it. Changes appear in the dialog.

It contains the following fields:

* **Active files**: lists project files and whether they are enabled or disabled.
* **Visible**: by default, selecting a file loads it from disk and makes it visible. You can disable its display while still loading and retaining it in memory.
* **TIN**: enables changes to TIN file display settings.
* **DEM**: enables changes to DEM file display settings.
* **Drawings**: enables changes to drawing file display settings.
* **Images**: enables changes to image file display settings.
* **Roads**: enables changes to road file display settings.
