# Extract entities

[Edit project](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-proyecto/editar-proyecto.md)

Complete the following fields in this dialog:

* **Boundary file**: specifies a drawing file containing closed entities to use as clipping boundaries for project files. Click the button to the right of the control to open Windows Explorer and select a file.
* **Output file**: chooses between generating a single file containing all clipped portions of project files or one file for each closed entity in the boundary file.
* **File name**: specifies the output file's name and format. The output is a drawing file, so select a corresponding format \(DIGI, DXF, LAS, etc.). Also specify the folder for the file or files, depending on the preceding selection. File names can use the text of a centroid found inside each closed entity in the boundary file, or a name generated randomly by the program with an index appended. With the second option, the index replaces the '\#' characters in the specified name.
