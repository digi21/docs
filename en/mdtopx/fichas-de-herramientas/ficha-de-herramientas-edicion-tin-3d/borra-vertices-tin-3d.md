# Delete 3D TIN vertices
<!-- id: borra-vertices-tin-3d -->
<!-- origen: fbd58d887f6b327863a0f8447bec4c212a30d04f -->

[3D TIN edition tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-edicion-tin-3d/)

This group contains the following tools for deleting points from the 3D model:

* **Delete vertex**: selects a point to delete on screen. Left-click it to highlight it in red. If it is the desired point, left-click again to confirm. If another point was selected, right-click to search for another at the same location until the desired point is found.
* **Delete vertex by fence**: defines a boundary on screen and deletes all vertices inside it.
