# Insert 3D TIN elements
<!-- id: insertar-elementos-tin-3d -->
<!-- origen: 70c7a0d7bf99a7cf6414b8edb1258bee45a8a3cf -->

[3D TIN edition tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-edicion-tin-3d/)

This group contains tools for adding new points to the model:

* **New point**: specifies a new point's position on screen. The program displays a dialog with coordinates interpolated from surrounding points, which you can accept or change.
* **Points on a plane**: inserts points belonging to a particular plane. Follow these steps:
  * Define the boundary of the insertion area on screen. Enter boundary points with the left mouse button and finish with the right button. Press BACKSPACE while drawing to remove the last point if it is incorrect.
  * The program displays a dialog for calculating the plane. Select model points to use in the calculation. See the Compute plane tool for more information.
  * Finally, a dialog requests the X and Y density of the new point grid belonging to the calculated plane within the specified boundary.
