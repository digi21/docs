# View

[Home tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-inicio/)

This group contains commands controlling the view's appearance:

* [**Code list**](../../otras-herramientas/lista-de-codigos/): displays drawing codes and assigns mapping entities their symbology \(color, thickness, style, etc.).
* **Background color**: displays preset colors or Windows color selection for open documents' background color. You can also select it with [Background](../../herramientas-de-visualizacion/color-de-fondo.md) in this group.
* [**Light**](../../herramientas-de-visualizacion/propiedades-de-iluminacion.md): changes the current document's lighting.
* [**Material**](../../herramientas-de-visualizacion/propiedades-de-material.md): changes the material used to fill digital models.
* [**Background**](../../herramientas-de-visualizacion/color-de-fondo.md): chooses the background color for open documents and the digital models' material color. It also selects a raster background image, such as a sky. Sample sky images are included in the installation folder.
* **Cartesian axes**: displays a graphic showing the Cartesian axes' positions in the current view, useful during rotation. Place it at the view's center or lower left corner.
* **Vertical exaggeration**: sets the current view's vertical exaggeration, emphasizing Z to highlight terrain relief.
* **Point thickness**: sets the thickness of digital model entities, whether points or cells. It also affects laser file point display.
* **Limits**: displays a cube representing the document boundaries.
* **Reference**: displays reference documents loaded with [Load reference](../../operaciones-con-archivos/abrir-archivos-de-referencia.md).
* **Filled surfaces**: displays closed entities with a transparent fill matching the entity color.
* **Opacity**: controls the opacity of closed vector entity fills.

Additional commands are not displayed, but can be added to the [Quick Access Toolbar](../../cinta-de-herramientas/barra-de-herramientas-de-acceso-rapido.md) or invoked with [keyboard shortcuts](../../introduccion/teclas-rapidas.md):

* **More exaggeration**: increases vertical exaggeration. Shortcut: \[F4]. Set its value with [Edit](../../herramientas-de-visualizacion/parametros-de-perspectiva.md) on the [Home tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-inicio/), or with Vertical exaggeration in this group.
* **Less exaggeration**: reduces vertical exaggeration. Shortcut: \[F5]. Set its value with [Edit](/mdtopx/modulo-laser/editar/) or Vertical exaggeration in this group.
* **More width**: increases the current digital model's entity thickness. Shortcut: \[F7]. Set its value with Point thickness in this group.
* **Less width**: reduces the current digital model's entity thickness. Shortcut: \[F8]. Set its value with Point thickness in this group.
