# Point of view

[Home tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-inicio/)

This group contains viewpoint commands:

* [**Edit**](../../herramientas-de-visualizacion/parametros-de-perspectiva.md): opens a dialog containing the current view's display values.
* **Orthogonal view**: displays the model with parallel projection rays.
* **Perspective view**: displays the model with rays converging at a point.
* **Default**: selects a preset viewpoint:
  * _Frontal_
  * _Rear_
  * _Top_
  * _Bottom_
  * _Left_
  * _Right_
