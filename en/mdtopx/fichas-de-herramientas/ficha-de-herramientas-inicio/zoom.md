# Zoom

[Home tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-inicio/)

This group contains zoom and screen navigation commands:

* **Zoom**: zooms in with the left mouse button and out with the right. Hold \[CTRL] to select this tool. \[PAGE DOWN] and \[PAGE UP] also zoom the current document in and out, respectively, as does the mouse wheel if available.
* **Fit window**: fits the entire drawing into the active view. Loaded [reference files](../../operaciones-con-archivos/abrir-archivos-de-referencia.md) are included when calculating the drawing's extent.
* **Fit to selection**: fits selected entities into the active view. Select entities using the **Select** options in [Edit Elements](../ficha-de-herramientas-editar/editar-elementos.md).
* **Zoom window**: fits the view to a window selected with the left mouse button.
* **Zoom center**: centers the image on a point.
* **Zoom to Point**: centers the image on specified coordinates, entered in a [dialog](../../otras-herramientas/editar-elementos/informacion-de-punto.md).
* **Zoom move**: pans the view in real time while you hold the left mouse button and move the mouse. Select this tool by holding \[SPACE]. You can also use arrow keys or press the middle mouse button.
* **Rotate view**: changes the viewpoint for a digital model or drawing document. Hold the left mouse button and move the mouse to rotate about X (vertical mouse movement) or Y (horizontal mouse movement). Hold the right button to rotate about Z. Change these visually determined values with [Edit](/mdtopx/modulo-laser/editar/). Select this tool by holding \[SPACE] + \[CTRL]. You can also hold \[SHIFT] and use \[PAGE DOWN], \[PAGE UP] or the arrow keys.

These commands are mutually exclusive: only one can be selected at a time. Press \[ESC] to return to Arrow, which has no function.

Additional commands are not displayed, but can be added to the [Quick Access Toolbar](../../cinta-de-herramientas/barra-de-herramientas-de-acceso-rapido.md) or invoked with [keyboard shortcuts](../../introduccion/teclas-rapidas.md):

* **More speed**: increases movement speed in the current view. Shortcut: \[F11]. Set the speed value with [Edit](/mdtopx/modulo-laser/editar/).
* **Less speed**: reduces movement speed in the current view. Shortcut: \[F12]. Set the speed value with [Edit](/mdtopx/modulo-laser/editar/).
