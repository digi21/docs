This group contains window organization commands:

* [**Status bar**](../../introduccion/barra-de-estado.md): shows or hides the status bar at the bottom of the program.
* [**Properties**](../../introduccion/paneles-de-la-aplicacion/panel-propiedades/): shows or hides the current document's properties.
* [**Output**](../../introduccion/paneles-de-la-aplicacion/panel-resultados.md): shows or hides tool activity messages.
* [**Project**](../../introduccion/paneles-de-la-aplicacion/panel-proyecto.md): shows or hides the project window listing its files.
* [**LiDAR**](../../introduccion/paneles-de-la-aplicacion/panel-lidar.md): shows or hides quick classification tools for LiDAR files.
* [**Background images**](../../introduccion/paneles-de-la-aplicacion/panel-imagenes-de-fondo.md): shows or hides management of background images loaded through a project.
* **Windows**: manages open document windows:
  * _New Window_: opens another window for the current document. One document can have several windows showing different views.
  * _Tile Windows_: tiles open windows so all are shown at the largest possible size.
  * _Cascade Windows_: arranges windows so their titles remain visible.
  * _Open window list_: lists open windows so you can activate one. The icon in the upper right corner of the window view also displays this list.
  * _Windows..._: opens a dialog for activating windows, saving documents or closing windows. Multiple windows can be selected for closing or saving their documents.
