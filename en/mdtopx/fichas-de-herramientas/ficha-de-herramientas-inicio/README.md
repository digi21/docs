[Ribbon](/mdtopx/cinta-de-herramientas/)

![Home ribbon](../../../images/ficha-de-herramientas-inicio.jpg)

This tab contains general program commands and commands for changing the current view.

They are grouped as follows:

* Arrow: select this when you do not want any tool active.
* [Zoom](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-inicio/zoom.md): commands for zooming and navigating the screen.
* [View](/mdtopx/modulo-laser/vista/): commands controlling the view's appearance.
* [Point of view](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-inicio/punto-de-vista.md): commands controlling the viewpoint.
* [Window](/digi3d-ai/referencia/ventana-de-dibujo/menus/ventana.md): window organization commands.
