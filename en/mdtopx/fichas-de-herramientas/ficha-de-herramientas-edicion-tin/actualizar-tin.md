# Update TIN
<!-- id: actualizar-tin -->
<!-- origen: 00e4f0a9b70a64f9441a520eb51e693e55f14323 -->

[TIN edition tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-edicion-tin/)

This group contains the following tools for updating a TIN digital model:

* **Refresh limit**: recalculates the triangulation's outer and inner boundaries, defined by the generated triangles. The boundary is not updated automatically when the model changes, for example when triangles are deleted or new points inserted, so this command must be run. The triangulation boundary is displayed with a different code, which can be changed in the [TIN document Properties pane](../../introduccion/paneles-de-la-aplicacion/panel-propiedades/panel-propiedades-documento-tin.md).
* **New triangulation**: generates the triangulation again using the available original data.
