[Ribbon](/mdtopx/cinta-de-herramientas/)

![TIN edition ribbon](../../../images/ficha-de-herramientas-edicion-tin.jpg)

This tab contains digital model editing commands. A digital model document must be active for them to be available.

The commands are grouped as follows:

* [**View**](vista-tin.md)
* [**Update**](actualizar-tin.md)
* [**Delete triangles**](borrar-triangulos-del-tin.md)
* [**Delete vertex**](borra-vertices-del-tin.md)
* [**Insert elements**](insertar-elementos-en-el-tin.md)
* [**Generate**](generar-a-partir-del-tin.md)
* [**DTM Objects**](objetos-mdt.md)
