[Ribbon](/mdtopx/cinta-de-herramientas/)

![LiDAR points ribbon](../../../images/ficha-de-herramientas-puntos-lidar.jpg)

This tab contains commands for airborne laser point documents, available with the [Laser module](../../modulo-laser/), in the following groups:

* [Edit by profile](editar-mediante-perfil.md)
* [By classification](../../modulo-laser/segun-clasificacion-lidar/)
* [By echo](../../modulo-laser/segun-eco-lidar/)
* [By origin](../../modulo-laser/segun-punto-de-registro/)
* [By color](../../modulo-laser/segun-color-registrado/)
* [By intensity](../../modulo-laser/segun-intensidad/)
* [By GPS Time](../../modulo-laser/segun-tiempo-gps/)

See also the [LiDAR Files tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-archivos-lidar/) and the [LiDAR classification tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-clasificar-lidar.md).
