# Edit by profile
<!-- id: editar-mediante-perfil -->
<!-- origen: 445511a2836ceed30f2be883907ddc316a61815e -->

[LiDAR points tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-puntos-lidar/)

These tools edit a laser file in an elevation profile:

* **Define profile**: select two points on screen. A new window below the main view displays the section in elevation. It provides the same tools as the upper window; commands apply to the focused view. Click again to hide the profile. Define the profile in an overhead plan view for best results.
* **Move left**: moves the section left relative to the first point, allowing you to continue editing the region.
* **Move right**: moves the section right relative to the first point, allowing you to continue editing the region.
* **Select**: defines a boundary with the left mouse button; finish with the right button.
* **Select above**: selects points vertically above a line.
* **Select below**: selects points vertically below a line.
* **Select left**: selects points horizontally to the left of a line.
* **Select right**: selects points horizontally to the right of a line.
