# Edit tab
<!-- id: ficha-de-herramientas-editar -->
<!-- origen: ff57b90629ef6699d6b7f1b01b9592ea25df874b -->

[Ribbon](/mdtopx/cinta-de-herramientas/)

![Edit ribbon](../../../images/ficha-de-herramientas-editar.jpg)

This tab contains general program commands and commands for changing the current view.

They are grouped as follows:

* [**Insert elements**](insertar-elementos.md): commands for inserting new drawing elements.
* [**Elements**](editar-elementos.md): commands for editing active document elements.
* [**View**](editar-vista.md): commands for viewing the current document's properties.
* [**File**](editar-archivo.md): commands for editing the active document.
