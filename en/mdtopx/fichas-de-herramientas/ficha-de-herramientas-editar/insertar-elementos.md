[Edit tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-editar/)

This group contains commands for inserting new drawing elements in the active document:

* **New line**: inserts lines in a drawing document. Click points with the left mouse button. To select an existing file point, hold SHIFT while clicking. Press Backspace to remove the last point entered. Right-click to finish the line and display its [information dialog](../../otras-herramientas/editar-elementos/informacion-de-linea.md). Accept the information to store the new line in the file.

* **New text**: inserts text in a drawing document. Click the desired location with the left mouse button to display the new text's [information dialog](../../otras-herramientas/editar-elementos/informacion-de-texto.md). Accept the information to store it in the file.
