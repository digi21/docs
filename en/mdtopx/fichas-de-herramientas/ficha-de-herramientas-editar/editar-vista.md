[Edit tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-editar/)

This group contains commands for viewing the current document's properties:

* [**Hypso curve**](../../otras-herramientas/curva-hipsometrica.md): moves a raster image. Specify two screen points defining the displacement. Only its georeferencing file changes; the image itself does not. Available only for image documents.
* **Compute plane**: calculates the 3D plane best fitting a point set and displays results in the [Output pane](../../introduccion/paneles-de-la-aplicacion/panel-resultados.md).
