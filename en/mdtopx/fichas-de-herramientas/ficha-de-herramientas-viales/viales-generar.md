# Roads Generate
<!-- id: viales-generar -->
<!-- origen: 00bb1dabd3e1def8172357f0f3c0ecb45bcbcce4 -->

[Roads tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-viales/)

This group contains Roads module tools generating new documents:

* **Project alignment**: projects an alignment onto a DTM to obtain the terrain profile, useful as an elevation reference when starting a road's vertical design. Load a DTM with Load first. The command switches to horizontal alignment view for left-button selection, then automatically displays the resulting profile and data band in vertical alignment view. Available only with a loaded DTM.
* [**Profile**](../../modulo-viales/generar/perfil-longitudinal-de-viales.md): generates an alignment's longitudinal profile. The program automatically switches to horizontal alignment view for selection, then opens a profile configuration dialog.
* [**Cross sections**](../../modulo-viales/generar/perfiles-transversales-de-viales.md): calculates an alignment's cross profiles in a new drawing document. The program switches to horizontal alignment view for selection, then opens their configuration dialog. Available only with a loaded DTM.
* [**DTM with road**](../../modulo-viales/generar/proyectar-viales-sobre-mdt.md): after designing horizontal and vertical alignments and assigning templates, calculates terrain modified by the new roads on an existing DTM. Load a DTM with Load first. A dialog selects horizontal and vertical alignments to use. Available only with a loaded DTM.
* [**Volume of layers**](../../modulo-viales/generar/cubicar-capas-intermedias.md): calculates material volumes for layers defined in a road's assigned templates. Select the alignment, then configure the dialog.
* [**Mass diagram**](../../modulo-viales/generar/diagrama-de-masas.md): calculates a longitudinal profile showing total road earthwork by chainage.
* [**Sequential points**](../../modulo-viales/generar/obtener-puntos-secuenciales-del-trazado.md): extracts sequential alignment points for later setting out. Select the alignment, then configure the dialog.
