[Ribbon](/mdtopx/cinta-de-herramientas/)

![DTM ribbon](../../../images/ficha-de-herramientas-herramientas-mdt.jpg)

This tab contains digital terrain model commands, grouped as follows:

* [**Triangulate**](../../como/como-triangulacion.md): generates a TIN digital terrain model.
* [**Civil products**](productos-civil.md): generates civil engineering documents.
* [**Raster products**](productos-raster.md): generates raster image documents.
* [**View**](vista-de-mdt.md): manages the DTM view.

Triangulate is available with a drawing document; the remaining tools require an active digital model document.
