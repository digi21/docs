# Raster products
<!-- id: productos-raster -->
<!-- origen: 914035c82b76ec5d8660d7bee6d33f202858deac -->

[DTM tools tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-mdt/)

This group contains commands generating raster image documents:

* [**Hypsometric**](../../como/como-mapa-de-tintas-hipsometricas.md): generates a hypsometric tint map.
* [**Shading**](../../como/como-sombreado.md): generates a shading map.
* [**Orthophoto**](../../modulo-ortofoto/calculo-de-ortofoto.md): calculates orthorectified images. Requires the [Orthophoto module](../../modulo-ortofoto/).
* [**Orientations**](../../como/como-mapa-de-orientaciones.md): generates a slope aspect map.
* [**Slopes**](../../como/como-mapa-de-pendientes.md): generates a slope map.
* [**Grid**](../../como/como-rejilla.md): generates a grid projected onto the digital model.
* [**Visibility**](../../herramientas-mdt/visibilidad.md): calculates the area visible from a given point.
