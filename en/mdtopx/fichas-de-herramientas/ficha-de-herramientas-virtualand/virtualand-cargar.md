# VirtuaLand Load
<!-- id: virtualand-cargar -->
<!-- origen: 15aa2f4411bcf7b2905b16570e4c0b4e0807b96d -->

[VirtuaLand tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-virtualand/)

This group loads items onto the model:

* [**Textures**](../../modulo-virtualand/cargar-texturas/): overlays textures on triangles or cells.
* [**Export OBJ**](../../modulo-virtualand/exportar-obj.md): exports a Wavefront OBJ file with the loaded textures for use in other 3D applications.
* [**Integrate textures**](../../modulo-virtualand/integrar-texturas.md): saves the loaded textures inside the model file so that they load automatically when it opens.
* [**Remove integrated textures**](../../modulo-virtualand/integrar-texturas.md#remove-integrated-textures): removes textures stored inside the model.
* [**Colored surfaces**](../../modulo-virtualand/cargar-superficies-de-color.md): overlays colored surfaces on triangles or cells.
* [**Buildings**](../../modulo-virtualand/cargar-edificios.md): loads building prisms with a fixed height above the terrain.
* [**Trees**](../../modulo-virtualand/cargar-arboles.md): loads tree objects onto the terrain.
* [**Web Map Services**](../../modulo-virtualand/web-map-services.md): downloads raster data from free geospatial servers.
