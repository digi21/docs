# Project limits
<!-- id: limites-proyecto -->
<!-- origen: ac05e546da3ef464999c884da293533bd432f44d -->

[Project tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-proyecto/)

This group contains calculation tools for the boundaries of files included in an MDTopX project:

* **View limits**: shows or hides the boundaries of each file included in the project.
* [**Refresh limits**](../../herramientas-proyectos/regenerar-limites.md): recalculates the boundaries of the different project files.
* [**Active using limits**](../../herramientas-proyectos/activar-segun-limites.md): enables or disables the display of project files. To enable a file, left-click inside its boundary. To disable a file, right-click inside its boundary.
* **Export limits**: generates a new drawing document containing the boundaries of files included in the project.
