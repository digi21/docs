# Edit project

[Project tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-proyecto/)

This group contains editing tools for files included in an MDTopX project:

* [**Extract entities**](../../herramientas-proyectos/extraer-entidades.md): extracts entities using a file containing clipping boundaries.
* **Path from images**: generates a linear entity joining the positions of georeferenced images included in the project. This is useful for obtaining a linear entity representing the route of a vehicle equipped with a Mobile Mapping system that recorded images.
* [**Sort elements**](../../herramientas-proyectos/ordenar-ficheros.md): sorts files included in the project by one of their properties.
