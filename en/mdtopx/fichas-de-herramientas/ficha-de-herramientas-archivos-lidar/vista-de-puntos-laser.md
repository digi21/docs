# Laser point view
<!-- id: vista-de-puntos-laser -->
<!-- origen: 41302eb8762caf81291ef33dd738d73602d193b4 -->

[Laser tab](../ficha-de-herramientas-puntos-lidar/)

* [**Preprocess Laser**](../../modulo-laser/vista/preprocesar.md): processes the file without displaying it.
* [**Laser Doc properties**](../../modulo-laser/vista/propiedades-documento-laser.md): displays the current document's properties.
* [**Cloud color**](../../modulo-laser/vista/color-de-nube.md): selects how to display points from a list.
* [**Classification list**](../../modulo-laser/vista/lista-de-clasificaciones.md): opens a dialog defining the colors for each point classification.
* [**Echo list**](../../modulo-laser/vista/lista-de-ecos.md): opens a dialog defining the colors for each point return type.
* **View with selection**: after selecting points, isolates them in the view so you can edit a region without displaying the entire file. Click again to display all points.
