This group contains calculation tools that use images to generate new documents:

* [**Join images**](../../herramientas-para-imagenes/unir-imagenes.md): joins several images into one using their georeferencing values.
* [**Seam Lines**](../../modulo-ortofoto/lineas-de-union.md): calculates seam lines between adjacent orthophotos. Requires the [Orthophoto module](../../modulo-ortofoto/).
* **Edit seam lines**:
* [**Image Mosaic**](../../modulo-ortofoto/mosaico-ortos.md): calculates the sheets covered by different adjacent orthophotos. Requires the [Orthophoto module](../../modulo-ortofoto/).
* [**Limit**](../../herramientas-para-imagenes/generar-limites-de-imagen.md): calculates the vector boundary of pixels with values other than white.
* [**Mipmap**](../../herramientas-para-imagenes/piramidales.md): calculates lower-resolution images derived from the current one.
* [**Differences**](../../herramientas-para-imagenes/diferencias.md): calculates differences between two images covering the same geographical area.
* [**NDVI**](../../herramientas-para-imagenes/ndvi.md): calculates NDVI from false-color images containing infrared values.
* [**Raster to Vector**](../../herramientas-para-imagenes/vectorizar.md): calculates vector boundaries enclosing pixels of a particular color.
