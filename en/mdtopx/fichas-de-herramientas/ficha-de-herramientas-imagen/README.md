![Image ribbon](../../../images/ficha-de-herramientas-imagen.jpg)

This tab contains commands for raster image documents: BMP, TIFF, JPEG or ECW.

The commands are grouped as follows:

* [**Orientation**](orientacion.md): tools for changing image georeferencing.
* [**Edit**](editar-imagen.md): tools for manually changing image content.
* [**Filters**](filtros.md): filters applied automatically to image content.
* [**Transform**](transformar.md):
* [**Compute**](imagen-calcular.md): various image calculation tools.
