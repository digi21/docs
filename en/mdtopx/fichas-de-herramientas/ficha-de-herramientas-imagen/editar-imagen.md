# Edit image
<!-- id: editar-imagen -->
<!-- origen: b22664a18f31c34c3530ee184576160e655712a0 -->

[Image tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-imagen/)

The following image editing tools are available:

* [**Preprocess Image**](../../herramientas-para-imagenes/preprocesar-imagen.md):
* [**Histogram**](../../herramientas-para-imagenes/histograma.md): displays an image's tonal range and redistributes the balance of highlights, midtones and shadows.
* [**Brightness & Contrast**](../../herramientas-para-imagenes/brillo-y-contraste.md): makes simple adjustments to an image's tonal range.
* [**Cut image**](../../herramientas-para-imagenes/cortar-imagen.md): crops an image using coordinates or boundaries stored in a vector file.
* [**Resampling**](../../herramientas-para-imagenes/remuestreo.md): changes an image's pixel size.
