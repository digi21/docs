# Filters
<!-- id: filtros -->
<!-- origen: cf6a6ce6bf21a6a71eef1e2ea7bafd8ae41d17f6 -->

[Image tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-imagen/)

This group contains tools that filter information in a raster file. The following filters are available:

* **Smoothing**: smooths image pixel colors by averaging neighboring pixels using a 3x3 matrix.
* **Find edges**: finds edges between areas with the same tone using the Prewitt operator.
* **Invert colors**: inverts the color stored in each pixel.
* **Enhance edges**: enhances edges between areas with the same tone using the negative Laplacian operator.
* [**Transform to hue**](../../herramientas-para-imagenes/transformar-a-tono.md): replaces RGB colors with combinations of Hue, Value and Saturation \(HSV).
