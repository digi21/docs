# Orientation

<!-- origen: e36d368bbe30c81c11439fd740841f1930460f10 -->

[Image tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-imagen/)

The following tools manage image georeferencing:

* [**Measuring points**](../../herramientas-para-imagenes/orientacion-midiendo-puntos.md): orients the image by specifying points on screen. A vector geometry file must be loaded as a reference to select points.
* **Edit**: changes image orientation parameters using the keyboard. It has two versions:
  * [When run from an image document](../../herramientas-para-imagenes/editar-orientacion-de-imagen.md)
  * [When run from a project containing images](../../herramientas-para-imagenes/editar-orientacion-de-imagenes-desde-archivo.md)
