# Roads module
<!-- id: modulo-viales -->
<!-- origen: 5144fe420ebfa132893a06f9567bceb76c0a0d3a -->

[What is MDTopX?](../introduccion/mdtopx.md)

The optional Roads module designs linear infrastructure and projects it onto terrain using digital terrain models. Its tools construct the geometry needed for road design in plan and elevation.

It provides commands for producing output drawings, including longitudinal profiles, cross sections and projection of designed roads onto a digital terrain model. The resulting modified terrain can be used for contours, volume calculations and other operations.

The module also creates template cross sections to apply to roads and complete their definition.

Road designs are stored in VIA files containing horizontal and vertical design and template cross sections applied along the route. Create a file with [New](../operaciones-con-archivos/archivo-nuevo.md) in the [MDTopX button](/mdtopx/introduccion/boton-de-mdtopx.md) menu.

Unlike other supported files, these have two views, \(Horizontal or Vertical), switched with the corresponding command. This keeps the complete road design together rather than spread across files.

Use dedicated drawing tools to enter road definition entities directly on screen, both horizontally and vertically.

As with other tools, run them through assigned keyboard shortcuts or these tabs:

* [Roads tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-viales/)
* [Horizontal tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-trazado.md)
* [Vertical tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-alzado.md)

Import and export tools support other drawing formats, such as DIGI, DXF, DGN and Shape, and other calculation programs, incorporating entities previously drawn elsewhere into roads.

Export generates a new document with entities from the current view: plan entities in Horizontal view or elevation entities in Vertical view.
