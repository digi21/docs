# Plan configuration
<!-- id: configuracion-de-la-planta -->
<!-- origen: d1b6c2edf74b7d7bec41d003959fa8447cc5f444 -->

[Project roads onto a DTM](/mdtopx/modulo-viales/generar/proyectar-viales-sobre-mdt.md)

This dialog changes options affecting the plan document generated when projecting a road document onto a digital model.

![Plan configuration dialog](../../../images/image-101.png)

Options:

* **Distance between cross sections**: spacing in meters between cross sections used to define the road.
* **Generate chainage texts**: labels each generated cross section with its chainage. Specify text code and height when enabled.
* **Calculate volume**: calculates volume for the road alignment generated.
* **Calculate all layer volumes**: when volume calculation is enabled, calculates the different layers formed by road templates.
* **Report file**: when volume calculation is enabled, generates an ASCII report of calculations. Enter its name in the following field or select its location with the button to the right.
