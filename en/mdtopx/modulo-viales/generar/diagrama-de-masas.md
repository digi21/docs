# Mass diagram

[Roads Generate](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-viales/viales-generar.md)

This tool calculates a longitudinal profile showing total road earthworks by chainage. Left-click an existing alignment in Horizontal view when prompted. The program then displays a dialog.

![Mass diagram dialog](../../../images/image-102.png)

Fields:

* **Select vertical alignment**: vertical alignment used for the diagram.
* **Cross sections settings**: profiles where templates are projected to calculate earthworks.
* **Interval**: spacing in meters.
* **Include original points**: applies templates at alignment points of interest.
* **Start**: diagram starting chainage.
* **End**: diagram ending chainage.
* **Scales**: graph display scale denominators.
* **Other output files**: optional ASCII results report.
* **Annotations**: texts around the diagram, such as name, scales or calculated areas.
* **Position**: one of eight positions for each text.
* **Text code**: recording code.
* **Text height**: text size in meters.
* **Lines codes**: codes for diagram lines:
  * _Box_: outer frame and lower lines.
  * _Inner lines_: lines inside the frame.
* **Volume**: line representing earthwork volume.
* **Include vertical scale**: horizontal interior lines every specified number of m3 of volume.
