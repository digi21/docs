![Intermediate layer volumes dialog](../../../images/image-104.png)

This tool calculates volumes of intermediate layers defined in a road's template cross sections, using cross sections. Its dialog contains:

* **Interval**: spacing along the alignment between cross sections, in meters.
* **Include original points**: includes profiles at characteristic alignment points.
* **Start**: starting chainage in meters, default 0.
* **End**: ending chainage in meters, default total alignment length.
* **Report with volume values for the different layers**.
