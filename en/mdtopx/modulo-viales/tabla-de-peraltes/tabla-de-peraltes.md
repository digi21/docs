# Superelevation table

[Superelevation table list](lista-de-tablas-de-peraltes.md)

This dialog designs a superelevation table for road alignments.

![Superelevations dialog](../../../images/image-95.png)

Fields for creating the table:

* **Name**: unique name identifying the table.
* **Relationship list**: radii and corresponding superelevations. Select a relationship and click **Erase** to remove it.
* **New superelevation**: creates a new radius-to-superelevation relationship. **Add** one by completing:
  * *Radius*: radius in meters. If it matches an existing radius, the program asks whether to change the current relationship.
  * *Super*: slope percentage.
