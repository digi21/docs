# Superelevation table list
<!-- id: lista-de-tablas-de-peraltes -->

[Superelevation table](/mdtopx/modulo-viales/tabla-de-peraltes/tabla-de-peraltes.md)

This tool manages superelevation tables for later application to alignments. Its dialog lists available tables and the radii and superelevations defined in the selected table.

![Superelevation list dialog](../../../images/image-94.png)

Use **Add**, **Edit**, **Duplicate** or **Delete** to manage tables.

Adding or editing opens a [dialog](tabla-de-peraltes.md) with the table's characteristics.
