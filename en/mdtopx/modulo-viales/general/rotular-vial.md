# Label road

[Roads General](../../fichas-de-herramientas/ficha-de-herramientas-viales/viales-general.md)

This tool displays elements to help interpret generated alignments: marks perpendicular to the road's direction, optionally accompanied by texts describing the road at that point.

![Label road dialog](../../../images/image-90.png)

The dialog contains these fields:

* **Perpendicular marks to the road**: generates perpendicular line marks at a specified distance interval and, if enabled, at special points. Lines use the specified width and code.
* **Perpendicular mark and information text**: generates a second set of wider marks, optionally with texts containing chainage or special point information and road characteristics there, radius and clothoid parameter. Assign separate heights and codes to each text using the corresponding fields.
