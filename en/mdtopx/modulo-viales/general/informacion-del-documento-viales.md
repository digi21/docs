# Road document information
<!-- id: informacion-del-documento-viales -->
<!-- origen: a3b44b8a5ab1ced6dd72373bb2faf02341cb58cb -->

[Roads General](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-viales/viales-general.md)

This tool displays information about the current road document and its elements, and configures longitudinal profile appearance in Vertical view.

![Road information dialog](../../../images/image-87.png)

It displays:

* Maximum and minimum coordinates of contained elements.
* Horizontal alignment list. Changing its selection updates the vertical alignment list below.
* Vertical alignment list for each horizontal alignment.

Two arrows to the right of the horizontal alignment list move alignments up or down, changing their order in the file. This determines longitudinal profile order in Vertical view.

Configure longitudinal profile appearance by setting horizontal and vertical scales, [annotation information](../generar/guitarra-de-viales.md) and [graphic presentation](../../herramientas-mdt/perfiles/presentacion-grafica.md).
