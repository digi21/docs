# Edit an alignment
<!-- id: editar-un-trazado -->
<!-- origen: 954489b575d308ea3958c8b9ea2348e3bc0841e9 -->

[Horizontal tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-trazado.md)

Graphically edit an existing alignment with Edit alignment on the [Horizontal tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-trazado.md).

Left-click the alignment to edit, then left-click the point to move. If another point in the same area is selected, right-click to keep searching there.

Drag the selected point while holding the left mouse button.

The recalculated alignment depends on the selected point's type and properties:

* Moving a non-clothoid curve's tangent point changes its radius without changing tangent directions.
* Moving a clothoid curve's tangent point changes its parameter without changing the central curve radius or tangent directions.
* Moving a vertex containing a curved element changes tangent directions without changing the radius.
