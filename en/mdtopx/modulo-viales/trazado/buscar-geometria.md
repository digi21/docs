# Find geometry
<!-- id: buscar-geometria -->
<!-- origen: 0a10fc94188487619e81702ff69ad4cee00cf058 -->

[Horizontal tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-trazado.md)

![Find geometry dialog](../../../images/image-29.png)

This tool calculates the elements defining a point sequence, distinguishing straight and curved elements. Various fitting operations locate curve entry and exit tangents and define their radii.

Required parameters:

* Generalization
* Fitting
* Maximum distance of points on curve
* Minimum and maximum radii
* Output file

After calculation, the program displays the calculated [alignment definition](informacion-del-trazado.md).
