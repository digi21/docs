# Find neighbors
<!-- id: buscar-vecinos -->
<!-- origen: c5dae55c2d8c1584c20ed8a8506cde89a8606645 -->

[LiDAR classification tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-clasificar-lidar.md)

Finds and classifies points adjacent to points already assigned a particular type, extending a classification from points classified by other means. The program requests the **Type** and a **Height tolerance** for extending the classified surface.
