# Get stations
<!-- id: obtener-estaciones -->
<!-- origen: 9f31c028b6297967d4a3bacf5a9cfd0986f69dab -->

[Generate from LiDAR](../../fichas-de-herramientas/ficha-de-herramientas-archivos-lidar/calcular-a-partir-de-lidar.md)

Extracts scanner station positions from a point cloud acquired by static scanning.

![Get stations dialog](../../../images/image-153.png)

Options:

* **Show points**: point entity for each station.
* **Show numbers**: station number text at the specified Text height.
* **Show elevation**: station elevation text at the specified Text height.
* **Sequential line**: line joining stations in sequence.
