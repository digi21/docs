# Laser module
<!-- id: modulo-laser -->
<!-- origen: 280d1332c5df39aee079b00eeacca82a6bf7e2f5 -->

[What is MDTopX?](../introduccion/mdtopx.md)

The optional Laser module processes information from laser measuring instruments such as airborne LiDAR or terrestrial laser scanners. These devices record object points in files of different formats.

The module has three ribbon tabs, [LiDAR Files](../fichas-de-herramientas/ficha-de-herramientas-archivos-lidar/), [LiDAR points](../fichas-de-herramientas/ficha-de-herramientas-puntos-lidar/) and [LiDAR classification](../fichas-de-herramientas/ficha-de-herramientas-clasificar-lidar.md), with commands for point documents acquired by laser measuring devices.
