# Generate digital model
<!-- id: obtener-modelo-digital -->

[Laser tab](../../fichas-de-herramientas/ficha-de-herramientas-archivos-lidar/)

Tools for generating a digital terrain model from a laser point file:

* [**Model 2D**](triangulacion-2d.md): generates a TIN digital terrain model using Delaunay triangulation.
* [**Model 3D**](triangulacion-3d.md): generates a TIN digital terrain model using Delaunay tetrahedralization.
* [**Model 2D from file**](triangulacion-2d.md): generates a TIN digital terrain model using Delaunay triangulation, reading multiple data files directly from disk.
* [**Model 3D from file**](triangulacion-3d.md): generates a TIN digital terrain model using Delaunay tetrahedralization, reading multiple data files directly from disk.
