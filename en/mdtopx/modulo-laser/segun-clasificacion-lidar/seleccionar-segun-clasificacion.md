# Select by classification
<!-- id: seleccionar-segun-clasificacion -->
<!-- origen: 1683751a1dc35c01912d8b7c3cd7a35cb1063fc0 -->

[By LiDAR classification](/mdtopx/modulo-laser/segun-clasificacion-lidar/)

Selects file points matching the specified LiDAR classification and saves them in a new document.

![Select by classification dialog](../../../images/image-131.png)

Required parameters:

* **Select typologies**: point classifications of the points to select.
* **Only in the selection**: processes only currently selected points.
* **Remove from source document**
