# Delete by classification
<!-- id: borrar-segun-clasificacion -->
<!-- origen: da29504c817393280659355b9fc4b87b09fc9e6a -->

[By LiDAR classification](/mdtopx/modulo-laser/segun-clasificacion-lidar/)

Removes file points matching the specified LiDAR classification.

![Delete by classification dialog](../../../images/image-130.png)

Required parameters:

* **Select typologies**: point classifications of the points to delete.
* **Only in the selection**: processes only currently selected points.
