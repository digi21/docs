# By LiDAR classification
<!-- id: segun-clasificacion-lidar -->
<!-- origen: 579ebbb1bff1ba487c6e883487192ad105b34a16 -->

[LiDAR points tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-puntos-lidar/)

Tools based on point LiDAR classification:

* [**Change on screen**](../editar/cambiar-clasificacion-en-grafico.md): changes classification by manually selecting points on screen.
* [**Delete**](borrar-segun-clasificacion.md): removes points with a specified LiDAR classification.
* [**Select**](seleccionar-segun-clasificacion.md): selects points with a specified classification and saves them in a new document.
* [**Change**](cambiar-clasificacion.md): changes LiDAR point classification.

For main classifications, these tools are also available in the [LiDAR pane](../../introduccion/paneles-de-la-aplicacion/panel-lidar.md), allowing faster execution without dialogs.
