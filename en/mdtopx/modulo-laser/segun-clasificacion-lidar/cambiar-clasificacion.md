# Change classification
<!-- id: cambiar-clasificacion -->
<!-- origen: b5d705f7aebef60b4fac1fdcf77e783f83e918e3 -->

[By LiDAR classification](/mdtopx/modulo-laser/segun-clasificacion-lidar/)

Changes LiDAR point classification.

![Change classification dialog](../../../images/image-129.png)

Required parameters:

* **Select source typologies**: source classifications to change.
* **Select target typology**: classification to assign to the selected points.
* **Only in the selection**: processes only currently selected points.
