# Delete by GPS time
<!-- id: borrar-segun-tiempo-gps -->
<!-- origen: b587e90c4b5ca36593ce1858ca8895f6cf813fd3 -->

[By GPS time](/mdtopx/modulo-laser/segun-tiempo-gps/)

Removes file points matching the specified recorded GPS time.

![Delete by GPS time dialog](../../../images/image-147.png)

Required parameters:

* **Select boundaries**: minimum and maximum GPS time values for points to delete. A histogram of file points helps choose limits. Move the mouse over it to display the point count and corresponding value.
* **Only in the selection**: processes only currently selected points.
