# Select by GPS time
<!-- id: seleccionar-segun-tiempo-gps -->
<!-- origen: 818c7e08e19a638c3acb0a1cb785363731bbec01 -->

[By GPS time](/mdtopx/modulo-laser/segun-tiempo-gps/)

Selects file points matching the specified recorded GPS time and saves them in a new document.

![Select by GPS time dialog](../../../images/image-148.png)

Required parameters:

* **Select boundaries**: minimum and maximum GPS time values for points to select. A histogram of file points helps choose limits. Move the mouse over it to display the point count and corresponding value.
* **Only in the selection**: processes only currently selected points.
