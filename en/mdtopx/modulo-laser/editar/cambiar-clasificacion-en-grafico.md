# Change classification on screen
<!-- id: cambiar-clasificacion-en-grafico -->
<!-- origen: 11b9c36e7274326361ea8d63c7c057535769db40 -->

[Edit LiDAR points](../../fichas-de-herramientas/ficha-de-herramientas-archivos-lidar/editar-puntos-en-archivos-lidar.md)

This tool changes LiDAR classification by manually selecting points on screen.

![Change classification on screen dialog](../../../images/image-125.png)

Required parameters:

* **Select source typologies**: classifications to change. Only points selected on screen whose current classification matches a listed selection are changed.
* **Select target typology**: classification assigned to selected points.
* **Only in the selection**: processes only currently selected points.
