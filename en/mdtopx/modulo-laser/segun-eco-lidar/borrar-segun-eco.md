# Delete by echo
<!-- id: borrar-segun-eco -->
<!-- origen: 0187fdfbd917609fbec08c9f6b6da1a1581d8b2f -->

[By LiDAR echo](/mdtopx/modulo-laser/segun-eco-lidar/)

Removes file points matching the specified LiDAR return type.

![Delete by echo dialog](../../../images/image-135.png)

Required parameters:

* **Select echo**: point return types of the points to delete.
* **Only in the selection**: processes only currently selected points.
