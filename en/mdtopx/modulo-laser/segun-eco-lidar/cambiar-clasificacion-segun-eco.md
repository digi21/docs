# Change classification by echo
<!-- id: cambiar-clasificacion-segun-eco -->
<!-- origen: 1fd04734bfc5fa6023c68427692f766e108006f8 -->

[By LiDAR echo](./)

Changes LiDAR point classification according to return type.

![Change classification by echo dialog](../../../images/image-132.png)

Required parameters:

* **Select source echo**: source return types of points to change.
* **Select target typology**: classification to assign to the selected points.
* **Only in the selection**: processes only currently selected points.
