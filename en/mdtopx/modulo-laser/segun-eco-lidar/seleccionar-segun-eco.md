# Select by echo
<!-- id: seleccionar-segun-eco -->
<!-- origen: cf7e5fa0d075de33eabc0f1ec2be833babef18bf -->

[By LiDAR echo](/mdtopx/modulo-laser/segun-eco-lidar/)

Selects file points matching the specified LiDAR return type and saves them in a new document.

![Select by echo dialog](../../../images/image-134.png)

Required parameters:

* **Select echo**: point return types of the points to select.
* **Only in the selection**: processes only currently selected points.
