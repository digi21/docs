[LiDAR points tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-puntos-lidar/)

Tools based on point LiDAR return:

* [**Delete**](borrar-segun-eco.md): removes points with a specified return type.
* [**Select**](seleccionar-segun-eco.md): selects points with a specified return type and saves them in a new document.
* [**Change**](cambiar-clasificacion-segun-eco.md): changes LiDAR point classification according to return type.
