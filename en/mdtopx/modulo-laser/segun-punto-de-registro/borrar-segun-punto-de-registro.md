# Delete by source point
<!-- id: borrar-segun-punto-de-registro -->
<!-- origen: 2310454b0fa188def98a9443b4b32516cbc0c5a5 -->

[By source point](/mdtopx/modulo-laser/segun-punto-de-registro/)

Removes file points matching the specified measurement source point.

![Delete by source point dialog](../../../images/image-137.png)

Required parameters:

* **Select point source**: measurement source points of the points to delete.
* **Only in the selection**: processes only currently selected points.
