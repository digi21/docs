# Join source points
<!-- id: unir-puntos-de-registro -->
<!-- origen: 15080d2e5c217b32838b272aaea674f3247ba830 -->

[By source point](/mdtopx/modulo-laser/segun-punto-de-registro/)

Joins LiDAR clouds recorded from different source points.

![Join source points dialog](../../../images/image-139.png)

Required parameters:

* **Select source points**: measurement source points whose clouds should be joined.
* **Only in the selection**: processes only currently selected points.
