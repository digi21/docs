# Select by source point
<!-- id: seleccionar-segun-punto-de-registro -->
<!-- origen: 072b72882a5a6a421c095bbc2d404be9c5d7511d -->

[By source point](/mdtopx/modulo-laser/segun-punto-de-registro/)

Selects file points matching the specified measurement source point and saves them in a new document.

![Select by source point dialog](../../../images/image-138.png)

Required parameters:

* **Select point source**: measurement source points of the points to select.
* **Only in the selection**: processes only currently selected points.
