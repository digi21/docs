# By source point
<!-- id: segun-punto-de-registro -->
<!-- origen: cbb3aefb037fc40808a9bd4bf35c44e08dea60df -->

[LiDAR points tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-puntos-lidar/)

Tools based on point measurement origin:

* [**Delete**](borrar-segun-punto-de-registro.md): removes points recorded from a specified LiDAR source point.
* [**Select**](seleccionar-segun-punto-de-registro.md): selects points recorded from a specified source point and saves them in a new document.
* [**Change**](cambiar-segun-punto-de-registro.md): changes the source point.
* [**Join**](unir-puntos-de-registro.md): joins two clouds recorded from different source points.
