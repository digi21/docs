# Change by source point
<!-- id: cambiar-segun-punto-de-registro -->
<!-- origen: 141e2745dc0932ab7f1b1f09fc9461f745761653 -->

[By source point](/mdtopx/modulo-laser/segun-punto-de-registro/)

Changes the source point of LiDAR points.

![Change by source point dialog](../../../images/image-136.png)

Required parameters:

* **Select source point**: measurement source points to change.
* **Select target point**: destination measurement source points to assign.
* **Only in the selection**: processes only currently selected points.
