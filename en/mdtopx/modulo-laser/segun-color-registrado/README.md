# By registered color
<!-- id: segun-color-registrado -->
<!-- origen: 1f650675b779f774931a1d623e299cd6ba100940 -->

[LiDAR points tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-puntos-lidar/)

Tools based on each point's recorded color:

* [**Delete**](borrar-segun-color-registrado.md): removes points recorded with a specified color.
* [**Select**](seleccionar-segun-color-registrado.md): selects points recorded with a specified color and saves them in a new document.
* [**Change**](cambiar-segun-color-registrado.md): changes classification of points recorded with a specified color.
* [**Histogram**](../../herramientas-para-imagenes/histograma.md): displays recorded point colors' tonal range and redistributes highlights, midtones and shadows.
* [**Brightness & Contrast**](../../herramientas-para-imagenes/brillo-y-contraste.md): makes simple tonal range adjustments to recorded point colors.
