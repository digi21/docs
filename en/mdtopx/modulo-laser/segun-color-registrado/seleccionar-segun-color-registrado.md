# Select by registered color
<!-- id: seleccionar-segun-color-registrado -->
<!-- origen: 72531e194cb06d844802e9a88fb5c447c860f68a -->

[By registered color](/mdtopx/modulo-laser/segun-color-registrado/)

Selects file points matching the specified recorded color and saves them in a new document.

![Select by registered color dialog](../../../images/image-142.png)

Required parameters:

* **List of colours**: colors of points to process, specified as RGB components with a plus/minus tolerance for each component. Use **Add**, **Edit** or **Delete**.
* **Only in the selection**: processes only currently selected points.
