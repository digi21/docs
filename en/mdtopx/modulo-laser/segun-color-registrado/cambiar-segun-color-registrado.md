# Change by registered color
<!-- id: cambiar-segun-color-registrado -->
<!-- origen: 379652ef4f57b7f514a4fbfdb2537f08ed97b11a -->

[By registered color](/mdtopx/modulo-laser/segun-color-registrado/)

Changes LiDAR point classification according to each point's recorded color.

![Change by registered color dialog](../../../images/image-140.png)

Required parameters:

* **List of colours**: colors of points to process, specified as RGB components with a plus/minus tolerance for each component. Use **Add**, **Edit** or **Delete**.
* **Select target typology**: classification to assign to the selected points.
* **Only in the selection**: processes only currently selected points.
