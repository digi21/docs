# Laser document properties
<!-- id: propiedades-documento-laser -->
<!-- origen: 8ad184c3596932b0b75b426bb341519f53837a73 -->

[Laser point view](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-archivos-lidar/vista-de-puntos-laser.md)

This dialog displays characteristics of a document containing laser data. The subdivisions of the information appear on the right.

Information is organized as follows:

* **General**: point count, covered area and point density.

![Laser document properties, General tab](../../../images/image-5.png)

* [**Classification**](../segun-clasificacion-lidar/): point counts grouped by assigned LiDAR classification. Select types and click **Delete** to remove them from the current file. A missing description may mean the type is absent from the [Classification list](lista-de-clasificaciones.md); use **Add to list**.

![Laser document properties, Classification tab](../../../images/image-6.png)

* [**Intensity**](../segun-intensidad/): histogram of points by recorded intensity.

![Laser document properties, Intensity tab](../../../images/image-7.png)

* [**Source point**](../segun-punto-de-registro/): point counts grouped by measurement origin. Select origins and click **Delete** to remove them from the current file.

![Laser document properties, Source point tab](../../../images/image-8.png)

* [**Echo**](../segun-eco-lidar/): point counts grouped by recorded return. Select types and click **Delete** to remove them from the current file. A missing description may mean the type is absent from the [Echo list](lista-de-ecos.md); use **Add to list**.

![Laser document properties, Echo tab](../../../images/image-121.png)
