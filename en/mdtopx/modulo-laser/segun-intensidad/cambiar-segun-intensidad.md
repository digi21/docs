# Change by intensity
<!-- id: cambiar-segun-intensidad -->
<!-- origen: 168ee97d9ae38b9664ec0a11b434206dbfabcc0f -->

[By intensity](/mdtopx/modulo-laser/segun-intensidad/)

Changes LiDAR point classification according to each point's recorded intensity.

![Change by intensity dialog](../../../images/image-143.png)

Required parameters:

* **Select boundaries**: minimum and maximum intensity of points to select. A histogram of file points helps choose limits. Move the mouse over it to display the point count and corresponding value.
* **Select target typology**: classification to assign to the selected points.
* **Only in the selection**: processes only currently selected points.
