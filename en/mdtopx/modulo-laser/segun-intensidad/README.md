# By intensity
<!-- id: segun-intensidad -->
<!-- origen: 012f0c916ab1dbbb3fc439554c1f70f81789e9a9 -->

[LiDAR points tab](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-puntos-lidar/)

Tools based on each point's recorded intensity:

* [**Delete**](borrar-segun-intensidad.md): removes points recorded with a specified intensity.
* [**Select**](seleccionar-segun-intensidad.md): selects points recorded with a specified intensity and saves them in a new document.
* [**Change**](cambiar-segun-intensidad.md): changes LiDAR classification by recorded intensity.
* [**Fit limits**](ajustar-limites.md): adjusts intensity values stored in points.
