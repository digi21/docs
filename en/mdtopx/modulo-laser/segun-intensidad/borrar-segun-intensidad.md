# Delete by intensity
<!-- id: borrar-segun-intensidad -->
<!-- origen: a75fa092ec91792c7aa23dc49ac34b6048129b35 -->

[By intensity](/mdtopx/modulo-laser/segun-intensidad/)

Removes file points matching the specified recorded intensity.

![Delete by intensity dialog](../../../images/image-144.png)

Required parameters:

* **Select boundaries**: minimum and maximum intensity values for points to delete. A histogram of file points helps choose limits. Move the mouse over it to display the point count and corresponding value.
* **Only in the selection**: processes only currently selected points.
