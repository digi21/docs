# Fit intensity limits
<!-- id: ajustar-limites -->
<!-- origen: 5d50938368e3de47467105ed5a873d85a4465f2d -->

[By intensity](/mdtopx/modulo-laser/segun-intensidad/)

Adjusts intensity values stored in points.

![Fit intensity limits dialog](../../../images/image-146.png)

Required parameters:

* **Select boundaries**: minimum and maximum intensity within which new point intensity values will be adjusted. A histogram of file points helps choose limits. Move the mouse over it to display the point count and corresponding value.
* **Only in the selection**: processes only currently selected points.
