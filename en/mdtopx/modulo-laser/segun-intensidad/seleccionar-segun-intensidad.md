# Select by intensity
<!-- id: seleccionar-segun-intensidad -->
<!-- origen: 8e0607684ccf99e44cf703f8648f23f553b32635 -->

[By intensity](/mdtopx/modulo-laser/segun-intensidad/)

Selects file points matching the specified recorded intensity and saves them in a new document.

![Select by intensity dialog](../../../images/image-145.png)

Required parameters:

* **Select boundaries**: minimum and maximum intensity values for points to select. A histogram of file points helps choose limits. Move the mouse over it to display the point count and corresponding value.
* **Only in the selection**: processes only currently selected points.
