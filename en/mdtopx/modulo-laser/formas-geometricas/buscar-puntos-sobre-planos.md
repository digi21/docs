# Find points on planes
<!-- id: buscar-puntos-sobre-planos -->
<!-- origen: 4b7510e173ea62a7c518221c1a8543db7e186dd7 -->

[Find geometric shapes](./)

This tool classifies points forming planar surfaces.

![Points on planes dialog](../../../images/image-177.png)

Required fields:

* **Select source typologies**: point classifications considered.
* **Work only on the current selection**: processes only currently selected points.
* **Target type**: classification assigned to points meeting the calculation conditions.
* **Maximum distance among points**: maximum neighbor distance, based on point density. Excessive values include distant points; insufficient values leave points with no related neighbors.
* **Minimum surface area**: minimum area of the formed surface.
* **Maximum distance to plane**: maximum perpendicular distance for a point to belong to the surface.
* **Compute boundaries**: also calculates the vector entity defining the formed surface.
* **Name**: generated vector boundary file name.
* **Overwrite existing file**: replaces an existing file if desired.
* **Load as reference file**: loads vector boundaries after calculation.

Accepting opens a dialog for managing points defining the plane.
