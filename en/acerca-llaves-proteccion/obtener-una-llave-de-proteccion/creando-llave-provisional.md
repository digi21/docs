# Create a temporary software dongle
<!-- id: creando-llave-provisional -->
<!-- origen: 01759a623b31c92d26ad5c5a08f09789d34377be -->

If you have no _Hasp HL_ dongle, create a temporary dongle on your computer. This is a software dongle, so no hardware delivery is needed and you can start using our applications quickly.\
\
After this tutorial, your computer will have a temporary dongle lasting up to 90 days. These dongles evaluate both the program and the computer where installed. After 90 days without hardware problems, we must [convert it](convirtiendo-llave-provisional-permanente.md) to permanent:

1. Install the desired program if not already installed:

    * [Digi3D.AI](/digi3d-ai/referencia/)
    * [MDTopX](/mdtopx/)
    * [Topcal21](https://www.digi21.net/Topcal21/Download)

    These installers include the **Licenses Application Suite**. If using an older installer without it, download and install the [Licenses Application Suite](http://digi21.blob.core.windows.net/download/SetupSuiteLicencias\_es-ES.exe). &#x20;
2. Download [Digi21Demo.v2c](https://digi21.blob.core.windows.net/download/Digi21Demo.v2c), containing the information to create a temporary dongle.
3. Click [http://localhost:1947/\_int\_/checkin.html](http://localhost:1947/\_int\_/checkin.html). _Safenet Admin Control Center_ appears.
4. Click **Browse...**. **Choose files to upload** appears.
5. Select **Digi21Demo.v2c** downloaded in step 2 and click **Open**.
6. Click **Apply File**.

Your temporary dongle is ready. It has no rentals or purchases of our programs. View its contents with [Check licenses](/acerca-llaves-proteccion/programas-relacionados-con-licencias-y-llaves-de-proteccion/comprobar-licencias.md).

Register the newly created dongle in your dashboard:

1. Open [Register](https://www.digi21.net/MisLlaves/Registrar.cshtml) and follow its instructions.

Now assign an activation password:

1. Open [My dongles](https://www.digi21.net/MisLlaves).
2. Find the dongle in the list, enter an **Activation password** (it need not match your website sign-in password), then click **Change**.

If you have several dongles, assign aliases to identify them in your dashboard:

1. Open [My dongles](https://www.digi21.net/MisLlaves).
2. Find the dongle, fill in _Alias_ and click _Change_.

To start using the program:

1. Purchase or update a program.
2. Rent a program.
3. [Request a trial](../demostraciones.md).
