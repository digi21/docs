# Convert a temporary dongle to permanent
<!-- id: convirtiendo-llave-provisional-permanente -->
<!-- origen: b1564dfc796b840a138bbc696a242f022758511b -->

If you have decided to purchase a _software_ dongle:

1. Purchase through this [link](https://www.digi21.net/Tienda/Compra) (select _Hasp SL software dongle_).
2. Download and run [ActualizarLlaveLDK.exe](http://digi21.blob.core.windows.net/download/ActualizarLlaveLDK.exe).\
   It analyzes your dongle and creates a file allowing us to reprogram it remotely.
3. _Sentinel HASP RUS_ appears, with _Collect Key Status Information_ and _Apply License Update_ tabs.
4. On _Collect Key Status Information_, click _Collect Information._
5. _Save Key Status As_ appears.\
   Specify the location and name of the _.c2v_ file to send us.
6. Enter the location and name of the _.c2v_ file to create.
7. Send it to [info@digi21.net](mailto:info@digi21.net) with:
   * Company name.
   * Tax identification number (N.I.F.).
   * Address.
   * Postal code.
   * Contact person.
   * Telephone.
   * The email address you use to sign in to [www.digi21.net](http://www.digi21.net/).

We will reply by email with further instructions.
