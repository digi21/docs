# Activate computer
<!-- id: activar-ordenador -->
<!-- origen: ee065c404944fc7ec99d90930c7c24a7a49aecc2 -->

This program activates a computer in a specified dongle. It requires internet access. If the computer to activate has none, use [Activate computer offline](/acerca-llaves-proteccion/programas-relacionados-con-licencias-y-llaves-de-proteccion/activar-ordenador-offline/).\
\
To activate a computer in a dongle:

1. Click **Start/Programs/Digi21.NET/Licenses/Activate computer**. _Activate computer_ appears.
2. Its introductory _Activate computer_ page appears. Click **Next**.
3. **Select dongle** appears. **Next** is disabled until a dongle is selected from the list. Select the dongle whose licenses you want to check and click **Next**.
4. After a few seconds, **Select the maximum activation date** appears. Specify how long to activate the computer running **Activate computer** in that dongle.

    For a software dongle:

    Only **one computer at a time** can be activated, and the dongle can move to another computer only after activation on the last computer **has expired**.

    The following screenshot shows a dongle with a one-year rental. Clicking Next activates it until September 16, 2014 at 21:08, after which it can move to another computer. Activating until September 16, 2015 would prevent moving it **for one year**.

    **Lost or stolen** dongles, **whether software or hardware**, are replaced only after the last activated computer's expiration date. Each activation stores the maximum date on our servers.

    Select the maximum date and click **Next**.
5. The program requests the dongle's activation password. If forgotten or not yet assigned, set it in [My dongles](http://www.digi21.net/MisLlaves). Enter it and click **Next**.
6. The computer is activated in that dongle, or an error appears if the password is incorrect or the dongle lacks installation permission.
