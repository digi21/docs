# Delete activations and rentals
<!-- id: elimina-activaciones-alquileres -->
<!-- origen: 5b72915a6aad172ccaf337a95915a270ce6860fb -->

This program _formats_ dongle memory reserved for activations and rentals/trials.

Enter the dongle's **Administration password**. Assign it for a particular dongle at [https://www.digi21.net/MisLlaves](https://www.digi21.net/MisLlaves).

**Warning:**\
****This deletes both activations and rentals/trials. Recover rentals/trials by running [Consolidate rental](../consolidar-alquiler.md) afterward.

It can also [compress memory](comprimir-llave.md) if activating a computer produces [There is not enough free space to activate this computer in the dongle](../../solucion-de-problemas/no-hay-espacio-disponible-en-la-llave-de-proteccion.md).
