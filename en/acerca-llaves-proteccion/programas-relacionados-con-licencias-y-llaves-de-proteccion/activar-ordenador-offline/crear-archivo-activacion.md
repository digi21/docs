# Create activation file
<!-- id: crear-archivo-activacion -->
<!-- origen: 0ff6419ffd5384b306d177172ef28968d0108556 -->

This program creates a _computer activation file_ from an _activation request file_ generated by [Activate computer offline](/acerca-llaves-proteccion/programas-relacionados-con-licencias-y-llaves-de-proteccion/activar-ordenador-offline/).

The computer running it needs neither an installed Digi21 program nor any Digi21 product license. Internet access is the only requirement.
