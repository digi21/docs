# Get license files
<!-- id: obtener-archivos-licencia -->
<!-- origen: 2669908c4b462a0f940b61dabf2b0d589503466a -->

This program contacts Digi21's license server and obtains a license file containing a specified dongle's rentals.

Use it later with [Consolidate rental offline](/acerca-llaves-proteccion/programas-relacionados-con-licencias-y-llaves-de-proteccion/consolidar-alquiler-offline/) to program rentals into the dongle.

Internet access is required to obtain licenses.

If the dongle's computer has internet access, use [Consolidate rental](/acerca-llaves-proteccion/programas-relacionados-con-licencias-y-llaves-de-proteccion/consolidar-alquiler.md) instead: it programs the dongle without creating files.

![Get license files program screenshot](../../../images/obtener-archivos-licencia.png)

To obtain newly purchased rental licenses for a dongle:

1. Run **Get license files**, under **Start/Programs/Digi21.net/Licenses/Get license files**.
2. Enter the dongle's **Key ID**.
3. Specify the license output path. License files have extension _.lic_.
4. Click **Create licenses**.

After obtaining the file, program the dongle with [Consolidate rental offline](/acerca-llaves-proteccion/programas-relacionados-con-licencias-y-llaves-de-proteccion/consolidar-alquiler-offline/).
