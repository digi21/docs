# Consolidate rental offline
<!-- id: consolidar-alquiler-offline -->
<!-- origen: 2763ef420a5ed503eed736a70e40292f1f8ca5a3 -->

This program stores purchased rentals in a dongle on a computer without internet access.

The process has two stages:

1. On an internet-connected computer, run [Get license files](/acerca-llaves-proteccion/programas-relacionados-con-licencias-y-llaves-de-proteccion/consolidar-alquiler-offline/obtener-archivos-licencia.md) to generate a license file.
2. On the computer hosting the dongle without internet access, run **Consolidate rental offline** and select that file.

After completion, check the dongle's state with Check licenses.
