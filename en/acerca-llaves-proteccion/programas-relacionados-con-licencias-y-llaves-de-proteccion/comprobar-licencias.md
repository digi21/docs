# Check licenses
<!-- id: comprobar-licencias -->
<!-- origen: cc537ce87f409f69409f6f03c2a07e9c46f3c3e7 -->

This program checks your dongle's licenses.

To check stored licenses:

1. Click **Start/Programs/Digi21.NET/Licenses/Check licenses**. _Check licenses_ appears.
2. **Select dongle** appears. **Next** is disabled until a listed dongle is selected. Select the dongle to check and click **Next**. After a few seconds, **Key's properties** appears.

![Key's properties page with owner details and each product's rental end date](../../images/comprobar-licencias-propiedades.png)

Possible fields and their display conditions:

| Field | Description | Condition |
|---|---|---|
| Key ID | Dongle serial number. | Always shown. |
| Registered to | Dongle owner's name.<br>For temporary dongles, **Digi21.net**. | Always shown. |
| Telephone | Dongle owner's telephone.<br>For temporary dongles, **(34)910052271**. | Always shown. |
| Email | Dongle owner's email.<br>For temporary dongles, **info@digi21.net**. | Always shown. |
| Technical support expiration for: XXX | Technical support expiration for purchased product XXX. | Only for purchased products; one field per product. |
| Rent expiration for: XXX | Rental expiration for product XXX. | Only with an active rental in the dongle. |
| Computer activated on this key until: date/time | Date and time until which the computer running Check licenses is activated in the selected dongle. | Only if that computer is activated in the dongle. |
