# Computer not activated
<!-- id: ordenador-no-activado -->
<!-- origen: bb4a19f27f9ad3f89e5d86ebeab5268bf76dec4a -->

Three possible causes:

1. The computer running the program displaying the message has not been activated in the indicated dongle.
2. That computer's maximum activation date in that dongle has expired.
3. Several dongles are available, no specific one was selected and the program connected to another.

Resolve this with [Activate computer](/acerca-llaves-proteccion/programas-relacionados-con-licencias-y-llaves-de-proteccion/activar-ordenador.md).
