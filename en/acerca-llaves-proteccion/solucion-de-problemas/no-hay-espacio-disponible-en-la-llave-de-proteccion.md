# No space available in the dongle
<!-- id: no-hay-espacio-disponible-en-la-llave-de-proteccion -->
<!-- origen: 17c47dade76e5ed4eebb008d50a4eaafa588a04f -->

If activating a computer with [Activate computer](../programas-relacionados-con-licencias-y-llaves-de-proteccion/activar-ordenador.md) or [Activate computer offline](../programas-relacionados-con-licencias-y-llaves-de-proteccion/activar-ordenador-offline/) shows:

> There is not enough free space to activate this computer in the dongle

The dongle memory reserved for activations is full.

This happens because activation storage is limited.

Use [Delete activations and rentals](../programas-relacionados-con-licencias-y-llaves-de-proteccion/elimina-activaciones-alquileres/) to remove activations and free space to reactivate all computers to be used.

For a network dongle where activations for all potential computers do not fit, [Delete activations and rentals](../programas-relacionados-con-licencias-y-llaves-de-proteccion/elimina-activaciones-alquileres/) provides a checkbox to [compress the dongle](../programas-relacionados-con-licencias-y-llaves-de-proteccion/elimina-activaciones-alquileres/comprimir-llave.md).
