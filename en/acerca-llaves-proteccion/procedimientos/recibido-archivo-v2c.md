# Received V2C file
<!-- id: recibido-archivo-v2c -->
<!-- origen: 7ee0481a2fcd4d89ff63de294a80d38f29f7062c -->

If you converted a temporary dongle to permanent, or purchased a product and requested storing its licenses in your own dongle \(permanent software or hardware\), we will have sent a file with extension _.v2_c.

Update the dongle's memory with the file as follows:

1. Click [http://localhost:1947/\_int\_/checkin.html](http://localhost:1947/_int_/checkin.html). _Sentinel Admin Control Center_ appears.
2. Click _Browse._
3. _Choose files to upload_ appears.
4. Select the emailed _.v2c_ file and click _Open_.
5. Click _Apply File_.

The dongle is now in its factory state, so previous computer activations may have been lost. Activate the computer again:

1. Open your dongle dashboard at [My dongles](http://www.digi21.net/MisLlaves).
2. Assign an activation password to the dongle.
3. Activate it with [Activate computer](/acerca-llaves-proteccion/programas-relacionados-con-licencias-y-llaves-de-proteccion/activar-ordenador.md) if the installation computer has internet access, or Activate computer offline otherwise.
4. Use Check licenses to verify correct activation.
