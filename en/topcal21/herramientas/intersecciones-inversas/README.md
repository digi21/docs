# 3-point resections
<!-- id: intersecciones-inversas -->
<!-- origen: 4985e722b096f1aa9610bfb1233f426f1412ccc3 -->

This tool is used to give coordinates to points by means of 3-point resections. To give coordinates to a point, at least three observations to points of known coordinates are needed, made from the point whose coordinates are to be computed.

If more than one point has to be computed, the tool chooses as the first computation point the one with the most observations to points of known coordinates and then gives coordinates to all the new points in succession.

To carry out this computation, the program only requires horizontal readings in the observations, since the computation is performed in planimetry only. If you want to compute the heights of the points, use the [Altimetry computation](../compensacion-de-altimetria/README.md) tool.

The tool is structured in six steps that guide the user through the computation:

* [Step 1: Enter input data files](paso-1-introducir-ficheros-de-datos-de-entrada.md)
* [Step 2: Point selection](paso-2-seleccion-de-puntos.md)
* [Step 3: Observation selection](paso-3-seleccion-de-visuales.md)
* [Step 4: Computed results](paso-4-resultados-calculados.md)
* [Step 5: Generated residuals](paso-5-residuos-generados.md)
* [Step 6: Output data setup](paso-6-configurar-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
