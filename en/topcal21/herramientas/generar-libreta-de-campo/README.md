# Generate observations
<!-- id: generar-libreta-de-campo -->
<!-- origen: 3ee45b499bb09ccf76d93f0bb3ce9a349e587fab -->

This tool is used to generate a field notebook from a set of points with known coordinates. In other words, it is the reverse of radial survey.

The tool is structured in four steps that guide the user through the computation:

* [Step 1: Enter input data files](paso-1-introducir-ficheros-de-datos-de-entrada.md)
* [Step 2: Station setup](paso-2-configuracion-de-la-estacion.md)
* [Step 3: Target point selection](paso-3-seleccion-de-los-puntos-visados.md)
* [Step 4: Output data setup](paso-4-configurar-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and to change the data or the selections.
