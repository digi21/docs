# Step 3: Observation selection
<!-- id: topcal21-intersecciones-directas-paso-3-seleccion-de-visuales -->
<!-- origen: 84fc1df2649e36d052ba58d7d9fa489e85348e1e -->

This is the third step in computing direct intersections.

![Intersections — Step 3](../../../images/intersecciones-directas-paso3.jpg)

A screen is shown with the observations stored in the observation files selected in *Step 1* that involve points selected in *Step 2*.

The list shown contains the following fields:

* **File index**: Indicates the index of the observation file where the observation is stored.
* **Station point number**
* **Target point number**
* **Horizontal angle**
* **Vertical angle**
* **Distance**: It is shown but is not used in the computation.

You can select multiple observations by holding down the *\[CTRL\]* key and clicking the desired observations with the left mouse button. If you click an observation that is already selected, it is deselected.

You can also select observations arranged in ranges by holding down the *\[SHIFT\]* key and clicking the left mouse button on the boundary observations that define the range.

Likewise, you can use the **All** or **None** buttons to select or deselect all the observations.

When you have selected the desired observations, click the **Next** button to go to [Step 4: Computed results](paso-4-resultados-calculados.md), or click the **Back** button to return to [Step 2: Point selection](paso-2-seleccion-de-puntos.md).
