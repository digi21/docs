# COGO: Radial survey
<!-- id: radiacion -->
<!-- origen: c4b5f47a4f39e001a87a599845249153f0eb23e7 -->

This tool is used to compute the XYZ coordinates of points sighted from a point with known coordinates, or station. Horizontal angle, vertical angle and distance readings are used to compute the coordinate triplet of unknown points.

The tool is structured in four steps that guide the user through the computation:

* [Step 1: Enter input data files](paso-1-introducir-ficheros-de-entrada.md)
* [Step 2: Point selection](paso-2-seleccion-de-puntos.md)
* [Step 3: Observation selection](paso-3-seleccion-de-visuales.md)
* [Step 4: Output data setup](paso-4-configurar-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and to change the data or the selections.
