# Altimetry computation
<!-- id: compensacion-de-altimetria -->
<!-- origen: 8d8a0663cdd7c537a8ebbe0b17396d55eb0c3e97 -->

This tool is used to give a height to a series of points from the coordinates of at least one point, starting from multiple observations between the different points that make up a network, whether or not their heights are known.

The tool is structured in five steps that guide the user through the computation:

* [Step 1: Enter input data files](paso-1-introducir-ficheros-de-datos-de-entrada.md)
* [Step 2: Point selection](paso-2-seleccion-de-puntos.md)
* [Step 3: Observation selection](paso-3-seleccion-de-visuales.md)
* [Step 4: Results and generated residuals](paso-4-resultados-y-residuos-generados.md)
* [Step 5: Output data setup](paso-5-configurar-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and to change the data or the selections.
