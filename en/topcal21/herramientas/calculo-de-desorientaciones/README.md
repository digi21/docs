# Orientations
<!-- id: calculo-de-desorientaciones -->
<!-- origen: ec03fbaa0fe15d0bdd41d90cf6a3c672460dc0fb -->

This tool computes the orientation of a station from the observations to other points. To compute the orientation, coordinates of the station point and of the target point must exist. With these coordinates the azimuth is computed, and with the horizontal angle to the point the orientation can be computed.

Therefore, to perform this type of computation, only horizontal angles between the points are needed, and the coordinates of these points must exist in the point file.

The tool is structured in three steps that guide the user through the computation:

* [Step 1: Enter input data files](paso-1-introducir-ficheros-de-datos-de-entrada.md)
* [Step 2: Station selection](paso-2-seleccion-de-la-estacion.md)
* [Step 3: Observation selection](paso-3-seleccion-de-visuales.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
