# Transformation
<!-- id: transformacion -->
<!-- origen: c4bb3bb23699bd3b478682f598c2b2d847cd459d -->

This tool is used to transform the coordinates of points belonging to one reference system into another reference system, starting from the knowledge of points that are common to both systems.

From these common data, the application computes transformation parameters that it applies to the rest of the points of the file to refer them to the new coordinate system.

The tool is organized in five steps that guide the user through the computation:

* [Step 1: Reference system files selection](paso-1-seleccionar-ficheros-de-ambos-sistemas.md)
* [Step 2: Common points to both systems](paso-2-puntos-comunes-a-ambos-sistemas.md)
* [Step 3:](paso-3-puntos-transformados-y-residuos.md) Residuals
* [Step 4: Transformation parameters](paso-4-parametros-de-la-transformacion.md)
* [Step 5: Transformed points and output](paso-5-puntos-transformados-y-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
