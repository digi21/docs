# Closure of triangles
<!-- id: cierre-de-triangulos -->
<!-- origen: 883772bd49f1d06d6f85b595eab526b17c7d4d43 -->

This tool closes triangles by means of the observations made between the points. With it you can find gross errors in those observations, because the triangles must close at 200 grads. Triangles can be closed only if direct and reciprocal horizontal angles exist between the points.

The tool is structured in three steps that guide the user through the computation:

* [Step 1: Observation selection](paso-1-seleccion-de-visuales.md)
* [Step 2: Repeated and non-reciprocal observations](paso-2-visuales-repetidas-y-sin-reciproca.md)
* [Step 3: Resulting closures](paso-3-cierres-resultantes.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
