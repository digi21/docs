# 2-point resection
<!-- id: biseccion-mixta -->
<!-- origen: 1b0e4d4e8c582d2ef2f8818c33c9bebc9873e139 -->

This tool gives coordinates to a point by means of the angle and distance observations made from that point to two other points of known coordinates. To carry out the computation, at least one measured distance to these points is needed. In addition, the program computes the elevation coordinate.

The tool is structured in two steps that guide the user through the computation:

* [Step 1: Enter input data files](paso-1-introducir-ficheros-de-datos-de-entrada.md)
* [Step 2: Calculation and output data setup](paso-2-configurar-calculo-y-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
