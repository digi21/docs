# Hansen's problem
<!-- id: intersecciones-de-hansen -->
<!-- origen: b073e5c85de49b83775458667e0c611ce3fda0f2 -->

This tool gives coordinates to two points by means of the observations made from both of them to two other points with known coordinates. To proceed with the computation, three observations are needed from each unknown point: one to the other unknown point and two to the points with known coordinates.

To perform this computation, the application only requires horizontal angle readings in the observations, because the computation is carried out in planimetry only. If you want to compute the heights of the points, use the [Altimetry computation](../compensacion-de-altimetria/README.md) tool.

The tool is structured in two steps that guide the user through the computation:

* [Step 1: Enter input data files](paso-1-introducir-ficheros-de-datos-de-entrada.md)
* [Step 2: Calculation and output data setup](paso-2-configurar-calculo-y-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and to change the data or the selections.
