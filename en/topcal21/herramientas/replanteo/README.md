# Stakeout
<!-- id: replanteo -->
<!-- origen: e7cd284f520a65a04ea5af8210c56a4033f3d2df -->

This tool is used to obtain the angular and distance observations needed to restore or place points that do not exist on the ground, from the knowledge of their coordinates. This operation is called stakeout.

The tool is structured in three steps that guide the user through the computation:

* [Step 1: Enter input data files](paso-1-introducir-ficheros-de-datos-de-entrada.md)
* [Step 2: Station point selection](paso-2-seleccion-de-puntos-estacion.md)
* [Step 3: Target point selection](paso-3-seleccion-de-puntos-visados.md)

Use the **Next** and **Back** buttons to move between steps and to change the data or the selections.
