# Topcal21 web

Topcal21 web, at [https://topcal21.ai](https://topcal21.ai), is the version of Topcal21 that runs in the browser. It computes with the same formulas and algorithms as [Topcal21 for Windows](../README.md) and works with the same files: projects (`.prt`), point files (`.pts`) and observation files (`.obs`). The website keeps sketches (`.crq`) in projects, but it does not yet open or edit them.

Each user has a personal file space in the cloud. The user uploads the project files to that space from the browser and downloads them to open them with Topcal21 for Windows. The website does not convert any file in either direction.

Topcal21 web is free during the trial period. Digi21 will give notice before it starts charging.

The other pages of the Topcal21 help describe the Windows version. The pages in this section describe what is specific to the web version and refer to the Windows pages when an operation works the same way in both versions.

## Getting started

1. [Create an account or sign in](acceso-y-cuenta.md). When you first open the home page, "My files" or the workspace with a signed-in session, the website attempts to activate the Topcal21 account and create the file space.
2. [Upload the files of a project](mis-archivos.md) to a folder in "My files". The website recommends one folder per project.
3. Click the "Open in Topcal21" button of a `.prt`, `.pts` or `.obs` file in the list. The website opens the file in the [workspace](espacio-de-trabajo.md).
4. View and edit the data in the [grids](rejillas-de-puntos-y-de-visuales.md) and run the [computations](calculos.md) in the Tools and Computations menus.
5. Save the changes with "Save" or "Save project". Until they are saved, the changes exist only in the browser session.
