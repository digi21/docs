# Technical support
<!-- id: topcal21-web-soporte -->
<!-- origen: 82e4464ac9dc05ada917fde7eef9a9008c2fa0bf -->

Technical support for Topcal21 web works with support tickets on www.digi21.net. The Topcal21 web account works for signing in to www.digi21.net because the two websites share accounts.

## Creating a ticket

1. Open the **Help** menu of the workspace.
2. Click **Create a technical support ticket**. The website opens the support form of www.digi21.net in a new tab, in the language of the page.
3. Describe the problem. State the name of the file or project, the command you were running and the text of the message the website showed.

The **About TopCal 21...** dialog box of the Help menu also has a link to **Technical support**.

## Other help

* **Contents** in the Help menu opens this help in a new tab. The other pages of the [Topcal21 help](../README.md) explain the computations in detail.
* The [differences from Topcal21 for Windows](diferencias-con-el-escritorio.md) indicate the functions that the website does not yet include.
