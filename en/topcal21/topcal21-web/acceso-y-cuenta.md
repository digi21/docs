# Sign-in and account

Topcal21 web uses the same accounts as www.digi21.net: the email address and the personal data are the same on both websites. Topcal21 web does not use passwords. Each sign-in is confirmed with a 6-digit code that the website sends by email.

## Create an account

If the email address does not have an account on www.digi21.net:

1. Open `https://topcal21.ai` and click **Create an account**.
2. Fill in the form. The email address, first name, last name and phone number are required. The company, the tax identification number (NIF) and the address can be left empty; if the account belongs to a company, enter the company name and the company tax identification code (CIF).
3. Click **Register**. The website checks the Google reCAPTCHA security verification and sends a verification code to the email address you entered.
4. Enter the code on the "Confirm your email address" page and click **Verify**. When the code is verified, the website confirms the email address and opens the session.

## Sign in

With an account created in Topcal21 web or on www.digi21.net:

1. Click **Sign in** and enter the email address of the account.
2. Select or clear **Keep me signed in on this computer**. With the check box selected, the session is kept after you close the browser; with the check box cleared, the session ends when you close the browser.
3. Click **Send verification code**. The website sends an email with a 6-digit code, which expires 5 minutes after it is generated.
4. Enter the code and click **Verify**.

If the code has expired or has not arrived, click **Resend code** to receive another one. After 5 failed verification attempts, the website rejects the code and you must request a new one.

If the email does not appear in the inbox, look for the message in the junk mail folder and add `servidor@digi21.net` to the contacts of your email program.

## Activating the Topcal21 account

The Topcal21 account is the file space associated with the www.digi21.net account. The website activates it the first time you open the home page, "My files" or the workspace with a signed-in session and, if the activation completes, tries to send a confirmation email. You do not need to fill in any request. While the website creates the file space, it shows the "Preparing your space" page; reload the page a few seconds later.

If the automatic activation does not complete, the account stays in the "Requested" status and a Digi21 administrator reviews the request. The "Topcal21 sign-up" page shows the status of the account. The account menu includes that page when the account does not exist, is in the "Requested" status or is in the "Rejected" status. The statuses are:

| Status | Effect |
|---|---|
| Requested | The account cannot open "My files" or the workspace. The website sends an email when an administrator approves or rejects the request. |
| Active | The account can use all the functions of the website. |
| Suspended | The account can view and download files, but it cannot create folders, upload files, delete them or save changes. The workspace shows "Read-only" in the status bar. |
| Rejected | The page shows the reason for the rejection and lets you submit another request. |

## Terms and privacy

The terms of service and the privacy policy are in the footer of the home page. Signing in or creating an account to use Topcal21 means accepting the terms of service. The cookies of the website store the session, the language and the light or dark theme.

## Sign out

In the workspace, open the account menu (top right corner, with the user name) and click **Sign out**.
