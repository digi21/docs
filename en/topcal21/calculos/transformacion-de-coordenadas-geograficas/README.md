# Transformation of geographic coordinates
<!-- id: transformacion-de-coordenadas-geograficas -->
<!-- origen: e145e8380d5e4288191a992b5819a6278c978440 -->

This tool reads geographic coordinates from an ASCII file, converts them to projected coordinates using the projection defined in the current point file and adds the transformed points to that file. It can also transform the current point file into an ASCII file of geographic coordinates.

If you want to transform coordinates that you enter manually with the keyboard, use the [Manual transformation of geographic coordinates](../transformacion-manual-de-coordenadas-geograficas.md) tool of the [Computations menu](../../menus-de-la-aplicacion/menu-calculos.md).

The tool is structured in three steps:

* [Step 1: Enter the transformation type](paso-1-introducir-tipo-de-transformacion.md)
* [Step 2: Selection of points to transform](paso-2-seleccion-de-los-puntos-a-transformar.md)
* [Step 3: Transformed coordinates of the points](paso-3-coordenadas-transformadas-de-los-puntos.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
