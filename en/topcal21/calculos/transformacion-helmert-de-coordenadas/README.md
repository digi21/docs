# Helmert/Affine coordinate transformation
<!-- id: transformacion-helmert-afin-de-coordenadas -->
<!-- origen: 812ff1c00ccf03bff2d5149ecb90b0f4d7747ba3 -->

This tool transforms a set of points from transformation values entered by the user. You can perform a 2- or 3-dimension Helmert transformation or a 2-dimension Affine transformation from the known displacement vectors, rotation angles and scale factor; or from the known tensors associated with the transformation; or also from a file with the transformation parameters.

The tool is structured in three steps:

* [Step 1: Choose transformation parameters](paso-1-elegir-parametros-de-transformacion.md)
* [Step 2: Point selection](paso-2-seleccion-de-puntos.md)
* [Step 3: Output data setup](paso-3-configurar-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
