# Transformation of heights using a grid
<!-- id: cambio-de-altura-segun-rejilla -->
<!-- origen: 2fa5667110d8509582851dd17f166c4142ffdb3a -->

This tool transforms the height of a set of points by interpolating a value from a grid file for each point and adding that value to, or subtracting it from, the point's height.

This tool is useful for adding or subtracting the geoid undulation to a set of points whose height is orthometric or ellipsoidal. The geoid undulation values must be in an ASCII file in grid format.

The tool is structured in three steps, as follows:

* [Step 1: Enter input data](paso-1-introducir-datos-de-entrada.md)
* [Step 2: Point selection](paso-2-seleccion-de-puntos.md)
* [Step 3: Output data setup](paso-3-configurar-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
