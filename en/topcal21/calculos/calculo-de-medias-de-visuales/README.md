# Compute average of observations
<!-- id: calcular-medias-de-visuales -->
<!-- origen: 6371e9625828eeb77448f45d431a671dcde96031 -->

This tool is used to compute the average observations after several observations have been made to the same points, showing the possible differences between those observations.

If observations to the same points were repeated, compute their averages before computing the systematic errors of the instrument or using the observations in other computations.

The tool is organized in three steps, which are the following:

* [Step 1: Observation selection](paso-1-seleccion-de-visuales.md)
* [Step 2: Standard deviations](paso-2-desviaciones-tipicas.md)
* [Step 3: Output data setup](paso-3-configurar-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
