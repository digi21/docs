# Compute DC-IC averages
<!-- id: calcular-medias-cd-ci -->
<!-- origen: b0f94a45f595e185ba374756ae29e32c07faf287 -->

This tool computes the averages of the observations taken in direct circle (DC) and inverse circle (IC), and the systematic errors of the surveying instrument. The computed systematic errors can be applied to the other observations made with that instrument.

To compute these errors, observations in direct circle and inverse circle must have been taken to a set of points.

The tool is structured in three steps, as follows:

* [Step 1: Observation selection](paso-1-seleccion-de-visuales.md)
* [Step 2: Computation of systematic errors](paso-2-calculo-de-errores-sistematicos.md)
* [Step 3: Output data setup](paso-3-configurar-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
