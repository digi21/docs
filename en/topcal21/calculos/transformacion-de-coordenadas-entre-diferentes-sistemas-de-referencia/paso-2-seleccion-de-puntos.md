# Step 2: Point selection
<!-- id: topcal21-transformacion-de-coordenadas-entre-diferentes-sistemas-de-referencia-paso-2-seleccion-de-puntos -->
<!-- origen: 07f4679e9357ec6f2c81b8e5fd05248ca5844b0b -->

This is the second step in the reference system change, in which a screen is displayed with the points with coordinates stored in the current file. Select the points you want to transform.

![Transformation of coordinates between different reference systems — Step 2](../../../images/cambio-de-sistema-de-referencia-paso2.jpg)

The list that is displayed contains the following fields:

* **Point number**
* **Point coordinates**
* **Point name**

You can select multiple points by holding down the *\[CTRL\]* key and clicking the desired points with the left mouse button. If you click a point that is already selected, it is deselected.

You can also select points arranged in ranges by holding down the *\[SHIFT\]* key and clicking with the left mouse button the limit points that define the range.

Likewise, you can use the **All** or **None** buttons to select or deselect all the points.

When you have selected the desired points, you can click the **Next** button to go to [Step 3: Output data setup](paso-3-configurar-salida-de-datos.md), or return to [Step 1: Reference system selection](paso-1-seleccion-de-los-sistemas-de-referencia.md) by clicking the **Back** button.
