# Step 3: Output data setup
<!-- id: topcal21-transformacion-de-coordenadas-entre-diferentes-sistemas-de-referencia-paso-3-configurar-salida-de-datos -->
<!-- origen: f36823fc7bbacb53e742b09a953e3d6a62547023 -->

This is the third and last step in the reference system change where, in addition to a list with the coordinates of the transformed points, the following fields are displayed:

![Transformation of coordinates between different reference systems — Step 3](../../../images/cambio-de-sistema-de-referencia-paso3.jpg)

* **TopCal output file**: You can select the name of the TopCal file where the points will be stored. You can choose one of the existing files or generate a new file. If you want to generate a new file, you can choose whether or not to add the file to the current project.
* **Adding new points**: If the point file already exists, you can choose **Modify existing points** or **Not modify existing points** for the points of the output file whose number matches that of the computed points.

Once the output data have been configured, you can finish the process by clicking the **Compute** button, or return to the previous step, [Step 2: Point selection](paso-2-seleccion-de-puntos.md), by clicking the **Back** button.
