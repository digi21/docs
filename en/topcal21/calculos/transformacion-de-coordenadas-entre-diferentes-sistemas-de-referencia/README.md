# Transformation of coordinates between different reference systems
<!-- id: transformacion-de-coordenadas-entre-diferentes-sistemas-de-referencia -->
<!-- origen: a5ba4d74e2ae62a36478248acaa54bcd1889d40c -->

This tool transforms a set of points defined in one coordinate system to another coordinate system. To do so, the program computes the geographic coordinates of the points and performs the change of system. The source and destination reference systems must use the same ellipsoid so that the coordinate origins coincide. That is, the coordinate change should only be a change of projection, for example, to go from UTM coordinates on the Hayford ellipsoid to Cartesian geocentric coordinates referred to the same ellipsoid.

The tool is structured in three steps:

* [Step 1: Reference system selection](paso-1-seleccion-de-los-sistemas-de-referencia.md)
* [Step 2: Point selection](paso-2-seleccion-de-puntos.md)
* [Step 3: Output data setup](paso-3-configurar-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
