# Compute random errors
<!-- id: calcular-errores-accidentales -->
<!-- origen: 136c63fc7248e739822ebbc5c52ddd65d271ada3 -->

This tool is used to compute the random errors specific to an [instrument](../../otros-comandos/instrumentos-topograficos/listado-de-instrumentos-topograficos.md) and to a set of [observation characteristics](../../opciones-de-visualizacion/propiedades-de-los-objetos/propiedades-del-archivo-de-visuales.md). In addition to showing the random errors that occur in the observations, it presents the a priori errors that some surveying methods ([radial survey](../../herramientas/radiacion/README.md) and [traversing](../../herramientas/poligonales/README.md)) can have, so that you can check whether these methods are suitable before starting a job.

The tool is only available if a document with observations is active, and it uses the instrument defined in the observation document and the averages of distance, vertical angle and prism height of the observations of that document.

The tool is organized in two steps, which are the following:

* [Step 1: Common random errors](paso-1-errores-accidentales-comunes.md)
* [Step 2: Errors by method and output data](paso-2-errores-en-metodos-y-salida-de-datos.md)

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
