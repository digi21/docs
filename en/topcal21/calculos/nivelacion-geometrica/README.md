# Levelling
<!-- id: nivelacion-geometrica -->
<!-- origen: f6fe8ab6f41584da66395df1ec620c6554c23928 -->

This tool computes the height difference between points observed by geometric levelling. The observations of this geometric levelling must be stored in a digital file. The format of this file must be the one produced by Leica digital levels (GSI).

The tool is structured in two steps:

* [Step 1: Input and output file selection](paso-1-seleccion-de-archivos-de-entrada-y-salida.md)
* Step 2: Computed height differences

Use the **Next** and **Back** buttons to move between steps and modify the data or the selections.
