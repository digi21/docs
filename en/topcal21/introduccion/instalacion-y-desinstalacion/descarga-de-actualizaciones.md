# Downloading updates
<!-- id: topcal21-descarga-de-actualizaciones -->
<!-- origen: cf75557ca8c4542c9d9c301ee65c20eabf5b50c7 -->

The Digi21.net development team periodically publishes new versions of its programs on its website, which may include new tools.

The Internet address for TopCal 21 users is www.digi21.net/topcal21, from where new versions can be downloaded.

The update is a Windows installation file named *TopCal21.msi*. To update TopCal 21, download this file, run it and follow the instructions shown by the installer.

You do not need to uninstall the previous version.
