# Installing the program
<!-- id: topcal21-instalacion-del-programa -->
<!-- origen: 6e4481b9918f1b4ccefa5c5c8f51c3a4bdf77112 -->

Before installing TopCal 21 on the hard disk, check that the minimum requirements listed in [System requirements](../requisitos-del-sistema.md) are met.

* Insert the installation CD into the CD-ROM drive of the system.
* Wait for the CD-ROM autorun program to display the list of applications available for installation.
* Select TopCal 21 from the list.
* Follow the instructions shown by the installer.
