# Starting the program
<!-- id: topcal21-inicio-del-programa -->
<!-- origen: ce8c12b37e29ba34db2357aad360c8b80ea50a73 -->

The installation program will have created a startup icon on the Windows desktop and a folder in the *Programs* menu of the Windows *Start* menu.

Start TopCal 21 using either of the following methods:

* Double-click the desktop icon.
* Select *Start* → *Programs* → *Digi21.net* → *TopCal 21* → *TopCal 21*.

> [!NOTE]
> At startup, Topcal21 checks the protection. If the computer has a software license activation, Topcal21 uses that license and does not look for a dongle. If the computer has no activation, Topcal21 looks for a dongle. If it finds neither an activation nor a dongle, Topcal21 shows the **Protection of Topcal21** dialog box, with the buttons **Activate a software license**, **Select key** and **Exit**. See [Software licenses](../../../licencias-de-software/README.md).

To start Topcal21 from the command line, see [Command-line options](../../opciones-de-la-linea-de-ordenes.md).
