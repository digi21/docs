# System requirements
<!-- id: topcal21-requisitos-del-sistema -->
<!-- origen: e3bd0c9d3030728d1da470ce9ec5bb39ea47496b -->

TopCal 21 runs on the Microsoft Windows operating system. To install and start using TopCal 21, the following hardware and software are required:

* An Intel Pentium II processor (300 MHz or faster), or equivalent, running Windows 2000 or Windows XP.
* Enough RAM to meet the operating system requirements (128 MB recommended).
* 15 MB of free disk space.
* A CD-ROM drive.
* A color monitor capable of a resolution of 1024 × 768 pixels and a color depth of 16 bits per pixel, with thousands of colors (millions of colors recommended).
* A USB port if you will connect a dongle directly to this computer.
