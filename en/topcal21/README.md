# Topcal21
<!-- id: topcal21 -->
<!-- origen: b1433e3133ba931073304487e2a160dcfcb8a589 -->

Surveying calculation software designed to solve all calculation problems in surveying work.

Topcal21 works with projects, allowing work to be organized in subdirectories and several point and observation files to be handled at once. Its data display window resembles a spreadsheet, and all tools use guided dialogs to assist during calculations.

## Tools

* Triangulation calculation.
* Forward intersections.
* Resections.
* Orientation correction calculation.
* Traverses.
* Radial surveys.
* Area calculation.
* Drawing generation from points.
* Coordinate transformation between systems.
* Station description generation.
* Longitudinal profile and cross-section calculation.
* Volume calculation.
* Cut and fill calculation.
* Least-squares adjustment of survey networks.
* Automatic sketch reconstruction from field coding.
* Triangle solving.
* Conversion between polar and rectangular coordinates.
* Line and circle intersections.
* Distance calculation in UTM projection or geographic coordinates.
