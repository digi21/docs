# Soporte técnico

Las dudas, los problemas y las peticiones de funcionalidades nuevas para _Digi3D.AI_ se envían como tiques de soporte técnico desde la web de Digi21: [https://www.digi21.net/Soporte](https://www.digi21.net/Soporte).

Cada tique es una conversación entre tú y el equipo de soporte técnico. En el tique se escriben mensajes y se adjuntan archivos de cualquier tamaño. La web envía un correo electrónico cada vez que el soporte técnico responde.

Para usar el soporte técnico necesitas una cuenta en [www.digi21.net](https://www.digi21.net). La cuenta no tiene contraseña: cada inicio de sesión se confirma con un código que llega por correo electrónico.

Páginas de esta sección:

* [Creando una cuenta y enviando el primer tique de soporte técnico](/soporte-tecnico/creando-cuenta-soporte-tecnico.md): crear la cuenta, iniciar sesión, crear un tique y responder.
* [Reglas Soporte Técnico](/soporte-tecnico/reglas-soporte-tecnico.md): cómo redactar un tique para que el soporte técnico lo resuelva sin pedirte más datos.
* [Adjuntando archivos a un tique de soporte técnico](/soporte-tecnico/adjuntando-archivos-grandes-soporte-tecnico.md): subir archivos al crear el tique y al responder, y descargarlos en un ZIP.
* [Cerrando un tique de soporte técnico](/soporte-tecnico/cerrando-ticket-soporte-tecnico.md): estados del tique, cierre y reapertura.
