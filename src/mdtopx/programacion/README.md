# Programación
<!-- id: programacion-2 -->

El motor de cálculo de MDTopX (triangulación, rejillas, análisis de nubes de puntos…) y todos sus
formatos de importación y exportación se pueden usar desde programas propios, sin abrir MDTopX.

- [Python](python/README.md): el paquete `mdtopx` para programas de Python.
