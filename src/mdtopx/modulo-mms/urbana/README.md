# Urbana
<!-- id: urbana -->

[Ficha de herramientas MMS](/mdtopx/fichas-de-herramientas/ficha-de-herramientas-mms.md)

Las herramientas para las nubes de puntos de calles del [módulo MMS](../), registradas con un MMS de vehículo o con un escáner SLAM llevado a mano, están agrupadas en esta sección y son las siguientes:

* [**Clasificación urbana**](clasificacion-urbana/): Herramienta para clasificar la nube (calzada, acera, bordillo, fachadas, árboles, mobiliario, marcas viales, tapas, cables aéreos…) y generar las líneas de rotura y el inventario urbano.
