# Especificación del Sistema de Referencia de Coordenadas del Sensor
<!-- id: especificacion-src-sensor -->

Todos los sensores tienen asociado un sistema de referencia de coordenadas. Algunos tienen un sistema de referencia de coordenadas fijo y otros lo tienen variable.

La siguiente tabla muestra los sistemas de referencia de coordenadas asociados a cada uno de los sensores implementados por Digi3D.AI.


| Sensor | Sistemas de referencia de coordenadas permitidos |
| :--- | :--- |
| Satélite RPC | El sensor de coeficientes polinómicos racionales (RPC) trabaja siempre en el sistema de referencia de coordenadas: [EPSG:4979](http://spatialreference.org/ref/epsg/4979/). El sistema de referencia de coordenadas EPSG:4979 es idéntico al [EPSG:4326](http://spatialreference.org/ref/epsg/4326/) pero en vez de ser geográfico de dos dimensiones (2D), es geográfico de tres dimensiones (3D) (con coordenadas Z elipsoidales). |
| VM Quasi-Panoramic | Este sensor trabaja siempre en el sistema de referencia de coordenadas: [EPSG:4979](http://spatialreference.org/ref/epsg/4979/). El sistema de referencia de coordenadas EPSG:4979 es idéntico al [EPSG:4326](http://spatialreference.org/ref/epsg/4326/) pero en vez de ser geográfico 2D, es geográfico 3D (con coordenadas Z elipsoidales). |
| ADS 40/80 | Este sensor trabaja siempre en el sistema de referencia de coordenadas: [EPSG:4979](http://spatialreference.org/ref/epsg/4979/). El sistema de referencia de coordenadas EPSG:4979 es idéntico al [EPSG:4326](http://spatialreference.org/ref/epsg/4326/) pero en vez de ser geográfico 2D, es geográfico 3D (con coordenadas Z elipsoidales). |
| Ortofoto | Se obtiene el sistema de referencia de coordenadas de la orientación de la ortofoto. Si la ortofoto es un GeoTiff que aporta información del sistema de referencia de coordenadas, el sensor tendrá ese sistema. Si la ortofoto no aporta esa información y existe un archivo [.prj](http://en.wikipedia.org/wiki/Shapefile), Digi3D.AI asignará al sensor el sistema indicado en el archivo .prj. Si no hay información en la ortofoto ni un archivo .prj, los sistemas de referencia de coordenadas vertical y horizontal serán desconocidos. |
| Ortofoto estereoscópica | Se obtiene el sistema de referencia de coordenadas de la orientación de la ortofoto. Si la ortofoto es un GeoTiff que aporta información del sistema de referencia de coordenadas, el sensor tendrá ese sistema. Si la ortofoto no aporta esa información y existe un archivo [.prj](http://en.wikipedia.org/wiki/Shapefile), Digi3D.AI asignará al sensor el sistema indicado en el archivo .prj. Si no hay información en la ortofoto ni un archivo .prj, los sistemas de referencia de coordenadas vertical y horizontal serán desconocidos. |
| Web Map Service | El sensor utiliza el sistema de referencia de coordenadas que elijas en el panel del sensor entre los que el servidor Web Map Service (WMS) admite para la capa. Si no hay ninguna capa seleccionada, el sistema es local. |
| Web Map Tile Service | El sensor utiliza el sistema de referencia de coordenadas de la matriz de teselas que elijas en el panel del sensor. Si no hay ninguna capa seleccionada o Digi3D.AI no reconoce el sistema, se utiliza un sistema local. |
| Cónico | Si cargas un modelo sin orientación absoluta ni aerotriangulación asociada, el sistema de referencia de coordenadas será Horizontal local + Vertical local. Si el modelo tiene una aerotriangulación y el archivo informa internamente de un sistema de referencia de coordenadas, se seleccionará este sistema de referencia de coordenadas. Actualmente, solo los archivos *.prj* de Inpho informan internamente de su sistema de referencia de coordenadas. Si el archivo de aerotriangulación no informa internamente de un sistema de referencia de coordenadas, pero se localiza un archivo *.prj* en el mismo directorio que el archivo de aerotriangulación con un sistema de referencia de coordenadas, se seleccionará el sistema de referencia de coordenadas de ese archivo *.prj*. Si el archivo de aerotriangulación no informa de sistema de referencia de coordenadas ni se localiza un archivo .prj, se seleccionará como sistema de referencia de coordenadas Horizontal local + Vertical local. Si se localiza un archivo de orientación absoluta que proporciona un sistema de referencia de coordenadas, se seleccionará el sistema de la orientación absoluta, que sustituirá al proporcionado por el archivo de aerotriangulación. |
