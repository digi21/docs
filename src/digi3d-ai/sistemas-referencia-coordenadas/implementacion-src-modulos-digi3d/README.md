# Módulos de Digi3D.AI que tienen asignado su propio sistema de referencia de coordenadas
<!-- id: implementacion-src-modulos-digi3d -->

Digi3D.AI está formado por varios módulos que interactúan entre sí: la interfaz de usuario \(menús, barras de herramientas\), las ventanas \(ventanas fotogramétricas y ventanas de dibujo\), los sensores \(_ADS40/80, cónico, satelital_\), los archivos de dibujo \(._bind, .bin, .shp_, ...\) y los archivos de configuración \(de teclas, de tablas de códigos...\).

Esta sección explica qué módulos tienen asignado un sistema de referencia de coordenadas, cómo cambiar el sistema de cada módulo y cuándo transforma Digi3D.AI las coordenadas al sistema de referencia de coordenadas de un módulo.
