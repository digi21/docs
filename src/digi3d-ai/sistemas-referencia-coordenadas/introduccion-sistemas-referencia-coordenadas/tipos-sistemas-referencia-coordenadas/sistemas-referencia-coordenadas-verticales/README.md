# Sistemas de Referencia de Coordenadas Verticales
<!-- id: sistemas-referencia-coordenadas-verticales -->

Los sistemas verticales representan siempre una elevación, altitud o profundidad. Tienen una única dimensión, que suele ser la _Z_. Las alturas que representan estos sistemas son siempre ortométricas, nunca elipsoidales.

Existen los siguientes tipos:

| Sistema de referencia de coordenadas | Dimensiones |
| :--- | :--- |
| [Desconocido o local](sistema-referencia-vertical-desconocido.md) | 1D o 2D |
| De ingeniería | No aplicable, pues Digi3D.AI no los admite. |
| Verticales | 1D |

Digi3D.AI solo permite seleccionar un sistema de referencia de coordenadas vertical como la parte vertical de un [sistema de referencia de coordenadas compuesto](../sistemas-referencia-coordenadas-compuestos.md).

Los sistemas EGM08_REDNAP Península y EGM08_REDNAP Canarias se sustituyen automáticamente por los sistemas oficiales de EPSG _Alicante height_ y _Tenerife height_. Consulta [EGM08_REDNAP pasa a Alicante height y Tenerife height](/digi3d-ai/usuarios-de-versiones-anteriores/egm08-rednap-sustituido-por-alicante-height.md).
