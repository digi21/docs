# Sistemas de Referencia de Coordenadas Geográficos 2D
<!-- id: sistemas-referencia-coordenadas-geograficos-2d -->

Representan puntos como coordenadas polares, es decir, ángulos. Tienen dos dimensiones, una para la _Latitud_ y otra para la _Longitud_.

Las unidades y el orden de los ejes pueden variar. La mayoría de los sistemas de referencia de coordenadas geográficos tienen el siguiente orden de coordenadas: _Latitud, Longitud_ y las unidades de estos sistemas son grados sexagesimales.

Digi3D.AI no permite al usuario seleccionar un sistema de referencia de coordenadas geográfico de dos dimensiones (2D) directamente; únicamente permite seleccionarlo como parte de un [sistema de referencia de coordenadas compuesto](../sistemas-referencia-coordenadas-compuestos.md).
