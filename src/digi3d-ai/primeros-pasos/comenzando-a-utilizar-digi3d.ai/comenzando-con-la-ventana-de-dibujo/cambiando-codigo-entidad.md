# Cambiando el código de una entidad
<!-- id: cambiando-codigo-entidad -->

Para **cambiar el código** de una entidad, sigue estos pasos:

1. **Dibuja** un edificio con el código _050146 EDIFICIO PRIVADO._
2. **Visualiza** la [Barra de herramientas Editar códigos](/digi3d-ai/referencia/barras-de-herramientas/editar-codigos.md). Si no está activa, aprende a activarla pulsando [aquí](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-de-dibujo/barras-herramientas-basicas.md).
3. **Pulsa** el primer botón de la [Barra de herramientas Editar códigos](/digi3d-ai/referencia/barras-de-herramientas/editar-codigos.md). Este botón ejecuta la orden [EDITAR\_COD](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/e/editar-cod.md).
4. **Selecciona** el edificio cuyo código quieres editar con el [botón de tentativo](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#números-de-los-botones-del-ratón) del ratón cuando **DIGI3D.AI** solicite una entidad.
5. **Confirma** la selección con el [botón de dato](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#números-de-los-botones-del-ratón) del ratón.
6. **Pulsa** el botón **Borrar** del cuadro de diálogo **Editor de códigos** para borrar el código de la entidad.
7. **Pulsa** el botón **Añadir nuevo** para añadir un nuevo código.
8. **Busca** el código _050150 EDIF. CONSTRUCCIÓN_ y **pulsa** el botón **Seleccionar**.
9. **Pulsa** el botón **Aceptar** y comprueba que el código del edificio se ha modificado.
10. **Finaliza** la orden [EDITAR\_COD](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/e/editar-cod.md) del ratón.

Otra forma de **cambiar el código** de una entidad es la siguiente:

1. **Pulsa** el segundo botón de la [Barra de herramientas Editar códigos](/digi3d-ai/referencia/barras-de-herramientas/editar-codigos.md). Este botón ejecuta la orden [CAMB\_COD](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/c/camb-cod.md).
2. **Selecciona** el edificio cuyo código quieres cambiar con el [botón de tentativo](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#números-de-los-botones-del-ratón) del ratón cuando **DIGI3D.AI** solicite una entidad.
3. **Confirma** la selección con el [botón de dato](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#números-de-los-botones-del-ratón) del ratón. Al confirmar la selección, automáticamente el código de la entidad se cambiará por el código activo en la [Barra de herramientas Código](/digi3d-ai/referencia/barras-de-herramientas/codigo.md).
4. **Finaliza** la orden [CAMB\_COD](/digi3d-ai/referencia/ventana-de-dibujo/ordenes/c/camb-cod.md) del ratón.
