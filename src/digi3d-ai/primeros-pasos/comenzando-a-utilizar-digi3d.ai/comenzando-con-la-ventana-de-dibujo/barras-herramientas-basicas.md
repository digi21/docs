# Presentación de las barras de herramientas básicas
<!-- id: barras-herramientas-basicas -->

Al ejecutar **Digi3D.AI**, todas las **Barras de herramientas** aparecen visibles. Sigue estos pasos para seleccionar las barras de herramientas básicas:

1. Pulsa con el [botón de cancelar](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#números-de-los-botones-del-ratón) del ratón sobre una de las barras de herramientas para que te aparezca un listado con todas las barras de herramientas de las que dispone Digi3D.AI.
2. Desactiva todas las barras de herramientas pulsando con el [botón de dato](/digi3d-ai/referencia/cuadros-de-dialogo/programar-botones.md#números-de-los-botones-del-ratón) del ratón sobre cada barra de herramientas.
3. Marca únicamente la barra de herramientas [Coordenadas](/digi3d-ai/referencia/barras-de-herramientas/coordenadas.md).

Sigue el mismo procedimiento para activar cualquier otra barra de herramientas.
