# Aprendiendo a desplazarnos con el ratón en la ventana fotogramétrica
<!-- id: desplazando-ventana-foto-raton -->

Puedes capturar el ratón de Windows en la ventana fotogramétrica para desplazar la ventana con el ratón, independientemente de que dispongas o no de un topo-mouse o de sistemas de manivelas.

### Capturando el ratón en la ventana fotogramétrica

Existen dos formas distintas de capturar el ratón en la ventana fotogramétrica:

1. Ejecuta la orden [RATON\_DIGI3D](/digi3d-ai/referencia/ventana-fotogrametrica/ordenes/r/raton-digi3d.md).
2. Haz clic con el ratón en la ventana fotogramétrica \(siempre y cuando esté así configurado en la configuración del programa\).

### Descapturando el ratón de la ventana fotogramétrica

Existen cuatro formas distintas de descapturar el ratón de la ventana fotogramétrica:

1. Cambia a otra aplicación \(pulsa la combinación de teclas **Alt+Tab.**\)
2. Ejecuta la orden [RATON\_DIGI3D](/digi3d-ai/referencia/ventana-fotogrametrica/ordenes/r/raton-digi3d.md).
3. Pulsa la tecla **Intro** para liberar el ratón.
4. Pulsa \(y mantén pulsada\) la tecla **Ctrl** para liberar temporalmente el ratón. Al dejar de pulsar la tecla _Ctrl_, Digi3D.AI captura automáticamente el ratón en la ventana fotogramétrica.
