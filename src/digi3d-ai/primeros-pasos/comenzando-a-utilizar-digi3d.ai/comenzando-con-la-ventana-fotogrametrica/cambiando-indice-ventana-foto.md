# Cambiando el tipo de índice en la ventana fotogramétrica
<!-- id: cambiando-indice-ventana-foto -->

Puedes cambiar tanto la forma como el color del índice de la ventana fotogramétrica.

Digi3D permite elegir entre las siguientes formas de índice:

| Índice pequeño | Es un punto de 1x1 píxeles en pantalla del color que indiques y rodeado de un aro negro. |
| :--- | :--- |
| Índice mediano | Es un punto de 3x3 píxeles en pantalla del color que indiques y rodeado de un aro negro. |
| Índice grande | Es un punto de 6x6 píxeles en pantalla del color que indiques y rodeado de un aro negro. |
| Aspa | Un aspa grande. Se utiliza para digitalizar con precisión en marcas fiduciales con forma de aspa al realizar una [orientación interna](/digi3d-ai/primeros-pasos/comenzando-a-utilizar-digi3d.ai/comenzando-con-la-ventana-fotogrametrica/sensor-camara-conica/orientacion-de-modelos-fotogrametricos/orientacion-interna/README.md) de cámara analógica. |
| Cruz horizontal | Una cruz grande. Se utiliza para digitalizar con precisión en marcas fiduciales con forma de cruz al realizar una orientación interna de cámara analógica. |

Sigue estos pasos para cambiar el tipo de índice y el color:

### Mediante el menú Ventana fotogramétrica

1. Abre el menú **Ventana fotogramétrica** y selecciona la opción **Índices/Índice grande**. Comprobarás que Digi3D ha cambiado el tamaño del índice.
2. Abre el menú **Ventana fotogramétrica** y selecciona la opción **Índices/Color**.
3. Selecciona en el cuadro de diálogo **Color** el color que te interese y pulsa el botón **Aceptar**. Comprobarás que Digi3D ha cambiado el color del índice.

El color por defecto que selecciona Digi3D si no has seleccionado uno es **verde puro**.

### Mediante el teclado

La tecla de función **F2** tiene asignada una orden que cambia el tipo de índice cada vez que la pulsas.

* Pulsa la tecla de función **F2**.

Comprobarás que Digi3D cambia el tipo de índice. El índice varía siguiendo un bucle repetitivo \(pequeño, mediano, grande, aspa, cruz\).
