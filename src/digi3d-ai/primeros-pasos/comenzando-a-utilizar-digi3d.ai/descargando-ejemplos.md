# Descargando ejemplos y configurando Digi3D.AI para el tutorial
<!-- id: descargando-ejemplos -->

Este tema explica cómo utilizar las funciones básicas de _Digi3D.AI_.

Los pasos presentan el funcionamiento básico del programa, sin profundizar en cada tema.

Para poder seguir estos pasos es necesario que descargues dos proyectos:

| Nombre del proyecto | Descripción |
| :--- | :--- |
| [Bronchales](http://digi21.blob.core.windows.net/ejemplos/Bronchales.zip) | Consta de dos modelos de cámara cónica analógica. Las imágenes están en tonos de gris. El proyecto permite practicar las orientaciones interna, relativa y absoluta. |

Descarga y descomprime los proyectos antes de continuar.

También será necesario que configures en Digi3D.AI el archivo de teclas proporcionado por el instalador. Para ello, sigue estos pasos:

1. Selecciona la opción del menú **Herramientas/Configurar teclados virtuales...** Aparecerá el [Cuadro de diálogo Configuración de Teclados Virtuales](/digi3d-ai/referencia/cuadros-de-dialogo/configuracion-de-teclados-virtuales.md).
2. Selecciona una entrada de la lista **Archivos de asignación de teclas** y pulsa el botón **Quitar** si la lista contiene alguna entrada. Repite esta acción hasta que la lista **Archivos de asignación de teclas** esté vacía.
3. Pulsa el botón **Añadir**. Aparecerá el cuadro de diálogo **Abrir**.
4. Teclea en el campo **Nombre** lo siguiente: _%Programdata%_. Comprobarás que se muestra el contenido del directorio %ProgramData%.
5. Selecciona el directorio **Digi3D.AI**. Este es el directorio donde se instalan las tablas y configuraciones de Digi3D.AI.
6. Selecciona el directorio **Tablas**.
7. Selecciona el archivo **Teclas.keyboard.xml**. Este es el archivo de configuración de teclas estándar de Digi3D.AI. Las teclas enumeradas en ese archivo coinciden con lo que se explica en este tutorial.
8. Pulsa el botón **Aceptar** del cuadro de diálogo **Configuración de teclados virtuales.**
