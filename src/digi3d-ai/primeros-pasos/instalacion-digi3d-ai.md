# Instalación de Digi3D.AI
<!-- id: instalacion-digi3d-ai -->

Para instalar Digi3D.AI, tan solo tienes que [descargar el instalador](https://www.digi21.net/Digi3D/Download) de nuestra página web.

El instalador es un _bootstrapper,_ que es un instalador de instaladores. Este instalador se encargará de instalar todos los componentes necesarios para el programa \(suite de licencias, controlador de la llave de protección, modelos de geoide, etc.\).

![Instalador de Digi3D.AI](../../images/instalador-digi3d-ai.png)

El instalador muestra una fila por componente: Digi3D.AI, el modelo de geoide EGM2008 y la suite de aplicaciones Licencias. Si un componente ya está instalado en el equipo, puedes **Reparar**lo, **Omitir**lo o **Quitar**lo. Pulsa **Siguiente** para aplicar lo que hayas elegido.

En **Otras aplicaciones de Digi21**, el botón **Microsoft Store** abre la página de la tienda desde la que se instala cada aplicación:

* **Reproject**: convierte coordenadas entre sistemas de referencia.
* **Lot Of Points Studio**: genera niveles piramidales de nubes de puntos y los sube a Azure.

Una vez finalizado el proceso de instalación, ya puedes utilizar el programa. Pero para ello tienes que tener una licencia de éste \(comprada, alquilada o demostración\). Puedes aprender más sobre cómo obtener una licencia en [Acerca de las llaves de protección](/acerca-llaves-proteccion/).
