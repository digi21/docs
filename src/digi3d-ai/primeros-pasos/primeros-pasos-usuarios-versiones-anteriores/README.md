# Información para usuarios de versiones 2005 y 2007
<!-- id: primeros-pasos-usuarios-versiones-anteriores -->

Si utilizas Digi3D 2005 o Digi3D 2007, consulta los cambios de Digi3D.AI descritos en esta sección.

Digi3D.AI mantiene la compatibilidad con versiones anteriores en la medida de lo posible. Algunos cambios responden a las políticas de seguridad de Windows 10 y Windows 11, y otros modernizan el formato de algunos tipos de archivo.
