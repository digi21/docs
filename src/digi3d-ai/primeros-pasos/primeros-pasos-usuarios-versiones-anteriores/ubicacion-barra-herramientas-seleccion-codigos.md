# ¿Dónde está la barra de herramientas de selección de códigos?
<!-- id: ubicacion-barra-herramientas-seleccion-codigos -->

Si utilizas _Digi3D.AI_ después de trabajar con versiones anteriores de _Digi3D_, es posible que no veas la barra de herramientas _Código_, que permite seleccionar el código con el que digitalizar entidades.

_Digi3D.AI_ no muestra la barra de herramientas _Código_ cuando el programa está configurado en modo _multi-codificación_ (asignación de varios códigos a una entidad).

Cambia la configuración de selección de códigos en [Interfaz para seleccionar código](/digi3d-ai/referencia/cuadros-de-dialogo/configuracion/diging/interfaz-para-seleccionar-codigo.md).
