# Ubicación del archivo de esquemas Von Grouber para orientaciones relativas
<!-- id: ubicacion-esquemas-von-grouber -->

Digi3D.AI no requiere un archivo de configuración de esquemas de orientación relativa, pues incorpora una opción que calcula las fotocoordenadas de Von Grouber automáticamente en función del tamaño de la imagen.

Puedes configurar el archivo con los esquemas de Von Grouber utilizado en versiones anteriores, en el campo Esquemas del cuadro de diálogo de configuración, en la sección Orientación Relativa.

El instalador de Digi3D.AI instala una copia del archivo que se instalaba con la versión 2007 en la siguiente ubicación en función del sistema operativo:

| Sistema operativo | Ubicación |
| :--- | :--- |
| Windows 10/11 | C:\ProgramData\Digi3D.NET\Esquemas Orientaciones\Esquemas de orientación relativa.relscheme.xml |

Sigue estos pasos para configurar el archivo de esquemas de Von Grouber para orientaciones relativas:

1. Ejecuta **Digi3D.AI**.
2. Cierra el cuadro de diálogo **Nuevo proyecto**.
3. Ejecuta la opción del menú **Herramientas/Configuración...**.
4. Localiza la sección **Orientación Relativa**.
5. Pega en el campo **Esquemas** la ruta del archivo de esquemas de Von Grouber que corresponda a tu sistema operativo en la tabla o localiza la ruta de tu archivo de esquemas personalizado.
6. Acepta el cuadro de diálogo **Configuración**.
