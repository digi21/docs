# Archivos VEC de Latino
<!-- id: vec -->

Importador y exportador de **Archivos VEC de Latino**.

## Parámetros

Esta extensión no recibe parámetros por la línea de comandos.

## Parámetros del motor de importación/exportación

Este formato no añade propiedades a la categoría **Motor de importación/exportación** de los cuadros de diálogo que importan o exportan archivos de este formato.

### Sistema de referencia de coordenadas

El formato no guarda el sistema de referencia y Digi3D.AI no lo pide: el archivo toma el sistema de la ventana fotogramétrica, si hay una abierta, o el de la ventana de dibujo.

### Opciones de la configuración

El cuadro de diálogo Configuración tiene más opciones de este formato en [Importador/exportador de formato VEC de Latino](../../cuadros-de-dialogo/configuracion/importador-exportador-de-formato-vec-de-latino/README.md).

## Características del importador/exportador

| | |
| :--- | :--- |
| Extensiones | `.vec` |
| Importación (orden [IMPORTAR](../ordenes/i/importar.md)) | Sí |
| Exportación (orden [EXPORTAR](../ordenes/e/exportar.md)) | Sí |
