# WMS (Web Map Service)

Importador de **WMS (Web Map Service)**.

## Parámetros

Esta extensión no recibe parámetros por la línea de comandos.

## Véase también

- [Conectarse a un servidor WMS](/digi3d-ai/procedimientos/conectar-servidor-wms.md): crear el archivo de conexión, cargarlo y elegir las capas.

## Características del importador/exportador

| | |
| :--- | :--- |
| Extensiones | `.wmsconnection` |
| Importación (orden [IMPORTAR](../ordenes/i/importar.md)) | Sí |
| Exportación (orden [EXPORTAR](../ordenes/e/exportar.md)) | No |
| Se puede abrir una ventana de dibujo con este formato | Sí |
