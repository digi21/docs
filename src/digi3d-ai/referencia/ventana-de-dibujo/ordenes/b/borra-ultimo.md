# BORRA\_ULTIMO
<!-- id: borra-ultimo -->

Borra la última entidad registrada en el fichero de dibujo.

## Parámetros

No admite parámetros.

## Observaciones

Cada vez que se ejecute la orden desaparecerá la última entidad no borrada del archivo de dibujo activo. Esta orden no pide confirmación para ejecutarse.

## Características de la orden

| Tipo de orden | [Orden inmediata](/digi3d-ai/referencia/ordenes/ordenes-no-interactivas.md) |
| :--- | :--- |
| Repite automáticamente | No |
| Opción del menú donde aparece la orden | Editar/Eliminar la última entidad del archivo de dibujo |
| Barra de herramientas en la que aparece la orden | Eliminar y recuperar |

| Variables relacionadas | No tiene variables relacionadas |
