# PUNTO\_VISTA

Sitúa el punto de vista de la ventana ortográfica en una de las vistas predefinidas.

## Parámetros

| Número de parámetro | Descripción | Valores | Opcional |
| :--- | :--- | :--- | :--- |
| 1 | Número de punto de vista | 1 = Superior<br>2 = Inferior<br>3 = Izquierdo<br>4 = Derecho<br>5 = Frontal<br>6 = Trasero<br>7 = Isométrico SW<br>8 = Isométrico SE<br>9 = Isométrico NE<br>10 = Isométrico NW | Si |

## Características de la orden

| Tipo de orden | [Orden interactiva](punto-vista.md) |
| :--- | :--- |
| Repite automáticamente | No |
| Opción del menú donde aparece la orden | Zooms/Punto de vista/Superior, Inferior, Izquierdo, Derecho, Frontal, Trasero, Isométrico SW, Isométrico SE, Isométrico NE e Isométrico NW |
| Barra de herramientas en la que aparece la orden | _Esta orden no tiene asociado ningún botón en ninguna barra de herramientas_ |
| Extensión | DigiNG.OrdenesStandard.dll |
| Variables relacionadas | No tiene variables relacionadas |
| Nombre interno | {4CA45C16-E359-4B13-96CC-67DFC0F12A4D} |
