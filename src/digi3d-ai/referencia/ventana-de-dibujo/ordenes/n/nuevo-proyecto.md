# NUEVO\_PROYECTO
<!-- id: nuevo-proyecto -->

Muestra el cuadro de diálogo para abrir un modelo fotogramétrico o un archivo de dibujo.

## Parámetros

No admite parámetros.

## Observaciones

No puedes abrir dos archivos de dibujo simultáneamente.
