# AUTOMODOB\_EXHAUSTIVO

Activa o desactiva el modo de búsqueda exhaustivo. Este modo evita que hagas tentativo en una entidad cuyo código no esté especificado en la tabla de búsqueda.

## Parámetros

| Número de parámetro | Descripción | Valores | Opcional |
| :--- | :--- | :--- | :--- |
| 1 | Modo de búsqueda exhaustivo |Si no se especifica ningún parámetro el valor de la variable booleana cambiará de modo Activado a Desactivado y de Desactivado a Activado.<br>**0**: Para desactivar la variable booleana.<br>**1**: Para activar la variable booleana.<br>**?**: Para consultar el valor de la variable booleana. Aparecerá un globo indicando si la orden está activada o desactivada.| Si |
