# ZOOME

Realiza un zoom extendido.

## Parámetros

Esta orden no admite parámetros.

## Observaciones

Ajusta el factor de zoom para que el dibujo completo se visualice en la pantalla. Además, devuelve la cámara a la orientación del punto de vista estándar.

## Características de la orden

| Tipo de orden | [Orden inmediata](zoome.md) |
| :--- | :--- |
| Repite automáticamente | No |
| Opción del menú donde aparece la orden | Zooms/Zoom Extendido |
| Barra de herramientas en la que aparece la orden | Zooms |
| Extensión | DigiNG.OrdenesStandard.dll |
| Variables relacionadas | No tiene variables relacionadas |
