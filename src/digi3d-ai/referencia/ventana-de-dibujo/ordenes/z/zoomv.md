# ZOOMV

Visualiza por pantalla el contenido de una zona de dibujo que el usuario ha de indicar, delimitando el contorno con una ventana.

## Parámetros

No admite parámetros.

## Observaciones

La ventana se define señalando dos puntos en pantalla.
