# Macros de base de datos
<!-- id: macros-de-base-de-datos -->

Las macros de base de datos indican a Digi3D.AI qué valores debe calcular al crear un registro en la base de datos.

Puedes introducir las macros en la propiedad [Valor por defecto](propiedades-de-los-campos.md#valor-por-defecto) de un campo de base de datos.

Si un campo tiene asignada una macro, Digi3D.AI sustituye la macro por el valor calculado al almacenar el registro en la base de datos.

El programa admite las siguientes macros:

| Macro                                          | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| %UID%                                          | Almacena un identificador único global (GUID) calculado al crear el registro, incluidas las llaves. Por ejemplo: `{F9E7E680-3CDD-4733-A8F1-22F850F8774B}`                                                                                                                                                                                                                                                                                                                                                                                |
| %UID\_SIMPLE%                                  | Almacena un GUID calculado en ese instante. Se almacena completo, con sus llaves como, por ejemplo: `F9E7E680-3CDD-4733-A8F1-22F850F8774B`                                                                                                                                                                                                                                                                                                                                                                                  |
| %CENTROID\_TEXT%                               | En caso de que la geometría que se esté almacenando sea un polígono generado por una topología, almacena en este campo el texto del centroide del polígono.                                                                                                                                                                                                                                                                                                                                                                 |
| %CENTROID\_VALUE=\[valor]%                     | En caso de que la geometría que se esté almacenando sea un polígono generado por una topología, almacena en este campo el valor indicado a la derecha del igual de entre todos los valores que tenga asignados el código del centroide en la propiedad [Valores](../codigos/propiedades-del-codigo.md#valores).                                                                                                                                                                                                             |
| %ENTITY\_CODE%                                 | Almacena el código principal de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| %ENTITY\_CODE\_ID%                             | Almacena el ID de registro de base de datos del código principal de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| %ENTITY\_TEXT%                                 | En caso de que la geometría que se esté almacenando sea de tipo texto, almacena el texto de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_LENGTH\_2D%                           | Almacena el perímetro en el plano X, Y de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| %ENTITY\_LENGTH\_3D%                           | Almacena el perímetro tridimensional de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| %ENTITY\_AREA%                                 | Almacena el área de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| %ENTITY\_FIRST\_VERTEX\_Z%                     | Almacena la coordenada Z del primer vértice de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| %ENTITY\_FIRST\_VERTEX\_Z\_INT%                | Almacena la coordenada Z del primer vértice de la geometría redondeada al número entero más cercano.                                                                                                                                                                                                                                                                                                                                                                                                                        |
| %ENTITY\_XMIN%                                 | Almacena la coordenada X mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| %ENTITY\_XMIN\_TRUNC\_INT%                     | Almacena el resultado de truncar a un número entero la coordenada X mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_XMIN\_ROUND\_INT%                     | Almacena la coordenada X mínima de la geometría redondeada al número entero más cercano.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_XMIN\_FLOOR\_INT%                     | Almacena el mayor número entero que no supera la coordenada X mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_XMIN\_CEIL\_INT%                      | Almacena el menor número entero que no es inferior a la coordenada X mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_YMIN%                                 | Almacena la coordenada Y mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| %ENTITY\_YMIN\_TRUNC\_INT%                     | Almacena el resultado de truncar a un número entero la coordenada Y mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_YMIN\_ROUND\_INT%                     | Almacena la coordenada Y mínima de la geometría redondeada al número entero más cercano.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_YMIN\_FLOOR\_INT%                     | Almacena el mayor número entero que no supera la coordenada Y mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_YMIN\_CEIL\_INT%                      | Almacena el menor número entero que no es inferior a la coordenada Y mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_ZMIN%                                 | Almacena la coordenada Z mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| %ENTITY\_ZMIN\_TRUNC\_INT%                     | Almacena el resultado de truncar a un número entero la coordenada Z mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_ZMIN\_ROUND\_INT%                     | Almacena la coordenada Z mínima de la geometría redondeada al número entero más cercano.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_ZMIN\_FLOOR\_INT%                     | Almacena el mayor número entero que no supera la coordenada Z mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_ZMIN\_CEIL\_INT%                      | Almacena el menor número entero que no es inferior a la coordenada Z mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_XMAX%                                 | Almacena la coordenada X mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| %ENTITY\_XMAX\_TRUNC\_INT%                     | Almacena el resultado de truncar a un número entero la coordenada X máxima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_XMAX\_ROUND\_INT%                     | Almacena la coordenada X máxima de la geometría redondeada al número entero más cercano.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_XMAX\_FLOOR\_INT%                     | Almacena el mayor número entero que no supera la coordenada X máxima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_XMAX\_CEIL\_INT%                      | Almacena el menor número entero que no es inferior a la coordenada X máxima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_YMAX%                                 | Almacena la coordenada Y mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| %ENTITY\_YMAX\_TRUNC\_INT%                     | Almacena el resultado de truncar a un número entero la coordenada Y máxima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_YMAX\_ROUND\_INT%                     | Almacena la coordenada Y máxima de la geometría redondeada al número entero más cercano.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_YMAX\_FLOOR\_INT%                     | Almacena el mayor número entero que no supera la coordenada Y máxima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_YMAX\_CEIL\_INT%                      | Almacena el menor número entero que no es inferior a la coordenada Y máxima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_ZMAX%                                 | Almacena la coordenada Z mínima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| %ENTITY\_ZMAX\_TRUNC\_INT%                     | Almacena el resultado de truncar a un número entero la coordenada Z máxima de la geometría.                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_ZMAX\_ROUND\_INT%                     | Almacena la coordenada Z máxima de la geometría redondeada al número entero más cercano.                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| %ENTITY\_ZMAX\_FLOOR\_INT%                     | Almacena la coordenada Z máxima de la geometría redondeada al número entero inferior más cercano.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_ZMAX\_CEIL\_INT%                      | Almacena la coordenada Z máxima de la geometría redondeada al número entero superior más cercano.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_WIDTH%                                | Almacena el ancho de la geometría (diferencia de coordenadas X máxima - X mínima)                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| %ENTITY\_HEIGHT%                               | Almacena el alto de la geometría (diferencia de coordenadas Y máxima - Y mínima)                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| %ENTITY\_LENGTH%                               | Almacena el largo de la geometría (diferencia de coordenadas Z máxima - Z mínima)                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| %ENTITY\_ROTATION\_TRIGONOMETRIC\_SEXAGESIMAL% | Almacena la rotación trigonométrica de la geometría en grados sexagesimales.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| %ENTITY\_ROTATION\_TRIGONOMETRIC\_CENTESIMAL%  | Almacena la rotación trigonométrica de la geometría en grados centesimales.                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %ENTITY\_ROTATION\_TRIGONOMETRIC\_RADIAN%      | Almacena la rotación trigonométrica de la geometría en radianes.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| %ENTITY\_ROTATION\_AZIMUTAL\_SEXAGESIMAL%      | Almacena la rotación azimutal de la geometría en grados sexagesimales.                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| %ENTITY\_ROTATION\_AZIMUTAL\_CENTESIMAL%       | Almacena la rotación azimutal de la geometría en grados centesimales.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| %ENTITY\_ROTATION\_AZIMUTAL\_RADIAN%           | Almacena la rotación azimutal de la geometría en radianes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| %MACRO%                                        |Expande las variables que aparecen a la derecha de %MACRO%: `$(NombreUsuario)`, `$(NombreOrdenador)`, `$(Fecha)`, `$(Dia)`, `$(Mes)`, `$(Año)`, `$(Escritorio)`, `$(Temp)` y las demás carpetas del sistema, con sus nombres en inglés o en español.<br>Ejemplo:<br>`%MACRO%Digitalizado por $(NombreUsuario)`|
| %DATE%                                         | Fecha actual.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| %DAY%                                          | Día del mes actual.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| %MONTH%                                        | Mes del año actual.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| %YEAR%                                         | Año actual.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| %TIME%                                         | Hora actual, incluyendo hora, minuto y segundo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| %HOUR%                                         | Hora actual.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| %MINUTE%                                       | Minuto actual.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| %SECOND%                                       | Segundo actual.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| %CODE\_VALUE=\[valor]%                         |Extrae el valor "valor" del [diccionario de valores](../codigos/propiedades-del-codigo.md#valores) asociado con el código de la geometría que se está almacenando.<br>Ejemplo: si la geometría tiene el código `020102` y ese código tiene asignado `tipo_de_suelo=superficial` en el campo Valores, introduce `%CODE_VALUE=tipo_de_suelo%` como valor por defecto del campo de base de datos para almacenar el valor `superficial`.|
| %ENTITY\_ATTRIBUTE=\[nombre]%                  | Extrae el valor del diccionario de atributos de la geometría.<br>Ejemplo: si la geometría tiene asignado el atributo Carriles=3, introduce %ENTITY_ATTRIBUTE=Carriles% como valor por defecto del campo de base de datos para almacenar el valor 3.|
