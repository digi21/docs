# Códigos
<!-- id: menu-codigos-editor-tablas -->

Las opciones de este menú actúan sobre la lista de la pestaña [Códigos](../../pestanas/codigos/README.md).

## Importar

| Opción | Acción |
| :--- | :--- |
| **Importar códigos de archivo ASCII [código] [descripción]...** | Añade un código por cada línea de un archivo de texto con el código y su descripción. |
| **Importar códigos de archivo de recursos ASCII exportado con Erdas PRO600...** | Añade los códigos de un archivo de recursos de PRO600. |
| **Importar códigos de archivo de catálogo de características de MGCP...** | Añade los códigos de un catálogo de características MGCP. |
| **Importar códigos de archivo .dgn...** | Abre el cuadro [Importar códigos de archivo .dgn](importar-codigos-dgn.md). |
| **Importar códigos de archivo de catálogo de NGIX...** | Abre el cuadro [Importar catálogo de NGIX](importar-catalogo-ngix.md). |
| **Importar códigos de tabla BINDXF...** | Añade los códigos de una tabla de traducción BINDXF. |
| **Importar códigos de archivo de definición de espacio de trabajo de ArcGIS...** | Añade los códigos de un archivo XML de espacio de trabajo de ArcGIS. Después de elegir los archivos pide la versión del esquema en el cuadro [Versión de ArcGIS](../version-de-arcgis.md) y el estilo de los códigos en el cuadro [Selecciona el estilo](../../pestanas/selecciona-el-estilo.md). |
| **Importar códigos de un archivo .CSV [código] [nivel] [color] [estilo] [peso] [célula] [descripción]...** | Añade códigos con sus parámetros de traducción a DGN desde un archivo CSV. |
| **Completar parámetros de importación/exportación** | Calcula los parámetros de importación y exportación que faltan en los códigos. |
| **Sustituir parámetros de importación/exportación por los calculados automáticamente** | Sustituye los parámetros de importación y exportación de los códigos por los calculados. |
| **Eliminar códigos duplicados** | Elimina los códigos repetidos. |

## Etiquetas

| Opción | Acción |
| :--- | :--- |
| **Añadir etiqueta a múltiples códigos...** | Abre el cuadro [Añadir etiqueta a múltiples códigos](anadir-etiqueta-a-multiples-codigos.md). |
| **Añadir etiqueta a múltiples códigos por tabla...** | Abre el cuadro **Añadir etiqueta a múltiples códigos por tabla**, en el que se escriben los códigos, uno por línea, en lugar de seleccionarlos en una lista. |
| **Eliminar etiquetas de múltiples códigos...** | Abre el cuadro **Eliminar etiquetas**, que quita una etiqueta de los códigos seleccionados. |
| **Renombrar etiquetas...** | Abre el cuadro [Renombrar etiquetas](renombrar-etiquetas.md). |

## Ordenar

Las opciones **Ordenar por código** y **Ordenar por descripción** reordenan la lista de códigos alfabética o numéricamente, en orden ascendente o descendente.
