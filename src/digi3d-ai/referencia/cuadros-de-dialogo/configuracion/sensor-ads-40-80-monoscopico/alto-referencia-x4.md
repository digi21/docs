# Alto referencia x4
<!-- id: alto-referencia-x4 -->

Indica el alto de la ventana de referencia al correlar un punto en el nivel piramidal x4.

El valor por defecto es 200.

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\Extensiones\Digi3D.ADS40Sensor` |
| :--- | :--- |
| Valor | `nAltoReferenciaCorrelarPuntox4` |
| Tipo | `REG_DWORD` |
| Valor por defecto | 200 |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
