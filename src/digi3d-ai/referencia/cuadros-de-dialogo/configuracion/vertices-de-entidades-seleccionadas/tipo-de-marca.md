# Tipo de marca
<!-- id: tipo-de-marca -->

Indica la marca que se muestra sobre los vértices de las entidades seleccionadas.

## Valores posibles

* **No mostrar marcas**. No se muestra ninguna marca sobre los vértices.
* **Cuadrados**. Se muestran cuadrados sobre los vértices.
* **Triángulos**. Se muestran triángulos sobre los vértices.
* **Círculos**. Se muestran círculos sobre los vértices.

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\DigiNG\Configuration` |
| :--- | :--- |
| Valor | `TipoMarcaVértices` |
| Tipo | `REG_DWORD` |
| Valor por defecto | 1 |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
