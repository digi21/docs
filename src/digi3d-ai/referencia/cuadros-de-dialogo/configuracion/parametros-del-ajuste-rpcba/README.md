# Parámetros del ajuste RPCBA
<!-- id: parametros-del-ajuste-rpcba -->

Configura las precisiones a priori del ajuste de bloques de los coeficientes RPC \(RPCBA\) del sensor [Satélite RPC](/digi3d-ai/referencia/ventana-fotogrametrica/sensores/rpc/README.md). El ajuste se realiza en el panel [Ajuste en bloque de RPCs](/digi3d-ai/referencia/ventana-fotogrametrica/sensores/rpc/ajuste-en-bloque-de-rpcs.md).

Esta categoría solo aparece si está instalada la extensión del sensor Satélite RPC.

Configura estas opciones desde el cuadro de diálogo de **[Configuración](../README.md)**.
