# Directorio de macroinstrucciones
<!-- id: directorio-de-macroinstrucciones -->

Especifica el directorio donde se localizan los archivos de macroinstrucciones.

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Valor | `DirectorioTablas` |
| Tipo | `REG_SZ` |
| Valor por defecto | (vacío) |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
