# Animaciones zoom rueda
<!-- id: animaciones-zoom-rueda -->

Indica el número de animaciones en los zooms realizados con la rueda del ratón.

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\DigiNG\Configuration` |
| :--- | :--- |
| Valor | `AnimacionesZoom` |
| Tipo | `REG_DWORD` |
| Valor por defecto | 5. Si el valor no existe, el cuadro de diálogo **Configuración** muestra 0 y lo guarda al pulsar **Aceptar**. |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
