# Texto a voz en globos
<!-- id: texto-a-voz-en-globos -->

Indica si Digi3D.AI utilizará síntesis de voz para narrar el contenido de los globos que muestran las órdenes.

## Valores posibles

* **Sí**. Se narra por voz el contenido de los globos.
* **No**. No se narra por voz el contenido de los globos.

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Valor | `TextoAVozEnGlobos` |
| Tipo | `REG_DWORD` |
| Valor por defecto | 0 |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
