# Tema
<!-- id: tema -->

Permite configurar el tema visual del programa.

## Valores posibles

* **Claro**. Digi3D.AI muestra los menús, paneles y cuadros de diálogo con un tema claro.
* **Oscuro**. Digi3D.AI muestra los menús, paneles y cuadros de diálogo con un tema oscuro.
* **Azul**. Digi3D.AI muestra los menús, paneles y cuadros de diálogo con un tema azulado.

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Valor | `Tema` |
| Tipo | `REG_DWORD` |
| Valor por defecto | 1 |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
