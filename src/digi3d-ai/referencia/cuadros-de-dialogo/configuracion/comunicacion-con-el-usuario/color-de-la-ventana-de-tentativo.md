# Color de la ventana de tentativo
<!-- id: color-de-la-ventana-de-tentativo -->

Permite configurar el color con el que se muestran las coordenadas en la [barra de herramientas Tentativo](../../../barras-de-herramientas/tentativo.md).

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration\BarrasHerramientas\BarraHerramientasTentativo` |
| :--- | :--- |
| Valor | `ColorVentanaTentativo` |
| Tipo | `REG_SZ` |
| Valor por defecto | `255 0 0` |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
