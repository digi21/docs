# Topologías no definidas en la tabla de códigos

Configura cómo se representan las topologías que no están definidas en la tabla de códigos, como las que se crean con las órdenes BINTOP o CREAR_TOPOLOGIA_CODIGOS_VISIBLES.

Configura estas opciones desde el cuadro de diálogo de **[Configuración](../README.md)**.
