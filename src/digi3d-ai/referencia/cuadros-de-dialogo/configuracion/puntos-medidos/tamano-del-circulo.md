# Tamaño del círculo
<!-- id: tamano-del-circulo -->

Indica el tamaño, en píxeles, del círculo que marca dónde se midió un punto (en la orientación absoluta o en la medida de aerotriangulación).

## Dónde se almacena

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Valor | `TamanoCirculosPuntosMedidosv2` |
| Tipo | `REG_DWORD` |
| Valor por defecto | 5 |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.
