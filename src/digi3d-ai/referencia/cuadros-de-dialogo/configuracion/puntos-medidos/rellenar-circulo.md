# Rellenar círculo
<!-- id: rellenar-circulo -->

Indica si se rellena el círculo que muestra los puntos medidos.

## Valores posibles

* **Sí**. El círculo se dibuja relleno.
* **No**. El círculo se dibuja solo con su contorno.

## Dónde se almacena

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\App\Configuration` |
| :--- | :--- |
| Valor | `CirculosPuntosRelleno` |
| Tipo | `REG_DWORD` |
| Valor por defecto | 1 |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.
