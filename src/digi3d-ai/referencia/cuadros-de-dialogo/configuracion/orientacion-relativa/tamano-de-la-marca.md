# Tamaño de la marca
<!-- id: tamano-de-la-marca -->

Indica el tamaño de la marca que se muestra en la ventana fotogramétrica por cada punto medido.

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\Extensiones\Digi3D.ConicSensor\RelativeOrientation` |
| :--- | :--- |
| Valor | `TamanoCirculos` |
| Tipo | `REG_DWORD` |
| Valor por defecto | 5 |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
