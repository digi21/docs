# Interpolación de subpixel

Configura si Digi3D.AI utiliza interpolación de subpixel en los cálculos, cuando el sensor lo admite. La interpolación de subpixel mejora la precisión, pero puede aumentar considerablemente el tiempo de proceso.

Configura estas opciones desde el cuadro de diálogo de **[Configuración](../README.md)**.
