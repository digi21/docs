# Interpolación de subpixel
<!-- id: interpolacion-de-subpixel -->

Configura si Digi3D.AI utiliza interpolación de subpíxel en los cálculos, cuando el sensor lo admite. Los cálculos con interpolación de subpíxel tienen más precisión y pueden requerir más tiempo de proceso que los cálculos sin interpolación.

Configura estas opciones desde el cuadro de diálogo de **[Configuración](../README.md)**.
