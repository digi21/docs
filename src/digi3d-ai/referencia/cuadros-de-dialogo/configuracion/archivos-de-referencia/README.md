# Archivos de referencia
<!-- id: archivos-de-referencia-2 -->

Configura qué guarda Digi3D.AI en el [archivo de archivos de referencia](../../../archivos/archivo-de-archivos-de-referencia.md) de cada archivo de dibujo: los archivos de referencia y la ruta del proyecto fotogramétrico o del archivo de modelo fotogramétrico asociado al archivo de dibujo.

Configura estas opciones desde el cuadro de diálogo de **[Configuración](../README.md)**.
