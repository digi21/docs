# Rotar el modelo para respetar el Norte
<!-- id: rotar-el-modelo-para-respetar-el-norte -->

Si se habilita, al cargar el modelo se calculará su azimut. Si es superior a 100 grados sexagesimales, se rotará el modelo para que el norte aparezca en la parte superior de las imágenes.

## Valores posibles

* **Sí**.
* **No**.
