# Archivos de recursos
<!-- id: archivos-de-recursos -->

Indica la ruta a los archivos de recursos de MicroStation (_.rsc_) en los que localizar fuentes, estilos de línea personalizados, etc.

## Dónde se almacena

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\DigiNG\IO\Digi21.Io.Dgn` |
| :--- | :--- |
| Valor | `ArchivosRecursos` |
| Tipo | `REG_SZ` |
| Valor por defecto | (vacío) |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.
