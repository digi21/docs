# Factor de multiplicación
<!-- id: factor-de-multiplicacion -->

Indica el valor por el que se multiplica la velocidad de desplazamiento actual cuando se cumple la condición para desencadenar la aceleración de las imágenes.

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\IO` |
| :--- | :--- |
| Valor | `FactorVelocidadAceleracion` |
| Tipo | `REG_DWORD` |
| Valor por defecto | 5 |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
