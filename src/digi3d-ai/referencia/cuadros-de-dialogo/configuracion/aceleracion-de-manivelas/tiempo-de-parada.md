# Tiempo de parada
<!-- id: tiempo-de-parada -->

Indica el tiempo, en milisegundos, que debe transcurrir desde que dejas de mover las imágenes hasta que se da por finalizado el proceso de aceleración.

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\IO` |
| :--- | :--- |
| Valor | `TiempoParadaAceleracion` |
| Tipo | `REG_DWORD` |
| Valor por defecto | 100 |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
