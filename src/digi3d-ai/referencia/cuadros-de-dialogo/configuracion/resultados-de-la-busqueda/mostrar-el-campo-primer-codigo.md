# Mostrar el campo Primer código

Indica si los paneles Resultados de la búsqueda mostrarán el campo **Primer código**.

> Este cambio requiere reiniciar Digi3D.AI.

## Valores posibles

* **Sí**. El campo Primer código se muestra en el panel.
* **No**. El campo Primer código no se muestra en el panel.
