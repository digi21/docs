# Esquemas
<!-- id: esquemas -->

Indica la ruta al archivo de esquemas de medida de aerotriangulación (_.aerotrischeme.xml_).

<details>
<summary>Dónde se almacena</summary>

| Registro | `HKEY_CURRENT_USER\Software\Digi21\Digi3D.NET\Digi3D\Extensiones\Digi3D.ConicSensor\AerotriangulationMeasurement` |
| :--- | :--- |
| Valor | `Esquema` |
| Tipo | `REG_SZ` |
| Valor por defecto | (vacío) |

Es un valor de cada usuario de _Windows_: no está en el archivo Digi3DNET.db y las sentencias SQL del cuadro de diálogo [Configuración avanzada](../../configuracion-avanzada.md) no lo modifican.

</details>
