# Transformador Universal de Coordenadas (sustituido por Reproject)
<!-- id: transformador-universal-de-coordenadas -->

El programa Transformador Universal de Coordenadas se ha sustituido por **Reproject**.

Reproject transforma coordenadas entre dos sistemas de referencia de coordenadas con el catálogo EPSG completo. Se instala desde la Microsoft Store.

Consulta la ayuda de [Reproject](/reproject/README.md).
