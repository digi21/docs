# Al seleccionar un código
<!-- id: al-seleccionar-un-codigo -->

Si cambias de código activo con la orden [COD](../../ventana-de-dibujo/ordenes/c/cod.md) o seleccionas un código en cualquiera de las ventanas del programa que permiten cambiar de código como por ejemplo la [barra de herramientas código](../../barras-de-herramientas/codigo.md), el programa ejecutará de manera automática las siguientes órdenes:

* Las órdenes que aparezcan en la ventana [Órdenes a ejecutar al seleccionar cualquier código](/digi3d-ai/referencia/editor-de-tablas-de-codigos/pestanas/ordenes.md) de la pestaña _Órdenes_ del programa [Editor de Tablas de códigos](/digi3d-ai/referencia/editor-de-tablas-de-codigos/).
* Las órdenes que tenga asignadas el código seleccionado en el campo [Órdenes al seleccionar código](/digi3d-ai/referencia/editor-de-tablas-de-codigos/pestanas/codigos/propiedades-del-codigo.md).
