# Procedimientos
<!-- id: procedimientos -->

Pasos para completar tareas concretas con Digi3D.AI.

- [Conectarse a un servidor WMS](/digi3d-ai/procedimientos/conectar-servidor-wms.md): muestra en la ventana de dibujo las capas de un servidor Web Map Service.
- [Convertir imágenes ALOS a TIFF con Alos2Digi3D](/digi3d-ai/procedimientos/convertir-imagenes-alos.md): convierte las escenas PRISM en formato CEOS a TIFF por teselas y con niveles piramidales.
- [Publicar un proyecto fotogramétrico en Azure Blob Storage y cargarlo desde una URL](/digi3d-ai/procedimientos/publicar-proyecto-fotogrametrico-remoto.md): sube un proyecto y sus imágenes a un servidor y los carga en el panel Proyecto fotogramétrico.
