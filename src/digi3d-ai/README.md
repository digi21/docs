# Digi3D.AI
<!-- id: digi3d-ai -->

![Icono de Digi3D.AI](../images/digi3d-ai-icono.png)

Digi3D.AI es una completa _Estación de Fotogrametría Digital_ que permite el registro de entidades geográficas a partir de imágenes aéreas, cámaras cónicas analógicas y digitales, Intergraph Digital Mapping Camera System, Vexcel UltraCamX, sensores de barrido como Leica ADS40/80, sensores satelitales como Ikonos, QuickBird, procedentes de Fotogrametría terrestre, a partir de ortofotos + MDTs y/o MDS y a partir de nubes de puntos densas.

**Digi3D.AI incorpora inteligencia artificial (IA).** El programa incluye un asistente de IA al que puedes pedirle en lenguaje natural que consulte y modifique el dibujo activo \(por ejemplo, _«haz un zoom al primer edificio»_ o _«borra los textos con el código 050146»_\), sin necesidad de programar. El asistente funciona con proveedores en la nube \(Claude, OpenAI, Azure OpenAI, Kimi, OpenRouter\) o con un modelo ejecutado en tu propio equipo con LM Studio u Ollama. Consulta [Asistente con IA](/digi3d-ai/referencia/asistente-ia/README.md).

Digi3D.AI es también un programa de diseño asistido por ordenador (CAD) y un sistema de información geográfica (SIG).

Con Digi3D.AI puedes registrar entidades con órdenes diseñadas para cartografía.

Digi3D.AI te permite abrir archivos de dibujo en distintos formatos, transformar coordenadas entre distintos sistemas de referencia, realizar análisis geométricos y topológicos y buscar entidades.

Además, puedes programar Digi3D.AI con tecnologías .NET para añadir órdenes, utilidades, exportadores, criterios de búsqueda y controles de calidad personalizados.
