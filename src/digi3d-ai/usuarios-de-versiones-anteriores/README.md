# Información para usuarios de Digi3D.NET
<!-- id: usuarios-de-versiones-anteriores -->

Esta sección describe los cambios que te afectan al empezar a usar Digi3D.AI después de trabajar con Digi3D.NET y explica cómo adaptar tus archivos.

- [Actualizar los controles de calidad Python de una tabla de códigos](actualizar-guiones-python.md): resuelve el error `No module named 'digi3d.relations'` de las tablas de códigos creadas para Digi3D.NET y los errores `NameError` y `AttributeError` que aparecen después de sustituir el entorno Python, y relaciona los nombres de la interfaz de programación de aplicaciones (API) de Python que han cambiado.
- [Actualizar las expresiones Python de selecciones y órdenes](actualizar-expresiones-python.md): traduce las expresiones escritas para Digi3D.NET (`digi3DGeometry`, `Points.Count`, `Atr`, `g.codes[0].name`) a la sintaxis de Digi3D.AI.
- [EGM08_REDNAP pasa a Alicante height y Tenerife height](egm08-rednap-sustituido-por-alicante-height.md): los sistemas verticales EGM08_REDNAP Península y EGM08_REDNAP Canarias se sustituyen automáticamente por los sistemas oficiales de EPSG, con las mismas alturas.
- [Migración a .NET 10](../programacion/.net/migracion-a-net-10.md): adaptar las extensiones .NET.
