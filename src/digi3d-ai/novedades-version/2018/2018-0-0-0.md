# Digi3D.AI 2018.0.0.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 19/01/2018.

## Novedades

* Ahora se pueden indicar múltiples llaves simultáneamente al crear un paquete de tablas cifrado en el editor de tablas de códigos.
* Se ha añadido una barra de herramientas al panel de tabla de códigos con un botón para buscar el código activo y otro para clonar.
* Ahora se pueden importar archivos con múltiples esquemas de espacios de trabajo de ArcGIS.
* Ahora el programa pregunta por el número de versión de ArcGIS al importar archivos, pues los archivos de definición de ArcGIS cambian el espacio de nombres de los nodos del XML en función de la versión.
* Ahora al añadir un código en el editor de tablas de códigos, se le asignan por defecto colores de relleno con transparencia.
* Ahora puedes activar o desactivar la visualización de capas en el panel de archivos de dibujo para archivos Shapefile.

## Correcciones

* El programa finaliza inesperadamente al cargar archivos .BIN con textos con cero caracteres.
* Se ha solucionado un problema al comprimir Shapefiles que corrompía los datos de última modificación. Si se realizaba un tentativo después de comprimir el archivo, el programa fallaba.
* Se ha solucionado un problema por el cual no aparecía la opción de "Color" en el desplegable de tipo de relleno del editor de tablas de códigos.
* Se ha solucionado un fallo en la orden MOD\_MULTIPLE. La orden finalizaba inesperadamente si se ejecutaba sobre ella una orden de selección múltiple.
