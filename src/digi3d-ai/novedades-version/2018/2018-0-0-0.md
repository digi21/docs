Publicada el 19/01/2018.

## Novedades

* Ahora se pueden indicar múltiples llaves simultaneamente al creear un paquete de tablas cifrado en el editor de tablas de códigos
* Añadida una barra de herramientas al panel de tabla de códigos con un botón para buscar el código activo y otro para clonar
* Ahora se pueden importar archivos con múltiples esquemas de espacios de trabajo de ArcGIS
* Ahora el programa pregunta por el número de versión de ArcGIS al  importar archivos, pues los archivos de definición de ArcGIS cambian el namespace de los nodos del XML en función de la versión.
* Ahora al añadir un código en el editor de tablas de códigos, se le asignan por defecto colores de relleno con transparencia
* Ahora se pueden activar/desactivar la visualización de capas en el panel de archivos de dibujo para archivos Shapefile

## Correcciones

* El programa finaliza inesperadamente al cargar archivos .BIN con textos con cero caracteres.
* Solucionado problema al comprimir Shapefiles, si luego se tentativaba el programa fallaba porque se corrompían los datos de última modificación
* Solucinado problema por el cual en el desplegable de tipo de relleno no sale la opción de "Color" en el editor de tablas de códigos
* Solucionado un fallo en la orden MOD\_MULTIPLE. La orden finalizaba inesperadamente si se ejecutaba sobre ella una orden de selección múltiple
