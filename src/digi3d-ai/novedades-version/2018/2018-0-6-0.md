# Digi3D.AI 2018.0.6.0

Publicada el 14/02/2018.

## Novedades

* Nueva orden FORMAR\_POLIGONOS ([commit](https://blog.digi21.net/2018/02/19/nueva-orden-formar_poligonos/))
* Añadida compatibilidad para almacenar geometrías virtuales en archivos de dibujo basados en base de datos como Shapefiles
* Ahora se puede configurar si el tentativo se acepta con el botón/pedal de Dato si la orden que se está ejecutando es la orden LINEA. Esta nueva opción de configuración aparece en Herramientas/Configuración/Tentativos
* Añadida una opción de configuración para indicar si al finalizar la orden INSERTAR\_HUECO ésta elimina la línea que seleccionó como hueco
* La orden MOD\_MULTIPLE no elimina la línea que define la nueva geometría cuando finaliza su ejecución
* Ahora las órdenes no realizan regeneraciones de pantalla innecesarias cuando el usuario se desplaza sobre un polígono que ya se ha rellenado de color
* Ahora al ejecutar las órdenes TAREA+ y TAREA- para las tareas que desplazan la ventana de dibujo a unas determinadas coordenadas, si tenemos abierta una ventana fotogramétrica, ésta también se desplaza
* Añadido soporte para duplicar polígonos a la orden DUP

## Correcciones

* Solucionado un problema en el cálculo de centroides en polígonos. No se estaba calculando correctamente el centroide en polígonos con huecos.
* Al ir al punto de origen en modelos de PhotoScan con nodos camera/reference el programa lleva a coordenadas incorrectas. Ahora si el programa localiza el atributo zMedia hace caso omiso del nodo camera/reference, pues la coordenada Z que aparece en camera/reference no está en el terreno. Ahora además el programa asume que las coordenadas que aparecen en camera/reference son siempre coordenadas geográficas.
* Los archivos TIFF teselados con teselas rectangulares en vez de cuadradas se visualizan con artefactos
* La orden DESPLAZAR\_ORIGEN duplica el polígono si lo que se desplaza es el origen de un hueco del polígono
* Algunas órdenes duplican geometrías al ejecutarse con el flag AUTO\_INSERTAR\_VERTICE\_INTERSECCION\_AL\_FINALIZAR\_LINEA. Se ha modificado el comportamiento del programa al almacenar geometrías con el flag AUTO\_INSERTAR\_VERTICE\_INTERSECCION\_AL\_FINALIZAR\_LINEA activado. Ahora las modificaciones de geometrías que interseccionan con las geometrías que se acaban de almacenar se realizan tras finalizar cada orden en vez de realizarse cada vez que una orden añade una geometría al archivo de dibujo.
* En ocasiones el programa muestra ciertas geometrías que tienen un código cuya visualización está desactivada. Se ha detectado que si se recuperaba una geometría eliminada, esta nunca se dejaba de visualizar a pesar de que alguna orden ordenase que ésta no se visualizase.
* En ocasiones al formar topologías para inundación el programa va consumiento más y más memoria
* Desde que se añadió la funcionalidad de mostrar múltiples errores semánticos en una única geometría, al hacer el análisis bajo demanda el programa no muestra los errores en la lista de tareas
