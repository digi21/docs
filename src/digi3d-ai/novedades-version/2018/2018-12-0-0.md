# Digi3D.AI 2018.12.0.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 21/10/2018.

## Novedades

* Añadido soporte para valores booleanos a la extensión de PostGIS
* Ahora los valores de tipo booleano en la ventana de propiedades de la base de datos pueden mostrar valores de tipo NULL
* Mejorado el módulo de captura de errores para generar informes de errores si el programa finaliza inesperadamente
* Ahora los un archivos de proyecto puede referenciar a archivos .D3D en distintos directorios
* Ahora se pueden cargar archivos Shapefile sin base de datos (.DBF) asociada
* Añadida la propiedad "Copiable" a los campos de base de datos.
* Modificado el importador/exportador de PostGIS para que no copie los campos no copiables al copiar atributos de base de datos de una geometría en otra
* Ahora se puede indicar en los parámetros de configuración del importador de archivos binarios clásicos que el número de tabla 1 se interprete como una tabla y no como la tabla interna de Digi. Históricamente la tabla 1 significaba "sin enlace a base de datos" en los archivos .BIN clásicos, de manera que la primera tabla de base de datos tenía que ser forzosamente la 2. Con esta modificación podemos evitar esta restricción.
* Recompilado todo el programa con Visual Studio 2017 y gracias a ello se puede empezar a programar en C++ 17
* Actualizadas las librerías de DWG y DGN a Teigha 2019
* Añadido soporte para mostrar etiquetas de todo tipo de geometrías en el visualizador de atributos de BBDD
* Actualizada la librería de interfaz de usuario XTreme ToolkitPro a la versión 18.4.0
* Actualizada la librería de Erdas ECW a la versión 5.4.0
* Actualizada la librería Glew a la versión 2.1.0
* Actualizada la librería LibJPEG a la versión 9.3.0
* Actualizada la librería LibPNG a la versión 1.6.36
* Actualizada la librería LibTIFF a la versión 4.0.6.2
* Actualizada la librería MrSid a la versión 9.5.4.4709
* Actualizada la librería ZLib a la versión 1.2.11
* Añadido soporte a la orden INTER\_EJE para trabajar con polígonos o líneas cerradas
* Añadido soporte a la orden INSERTAR\_HUECO para insertar polígonos como huecos
* Añadidos en el cuadro de diálogo de configuración parámetros para indicar qué hacer con la geometría utilizada en INSERTAR\_HUECO: nada, eliminarla o preguntar
* Ahora en los programas .NET dentro de tablas de códigos se pueden referenciar ensamblados por su nombre seguro en vez de por la ruta en la que están ubicados
* Nueva orden POL para dibujar un polígonos
* Ahora se puede finalizar la orden LINEA pulsando la tecla ESC si aún no se ha digitalizado ningún vértice
* Mejorado el algoritmo de UNIR\_POLIGONOS que ahora se queda con el contorno exterior de la geometría y no requiere que los polígonos originales tengan caras comunes.
* Añadido soporte para cargar shapefiles con coordenadas Z de tipo not-a-number
* Añadido el tipo de programación Digi21.DigiNG.Topology.DuplicityDetector para detectar geometrías duplicadas.
* Mejorado el rendimiento al almacenar geometrías en Shapefiles mediante Digi21.DigiNG.IO.Shp
* Solucionado un problema por el cual al almacenar geometrías mediante Digi21.DigiNG.Io.Shp.Add en la sobrecarga con diccionario de base de datos la geometría se almacenaba dos veces.
* Solucionado un problema de acumulación de memoria al trabajar con Shapefiles al acceder a un registro de la base de datos
* Solucionada una fuga de memoria en el método Digi21::DigiNG::IO::Shp::Add relacionada con los atributos de base de datos a almacenar junto con la geometría.
* Al explotar complejos en archivos Shapefile las geometrías que formaban parte del complejo pierden sus atributos de base de datos
* Añadidos constructores a Digi21.DigiNG.IO.Shp.Shp que permiten especificar la página de códigos (CODEPAGE) a asignar a la base de datos a crear

## Correcciones

* La extensión de PostGIS no respeta los tamaños de ventana de la región de interés asignados en el panel de archivos de dibujo
* Si el programa detecta un error no envía el informe de errores a los servidores de Digi21
* Si se cancela el cuadro de diálogo de selección de capas al carga un archivo de PostGIS el programa finaliza inesperadamente.
* El panel de ayuda dinámica no muestra el archivo de ayuda especificado en la configuración
* Si en intenta generar una geometría en una conexión PostGis en una capa no cargada el programa finaliza inesperadamente.
* Si se ejecuta la orden RECARGAR\_ARCHIVOS\_REFERENCIA\_VISTA en mitad de la ejecución de otra orden, es posible que se dupliquen geometrías o que el programa finalize inesperadamente. Ahora la orden RECARGAR\_ARCHIVOS\_REFERENCIA\_VISTA no permite ejecutarse si se está ejecutando una orden, para evitar liberar las geometrías utilizadas por esa orden.
* No se pueden ejecutar programas de modelo semántico en Windows 8
* Los cálculos de detección de intersecciones en BINTRAM no funcionan correctamente con sigmas mayores o igual a 1
* La orden PARALELA desde la línea de comandos bloquea el programa si el archivo de dibujo tiene geometrías eliminadas
* El panel de base de datos el programa muestra campos de otra tabla al cargar un Shapefile
* No se interpretan correctamente los números reales almacenados en una base de datos XBASE (.dbf asociado a shapefiles) en campos de tipo NUMERIC
* La ventana fotogramétrica no muestra puntos de determinados archivos LAS
* El instalador online de Digi3D.NET no instala Acces Database Engine en equipos con 64 bits.
* El programa Editor de Tablas carga dos veces las extensiones de importación/exportación
* El programa no permite tentativar entidades complejas
* Al instanciar un objeto de tipo Digi21.DigiNG.IO.Shp con cualquiera de los constructores que no tienen tabla de códigos, el programa finaliza inesperadamente
* El programa tentativa geometrías de archivos cuya visualización se ha deshabilitado en el panel de archivos de dibujo
* Al trabajar con archivos SHP y comprimir, los atributos de base de datos de las geometrías no corresponden con los que deberían. Solucionado un problema al comprimir archivos SHP, los índices en memoria a los registros de base de datos se movían una unidad, de manera que si teníamos dos entidades una con atributo "a" y otra con "b", tras comprimir, la primera quedaba con atributo nulo y la segunda con "b". Al abrir el archivo otra vez se solucionaba.
* El programa no permite cargar shapefiles con bases de datos con información entre la cabecera y los datos de base de datos
* Solucionado un problema en Digi21.DigiNG por el cual al instanciar desde un programa de consola un objeto de tipo Digi21.DigiNG.DigiTab.DigiTab éste no cargaba los importadores/Exportadores instalados en Digi3D.NET.
* Solucionado problema por el cual es posible que algunos códigos no se visualizasen en la ventana de dibujo
* Solucionado un problema por el cual los importadores administrados como Digi21.DigiNG.IO.\* no calculaban las máximas y mínimas de las geometrías cargadas de manera que las operaciones espaciales daban error.
* Solucionado un problema de representación en la rotación de los textos en la ventana fotogramétrica. No se estaba respetando el giro en kappa de la imagen.
* Solucionado un problema por el cual al cambiar de código mientras se digitalizaba una línea el programa podía finalizar inesperadamente.
* Solucionado problema por el cual la orden de paralela dinámica no se finalizaba al pulsar el pedal de Reset
* Solucionado problema por el cual si estaba actuando el COD\_CURVAS y se tentativava en una geometría el programa cortaba la geometría que se estaba digitalizando.
* Solucionado problema por el cual si no se seleccionaba ninguna capa a cargar en Geomedia el programa finalizaba inesperadamente.
