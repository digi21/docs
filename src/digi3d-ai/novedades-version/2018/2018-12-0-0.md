# Digi3D.AI 2018.12.0.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 21/10/2018.

## Novedades

* Se ha añadido soporte para valores booleanos a la extensión de PostGIS.
* La ventana de propiedades de la base de datos puede mostrar null en los campos booleanos.
* Se ha mejorado el módulo de captura de errores para generar informes de errores si el programa finaliza inesperadamente.
* Ahora los archivos de proyecto pueden hacer referencia a archivos .D3D en distintos directorios.
* Ahora se pueden cargar archivos Shapefile sin base de datos (.DBF) asociada.
* Se ha añadido la propiedad "Copiable" a los campos de base de datos.
* Se ha modificado el importador/exportador de PostGIS para que no copie los valores de los campos cuya propiedad Copiable esté desactivada al copiar atributos de una geometría a otra.
* Ahora se puede indicar en los parámetros de configuración del importador de archivos binarios clásicos que el número de tabla 1 se interprete como una tabla y no como la tabla interna de Digi. Históricamente la tabla 1 significaba "sin enlace a base de datos" en los archivos .BIN clásicos, de manera que la primera tabla de base de datos tenía que ser forzosamente la 2. Esta modificación permite evitar la restricción del número de tabla.
* Se ha recompilado todo el programa con Visual Studio 2017, lo que permite empezar a programar en C++ 17.
* Se han actualizado las librerías de DWG y DGN a Teigha 2019.
* Se ha añadido soporte para mostrar etiquetas de todo tipo de geometrías en el visualizador de atributos de BBDD.
* Se ha actualizado la librería de interfaz de usuario XTreme ToolkitPro a la versión 18.4.0.
* Se ha actualizado la librería de Erdas ECW a la versión 5.4.0.
* Se ha actualizado la librería Glew a la versión 2.1.0.
* Se ha actualizado la librería LibJPEG a la versión 9.3.0.
* Se ha actualizado la librería LibPNG a la versión 1.6.36.
* Se ha actualizado la librería LibTIFF a la versión 4.0.6.2.
* Se ha actualizado la librería MrSid a la versión 9.5.4.4709.
* Se ha actualizado la librería ZLib a la versión 1.2.11.
* Se ha añadido soporte a la orden INTER\_EJE para trabajar con polígonos o líneas cerradas.
* Se ha añadido soporte a la orden INSERTAR\_HUECO para insertar polígonos como huecos.
* Se han añadido en el cuadro de diálogo de configuración parámetros para indicar qué hacer con la geometría utilizada en INSERTAR\_HUECO: conservar la geometría, eliminarla o preguntar si debe eliminarse.
* Ahora en los programas .NET dentro de tablas de códigos se pueden referenciar ensamblados por su nombre seguro en vez de por la ruta en la que están ubicados.
* Se ha añadido la orden POL para dibujar un polígono.
* Ahora se puede finalizar la orden LINEA pulsando la tecla ESC si aún no se ha digitalizado ningún vértice.
* Se ha mejorado el algoritmo de UNIR\_POLIGONOS que ahora conserva el contorno exterior de la geometría y no requiere que los polígonos originales tengan caras comunes.
* Se ha añadido soporte para cargar shapefiles con coordenadas Z con el valor NaN (not a number, valor no numérico).
* Se ha añadido el tipo de programación Digi21.DigiNG.Topology.DuplicityDetector para detectar geometrías duplicadas.
* Se ha mejorado el rendimiento al almacenar geometrías en Shapefiles mediante Digi21.DigiNG.IO.Shp.
* Se ha solucionado un problema por el cual al almacenar geometrías mediante Digi21.DigiNG.Io.Shp.Add en la sobrecarga con diccionario de base de datos la geometría se almacenaba dos veces.
* Se ha solucionado un problema de acumulación de memoria al trabajar con Shapefiles al acceder a un registro de la base de datos.
* Se ha solucionado una fuga de memoria en el método Digi21::DigiNG::IO::Shp::Add relacionada con los atributos de base de datos a almacenar junto con la geometría.
* Al explotar complejos en archivos Shapefile las geometrías que formaban parte del complejo pierden sus atributos de base de datos.
* Se han añadido constructores a Digi21.DigiNG.IO.Shp.Shp que permiten especificar la página de códigos (CODEPAGE) a asignar a la base de datos a crear.

## Correcciones

* La extensión de PostGIS no respeta los tamaños de ventana de la región de interés asignados en el panel de archivos de dibujo.
* Si el programa detecta un error no envía el informe de errores a los servidores de Digi21.
* Si se cancela el cuadro de diálogo de selección de capas al cargar un archivo de PostGIS el programa finaliza inesperadamente.
* El panel de ayuda dinámica no muestra el archivo de ayuda especificado en la configuración.
* Si intentas generar una geometría en una conexión PostGis en una capa no cargada, el programa finaliza inesperadamente.
* Si se ejecuta la orden RECARGAR\_ARCHIVOS\_REFERENCIA\_VISTA en mitad de la ejecución de otra orden, es posible que se dupliquen geometrías o que el programa finalice inesperadamente. RECARGAR\_ARCHIVOS\_REFERENCIA\_VISTA no puede ejecutarse mientras otra orden esté en curso, para evitar liberar las geometrías que utiliza esa otra orden.
* No se pueden ejecutar programas de modelo semántico en Windows 8.
* Los cálculos de detección de intersecciones en BINTRAM no funcionan correctamente con sigmas mayores o iguales a 1.
* La orden PARALELA desde la línea de comandos bloquea el programa si el archivo de dibujo tiene geometrías eliminadas.
* El panel de base de datos del programa muestra campos de otra tabla al cargar un Shapefile.
* No se interpretan correctamente los números reales almacenados en una base de datos XBASE (.dbf asociado a shapefiles) en campos de tipo NUMERIC.
* La ventana fotogramétrica no muestra puntos de determinados archivos LAS.
* El instalador online de Digi3D.NET no instala Acces Database Engine en equipos con 64 bits.
* El programa Editor de Tablas carga dos veces las extensiones de importación/exportación.
* El programa no permite tentativar entidades complejas.
* Al instanciar un objeto de tipo Digi21.DigiNG.IO.Shp con cualquiera de los constructores que no tienen tabla de códigos, el programa finaliza inesperadamente.
* El programa tentativa geometrías de archivos cuya visualización se ha deshabilitado en el panel de archivos de dibujo.
* Se ha solucionado un problema al comprimir archivos SHP que hacía que los atributos de base de datos de las geometrías no coincidiesen con los esperados. Los índices en memoria de los registros de base de datos se desplazaban una unidad. Por ejemplo, si tenías dos entidades, una con atributo "a" y otra con "b", tras comprimir, la primera quedaba con atributo nulo y la segunda con "b". Al volver a abrir el archivo, se recuperaban los atributos correctos.
* El programa no permite cargar shapefiles con bases de datos con información entre la cabecera y los datos de base de datos.
* Se ha solucionado un problema al instanciar desde un programa de consola un objeto de tipo Digi21.DigiNG.DigiTab.DigiTab: el objeto no cargaba los importadores y exportadores instalados en Digi3D.NET.
* Se ha solucionado un problema por el cual algunos códigos podían no visualizarse en la ventana de dibujo.
* Se ha solucionado un problema por el cual los importadores administrados como Digi21.DigiNG.IO.\* no calculaban las coordenadas máximas y mínimas de las geometrías cargadas de manera que las operaciones espaciales daban error.
* Se ha solucionado un problema de representación en la rotación de los textos en la ventana fotogramétrica. No se estaba respetando el giro en kappa de la imagen.
* Se ha solucionado un problema por el cual al cambiar de código mientras se digitalizaba una línea el programa podía finalizar inesperadamente.
* Se ha solucionado un problema por el cual la orden de paralela dinámica no se finalizaba al pulsar el pedal de Reset.
* Se ha solucionado un problema por el cual si COD\_CURVAS estaba activo y se tentativaba en una geometría el programa cortaba la geometría que se estaba digitalizando.
* Se ha solucionado un problema por el cual si no se seleccionaba ninguna capa a cargar en Geomedia el programa finalizaba inesperadamente.
