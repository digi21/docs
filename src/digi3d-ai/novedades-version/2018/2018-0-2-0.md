## Correcciones

* Se ha solucionado un problema en Geomedia con el indicador auto\_intersectar\_vértices\_al\_finalizar\_entidad activado. Con auto\_intersectar\_vértices\_al\_finalizar\_entidad activado, si la orden que almacenaba una entidad eliminaba después una de las entidades modificadas por el algoritmo de inserción de vértices, se producía un error porque se intentaba eliminar una geometría que ya estaba eliminada. El problema afectaba a determinados archivos de dibujo, como los de Geomedia. Ahora el algoritmo no almacena una entidad nueva si la geometría propuesta no tiene más vértices que la geometría existente.
* Ahora, al cancelar las órdenes MOD\_MULTIPLE y MOD\_MULTIPLE\_Z, se elimina la entidad que se estaba digitalizando.
* Se ha solucionado un problema de intercambio de ejes en el sensor satelital.
* Se ha solucionado un problema con el intercambio de ojos automático con el cambio de modelo. No se estaban intercambiando los ojos.
