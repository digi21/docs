# Digi3D.AI 2017.0.61.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 23/11/2017.

## Novedades

* Ahora el importador de esquemas de espacios de trabajo de ArcGIS puede importar múltiples espacios de trabajo simultaneamente
* Ahora la orden COPIA\_ATRIBUTO\_BBDD\_ENTIDAD\_EN\_ENTIDAD no permite tentativar entidades que no tengan los atributos indicados en la línea de comandos.
* Ahora se leen los tipos de entidad shapefile al importar códigos de un archivo de espacio de trabajo de ArcGIS
* Añadido soporte para multipointz y multipath en el importador de espacios de trabajo de ArcGIS.
* Mejorada considerablemente la velocidad del algoritmo de selección de códigos de archivos Shapefile

## Correcciones

* El importador de esquemas de espacios de trabajo de ArcGIS no importa correctamente los campos de tipo double
* Al ejecutar la orden UNDO con importadores que utilizan las tablas Digi3D\_Eliminados el programa da un mensaje de error
* El programa finaliza inesperadamente al comparar atributos de base de datos si una de las geometrías no tiene asignado el atributo que se está comparando (es decir, tiene un valor nulo)
