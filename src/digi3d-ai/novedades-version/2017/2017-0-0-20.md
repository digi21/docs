Publicada el 16/03/2017.

## Novedades

* No se carga la fuente TrueType de los códigos que tienen una fuente TrueType asignada.
* Se han actualizado las bibliotecas de DWG y de DGN a v.4.2.2.
* Se ha añadido la orden CREAR\_VISTA\_BBDD. ([commit](https://blog.digi21.net/2017/03/21/vistas-de-base-de-datos/))
* Se ha solucionado un problema al conectarse con servicios de mapas web (WMS, Web Map Service) que devolvían cadenas Unicode.
* Ahora, si creas un archivo de conexión WMS y tienes una ventana de dibujo abierta, el archivo de conexión que acabas de crear se cargará automáticamente.

## Correcciones

* Se ha solucionado un problema en el menú en inglés del programa Editor de Tablas de Códigos. No aparecía la opción Archivo.
* Al pulsar el botón Limpiar en el cuadro de diálogo de Cambiar valores de Base de datos, el programa finaliza inesperadamente.
* Se ha solucionado un problema en el cliente de Web Map Service que podía hacer que el programa finalizase inesperadamente al intentar registrar errores en el registro de eventos de Windows.
