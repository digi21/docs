# Digi3D.AI 2017.0.0.60

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 17/11/2017.

## Novedades

* Mejoras en notificaciones de control de calidad. Si una geometría no supera X tests, se mostrarán dichos X test en la ventana de errores
* Modificaciones en el tipo GeometricRelationException. Ahora el tipo contiene un tipo nullable con las coordenadas en las que se ha detectado el error.
* Añadido soporte para esquemas al importador de PostGIS
* Ahora el importador de PostGIS si crea un código en la tabla de códigos, le asigna un estilo personalizado a dicho código
* Añadido soporte para eliminación y recuperación de entidades en PostGIS
* Ahora el importador de PostGIS puede cargar datos de la base de datos
* Ahora se pueden modificar campos de la base de datos en conexiones PostGIS
* Añadido soporte para comprimir archivos en conexiones PostGIS
* Ahora el programa carga representaciones SLD localizados en la tabla layer\_styles de bases de datos PostGIS
* Ahora el conector de PostGIS se vuelve a reconectar en caso de pérdida de conexión con el servidor
* Ahora el importador de PostGIS permite cargar regiones de interés
* Añadido soporte para geometrías de tipo punto, multilinestring y multipolígonos en conexiones PostGIS
* Mejorado el rendimiento de la orden GEN. Ahora no se almacenan las entidades que no se han generalizado.
* Añadido soporte para UTF8 en conexiones PostGIS
* Aañdidas las órdenes VER\_SOLO\_ENTIDADES\_CON\_ENLACE\_BBDD y VER\_SOLO\_ENTIDADES\_SIN\_ENLACE\_BBDD
* Añadida la orden FORZAR\_ALMACENAR\_GEOMETRIAS\_SIN\_ENLACE\_BBDD. Si está activo, todas las geometrías se almacenarán sin parámetros de enlace a base de datos.
* Ahora la orden GEN puede generalizar entidades de tipo polígono y complejo
* Añadidos nuevos buscadores para facilitar el trabajo con modelos de datos tipo MSLINK. Se han añadido los siguientes buscadores:

Buscar entidades con enlace a tabla y registro.
Buscar entidades con enlace a base de datos.
Buscar entidades con tabla y registro.
Buscar entidades sin enlace a base de datos.
