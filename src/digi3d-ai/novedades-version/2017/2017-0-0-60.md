# Digi3D.AI 2017.0.0.60

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 17/11/2017.

## Novedades

* Se han mejorado las notificaciones de control de calidad. Si una geometría no supera X comprobaciones, se mostrarán esas X comprobaciones en la ventana de errores.
* GeometricRelationException almacena las coordenadas del error en un valor que admite null.
* Se ha añadido soporte para esquemas al importador de PostGIS.
* Ahora, si el importador de PostGIS crea un código en la tabla de códigos, le asigna un estilo personalizado.
* Se ha añadido soporte para eliminación y recuperación de entidades en PostGIS.
* Ahora el importador de PostGIS puede cargar datos de la base de datos.
* Ahora se pueden modificar campos de la base de datos en conexiones PostGIS.
* Se ha añadido soporte para comprimir archivos en conexiones PostGIS.
* Ahora el programa carga descripciones de estilo de capas (SLD, Styled Layer Descriptor) localizadas en la tabla layer\_styles de bases de datos PostGIS.
* Ahora el conector de PostGIS se reconecta en caso de pérdida de conexión con el servidor.
* Ahora el importador de PostGIS permite cargar regiones de interés.
* Se ha añadido soporte para geometrías de tipo punto, multilinestring y multipolígonos en conexiones PostGIS.
* Se ha mejorado el rendimiento de la orden GEN. Ahora no se almacenan las entidades que no se han generalizado.
* Se ha añadido soporte para UTF8 en conexiones PostGIS.
* Se han añadido las órdenes VER\_SOLO\_ENTIDADES\_CON\_ENLACE\_BBDD y VER\_SOLO\_ENTIDADES\_SIN\_ENLACE\_BBDD.
* Se ha añadido la orden FORZAR\_ALMACENAR\_GEOMETRIAS\_SIN\_ENLACE\_BBDD. Si la orden está activa, todas las geometrías se almacenarán sin parámetros de enlace a base de datos.
* Ahora la orden GEN puede generalizar entidades de tipo polígono y complejo.
* Se han añadido los siguientes buscadores para modelos de datos MSLINK:

Buscar entidades con enlace a tabla y registro.
Buscar entidades con enlace a base de datos.
Buscar entidades con tabla y registro.
Buscar entidades sin enlace a base de datos.

## Correcciones

* El programa finaliza inesperadamente al cargar archivos .LAS con puntos con un número de clasificación superior a 32.
