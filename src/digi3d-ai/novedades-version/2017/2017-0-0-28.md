## Novedades

* Se ha modificado el programa para que los archivos de alias puedan incluir una transformación XSLT (Extensible Stylesheet Language Transformations) que muestre los nombres de las órdenes y las descripciones en forma de tabla.

## Correcciones

* El programa Editor de Tablas de Códigos no importa códigos al seleccionar la opción del menú Códigos/Impotar códigos de archivo .dgn.
* Al tentativar un complejo puntual cuyas entidades hijas son a su vez complejos, el programa puede finalizar inesperadamente.
* Al cargar un archivo DGN con complejos puntuales con escala no se respeta la escala del complejo.
* El editor de tablas de códigos finaliza inesperadamente al importar capas de un archivo DGN con capas con índice de color mayor que 255.
