Publicada el 11/03/2017.

## Novedades

* Se ha actualizado la librería ERDAS ECW JPEG 2000 a la versión 5.3.0 para evitar dependencias con Visual Studio 2010.
* Se ha actualizado la suite de licencias incorporada en el instalador a la versión 17.0.0.3.
* Se ha actualizado la librería MrSID\_DSDK a la versión 9.5.4.4703 para evitar dependencias con Visual Studio 2010.
* Se ha mejorado la velocidad de carga de imágenes JPEG. ([commit](https://blog.digi21.net/2017/02/27/mejora-impresionante-en-la-velocidad-de-carga-de-imagenes-jpeg/))
* Se ha actualizado la extensión de carga de archivos ECW y Jpeg2000 para permitir cargar imágenes compuestas por varias imágenes.
* Ahora se pueden indicar sistemas de referencia de coordenadas al cargar archivos DEM en formato ASCII de ArcGis.
* Ahora se pueden cargar archivos DEM en formato ASCII de ArcGis con valores de tipo XLLCENTER e YLLCENTER.
* Se ha añadido el modo de visualización estereoscópica Lado-a-lado (mitad). ([commit](https://blog.digi21.net/2017/03/10/nuevo-modo-de-visualizacion-estereoscopica/))
* Se ha mejorado el rendimiento de actualización en la ventana fotogramétrica para los modos estereoscópicos que no requieren Quad-Buffer.
* Se ha añadido la orden COPIA\_ATRIBUTOS\_BBDD\_ENTIDAD\_EN\_ENTIDAD. Esta orden copia atributos de base de datos de una entidad en otra.
Los parámetros de esta orden son \[nombre del campo origen\] \[nombre del campo destino\]
* Se ha añadido soporte para la carga de modelos de Pleyades con imágenes formadas por la concatenación de varias imágenes.

## Correcciones

* Se ha solucionado un problema con los atributos de base de datos al almacenar una geometría que se cruza con otra que enlaza con la misma tabla, si está activa la inserción automática de vértices en la intersección. En ese caso, el panel de atributos de base de datos conservaba los atributos de la última entidad reescrita, por lo que la geometría que estabas dibujando se almacenaba con los atributos de esa entidad.
* Se ha solucionado un problema con la comunicación con Google Earth.
* El instalador unificado de Digi3D.NET instala Microsoft .NET Framework 4.5.2 en vez de 4.0.
* Al cargar un modelo satelital cuyos parámetros de coeficientes polinómicos racionales (RPC) están en un archivo .BLK, si las rutas de las imágenes a cargar y las que aparecen en el archivo .BLK no coinciden, no se localizan las orientaciones.
