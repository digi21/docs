## Correcciones

* No se pueden establecer conexiones a servidores WMS que no estén en el puerto 80
* La ventana de dibujo indica que la conexión WMS no dispone de ninguna capa compatible con el sistema de referencia de coordenadas de la ventana de dibujo cuando en realidad hay subcapas que sí que disponen de un SRC compatible. Se ha modificado la lógica del programa para permitir localizar subcapas que proporcionan SRC hijas de capas que no proporcionan SRC
* Al pulsar el botón de tentativo cuando se está seleccionando una geometría para mostrar otra, es posible que queden rastros de la selección anterior
* El programa no carga correctamente archivos KML generados en el espacio de nombres http://www.opengis.net/kml/2.2. El importador de KML se desarrolló antes de que el formato KML fuera un estándar de OpenGis y se esperaba que el espacio de nombres fuera http://earth.google.com/kml/2.2 y no http://www.opengis.net/kml/2.2
* El programa Generador de niveles piramidales no transforma archivos TIFF de 4 canales
* Las órdenes INSR e INS\_AA no rotan los textos ni puntos que pudiera tener el bloque insertado
* Si se indica al cargar un archivo DWG que se importen los bloques del archivo DWG cargado, éstos no se importan
