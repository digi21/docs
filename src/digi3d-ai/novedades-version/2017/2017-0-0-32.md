# Digi3D.AI 2017.0.0.32

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 02/06/2017.

## Novedades

* Debido a que la inmensa mayoría de usuarios disponen de un único monitor, ahora la configuración por defecto para instalaciones nuevas es para un único monitor
* Debido a que la característica de capturar el ratón en la ventana fotogramétrica al hacer clic puede ser molesta para usuarios nuevos, ahora en instalaciones nuevas esta opción viene desactivada por defecto
* Debido a que ya no se fabrican manivelas de tipo REST4, ahora en instalaciones nuevas el dispositivo de entrada por defecto es Ninguno
* Ahora en instalaciones nuevas la opción de Activar epipolar por defecto viene configurada como activada
* Ahora en instalaciones nuevas la opción de Rotar las imágenes en función del sistema fiducial está deshabilitada por defecto
* Ahora en instalaciones nuevas la opción de Interfaz de multi-codificación está desactivada por defecto
* Modificado el comportamiento de la orden UNDO. Ahora no se permite ejecutar si se está ejecutando una orden. Únicamente se puede ejecutar cuando el programa está en modo prepadado
* Modificado el bootstrapper del instalador para que no oculte ninguno de los componentes que instala el programa

## Correcciones

* Solucionado un problema por el cual no se cargaban geometrías almacenadas dentro de carpetas en un archivo KML. Únicamente se cargaban las geometrías que no estuvieran dentro de una carpeta.
* Solucionado un problema en la propiedad DigiNG.DrawingFile que podía crear un objeto Digi21.DigiNG.DrawingFile innecesariamente. Si se obtenía una entidad mediante un tentativo y se intentaba eliminar dicha entidad (siempre antes de acceder a la propiedad DigiNG.DrawingFile), al acceder a la propiedad DigiNG.DrawingFile se creaba un objeto Digi21.DigiNG.DrawingFile nuevo en vez de utilizar el ya generado para la propiedad Entity.Owner.
* Las macros $(HoraCompleta) y $(HoraCompletaSubrayados) se están sustituyendo por la fecha en vez de la hora
* Al crear copias de seguridad de archivos DGN en ocasiones el programa finaliza inesperadamente
