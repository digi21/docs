## Novedades

* Se ha añadido la propiedad DigiNG.Wkt y añadido el método DigiNG.SendInputDeviceEvent para poder enviar eventos a la ventana de dibujo. ([commit](https://blog.digi21.net/2017/09/09/utiliza-tu-gps-como-dispositivo-de-entrada-en-digi3d-net/))
* Se han añadido separadores a los menús para permitir a las extensiones .NET crear submenús en el menú Ventana.
* Se ha añadido un cuadro de diálogo de selección de las capas que se cargarán de los archivos de dibujo en formato Geomedia Datawarehouse. ([commit](https://blog.digi21.net/2017/09/10/mejoras-al-cargar-archivos-de-dibujo-de-geomedia-y-en-formato-shapefile/))
* Se ha añadido un cuadro de diálogo de selección de las capas que se cargarán de los archivos de dibujo en formato Shapefile. ([commit](https://blog.digi21.net/2017/09/10/mejoras-al-cargar-archivos-de-dibujo-de-geomedia-y-en-formato-shapefile/))
* Se ha añadido soporte de carga parcial para archivos de dibujo en formato Shapefile. ([commit](https://blog.digi21.net/2017/09/26/carga-archivos-por-regiones-de-interes/))
* La orden PROYECTA\_DEM ahora crea archivos TIFF. ([commit](https://blog.digi21.net/2017/09/27/novedades-en-la-orden-proyecta_dem/))
* Se ha añadido una opción para preconfigurar los parámetros de importación/exportación de archivos de dibujo.
* Se ha actualizado el driver de Gemalto a la versión 20.0.1.70827.
* Ahora se pueden configurar los parámetros de importación/exportación para los distintos formatos de archivo de dibujo soportados en las configuraciones de proyectos. ([commit](https://blog.digi21.net/2017/10/03/novedades-en-la-configuracion-de-proyectos/))
* Se ha modificado la lógica de carga de archivos .BLK para permitir cargar imágenes cuya extensión no coincide con la extensión indicada en el archivo .BLK.
* Se ha añadido soporte para cargar orientaciones afines en archivos .BLK con orientaciones de sensores satelitales.
* Se ha añadido soporte para cargar archivos .BLK con orientaciones satelitales con proyección UTM.
* Se han mejorado las notificaciones de errores semánticos. Si un motor de modelo semántico detecta que una geometría no supera la comprobación y proporciona las coordenadas del error, la ventana de dibujo se centra en esas coordenadas cuando indicas que se almacene la entidad.
* Se han mejorado las notificaciones de errores semánticos. Ahora, si se detectan X errores semánticos al registrar una entidad, el programa te pregunta si quieres almacenarla por cada uno de los errores detectados. Si decides no almacenar la entidad en alguna de las preguntas, el programa deja de mostrar preguntas nuevas.

## Correcciones

* Si en el Editor de Tablas de Códigos se importa un esquema de base de datos de ArcMAP, el programa no solicita Guardar la tabla de códigos al cerrar el Editor de Tablas de Códigos.
* Si un código tiene espacios en su nombre, la barra de herramientas de selección de código no permite seleccionarlo.
* Al crear un archivo .DGN con células compartidas el programa muestra un mensaje de error.
* El importador/exportador de Shapefiles utiliza el valor seleccionado en Página de códigos únicamente para la exportación y no para la importación.
* Si está activado el indicador de inserción automática de vértices, al trabajar con archivos de dibujo en formato Geomedia si se realiza alguna modificación de una geometría existente aparece un mensaje de error y se duplica la entidad.
* El programa no localiza orientaciones en ciertos archivos .PRJ. Al cargar un archivo .PRJ de Inpho en el cual los nombres de las fotos que aparecen en la variable $PHOTO\_NUM no coinciden con los nombres de las fotos que aparecen en la variable  $PHOTO\_FILE, el programa no es capaz de localizar las orientaciones de las fotos.
* Si está activado el flag FIJAZ y se cambia de código clonando una geometría existente, el flag FIJAZ no se desactiva.
* Al ejecutar las órdenes SUBE\_Z y BAJA\_Z se bloquea la Z en la ventana fotogramétrica independientemente del estado del flag FIJAZ.
* El programa solicita los parámetros de importación aunque ya los hayas introducido en el cuadro de diálogo Abrir.
* La orden HORIZON nunca finaliza si se ejecuta en un archivo que tenga alguna geometría eliminada.
* Si se están digitalizando puntos con un determinado código y se cambia de código sin haber cancelado la orden antes, el primer punto digitalizado se almacena con el código anterior.
* Los botones de la barra de herramientas de coordenadas Z no tienen los iconos que les corresponden.
* Al cambiar de código mediante la orden CLONAR no se deshabilita la opción de FIJA\_Z si esta está activada.
* El programa no carga correctamente los archivos de auto-modo de búsqueda.
* En ocasiones al exportar a DGN y a DWG el programa finaliza inesperadamente.
* El programa no extrae los parámetros de orientación interna de cámaras Vexcel.
