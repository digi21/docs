# Digi3D.AI 2017.0.0.45

Publicada el 28/08/2017.

## Novedades

* Modificado el programa para permitir crear archivos TIFF mal formados creados con Imagine de Erdas versión 1.10.1.9.1.9.2.11
* Se ha añadido soporte para cargar archivos .PRJ de Inpho con cámaras analógicas.
* Se han añadido opciones para cambiar el Brillo/Contraste/Gamma en las ortofotos cargadas en la ventana de dibujo. ([commit](http://blog.digi21.net/2017/08/28/cambia-el-brillo-contraste-o-gamma-en-las-ortofotos-cargadas-en-la-ventana-de-dibujo))

## Correcciones

* Si se detectan excepciones administradas al cargar modelos desde el panel de proyecto fotogramétrico el programa finaliza inesperadamente.
* No se corrigen correctamente las distorsiones en archivos .PRJ de Inpho con cámaras con distorsiones de tipo radio-valor.
* En equipos nuevos con manivelas de tipo REST4 el cuadro de diálogo de comprobación de dispositivo de entrada muestra movimiento en las manivelas pero la ventana fotogramétrica no se mueve al mover las manivelas.
* En ocasiones, al cerrar una ventana de dibujo, el programa no permitía volver a abrir el archivo de dibujo. Era necesario reiniciar el programa. Este problema estaba ocasionado por el uso de punteros inteligentes y sucedía al abrir el archivo de dibujo, abrir la ventana fotogramétrica y cerrar el archivo de dibujo.
