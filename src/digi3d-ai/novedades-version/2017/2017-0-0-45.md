## Novedades

* Modificado el programa para permitir crear archivos TIFF mal formados creados con Imagine de Erdas versión 1.10.1.9.1.9.2.11
* Añadido soporte para cargar archivos .PRJ de Inpho con cámaras analógicas
* Añadidas opciones para cambiar el Brillo/Contraste/Gamma en las ortofotos cargadas en la ventana de dibujo ([commit](http://blog.digi21.net/2017/08/28/cambia-el-brillo-contraste-o-gamma-en-las-ortofotos-cargadas-en-la-ventana-de-dibujo))

## Correcciones

* Si se detectan excepciones administradas al cargar modelos desde el panel de proyecto fotogramétrico el programa finaliza inesperadamente
* No se corrigen correctamente las distorsiones en archivos .PRJ de Inpho con cámaras con distorsiones de tipo radio-valor
* En equipos nuevos con manivelas de tipo REST4 el cuadro de diálogo de comprobación de dispositivo de entrada muestra movimiento en las manivelas pero la ventana fotogramétrica no se mueve al mover las manivelas
* En ocasiones al cerrar una ventana de dibujo el programa no permite volver a abrir dicho archivo de dibujo. Es necesario reiniciar el programa. Este problema está ocasionado por el uso de punteros inteligentes y sucedía al seguir la siguiente secuencia: abrimos el archivo de dibujo, abrimos la ventana fotogramétrica, cerramos el archivo de dibujo. 

A partir de este momento ya no se podía abrir la ventana de dibujo con el mismo archivo de dibujo.
