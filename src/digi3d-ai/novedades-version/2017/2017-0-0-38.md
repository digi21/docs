# Digi3D.AI 2017.0.0.38

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 27/06/2017.

## Novedades

* Añadida nueva macro $(DirectorioAyuda) que se sustituye por el directorio de ayuda configurado por el usuario
* Nueva orden MUESTRA\_AYUDA que muestra en la ventana de ayuda el archivo HTML cuya ruta se pasa por parámetros a esta orden
* Añadida la opción del menú Inundación/Eliminar código
* Cambiado el título del menú Inundaciones/Generar inundaciones por Inundaciones/Generar topología para inundaciones
* Nueva opción del menú Inundación/Descargar topología para inundaciones
* Modificación en la política de UNDO. En la versión 2017.0.0.32 se realizó un cambio en la política de UNDO por el cual no se permitía ejecutar esta orden si el programa no estaba en modo "Preparado". Hemos relajado esta política, y ahora no se permite ejecutar la orden UNDO únicamente si se está en mitad de una transacción (es decir, se está ejecutando una orden y ésta aún no ha finalizado y ha realizado alguna modificación en el archivo de dibujo)
* Añadida la opción del menú Inundación/Descartar topología temporal
* Al Añadir nuevas entidades a un archivo Shapefile, Geomedia no reconoce las geometrías que están fuera de los límites de las geometrías digitalizadas con Digi3D.NET
* Nueva orden CARGAR\_ENSAMBLADO para cargar ensamblados .NET sin necesidad de modificar el registro
* Ahora se pueden cargar tablas de códigos de servidores WEB

## Correcciones

* El tentativo falla en polígonos con huecos. En la versión 2017.0.0.14 se realizó un cambio significativo en los tentativos para permitir trabajar en coordenadas geográficas con precisión de 1e-13, y eso provocó que los tentativos con huecos no tentasivasen correctamente.
* El tentativo falla si la diferencia de coordenada Z entre el cursor y la entidad a tentativar es muy grande
* Al tentativar una entidad no aparece la cruz que marca la zona de tentativo en la ventana de dibujo hasta que se regenera pantalla o se cambia el nivel de zoom
* Al añadir códigos por inundación, si se inunda un hueco de un polígono, se añade el código las entidades que definen el hueco
* Al realizar la relación de solape entre dos áreas, si el segundo área analizada tenía un punto en común con el primer vértice de la primera área, el programa podía finalizar inesperadamente
* Solucionado un fallo que podía hacer que el programa finalizase inesperadamente si se ejecutaban guiones .NET sobre el archivo de dibujo y se descargaba el archivo de dibujo y se cargaba uno nuevo.
* En equipos sin Visual Studio 2010 Redistributable Package al aceptar el cuadro de diálogo de Configuración se muestra un mensaje de error indicando que el servidor está ocupado
* La orden SELECCIONA\_POLIGONO\_NUEVO en ocasiones finaliza el programa inesperadamente
* La propiedad ReadOnlyPolygon.InteriorPoint no calcula correctamente el centroide si el polígono tiene huecos
* Al analizar una topología el objeto ClosedLoopWithHoles devuelto nunca tiene centroides asociados
* Al comprimir archivos .SHP el programa finaliza inesperadamente
* Al ejecutar la orden BINTRAM desde la línea de comandos no se interpretan correctamente los parámetros de agrupar vértices y de insertar vértices por tolerancia
* El operador - del tipo Digi21.Math.Point3D no resta correctamente la coordenada Z
