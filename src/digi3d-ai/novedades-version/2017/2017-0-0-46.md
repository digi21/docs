# Digi3D.AI 2017.0.0.46

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 29/08/2017.

## Novedades

* Se ha añadido soporte para cargar archivos .PRJ de Inpho de versión 7.1.0 en los que han cambiado los nombres de alguna variable como $CAMERA\_DEFINITION en vez de $CAMERA e $ID en vez de $TYPE.
* Se ha añadido soporte al programa Editor de Tablas de códigos para importar esquemas de bases de datos y códigos de archivos de definición de espacio de trabajo de ArcGIS.
* Se ha añadido soporte al programa Editor de Tablas de códigos para crear códigos a partir de un archivo CSV con datos de traducción de DGN.

## Correcciones

* Al seleccionar la opción del menú Símbolos/Importar símbolos de archivo .CEL de MicroStation en el Editor de Tablas de Códigos no se realiza ninguna acción.
* Si la llave de protección tiene múltiples activaciones de un ordenador, Digi3D.NET no es capaz de localizar la activación más reciente y por lo tanto indica que el ordenador no está activado.
* El programa no localiza orientaciones de cámaras digitales en archivos .PRJ de Inpho desde que se añadió el soporte para cargar orientaciones de cámaras analógicas.
* Se ha solucionado un problema introducido en la versión 2017.0.0.41 al activar la inserción automática de vértices en las intersecciones de las geometrías nuevas: al dibujar una geometría nueva, la geometría no se llegaba a almacenar.
