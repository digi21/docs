# Digi3D.AI 2017.0.67.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 18/12/2017.

## Novedades

* Añadida la orden AÑADIR\_CODIGOS
* Ahora al importar esquemas de trabajo de ArcGIS se crea un código sin condiciones cuyo nombre coincide con el nombre de la tabla de BBDD.
* Añadidos prefijos a los códigos importados de un esquema de trabajo de ArcGIS para diferenciar entre códigos de tipo línea, punto, polígono, etc
* Añadida opción para cambiar un campo a "No comparable" en todas las tablas en las que aparece en el programa Editor de Tablas de códigos
* Añadida opción para eliminar códigos duplicados al programa Editor de tablas de códigos
* Ahora el editor de tablas de códigos muestra la tabla asociada a cada código.
* Nuevo panel acoplable "Tabla de códigos" ([commit](https://blog.digi21.net/2018/01/16/nuevo-panel-tabla-de-codigos/))
* Ahora si se está trabajando sobre un Shapefile y se dibuja una línea abierta en una capa de tipo polígono, el programa muestra la línea cerrada en la ventana de dibujo
* Eliminada la opción de configuración "rotar sistema fiducial", pues únicamente era necesario para proyectos de Inpho. Ahora si el proyecto fotogramétrico que se está cargando es de Inpho, se aplica este cálculo automáticamente
* Ahora se pueden crear archivos .pg (archivos con parámetros de conexión PostGIS) desde el cuadro de diálogo de nuevo proyecto

## Correcciones

* El importador de códigos de esquema de ArcInfo genera códigos duplicados si ya existen dichos códigos en la tabla de códigos en el momento de importar
* En ocasiones no se selecciona correctamente el código al cargar un archivo shapefile. Ahora al seleccionar el código para una geometría cargada de un archivo shapefile con una tabla de códigos con múltiples códigos para la misma tabla, si se localiza la tabla sin restricciones en vez de asignar el código a esta tabla se asegura de que no hay más códigos con restricciones que apunten a la misma tabla
* En ocasiones al sincronizar zooms entre la ventana fotogramétrica y la de dibujo, éstos no se sincronizan completamente
