# Digi3D.AI 2017.0.67.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 18/12/2017.

## Novedades

* Se ha añadido la orden AÑADIR\_CODIGOS.
* Ahora al importar esquemas de trabajo de ArcGIS se crea un código sin condiciones cuyo nombre coincide con el nombre de la tabla de base de datos.
* Se han añadido prefijos a los códigos importados de un esquema de trabajo de ArcGIS para diferenciar entre códigos de tipo línea, punto, polígono, etc.
* Se ha añadido una opción para cambiar un campo a "No comparable" en todas las tablas en las que aparece en el programa Editor de Tablas de códigos.
* Se ha añadido una opción para eliminar códigos duplicados al programa Editor de tablas de códigos.
* Ahora el editor de tablas de códigos muestra la tabla asociada a cada código.
* Se ha añadido el panel acoplable "Tabla de códigos". ([commit](https://blog.digi21.net/2018/01/16/nuevo-panel-tabla-de-codigos/))
* Ahora si se está trabajando sobre un Shapefile y se dibuja una línea abierta en una capa de tipo polígono, el programa muestra la línea cerrada en la ventana de dibujo.
* Se ha eliminado la opción de configuración "rotar sistema fiducial", pues únicamente era necesaria para proyectos de Inpho. Ahora, si el proyecto fotogramétrico que se está cargando es de Inpho, la rotación del sistema fiducial se calcula automáticamente.
* Ahora se pueden crear archivos .pg (archivos con parámetros de conexión PostGIS) desde el cuadro de diálogo de nuevo proyecto.

## Correcciones

* El importador de códigos de esquema de ArcInfo genera códigos duplicados si ya existen dichos códigos en la tabla de códigos en el momento de importar.
* En ocasiones no se selecciona correctamente el código al cargar un archivo shapefile. Ahora, al seleccionar el código para una geometría de un archivo shapefile, si varios códigos apuntan a la misma tabla y el programa localiza un código sin restricciones, comprueba si hay más códigos con restricciones que apunten a esa tabla antes de asignar el código sin restricciones a la geometría.
* En ocasiones al sincronizar zooms entre la ventana fotogramétrica y la de dibujo, éstos no se sincronizan completamente.
