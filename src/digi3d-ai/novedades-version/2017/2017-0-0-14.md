## Novedades

* Añadida una opción al cuadro de diálogo de sustituir valores de base de datos para sustituir cualquier valor por uno determinado.
* Actualizada la dependencia al componente Glew a su última versión
* Cambios en las fechas de copyright para incluir 2017
* Mejorado el algoritmo para comprobar si dos vectores están alineados con precisiones inferiores a 1e-15
* Ahora al pre-almacenar una geometría de tipo polígono se eliminan los puntos dobles automáticamente tal y como siempre se ha hecho con líneas
* Ahora la orden COMPRIMIR no recibe parámetros. Hasta hoy la orden COMPRIMIR podía recibir como parámetros dos flags para indicar si se debían eliminar puntos dobles. Hemos eliminado esta funcionalidad de la orden COMPRIMIR pues no era compatible con archivos de Geomedia.
* Ahora el exportador de Geomedia no permite almacenar como distintas dos coordenadas cuya diferencia sea inferior al sigma activo
* Creada la orden ELIMINAR\_PUNTOS\_DOBLES
* Ahora en instalaciones de 64 bits el título del programa "Editor de Tablas de Códigos" pasa a ser "Editor de Tablas de Códigos x64"
* Ahora en instalaciones de 64 bits el título del programa "Generador de niveles piramidales" pasa a ser "Generador de niveles piramidales x64"
* Nueva orden EXPORTAR\_ENTIDADES\_SELECCIONADAS ([commit](https://blog.digi21.net/2017/01/24/exportar-las-entidades-seleccionadas/))
* Nueva orden DETECTAR\_BUCLES ([commit](https://blog.digi21.net/2017/01/23/detectar-bucles/))
* Nueva orden DETECTAR\_SEGMENTOS\_CORTOS ([commit](https://blog.digi21.net/2017/01/25/detectar-segmentos-cortos/))
* Modificado el cuadro de diálogo de cambiar valores de base de datos para que se muestre con el tema activo

## Correcciones

* El programa finaliza inesperadamente cargando archivos DWG que generan mensajes de error.
* Con sigmas de doble precisión, como 1e-15, los tentativos no tentativan en la proyección correcta
* Si se especifica una ondulación del geoide manualmente, el programa no muestra los vectores en su coordenada Z
* Si se selecciona como sistema de referencia de coordenadas vertical EGM2008, la ondulación del geoide calculada en coordenadas longitud negativas muy cerca de la latitud 0 son incorrectas. Hemos solucionado este problema ocasionado por un problema a la hora de cachear el grid EGM2008
* El cuado de diálogo de introducción de ondulación del geoide permite introducir un valor sin especificar previamente que se quiere introducir un valor manual. Hemos solucionado este problema estético.
