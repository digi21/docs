## Novedades

* Añadido el motor SQLite (3.19.3) en la instalación del programa
* Modificado el comportamiento de la orden auto\_insertar\_vertice\_interseccion\_al\_finalizar\_linea. Ahora se analizan las líneas creadas o modificadas por cualquier orden
* Ahora el importador de tablas BINDXF modifica los parámetros de importación/exportación para códigos ya existentes en vez de crear códigos duplicados.
* Ahora el cargador de inpho permite cargar pasadas cuyo nombre tenga un espacio especificado como "\\ ".
* Añadido el método de extensión UtilidadesSecuenciaEntity.QueNoTenganAlgúnCódigo
* Añadido un nuevo formato (.csv) de carga de proyectos fotogramétricos de tipo sensor cónico. El formato del archivo es:

\[pasada\] \[ruta a la foto izquierda\] \[ruta a la foto derecha\] \[ruta al archivo de orientaciones\]
* La orden CAMB\_AA ahora transforma puntos si se seleccionan con selección múltiple
* El importador de orientaciones de PhotoScan ahora lee el nodo "reference" para saber de un punto en el modelo.

## Correcciones

* Al cargar una tabla de códigos cifrada el programa indica que la contraseña es incorrecta
* Ahora la orden MUESTRA\_AYUDA permite indicar rutas URL ubicadas en servidores web
* Si un control de calidad indica que una entidad de tipo Punto tiene un error, al hacer doble clic en la tarea la ventana de dibujo muestra un zoom indeterminado
* Al cargar ciertos modelos de PhotoStan la epipolar se calcula al revés y el movimiento de las imágenes es el inverso al esperado. Ahora el sensor de cámara cónica tiene en cuenta si el punto de origen está por encima del centro de proyección de la cámara izquierda. En caso afirmativo, estaríamos trabajando con la simetría, de manera que se cambian el sentido de la matriz de nivelación y además las epipolares se calculan al revés.
* Si el usuario cancela el cuadro de diálogo de selección de sistema de referencia de coordenadas al cargar un archivo de proyecto fotogramétrico el programa finaliza inesperadamente
