* Mejorada la interpolación EGM2008 para coordenadas entre longitudes negativas y positivas. Ahora el programa interpola correctamente la rejilla EGM2008 entre dos longitudes si una de ellas es negativa y la otra positiva, como por ejemplo para la coordenada 39.4906552769439 -0.000277778

La librería GLEW actualizada en la versión anterior creaba un problema en el patrón haciendo que el programa finalizase inesperadamente si se activaba el patrón. Hemos actualizado la librería a una versión más moderna (2.0.0.0) y ha quedado resuelto el problema.
