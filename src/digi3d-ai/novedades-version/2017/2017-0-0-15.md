## Correcciones

* Se ha mejorado la interpolación EGM2008 para coordenadas entre longitudes negativas y positivas. Ahora el programa interpola correctamente la rejilla EGM2008 entre dos longitudes si una de ellas es negativa y la otra positiva, como por ejemplo para la coordenada 39.4906552769439 -0.000277778.
* Se ha solucionado un problema con el PATRON causado por la biblioteca GLEW actualizada en la versión anterior. Esa biblioteca hacía que el programa finalizase inesperadamente al activar el patrón. Se ha actualizado la biblioteca a una versión más moderna (2.0.0.0), lo que ha resuelto el problema.
