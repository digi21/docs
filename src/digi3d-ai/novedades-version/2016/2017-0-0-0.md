## Correcciones

* Solucionado un problema al añadir etiquetas por tabla en el editor de tablas de códigos. Se estaba añadiendo la etiqueta al siguiente código, y no al código en el que se pretendía añadir la etiqueta.
* El programa finaliza al comprimir en equipos con el programa recién instalado. Se ha solucionado este problema.
* Las órdenes MOD y MOD\_Z finalizan el programa inesperadamente al modificar un polígono con huecos.
* La orden Z no estaba modificando la coordenada Z en la ventana fotogramétrica si ésta estaba bloqueada
* Solucionado un problema en las entidades enumeradas por Digi21.DigiNG.DrawingFile. Estas entidades no tenían asignada la propiedad Owner, de manera que no se podían acceder a las propiedades de Base de Datos asociada con la entidad ya que se desconocía el archivo de dibujo propietario.
* Solucionado un problema en el programa Generador de Imágenes Piramidales. El programa podía finalizar inesperadamente al intentar procesar una cadena de caracteres enviada por la librería LibTIFF.
* La orden VELOCIDAD no muestra el cuadro de diálogo si hay abierta una ventana de dibujo. Se ha solucionado este problema, así como un problema relacionado en las órdenes ABRIR\_\_BING\_MAPS, CAMBIA\_BRILLO\_INDICE, MATRIZ\_NIVELACION, MOSTRAR\_FACTOR\_CORRELACION, VELOCIDAD y ZOOM.
* Solucionado un problema al calcular ortofotos si el SRC de la ventana de dibujo no coincide con el SRC del sensor. Se ha solucionado este problema. Ahora la orden CAL\_ORTO realiza la transformación de coordenadas entre el sistema de referencia de coordenadas de la ventana de dibujo (que es el SRC en el que se calcula la ortofoto) y el sistema de referencia de coordenadas de la ventana fotogramétrica.
* Solucionado un problema en el motor de EGM2008. Se ha localizado un problema relacionado con el motor de EGM2008 que podía hacer que el programa finalizase inesperadamente.  Si varios hilos de ejecución solicitaban simultáneamente datos a la rejilla EGM2008, es posible que el programa finalizase inesperadamente.
* La ventana fotogramétrica no muestra los puntos medidos. Se había deshabilitado esta opción al añadir al programa rotaciones de imágenes por hardware. Ahora volvemos a recuperar esta funcionalidad.
* El programa finaliza inesperadamente al crear niveles piramidales con archivos TIFF comprimidos en JPEG
* Si se cancela la carga de un archivo de dibujo porque no se ha localizado la tabla de códigos especificada en la pestaña Archivo de dibujo el programa finaliza inesperadamente
* Solucionado un problema en el cuadro de diálogo de configuración de proyectos de archivos. El programa no mostraba correctamente el sistema de referencia de coordenadas para la ventana de dibujo en la configuración. Este era un problema menor ya que la vista de dibujo sí que cargaba correctamente el sistema de referencia de coordenadas correspondiente.
* La orden LISTA no muestra correctamente el perímetro 3D de la entidad seleccionada. Se ha solucionado este problema que afectaba a las órdenes que requerían calcular módulos 3D en sistemas de referencia de coordenadas proyectados, se estaba calculando el perímetro en 2D y no en 3D.
