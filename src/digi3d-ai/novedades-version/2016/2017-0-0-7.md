# Digi3D.AI 2017.0.0.7

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 12/12/2016.

## Novedades

* Mejorada considerablemente la velocidad de carga de archivos DEM contenidos en archivos TIFF teselados
* Añadido soporte para generar ortofotos estereoscópicas con imágenes TIFF con 4 canal alfa
* Actualizada la suite de licencias incorporada en el instalador
* Añadido soporte para la orden INS\_FOTO
* Ahora se emiten mensajes de advertencia y error de LibTIFF como cadenas de depuración
* Ahora la orden BININFO muestra el rango de coordenadas de archivos de dibujo que no proporcionan gometrías, como MDTs
* Añadido soporte para compresión Adobe Deflate a los archivos TIFF
* Actualizada la versión del componente de terceros LibTIFF a la versión 4.0.6.2
* Actualizada la versión del componente de terceros LibTIFF a la versión 1.2.8.8
* Actualizada la versión del componente de terceros LibJpeg a la versión 9.2.0.1
* Añadido soporte para el modelo de calibración de cámaras de RapidCAL
* Modificadas las fórmulas de corrección de calibración de PhotoScan según el manual del programa
* Ahora los archivos de error propuestos por las órdenes BINTRAM y BINTOP tienen como extensión .BIND
* Añadida la posibilidad de cargar archivos .PNG con la orden CARGA\_RASTER

## Correcciones

* Al crear un par estereoscópico a partir de una ortofoto el modelo generado es invertido
* Las órdenes que admiten etiquetas desde la línea de comandos no funcionan correctamente. Se ha solucionado el problema para las órdenes CAMB\_AA, CAMT\_JT, CAMB\_JT2, CAMB\_MAXPUNTOS, CAMB\_SEN, CAMB\_SEN\_BAJA, CAMB\_SEN\_SUBE, CAMB\_Z
* En ocasiones se repite constantemente la órden asignada a un botón del dispositivo de entrada
* Si se carga como archivo de dibujo uno que tenga geometrías de tipo Bitmap no se muestran los bitmaps, pero si se carga como referencia sí
* Si se selecciona como archivo de tabla de códigos un archivo .xml que no sea una tabla de códigos el programa finaliza inesperadamente
* El programa externo Editor de Tablas de Códigos muestra mensajes en inglés
* Si se activa en el panel de proyecto fotogramétrico el botón de cambio automático de modelo y no hay ningún proyecto cargado el programa finaliza inesperadamente
* El panel de Archivos de dibujo muestra el archivo de dibujo activo en si el tema activo es oscuro, de manera que no se ve con claridad el nombre del archivo
* Al deshabilitar la opción "Mostrar imágenes" en el panel "Propiedades de visualización" de la ventana fotogramétrica, los vectores aparecen desplazados y estáticos
* Si se ejecuta la orden BINTRAM o BINTOP especificando crear un archivo de errores que está actualmente cargado como archivo de referencia, el programa finaliza inesperadamente
