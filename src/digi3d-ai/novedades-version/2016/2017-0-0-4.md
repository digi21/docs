# Digi3D.AI 2017.0.0.4

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 04/11/2016.

## Novedades

* Ahora los menús dinámicos que muestran etiquetas pueden mostrar únicamente las etiquetas de los códigos de las geometrías cargadas. ([commit](https://blog.digi21.net/2016/10/28/menus-dinamicos-mas-dinamicos-que-nunca/))
* Se ha mejorado la comunicación de errores al analizar topologías. ([commit](http://blog.digi21.net/2016/10/31/mejoras-en-la-comunicacion-de-errores-en-los-analisis-topologicos-de-digi3d-net))
* Se ha añadido la orden SELECCIONA\_INUNDACION. Esta nueva orden te permite enviar las líneas que forman el contorno exterior del polígono o polígonos que selecciones mediante una inundación a la orden que se esté ejecutando en este momento. ([commit](http://blog.digi21.net/2016/11/02/nueva-orden-selecciona_inundacion))
* Se ha añadido la orden RENOMCOD\_SEL. Con esta orden puedes renombrar el código indicado en todas las entidades seleccionadas. ([commit](http://blog.digi21.net/2016/11/03/nueva-orden-renomcod_sel))
* Ahora, si se localiza un error de modelo semántico al almacenar una geometría, el programa te pregunta si quieres almacenarla. ([commit](http://blog.digi21.net/2016/11/04/mejora-al-detectar-un-error-de-modelo-semantico-al-almacenar-una-geometria))
* Se ha añadido la posibilidad de indicar en el esquema de base de datos que un campo es de tipo fecha.
* Ahora no es obligatorio enlazar un código con una tabla en la tabla de códigos para que ese código se pueda exportar a Shapefile.

## Correcciones

* La opción "Ayuda" del menú principal aparece desplazada en la versión en español.
* Los análisis topológicos desde menús dinámicos a veces no comprueban si hay polígonos sin centroide.
* Si al cargar un modelo de sensor cónico con SRC horizontal pero sin SRC vertical se selecciona la opción de "desconozco el SRC vertical" el SRC compuesto creado no tiene un nombre correcto. Se ha solucionado este problema puramente estético pues el resto de la cadena WKT es correcta.
* Se ha solucionado un problema al detectar si dos áreas solapaban.
* Las extensiones compiladas para una versión de la rama 2017 no funcionan al actualizar a una versión posterior. Se ha solucionado este problema haciendo que los ensamblados .NET tengan como número de versión 2017.0.0.0.
* El panel de tentativos no muestra un histórico de los tentativos.
* Si al cargar un modelo cónico con SRC asociado sin componente vertical se indica que el sistema vertical es desconocido, el título del SRC formado es incorrecto.
* No se almacena el área de entidades de tipo polígono en el .DBF asociado a un shapefile si en un campo se indica utilizar la macro ENTITY\_AREA.
