# Digi3D.AI 2017.0.0.8

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 20/12/2016.

## Novedades

* Ahora la orden CAMBIAR\_VALORES\_BBDD permite asignar un identificador único global (GUID) (generado para cada registro) a un campo.
* Ahora la orden CAMBIAR\_VALORES\_BBDD permite trabajar con múltiples códigos simultáneamente.
* Ahora los elementos añadidos en el panel de Tareas pueden tener un menú contextual.
* Se ha añadido la orden ASIGNA\_ATRIBUTO\_BBDD\_ENTIDAD para sustituir el valor de un campo de base de datos de una geometría existente.
* Se han introducido mejoras en el cuadro de diálogo común de búsqueda de códigos.
* El cuadro de diálogo de borrar por ventana admite cambios de tamaño.
* El cuadro de diálogo de borrar recinto admite cambios de tamaño.
* Ahora las órdenes BINTRAM y BINTOP permiten seleccionar códigos de la lista de códigos activa en vez de trabajar con archivos de tablas. ([commit](https://blog.digi21.net/2016/12/17/mejoras-de-productividad-en-bintram-y-bintop-gracias-a-las-ultimas-modificaciones-en-el-cuadro-dialogo-generico-de-seleccionar-codigos/))
* Se ha implementado la orden CARGA\_RASTER.
* Se ha añadido soporte para cargar en la ventana de dibujo imágenes en formato Portable Network Graphics. ([commit](https://blog.digi21.net/2016/12/19/anadido-soporte-para-imagenes-en-formato-png/))
* Se han añadido las órdenes INS\_FOTO\_2P\_AA e INS\_FOTO\_3P. ([commit](https://blog.digi21.net/2016/12/19/nuevas-ordenes-para-insertar-fotos-en-un-archivo-de-dibujo/))
* Ahora se puede especificar el tamaño de la ventana de coordenadas en las barras de herramientas Coordenadas y Tentativo. Puedes cambiar el tamaño mediante la opción de la sección Barras de herramientas del cuadro de diálogo Configuración.

## Correcciones

* La orden MOVER no mueve geometrías de tipo Bitmap.
* No se muestran transparencias en bitmaps cargados en la ventana de dibujo.
