# Digi3D.AI 2017.0.0.2

Publicada el 21/10/2016.

## Novedades

* Se han añadido excepciones al ensamblado Digi21.DigiNG para análisis de modelo semántico. Se han añadido las excepciones: Digi21.DigiNG.DatabaseAttributeException, Digi21.DigiNG.DigitizeAsPointException, Digi21.DigiNG.GeometricRelationException, Digi21.DigiNG.GeometryException.
* Se han refactorizado partes del programa para adaptarlo a C++14.
* Se han añadido órdenes para analizar el modelo semántico: MODELO\_SEMANTICO, MODELO\_SEMANTICO\_COD.
* Se ha añadido al ensamblado Digi21.DigiNG el tipo Digi21.DigiNG.DigiTab.NodeDigiTab.Alias para poder acceder mediante programación .NET a los alias de un determinado código en la tabla de códigos.
* Se ha añadido el método Digi21.DigiNG.Entieies.Relations.AreaArea.CompletelyWithin con varias sobrecargas para comprobar si una entidad está completamente en el interior de otra.
* Ahora el cuadro de diálogo de Acerca De muestra la fecha y hora de compilación de la aplicación.
* Ahora el instalador muestra el icono de la aplicación en Agregar o quitar programas.

## Correcciones

* Se ha solucionado un problema en el instalador web. Ciertos componentes se estaban descargando de algunos servidores de Microsoft no compatibles con el mecanismo de descarga e instalación de componentes del instalador unificado de WiX.
* Los archivos de cámara no se almacenan correctamente en los archivos orientation.xml.
* Se ha solucionado un problema con los certificados de cámara clásicos de radio-distorsión, provocado por la nueva implementación del modelo de cámaras. La nueva implementación debe devolver el punto con la corrección aplicada, mientras que la anterior debía devolver la corrección que se debía aplicar al punto.
* Al cargar una tabla de códigos, el editor de tablas de códigos indica que todos los códigos tienen relleno de tipo bitmap.
* En ocasiones no se instala la aplicación porque falla la instalación del driver de Safenet. El instalador de tipo Microsoft Installer no puede detener servicios, por lo que fallaba al instalar el driver en equipos con una versión anterior del driver instalada. Se ha solucionado el problema utilizando el instalador de línea de comandos, que permite detener servicios.
