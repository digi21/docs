## Novedades

* Añadidas excepciones al ensamblado Digi21.DigiNG para análisis de modelo semántico. Se han añadido las excepciones: Digi21.DigiNG.DatabaseAttributeException, Digi21.DigiNG.DigitizeAsPointException, Digi21.DigiNG.GeometricRelationException, Digi21.DigiNG.GeometryException.
* Refactorización de partes del programa para adaptarlo a C++14
* Nuevas órdenes para análisis de modelo semántico. Se han añadido las órdenes MODELO\_SEMANTICO, MODELO\_SEMANTICO\_COD
* Añadidos tipos al ensamblado Digi21.DigiNG. Se ha añadido el tipo Digi21.DigiNG.DigiTab.NodeDigiTab.Alias para poder acceder mediante programación .NET a los alias de un determinado código en la tabla de códigos.
* Añadido el método Digi21.DigiNG.Entieies.Relations.AreaArea.CompletelyWithin. Se ha añadido este método con varias sobrecargas para comprobar si una entidad está completamente en el interior de otra.
* Ahora el cuadro de diálogo de Acerca De muestra la fecha y hora de compilación de la aplicación
* Ahora el instalador muestra el icono de la aplicación en Agregar o quitar programas

## Correcciones

* Solucionado un problema en el instalador web. Ciertos componentes se estaban descargando de algunos servidores de Microsoft no compatibles con la tecnología de Bootstrapping de Wix
* Los archivos de cámara no se almacenan correctamente en los archivos orientation.xml
* Problemas con certificados de cámara clásicos de radio-distorsión. Se ha solucionado este problema provocado por la nueva implementación de modelo de cámaras, en el que donde antes se tenía que devolver la corrección a aplicar a un punto, ahora se tiene que devolver el punto con la corrección aplicada.
* Al cargar una tabla de códigos, el editor de tablas de códigos indica que todos los códigos tienen relleno de tipo bitmap
* En ocasiones no se instala la aplicación porque falla la instalación del driver de Safenet. El instalador de tipo Microsoft Installer no puede paralizar servicios, y esto provoca que éste falle al instalarse en equipos con una versión anterior del driver instalada. Hemos solucionado este problema al utilizar el instalador de línea de comandos que es más versátil y es capaz de paralizar servicios.
