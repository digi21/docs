# Digi3D.AI 2019.1.0.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 29/03/2019.

## Novedades

* Se ha modificado el programa para que el panel de proyecto fotogramétrico muestre únicamente los modelos que se han localizado. ([commit](https://github.com/digi21/TareasDigi3D/issues/7))
* Ahora puedes configurar si las regiones de interés en PostGIS son de tamaño constante. ([commit](https://github.com/digi21/TareasDigi3D/issues/8))
* Se ha modificado el programa para que en el cuadro de diálogo de selección de capa de PostGIS el botón por defecto sea el de aceptar. ([commit](https://github.com/digi21/TareasDigi3D/issues/11))
* Se ha modificado el programa para que se puedan exportar Shapefiles con un esquema distinto al asignado al código. ([commit](https://github.com/digi21/TareasDigi3D/issues/15))
* Ahora el programa puede trabajar con cadenas WKT compatibles con ArcMAP. ([commit](https://github.com/digi21/TareasDigi3D/issues/17))
* Ahora puedes configurar el programa para que no cree cadenas WKT 3D si el sistema vertical es desconocido y para que, al cargar sistemas 2D, considere desconocido el sistema vertical. ([commit](https://github.com/digi21/TareasDigi3D/issues/18))
* La orden CAMB\_COD\_R no está preparada para multi-codificación. ([commit](https://github.com/digi21/TareasDigi3D/issues/20))
* El programa tarda mucho tiempo en finalizar las órdenes cuando la base de datos tiene cientos de campos. ([commit](https://github.com/digi21/TareasDigi3D/issues/24))
* Ahora puedes crear más de un panel del editor de base de datos para visualizar y editar múltiples tablas simultáneamente. ([commit](https://github.com/digi21/TareasDigi3D/issues/35))
* Se ha añadido la posibilidad de añadir varias veces el mismo código en una geometría pero con distinto registro. ([commit](https://github.com/digi21/TareasDigi3D/issues/13))
* Se ha creado una orden para localizar en el panel editor de base de datos una geometría seleccionada gráficamente. ([commit](https://github.com/digi21/TareasDigi3D/issues/36))
* Se ha modificado el programa para que la orden BININFO muestre el sistema de referencia de coordenadas de la ventana de dibujo. ([commit](https://github.com/digi21/TareasDigi3D/issues/40))
* Se ha modificado el programa para que se pueda configurar el tamaño de las teselas para imágenes que no están formadas por teselas. ([commit](https://github.com/digi21/TareasDigi3D/issues/48))
* Se han creado las órdenes EXPLOTAR\_POLIGONO y EXPLOTAR\_POLIGONOS\_COD. ([commit](https://github.com/digi21/TareasDigi3D/issues/47))
* Las órdenes EXPLOTAR\_COMPLEJO y EXPLOTAR\_COMPLEJOS\_COD explotan geometrías de tipo polígono. ([commit](https://github.com/digi21/TareasDigi3D/issues/46))
* Se ha modificado el programa para que la barra de mensajes de la ventana fotogramétrica muestre las unidades de los sistemas horizontal/vertical de la ventana. ([commit](https://github.com/digi21/TareasDigi3D/issues/42))
* Se ha modificado el programa para que la barra de herramientas de coordenadas muestre las unidades del sistema vertical. ([commit](https://github.com/digi21/TareasDigi3D/issues/41))
* Se ha modificado el programa para que la opción de añadir etiquetas por tabla en el editor de tablas de códigos admita comodines. ([commit](https://github.com/digi21/TareasDigi3D/issues/38))

## Correcciones

* Se ha añadido soporte para cargar polígonos de shapefile con múltiples anillos externos. ([commit](https://github.com/digi21/TareasDigi3D/issues/9))
* El cargador de proyectos de Inpho no soporta archivos de proyecto con múltiples calibraciones. ([commit](https://github.com/digi21/TareasDigi3D/issues/19))
* La orden CAMB\_COD no respeta el código que se debe eliminar si la geometría tiene multicodificación. ([commit](https://github.com/digi21/TareasDigi3D/issues/21))
* No se pueden cargar shapefiles con geometrías de tipo PolygonM. ([commit](https://github.com/digi21/TareasDigi3D/issues/22))
* Digi3D no responde al seleccionar una geometría con cientos de miles o millones de vértices. ([commit](https://github.com/digi21/TareasDigi3D/issues/23))
* No se lee la coordenada Z en geometrías de tipo Polyline2D en archivos DWG. ([commit](https://github.com/digi21/TareasDigi3D/issues/25))
* No se pueden cargar imágenes de Vexcel cuyos metadatos comienzan por la palabra Ultracam. ([commit](https://github.com/digi21/TareasDigi3D/issues/26))
* Al seleccionar "Detectar bucles en entidades visibles", el programa detecta bucles en entidades con códigos cuya visualización está desactivada. ([commit](https://github.com/digi21/TareasDigi3D/issues/1))
* Al cargar proyectos de PhotoScan con nodos "reference" el punto de origen del modelo está en el infinito. ([commit](https://github.com/digi21/TareasDigi3D/issues/10))
* Al ejecutar una medida de aerotriangulación mientras se está haciendo otra el programa cierra el panel de la que se está ejecutando y no es posible cerrar la orden. ([commit](https://github.com/digi21/TareasDigi3D/issues/6))
* Se produce un error al obtener el número de registros en tablas PostGIS con un punto en el nombre. ([commit](https://github.com/digi21/TareasDigi3D/issues/39))
* El exportador de shapefiles no se asegura de que los anillos que son huecos de un polígono estén digitalizados en sentido antihorario. ([commit](https://github.com/digi21/TareasDigi3D/issues/44))
* Al cargar un proyecto de Inpho mediante el panel de proyecto fotogramétrico el sistema de referencia de la orientación no coincide con el que aparece en el archivo de proyecto. ([commit](https://github.com/digi21/TareasDigi3D/issues/45))
* El botón Siguiente del cuadro de diálogo de la orden RENOMCOD no funciona correctamente. ([commit](https://github.com/digi21/TareasDigi3D/issues/37))
