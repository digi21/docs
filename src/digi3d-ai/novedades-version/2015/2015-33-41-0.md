## Novedades

* Añadida una opción en el menú para activar/desactivar la visualización de entidades con código desconocido. Se ha añadido la opción en el menú Ventana/Parámetros de visualización que ejecuta la orden VER\_DESCONOCIDOS.
* Modificada la posición de la opción del menú que habilita el panel de Proyectos Fotogramétricos. Ahora la opción está directamente en el menú Ventana
* No aparecen los Sistemas de Referencia de Coordenadas Rednap (península y Canarias) en la lista de Sistemas de Referencia de Coordenadas verticales. Este problema es debido a que ahora la BBDD con los sistemas de referencia de coordenadas es SQL Server Compact 4.0. Cuando se actualizó la BBDD de la versión 3.5 a 4.0 se utilizó como plantilla una BBDD que no tenía esos sistemas adicionales. ([commit](http://desarrollodigi3d.digi21.net/2013/11/26/implementando-egm08_rednap-en-digi3d-net/))

## Correcciones

* Al hacer una transformación que involucre un sistema de referencia de coordenadas vertical EGM2008, aparece un error con poca información. Esto era debido a una excepción con información interna y se estaba mostrando la información de la excepción externa. Se ha modificado el programa para que en caso de que las excepciones tengan una excepción interna, se muestre al usuario el contenido de la excepción interna.
* Al cargar un proyecto fotogramétrico que tenga imágenes en TIFF con compresión JPEG y con 12 bits de profundidad de color, el programa finaliza inesperadamente. Se ha modificado el programa para capturar errores a la hora de crear objetos cargadores de imágenes.
* En inglés el cuadro de diálogo que sale al exportar cuando no coinciden los SRC, se muestra en blanco. Se ha corregido este problema provocado por un archivo XML mal formado.
* Al exportar a un archivo .BIND indicando que hay conexión con BBDD pero con una cadena de conexión inválida, el programa finaliza inesperadamente. Se ha solucionado este problema. Ahora se muestra un mensaje de error con información para el usuario.
