## Novedades

* Se ha añadido una opción en la tabla de códigos que permite asignar a cada código una serie de órdenes. Las órdenes se ejecutan al pulsar el botón de Dato si el programa está en modo preparado y el código al que has asignado las órdenes es el código activo. ([commit](http://blog.digi21.net/2015/10/07/ejecutar-ordenes-al-pulsar-el-boton-de-dato/))
* Ahora, si varios códigos enlazan con la misma tabla de Geomedia, puedes dejar uno de esos códigos sin condiciones. Ese código agrupará las geometrías que no cumplan las condiciones de los demás códigos asociados a la tabla.
* Se ha añadido el desencadenador Detectar un punto cerca de otro punto. ([commit](http://blog.digi21.net/2015/10/08/nuevos-desencadenadores-en-tiempo-real/))
* Se ha añadido el desencadenador Detectar una geometría dentro de un polígono o área. ([commit](http://blog.digi21.net/2015/10/08/nuevos-desencadenadores-en-tiempo-real/))
* Al cargar un modelo de cámara cónica sin orientación relativa, el programa muestra coordenadas infinitas si está activa la opción de rectificación epipolar automática.

## Correcciones

* No se detectan correctamente polígonos dentro de polígonos con topologías virtuales sin huecos. Se ha modificado el algoritmo de localización de polígonos dentro de polígonos. Ahora, si el polígono no tiene huecos, se buscan otros polígonos que pudieran estar dentro del polígono sin huecos y se ordena la búsqueda por área.
* No se cambia el brillo/contraste en el panel de propiedades de la imagen. Se ha solucionado este problema relacionado con un fragment shader que se generaba dinámicamente en tiempo de ejecución.
* La opción Rotar imágenes en función del sistema fiducial no afectaba a la representación de las imágenes al cargar un modelo. Se ha solucionado este problema que consistía en que se almacenaba el valor en el registro con un nombre de variable incorrecto.
* Ahora el primer parámetro de ASIGNA ATRIBUTO es el nombre del campo de base de datos. Antes, la orden requería el título del campo mostrado en la interfaz.
