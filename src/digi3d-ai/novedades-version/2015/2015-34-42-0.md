# Digi3D.AI 2015.34.42.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 09/09/2015.

## Novedades

* Incrementada la velocidad del sensor Ortofoto Estereoscópica. Ahora el sensor Ortofoto Estereoscópica utiliza todos los núcleos de la CPU de manera que las imágenes se generan mucho más rápido.
* Modificado el instalador para que muestre Digi3D.NET y Licencias en Agregar/Quitar programas. Hasta ahora el instalador unificado (Bootstrapper) ocultaba los componentes Digi3D.NET y Licencias al realizarse la instalación.
Esto hacía que si se actualizaba Digi3D.NET de forma automática apareciera un segundo instalador en Agregar/Quitar programas.
Ahora el comportamiento es el contrario. Se oculta el Bootstrapper y no se ocultan los componentes Licencias y Digi3D.NET.

## Correcciones

* El parámetro de configuración Consumo de memoria bajo demanda no altera el comportamiento del programa. Se ha solucionado este problema debido a que se almacenaba en el registro el parámetro con un nombre incorrecto.
* Solucionado un problema que hacía que se hiciera un consumo excesivo de disco duro al cargar imágenes en la ventana fotogramétrica. Este problema se originó en la versión 2015.24.27.0 y es debido a código heredado de versiones anteriores.
* Solucionado un problema en la orden MOD\_MULTIPLE. Al ejecutarse esta orden el programa finalizaba inesperadamente.
