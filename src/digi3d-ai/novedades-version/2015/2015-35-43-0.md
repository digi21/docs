# Digi3D.AI 2015.35.43.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 12/09/2015.

## Novedades

* Mejorado el rendimiento del sensor Ortofoto Estereoscópica. Ahora el programa utiliza todos los núcleos del procesador principal para calcular la imagen sintética.
* Nueva orden SELECCIONA\_TODO\_EN\_CURSOR. Esta orden permite seleccionar todas las entidades que están en el ámbito del cursor. ([commit](http://blog.digi21.net/2015/09/12/nueva-orden-selecciona_todo_en_cursor/))
* Las órdenes MOD\_MULTIPLE y MOD\_Z\_MULTIPLE ahora aparecen en el menú Edición. Se han añadido estas órdenes al menú así como en la barra de herramientas Modifica
* Nueva orden GENERAR\_TOPOLOGIA\_SIN\_ISLAS. Esta orden permite generar topologías para inundación sin tener en cuenta la relación padre/hijo, entre polígono/hueco. ([commit](http://blog.digi21.net/2015/09/12/nueva-orden-generar_topologias_sin_islas/))

## Correcciones

* Aparecen comillas en algunos sistemas de refencia de coordenadas. Se ha solucionado un problema de presentación que hacía que aparecieran comillas en algunos sistemas de referencia de coordenadas.
* El cuadro de diálogo de selección de Sistemas de referencia de coordenadas aparece en inglés. Se ha solucionado este problema ocasionado porque no se instalaban correctamente los ensamblados de recursos en la carpeta WinSxS para el ensamblado Digi21.Epsg.dll
* En Windows XP surgen problemas al seleccionar el sistema de coordenadas de referencia desconocido o local. Este problema estaba ocasionado porque Windows XP no era capaz de localizar los recursos del ensamblado Digi21.Epsg.dll
* No aparece marcado en la parte izquierda del cuadro de diálogo de selección de Sistema de Referencia de Coordenadas el tipo de sistema seleccionado. Este problema estaba ocasionado por un fallo en la librería de interfaz de usuario Codejock.
* Al ejecutarse las órdenes MOD\_MULTIPLE y MOD\_Z\_MULTIPLE el programa finaliza inesperadamente
