# Digi3D.AI 2015.31.39.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 02/09/2015.

## Novedades

* Se ha actualizado la biblioteca de interfaz de usuario Codejock a su última versión para admitir Visual Studio 2015. Digi3D.NET comenzará a desarrollarse con Visual Studio 2015 para utilizar métodos asíncronos.
* Se ha modificado la opción Ayuda/Compartir mi escritorio. Ahora no se instala el cliente ligero de TeamViewer, sino que se abre un navegador para descargar el cliente ligero de los servidores de TeamViewer.
* Se ha cambiado el despliegue del cliente ligero de TeamViewer. Ahora la opción del menú Herramientas/Compartir mi escritorio abre un navegador para descargar el cliente ligero de TeamViewer.
* Se ha mejorado el cálculo de la matriz de nivelación en los sensores satelitales. Ahora se calcula de forma automática la rotación de las imágenes satelitales, lo que permite cargar imágenes satelitales con epipolar.

Se ha mejorado también el cálculo del tamaño del píxel, de manera que ahora un incremento en el dispositivo de entrada (ratón o topomouse) equivale a un incremento de un píxel en la ventana fotogramétrica.
* Ahora puedes cargar proyectos .SMTXML de Summit Evolution con orientaciones de proyectos satelitales. ([commit](http://blog.digi21.net/2015/09/01/carga-de-proyectos-satelitales-de-summit-evolution/))
* Ahora la versión de 64 bits de Digi3D puede comunicarse con Google Earth. ([commit](http://desarrollodigi3d.digi21.net/2015/09/01/haciendo-que-digi3d-x64-pueda-controlar-google-earth/))
* Ahora el panel de propiedades de la imagen conserva los valores de los parámetros. ([commit](Now the image properties panel memorises the parameters))
* Se han añadido nuevas condiciones para las acciones al almacenar una entidad. ([commit](http://blog.digi21.net/2015/09/01/nuevas-condiciones-para-los-desencadenadores-de-digi3d-net-para-el-control-de-calidad-de-la-cartografia/))

## Correcciones

* Se ha corregido la ejecución de Seleccionar Llave o Activar ordenador en la versión inglesa del programa. Si ejecutas Digi3D.NET y no se localiza la llave de protección o la llave no está activada, el programa muestra botones para ejecutar Seleccionar Llave o Activar Ordenador. En la versión inglesa, los botones no ejecutaban ninguna acción porque Digi3D.NET intentaba ejecutar los programas con sus nombres en español en vez de en inglés.
* Al hacer una orientación absoluta con sistemas de coordenadas verticales el programa muestra un mensaje de error que indica que no tiene permisos.
