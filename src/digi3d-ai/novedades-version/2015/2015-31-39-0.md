## Novedades

* Actualizada librería de interfaz de usuario para preparar el programa para ser desarrollado con Visual Studio 2015. Se ha actualizado la librería de interfaz de usuario Codejock a su última versión para soportar Visual Studio 2015 ya que Digi3D.NET comenzará a desarrollarse en Visual Studio 2015 para utilizar las últimas tendencias de programación como métodos asíncronos que mejorarán la experiencia de usuario.
* Modificada opción de Ayuda/Compartir mi escritorio. Ahora no se instala el cliente ligero de TeamViewer, sino que se abre un navegador para descargar el cliente ligero de los servidores de TeamViewer para asegurar ejecutar siempre la última versión.
* Cambios en el despliegue del cliente ligero de TeamViewer. Ahora la opción del menú Herramientas/Compartir mi escritorio abre un navegador para descargar el cliente ligero de TeamViewer para asegurarse de que el cliente dispone de la última versión.
* Mejorado el cálculo de la matriz de nivelación en los sensores satelitales. Ahora se calcula de forma automática la rotación de las imágenes satelitales, pudiendo cargar imágenes satelitales con epipolar. 

Se ha mejorado también el cálculo del tamaño del pixel, de manera que ahora un incremento en el dispositivo de entrada (ratón o topomouse) equivale a un incremento de un pixel en la ventana fotogramétrica.
* Añadida compatibilidad con proyectos satelitales de Summit Evolution. Ahora es posible cargar proyectos .SMTXML de Summit Evolution con orientaciones de proyectos satelitales. ([commit](http://blog.digi21.net/2015/09/01/carga-de-proyectos-satelitales-de-summit-evolution/))
* Ahora la versión de 64 bits de Digi3D puede comunicarse con Google Earth ([commit](http://desarrollodigi3d.digi21.net/2015/09/01/haciendo-que-digi3d-x64-pueda-controlar-google-earth/))
* Ahora el panel de propiedades de la imagen memoriza los parámetros ([commit](Now the image properties panel memorises the parameters))
* Añadidas nuevas condiciones para las acciones al almacenar una entidad ([commit](http://blog.digi21.net/2015/09/01/nuevas-condiciones-para-los-desencadenadores-de-digi3d-net-para-el-control-de-calidad-de-la-cartografia/))

## Correcciones

* No se ejecuta Seleccionar Llave o Activar ordenador en la versión inglesa del programa. Si se ejecuta Digi3D.NET y no se localiza la llave de protección o la llave no está activada, el programa invita a pulsar botones para ejecutar el programa Seleccionar Llave o Activar Ordenador. Si se está ejecutando la versión inglesa del programa, no se ejecutaba ninguna acción pues se estaba intentando ejecutar los programas con nombre en español en vez de en inglés.
