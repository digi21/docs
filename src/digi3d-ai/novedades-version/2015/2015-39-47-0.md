# Digi3D.AI 2015.39.47.0

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 30/10/2015.

## Correcciones

* Se ha solucionado un problema al mostrar cuadros de diálogo para seleccionar sistemas de referencia de coordenadas (SRC). Este problema apareció a partir de la publicación de la versión 2015.35.43.0 con la modificación que evitaba que los cuadros de diálogo de selección de sistemas de referencia de coordenadas apareciesen en inglés.
* Se ha solucionado un problema de representación al seleccionar la opción de Intercambiar ojos en la ventana fotogramétrica. Los vectores no se estaban proyectando correctamente al activar la opción de intercambiar ojos.
* Se ha solucionado un problema al calcular la matriz de nivelación en la ventana fotogramétrica con archivos de orientación absoluta con un SRC distinto al del modelo si uno de los dos tiene como ejes Latitud,Longitud en vez de Longitud,Latitud. El problema se producía si el archivo de orientación absoluta y el modelo fotogramétrico tenían sistemas de referencia de coordenadas distintos y uno de esos sistemas tenía los ejes en el orden Latitud, Longitud o Y,X. Por ejemplo, el modelo podía tener el SRC WGS84 (geográfico) y el archivo de orientación absoluta, WGS84 / UTM Zona 14N. El programa intercambiaba los ejes de forma incorrecta, por lo que la matriz de nivelación tenía algún eje invertido.
* El botón de cerrar ventana en la ventana fotogramétrica no se activa al cerrar el cuadro de diálogo de la orden Orientación Absoluta.
