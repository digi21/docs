Publicada el 20/05/2015.

## Novedades

* Nueva orden SUAVIZA\_SPLINE
* Nueva orden AGRUPAR\_ENTIDADES\_COD. Esta orden permite agrupar entidades por sus códigos, formando entidades complejas por cada código.
* El formato KML ahora es de lectura y escritura ([commit](http://blog.digi21.net/2015/05/18/kml-pasa-a-ser-un-ciudadano-de-primera-categoria-en-digi3d-net/))

## Correcciones

* Las orientaciones absolutas incluyen caracteres raros. Se ha solucionado este problema ocasionado al ser la aplicación Unicode y estar almacenando los parámetros de orientación en Ansi.
* Los archivos de teclas modificados no se pueden volver a cambiar. Solucionado este problema ocasionado en la versión 2015.21.24.0
* No se pueden recuperar entidades de tipo complejo. La orden RECUPERA no permitía seleccionar entidades complejas.
* El programa se cuelga al realizar una orientación absoluta. Se ha solucionado un problema provocado en la versión 2015.20.22.0 relacionado con el panel de instantáneas.
El programa asumía que el panel de instantáneas está siempre activo y desde esa modificación no tiene por que ser así. Si el panel no es visible, no está creado, y el programa finalizaba inesperadamente cuando se intentaba cargar la instantánea.
* Solucionado un problema de recursos con ediciones de Windows en Japonés. Ciertos componentes de interfaz de usuario no se cargaban correctamente en ediciones de Windows en Japonés.
