# Digi3D.AI 2015.0.5.5

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 06/03/2015.

## Novedades

* Ahora se admiten identificadores de sistemas de referencia de coordenadas como CRS:84, CRS:83 y CRS:27.
* Se ha añadido soporte para georreferenciaciones compatibles con ttMaps en los archivos .ECW. Ahora puedes cargar archivos ECW cuya georreferenciación no esté basada en códigos EPSG, como ETRS89 NUTM29.
* Ahora el sensor Ortofoto busca el archivo .PRJ asociado al archivo .ECW y lo carga si existe. Hasta ahora, si el sensor no reconocía el sistema de referencia de coordenadas de una ortofoto en formato ECW, consideraba desconocido ese sistema.

## Correcciones

* Se ha corregido la visualización de los saltos de línea en la descripción de la novedad del cuadro de diálogo "Detalles de novedad", que aparece al detectar una versión nueva del programa.
* Ahora Digi3D.NET no finaliza inesperadamente si falla la conexión al servicio de descubrimiento de nuevas versiones, por ejemplo, por falta de conexión a internet o porque el servicio está deshabilitado.
* Se ha solucionado un problema al cargar el importador de Geomedia. La versión de 64 bits de Digi3D.NET no estaba cargando correctamente el importador de Geomedia por un cambio provocado en la versión 2015.0.4.4.
* Se ha solucionado un problema de conexión a servicios Web Map Service. La ventana de dibujo no se conectaba correctamente a servicios Web Map Service desde que los sistemas de referencia de coordenadas se convirtieron en 3D.
* Se ha solucionado un problema con los buscadores. Los buscadores no cargaban correctamente y, al intentar buscar una entidad, el programa finalizaba inesperadamente.
