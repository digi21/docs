# Digi3D.AI 2015.0.5.5

<!-- Generado desde la base de datos de digi21.net. No editar a mano. -->

Publicada el 06/03/2015.

## Novedades

* Añadido soporte para Sistemas de Referencia de Coordenadas no EPSG. Se ha añadido soporte para que ciestos componentes puedan instanciar Sistemas de Referencia de Coordenadas que no sean cadenas WKT o códigos EPSG, como por ejemplo CRS:84, CRS:83 y CRS:27
* Añadido soporte para georeferenciaciones compatibles con ttMaps en los archivos .ECW. Ahora se pueden cargar archivos ECW con georeferenciación que no sea basada en códigos EPSG, como por ejemplo ETRS89 NUTM29
* Ahora el sensor Ortofoto localiza archivos .prj con archivos ECW. Hasta ahora, si no se reconocía el sistema de referencia de coordenadas en una ortofoto en formato ECW, se suponía que éste era desconocido. Ahora se localiza un archivo .PRJ asociado al archivo .ECW y se carga en caso de que éste exista.

## Correcciones

* Mejoras en el cuadro de diálogo de detalles de novedad. El cuadro de diálogo de "Detalles de novedad" que aparece al detectar una versión nueva del programa no estaba mostrando correctamente los saltos de línea en la descripción de la novedad.
* Digi3D.NET ahora no se cuelgan si falla el servicio de versionado. Ahora Digi3D.NET no finaliza inesperadamente si por cualquier motivo (falta de conexión a internet, el servicio está deshabilitado,...) falla la conexión al servicio de descubrimiento de nuevas versiones.
* Solucionado problema al cargar el importador de Geomedia. La versión de 64 bits de Digi3D.NET no estaba cargando correctamente el importador de Geomedia por un cambio provocado en la versión 2015.0.4.4.
* Solucionado problema de conexión a Wms. La ventana de dibujo no se conectaba correctamente a servicios Web Map Service desde que los sistemas de referencia de coordenadas se convirtieron en 3D
* Solucionado un problema con los buscadores. Los buscadores no cargaban correctamente y al intentar buscar una entidad el programa finalizaba inesperadamente.
