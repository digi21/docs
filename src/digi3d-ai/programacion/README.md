# Programación
<!-- id: programacion -->

Digi3D.AI publica ensamblados que permiten crear aplicaciones y extensiones. Las aplicaciones pueden acceder al motor de importación y exportación, al motor de topología y a otros componentes. Las extensiones permiten añadir opciones en el panel de búsqueda, crear órdenes nuevas y crear controles de calidad que se ejecutan al almacenar geometrías o a petición del usuario.

Además, Digi3D.AI incorpora el motor de IronPython, que permite programar en Python y acceder a todos los tipos publicados por los ensamblados de Digi3D.AI.
