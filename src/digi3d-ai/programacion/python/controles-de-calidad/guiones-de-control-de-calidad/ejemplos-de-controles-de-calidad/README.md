# Ejemplos de controles de calidad
<!-- id: ejemplos-de-controles-de-calidad -->

El archivo `guiones.py` del repositorio [Guiones-Control-Calidad-Python-Digi3D](https://github.com/digi21/Guiones-Control-Calidad-Python-Digi3D) contiene 64 funciones de control de calidad. La página [Repositorio de controles de calidad en Python](/digi3d-ai/programacion/python/guiones-control-calidad/README.md) describe cada una con sus parámetros.

Para usarlas, copia el contenido de `guiones.py` en la pestaña [Entorno Python](/digi3d-ai/referencia/editor-de-tablas-de-codigos/pestanas/entorno-python.md) del Editor de Tablas de Códigos, o pulsa en esa pestaña **Descargar de GitHub la última versión**, y asigna las funciones a los códigos en la propiedad **Controles de calidad a aplicar**.

| Ejemplo | Qué comprueba |
| :--- | :--- |
| [Detectar vértices con Z superior a la del anterior vértice](detectar-vertices-con-z-superior-a-la-anterior.md) | Que la Z de los vértices de la geometría no aumente. |
