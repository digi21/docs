# Ejemplos de programación
<!-- id: ejemplos -->

Tutoriales con ejemplos para aprender a programar **aplicaciones de consola** con la API de
Python de Digi3D.AI. Cada tema parte de un objetivo práctico y muestra el código completo.

Para la descripción detallada de cada clase y método, consulta la
[Referencia](../../referencia/README.md).

## Temas

- [Leer un archivo de dibujo](leer-un-archivo-de-dibujo.md) — abrir un archivo y recorrer
  sus geometrías.
- [Crear un archivo de dibujo](crear-un-archivo-de-dibujo.md) — escribir geometrías en un
  archivo nuevo y convertir un archivo de un formato a otro.
- [Crear un shapefile](crear-un-shapefile.md) — escribir una capa por código y configurar la tabla
  de códigos.
- [Convertir a GeoPackage](convertir-a-geopackage.md) — pasar las capas de un shapefile a un
  GeoPackage.
- [Exportar a KML y GeoJSON](exportar-a-kml-y-geojson.md) — escribir longitud y latitud para visores
  web.
- [Exportar a SVG, WKT y PDF](exportar-a-svg-wkt-y-pdf.md) — formatos sin sistema de coordenadas.
- [Exportar a VEC, IFC, GeoMedia y PostGIS](exportar-a-vec-ifc-geomedia-y-postgis.md) — caras de
  edificios y bases de datos que ya tienen las capas.
- [Crear geometrías](crear-geometrias.md) — construir puntos, líneas, polígonos, textos y
  complejos.
- [Relaciones entre geometrías](relaciones-entre-geometrias.md) — consultar si dos
  geometrías se cruzan, se tocan, una está dentro de otra, etc.
