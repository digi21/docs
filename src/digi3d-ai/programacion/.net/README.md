# .NET

Digi3D.AI publica una API .NET para crear dos tipos de programas:

- **Aplicaciones de consola** que leen o escriben archivos de dibujo sin abrir Digi3D.AI, por ejemplo para convertir o revisar archivos por lotes.
- **Extensiones** que se cargan dentro de Digi3D.AI: órdenes, buscadores de geometrías, controles de calidad, paneles…

Los programas se escriben en C# para **.NET 10** y referencian los paquetes NuGet de Digi21, versión 26.0.0. Los paquetes están listados en la [referencia](referencia/README.md).

Para empezar, sigue uno de los dos tutoriales:

- [Tutorial: crear una aplicación de consola](tutorial-aplicacion-de-consola.md).
- [Tutorial: crear una extensión](tutorial-extension.md).

Si tienes programas creados para versiones anteriores (paquetes 24.0.0 o .NET 8), lee [Migración a .NET 10](migracion-a-net-10.md).

Para aprender a usar los tipos de la API, sigue el [curso de programación en C#](curso-de-programacion-en-c/README.md).
