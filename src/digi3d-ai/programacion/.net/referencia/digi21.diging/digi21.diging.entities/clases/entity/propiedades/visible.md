# Visible

Espacio de nombres: [Digi21.DigiNG.Entities](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.entities/)  
Ensamblado: [Digi21.DigiNG](/digi3d-ai/programacion/.net/referencia/digi21.diging/)

Indica si la entidad se muestra en la ventana de dibujo.

```csharp
public bool Visible { get; }
```

## Valor de la propiedad

`true` si la entidad no está oculta ([Hidden](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.entities/clases/entity/propiedades/hidden.md) es `false`) y alguno de sus códigos tiene activo, en [Code.Visible](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.entities/clases/code/propiedades/visible.md), el bit del tipo de la entidad.
