```csharp
public string Path { get; }
```

## Valor de la propiedad

`string`. En una tabla cargada con [Load](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.digitab/clases/digitab/metodos-estaticos/load.md), es el valor del parámetro `path`. Una tabla que no se ha cargado de un archivo devuelve una cadena vacía. [Write](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.digitab/clases/digitab/metodos/write.md) no cambia esta propiedad.
