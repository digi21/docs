# Digi21.DigiNG.Cameras
<!-- id: digi21.diging.cameras -->

Tipos que describen la cámara de la ventana de dibujo. Una extensión lee y cambia la cámara de la ventana de dibujo activa con la propiedad estática `Camera` de la clase [DigiNG](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.diging/clases/diging/).

## Clases

| Clase | Descripción |
| :--- | :--- |
| [Camera](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.cameras/clases/camera/) | Clase base abstracta: nombre, posición, giros y planos de recorte. |
| [ConicCamera](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.cameras/clases/coniccamera/) | Cámara con proyección en perspectiva. |
| [OrthographicCamera](/digi3d-ai/programacion/.net/referencia/digi21.diging/digi21.diging.cameras/clases/orthographiccamera/) | Cámara con proyección ortográfica. |
