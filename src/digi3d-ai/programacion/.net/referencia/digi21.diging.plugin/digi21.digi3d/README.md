# Digi21.Digi3D
<!-- id: digi21.digi3d -->

Ensamblado: [Digi21.DigiNG.Plugin](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/)

Tipos para usar la ventana principal de Digi3D.AI desde una extensión: ventana de resultados, panel de tareas, barra de estado, paneles acoplables, sonidos y globos de notificación. El punto de entrada es la clase estática `Digi3D`.

## Clases

| Clase | Descripción |
| :--- | :--- |
| [Digi3D](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.digi3d/clases/digi3d.md) | Clase estática que da acceso a la ventana de resultados, al panel de tareas, a la barra de estado y a los paneles, y que reproduce sonidos, pronuncia textos y muestra globos de notificación. |
| [OutputWindow](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.digi3d/clases/outputwindow.md) | Ventana de resultados: escribe líneas de texto, borra el texto, muestra u oculta la ventana. |
| [Pane](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.digi3d/clases/pane.md) | Panel acoplable creado con `Panes.Add`: título, acoplamiento y eventos del panel. |
| [Panes](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.digi3d/clases/panes.md) | Añade paneles acoplables con un formulario de Windows Forms a la ventana principal. |
| [Progress](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.digi3d/clases/progress.md) | Barra de progreso de la barra de estado. |

| [Tasks](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.digi3d/clases/tasks.md) | Panel de tareas: añade y borra tareas, muestra u oculta el panel. |
