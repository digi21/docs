# Digi21.DigiNG.Plugin.Search
<!-- id: digi21.diging.plugin.search -->

Espacio de nombres: `Digi21.DigiNG.Plugin.Search`  
Ensamblado: [Digi21.DigiNG.Plugin](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/)

Tipos para escribir buscadores del panel de búsqueda de Digi3D.AI. Un buscador selecciona entidades del archivo de dibujo activo y las envía a un panel de resultados o a la orden activa.

## Atributos

| Atributo | Descripción |
| :--- | :--- |
| [SearcherAttribute](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.diging.plugin.search/atributos/searcherattribute.md) | Marca una clase como buscador e indica su título en la lista de buscadores. |
| [LocalizableSearcherAttribute](/digi3d-ai/programacion/.net/referencia/digi21.diging.plugin/digi21.diging.plugin.search/atributos/localizablesearcherattribute.md) | Igual que `SearcherAttribute`, con el título leído de los recursos de la extensión. |
