# Digi21.DigiNG.IO.Bin
<!-- id: digi21.diging.io.bin -->

Este paquete [NuGet](https://www.nuget.org/packages/Digi21.DigiNG.IO.Bin/) proporciona un importador/exportador de archivos binarios clásicos de Digi3D.AI.

### Package manager
```bash
Install-Package Digi21.DigiNG.IO.Bin -Version 26.0.0
```

### .NET Cli
```
dotnet add package Digi21.DigiNG.IO.Bin --version 26.0.0
```

### Package reference
```markup
<PackageReference Include="Digi21.DigiNG.IO.Bin" Version="26.0.0" />
```

## Tipos

| Tipo | Descripción |
| :--- | :--- |
| [Bin](bin.md) | Archivo de dibujo en el formato binario clásico (`.bin`). Lee y escribe líneas, puntos, textos, polígonos y complejos. |

Para archivos `.bind`, con coordenadas en coma flotante de doble precisión, usa el paquete [Digi21.DigiNG.IO.BinDouble](/digi3d-ai/programacion/.net/referencia/digi21.diging.io.bindouble/).
