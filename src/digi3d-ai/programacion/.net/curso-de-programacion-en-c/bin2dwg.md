# Bin2Dwg
<!-- id: bin2dwg -->

<video controls><source src="https://digi21.blob.core.windows.net/videos-ayuda/desarrollo/8.%20Bind2Dwg.mp4" caption="" type="video/mp4"></video>

El repositorio de ejemplos contiene un programa de conversión de `.bind` al formato de dibujo de AutoCAD (DWG). El programa de conversión está explicado en el ejemplo [BindADwg](../ejemplos/bind-a-dwg.md). El ensamblado `Digi21.DigiNG.IO.Dwg` no tiene paquete NuGet, así que el ejemplo referencia ese ensamblado desde la carpeta de instalación de Digi3D.AI.
