# Fichero de proyecto
<!-- id: fichero-de-proyecto -->

Este tipo de fichero relaciona los diferentes archivos que componen un trabajo. Así, se deberá crear un proyecto para cada trabajo donde se irán almacenando los diferentes cálculos realizados. En estos proyectos, se podrán tener archivos de [puntos](ficheros-de-puntos.md), de [observaciones](ficheros-de-visuales.md) o de [croquis](fichero-de-croquis.md).

Genere un archivo por cada cálculo para conservar separados los puntos de cada resultado. Por ejemplo:

* *Poligonal.pts*: Archivo con las estaciones de la poligonal
* *Ajuste.pts*: Archivo con las coordenadas ajustadas por mínimos cuadrados de la poligonal.
* *Radiación.pts*: Archivo con las coordenadas de los puntos radiados desde las estaciones de la poligonal.
* *Visuales.obs*: Visuales realizadas en la poligonal.

Al crear un fichero de proyecto nuevo se crea, igualmente, una carpeta con el nombre del archivo, de tal forma que, cuando se vayan creando ficheros nuevos (puntos, observaciones, croquis) y se inserten en este proyecto, se generen en esta carpeta.

Los archivos de proyecto de TopCal 21 tienen, por defecto, extensión **PRT**.
