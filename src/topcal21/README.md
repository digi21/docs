# Topcal21
<!-- id: topcal21 -->

Programa de cálculos topográficos, diseñado para resolver todos los problemas de cálculo en trabajos topográficos.

Topcal21 trabaja con proyectos, de manera que puede organizar sus trabajos en subdirectorios y manejar a la vez más de un archivo de puntos y de observaciones. Dispone de una ventana de visualización de datos a modo de hoja de cálculo, y todas sus herramientas se presentan con cuadros de diálogo guiados que ayudan al usuario durante el cálculo.

Esta ayuda describe Topcal21 para Windows. Para la versión que se ejecuta en el navegador, consulta [Topcal21 web](topcal21-web/README.md).

## Herramientas

* Cálculo de triangulaciones.
* Intersecciones directas.
* Intersecciones inversas.
* Cálculo de desorientaciones.
* Poligonales.
* Radiaciones.
* Cálculo de superficies.
* Generación de dibujos con los puntos.
* Transformación de coordenadas entre diferentes sistemas.
* Generación de reseñas.
* Cálculo de perfiles longitudinales y transversales.
* Cálculo de volúmenes.
* Cálculo de desmontes y terraplenes.
* Compensación por mínimos cuadrados de redes topográficas.
* Reconstrucción automática del croquis a partir de la codificación tomada en campo.
* Resolución de triángulos.
* Paso de coordenadas polares a rectangulares y viceversa.
* Intersección de rectas y círculos.
* Cálculo de distancias en proyección UTM o con coordenadas geográficas.
