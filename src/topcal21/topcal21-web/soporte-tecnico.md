# Soporte técnico
<!-- id: topcal21-web-soporte -->

El soporte técnico de Topcal21 web funciona con tickets de soporte en www.digi21.net. La cuenta de Topcal21 web sirve para iniciar sesión en www.digi21.net porque las dos webs comparten las cuentas.

## Crear un ticket

1. Abre el menú **Ayuda** del espacio de trabajo.
2. Pulsa **Crear ticket de soporte técnico**. La web abre el formulario de soporte de www.digi21.net en una pestaña nueva, en el idioma de la página.
3. Describe el problema. Indica el nombre del archivo o del proyecto, la orden que ejecutabas y el texto del mensaje que mostró la web.

El cuadro **Acerca de TopCal 21...** del menú Ayuda también tiene un enlace a **Soporte técnico**.

## Otras ayudas

* **Temas de ayuda** del menú Ayuda abre esta ayuda en una pestaña nueva. Las demás páginas de la [ayuda de Topcal21](../README.md) explican los cálculos con detalle.
* Las [diferencias con Topcal21 para Windows](diferencias-con-el-escritorio.md) indican las funciones que la web todavía no incluye.
