# Menú Cálculos
<!-- id: menu-calculos -->

En este menú están reunidos los diversos cálculos geométricos que se pueden realizar con los puntos, así como operaciones con visuales, transformaciones de coordenadas, etc. Estos comandos son los siguientes:

* [Rectangulares a polares](../calculos/rectangulares-a-polares.md): Calcula el acimut y la distancia a partir de las coordenadas de dos puntos. Esta opción sólo estará habilitada si se tiene activo un archivo de puntos.
* [Polares a rectangulares](../calculos/polares-a-rectangulares.md): Calcula las coordenadas de un punto a partir de las de otro y un acimut y una distancia. Esta opción sólo estará habilitada si se tiene activo un archivo de puntos.
* [Intersección de rectas](../calculos/interseccion-de-rectas.md): Calcula las coordenadas de un punto intersección de dos rectas. Estas rectas pueden estar definidas por dos puntos o un punto y un acimut. Esta opción sólo estará habilitada si se tiene activo un archivo de puntos.
* [Intersección de recta y círculo](../calculos/interseccion-de-recta-y-circulo.md): Calcula las coordenadas de las intersecciones generadas entre un círculo y una recta. La recta puede estar definida por dos puntos o por un punto y un acimut. El círculo puede estar definido por tres puntos, dos puntos, el centro y el radio o el centro y un punto por donde pasa el círculo. Esta opción sólo estará habilitada si se tiene activo un archivo de puntos.
* [Intersección de círculos](../calculos/interseccion-de-circulos.md): Calcula las coordenadas de las intersecciones generadas entre dos círculos. Los círculos pueden estar definidos por tres puntos, dos puntos, el centro y el radio o el centro y un punto por donde pasa el círculo. Esta opción sólo estará habilitada si se tiene activo un archivo de puntos.
* [Cálculo de un arco](../calculos/arco-definido-por-tres-puntos.md): Calcula un arco definido por tres puntos y permite almacenar las coordenadas de su centro. Esta opción sólo estará habilitada si se tiene activo un archivo de puntos.
* Cálculo de distancias: Permite calcular la distancia entre dos puntos en [proyección UTM](../calculos/distancia-en-proyeccion-utm.md) o definidos por [coordenadas geográficas](../calculos/distancia-en-geograficas.md).
* [Resolución de triángulos](../calculos/resolucion-de-triangulos.md): Permite calcular los elementos de un triángulos a partir del conocimiento de tres de estos elementos, ya sean lados o ángulos de éste.
* [Máximas y mínimas](../calculos/maximas-y-minimas.md): Permite calcular las máximas, mínimas e incrementos de coordenadas de un conjunto de puntos. Esta opción sólo estará habilitada si se tiene activo un archivo de puntos.
* [Cálculo de superficies](../calculos/calculo-de-superficies/README.md): Permite calcular la superficie de un elemento cerrado formado por un determinado conjunto de puntos. Esta opción sólo estará habilitada si se tiene activo un archivo de puntos.
* Perfiles: Permite generar archivos de dibujo con perfiles [longitudinales](../calculos/perfiles-longitudinales/README.md) o [transversales](../calculos/perfiles-transversales/README.md) formados por un determinado conjunto de puntos. Esta opción sólo estará habilitada si se tiene activo un archivo de puntos.
* Transformaciones: Son varias las transformaciones de coordenadas que permite el programa, que sólo estarán habilitadas si se tiene activo un archivo de puntos:
  * [Transformación Helmert de coordenadas](../calculos/transformacion-helmert-de-coordenadas/README.md): Permite realizar una transformación 2D ó 3D a partir del conocimiento de los parámetros de la transformación.
  * [Transformación de coordenadas geográficas](../calculos/transformacion-de-coordenadas-geograficas/README.md): Para la transformación de un archivo de coordenadas geográficas al archivo actual, o para transformar el archivo de puntos actual a un archivo de coordenadas geográficas
  * [Transformación manual de coordenadas geográficas](../calculos/transformacion-manual-de-coordenadas-geograficas.md): Para transformar coordenadas geográficas introducidas manualmente al archivo de puntos actual
  * [Transformación de coordenadas del elipsoide de Struve al de Hayford](../calculos/transformacion-de-coordenadas-del-elipsoide-de-struve-al-de-hayford.md): Para transformar coordenadas de la antigua red geodésica española cuyo elipsoide era el de Struve y cuyo datum estaba en Madrid al actual cuyo elipsoide es el de Hayford y datum en Postdam.
  * [Transformación de coordenadas entre diferentes sistemas de referencia](../calculos/transformacion-de-coordenadas-entre-diferentes-sistemas-de-referencia/README.md): Permite la transformación de coordenadas entre diferentes proyecciones o sistemas de referencia.
  * [Transformación de coordenadas utilizando rejilla NTV2](../calculos/transformacion-de-coordenadas-utilizando-rejilla-ntv2/README.md): Permite la transformación de coordenadas entre diferentes sistemas de referencia a partir de la interpolación de las correcciones almacenadas en un archivo.
  * [Transformación de unidades](../calculos/transformacion-de-unidades.md): Permite la transformación de valores a diferentes unidades, contemplando tanto unidades angulares como lineales.
  * [Cambio de altura según rejilla](../calculos/cambio-de-altura-segun-rejilla/README.md): Permite la transformación de la coordenada altimétrica interpolando en una rejilla con valores de altitud que se podrán sumar o restar al valor actual.
* Generar reseñas: Permite generar un archivo html con las reseñas de [puntos de apoyo](../calculos/generar-resenas-de-puntos-de-apoyo/README.md) o [vértices](../calculos/generar-resenas-de-vertices/README.md), a partir de sus fotos o croquis. Esta opción sólo estará habilitada si se tiene activo un archivo de puntos.
* [Calcular medias CD-CI](../calculos/calculo-medias-cd-ci/README.md): Permite calcular los errores sistemáticos de un aparato a partir de las observaciones en círculo directo (CD) y círculo inverso (CI) entre un conjunto de puntos. Esta opción sólo estará habilitada si se tiene activo un archivo de observaciones.
* [Calcular errores accidentales](../calculos/calculo-de-errores-accidentales/README.md): Permite calcular los errores accidentales asociados a un instrumental y unas características de observación. Esta opción sólo estará habilitada si se tiene activo un archivo de observaciones.
* [Calcular medias de visuales](../calculos/calculo-de-medias-de-visuales/README.md): Permite calcular las visuales promedio de un conjunto de visuales repetidas entre la misma estación y el mismo punto visado, realizadas para mejorar la precisión. Esta opción sólo estará habilitada si se tiene activo un archivo de observaciones.
* [Nivelación geométrica](../calculos/nivelacion-geometrica/README.md): Herramienta para calcular el desnivel entre puntos a partir del fichero con las lecturas de una nivelación geométrica.
* [Compensación MMCC de red de nivelación](../calculos/compensacion-mmcc-de-red-de-nivelacion/README.md): Permite ajustar por el método matemático de mínimos cuadrados una red de nivelación formada por un conjunto de puntos entre los que se han medido desniveles.
