# Transformación de coordenadas geográficas
<!-- id: transformacion-de-coordenadas-geograficas -->

Esta herramienta permite transformar un conjunto de puntos almacenado en un fichero ASCII en formato coordenadas geográficas al archivo de puntos actual, utilizando la proyección definida en el archivo de puntos actual. También permite transformar el archivo de puntos actual a un archivo ASCII de coordenadas geográficas.

Si se desean transformar coordenadas introducidas manualmente por el usuario mediante teclado utilice la herramienta [Transformación manual de coordenadas geográficas](../transformacion-manual-de-coordenadas-geograficas.md) del [Menú Cálculos](../../menus-de-la-aplicacion/menu-calculos.md).

La herramienta está estructurada en tres pasos, que son los siguientes:

* [Paso 1: Introducir tipo de transformación](paso-1-introducir-tipo-de-transformacion.md)
* [Paso 2: Selección de puntos a transformar](paso-2-seleccion-de-los-puntos-a-transformar.md)
* [Paso 3: Coordenadas transformadas de los puntos](paso-3-coordenadas-transformadas-de-los-puntos.md)

Use los botones **Siguiente** y **Anterior** para cambiar de paso y modificar los datos o las selecciones.
