# Cambio de altura según rejilla
<!-- id: cambio-de-altura-segun-rejilla -->

Esta herramienta permite transformar la altitud de un conjunto de puntos interpolando en un archivo de rejilla con valores a sumar o restar.

Esta herramienta es útil para sumar o restar la ondulación del geoide a un conjunto de puntos cuyo altitud es ortométrica o elipsoidal. Los valores de la ondulación del geoide deberán estar en un archivo ASCII en formato de rejilla.

La herramienta está estructurada en tres pasos, que son los siguientes:

* [Paso 1: Introducir datos de entrada](paso-1-introducir-datos-de-entrada.md)
* [Paso 2: Selección de puntos](paso-2-seleccion-de-puntos.md)
* [Paso 3: Configurar salida de datos](paso-3-configurar-salida-de-datos.md)

Use los botones **Siguiente** y **Anterior** para cambiar de paso y modificar los datos o las selecciones.
