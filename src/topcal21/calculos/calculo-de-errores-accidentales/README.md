# Calcular errores accidentales
<!-- id: calcular-errores-accidentales -->

Esta herramienta sirve para calcular los errores accidentales propios de un [instrumental](../../otros-comandos/instrumentos-topograficos/listado-de-instrumentos-topograficos.md) y para unas [características de observación](../../opciones-de-visualizacion/propiedades-de-los-objetos/propiedades-del-archivo-de-visuales.md). Además de mostrar los errores accidentales que se manifiestan en las observaciones se presentan los errores a priori que pueden tener algunos métodos topográficos ([radiación](../../herramientas/radiacion/README.md) y [poligonación](../../herramientas/poligonales/README.md)) para comprobar la idoneidad de éstos antes de comenzar un trabajo.

La herramienta sólo estará disponible si se tiene activo un documento con observaciones y utilizará el instrumental definido en el documento de observaciones y las medias de distancia, ángulo vertical y altura de prisma de las observaciones de ese documento.

La herramienta está estructurada en dos pasos, que son los siguientes:

* [Paso 1: Errores accidentales comunes](paso-1-errores-accidentales-comunes.md)
* [Paso 2: Errores en métodos y salida de datos](paso-2-errores-en-metodos-y-salida-de-datos.md)

Use los botones **Siguiente** y **Anterior** para cambiar de paso y modificar los datos o las selecciones.
