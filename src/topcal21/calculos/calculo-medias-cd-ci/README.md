# Calcular medias CD-CI
<!-- id: calcular-medias-cd-ci -->

Esta herramienta calcula las medias de las observaciones en círculo directo (CD) y círculo inverso (CI) y los errores sistemáticos del instrumento topográfico. Los errores sistemáticos calculados pueden aplicarse a las demás visuales realizadas con ese instrumento.

Para calcular estos errores es necesario que se hayan realizado visuales en círculo directo y círculo inverso a un conjunto de puntos.

La herramienta está estructurada en de tres pasos, que son los siguientes:

* [Paso 1: Selección de visuales](paso-1-seleccion-de-visuales.md)
* [Paso 2: Cálculo de errores sistemáticos](paso-2-calculo-de-errores-sistematicos.md)
* [Paso 3: Configurar salida de datos](paso-3-configurar-salida-de-datos.md)

Use los botones **Siguiente** y **Anterior** para cambiar de paso y modificar los datos o las selecciones.
