# Nivelación geométrica
<!-- id: nivelacion-geometrica -->

Esta herramienta sirve para calcular el desnivel existente entre puntos observados mediante una nivelación geométrica. Las observaciones de esta nivelación geométrica deben estas almacenados en un archivo digital. El formato de este archivo debe ser el procedente de los equialtímetros digitales Leica (GSI).

La herramienta está estructurada en dos pasos, que son los siguientes:

* [Paso 1: Selección de archivos de entrada y salida](paso-1-seleccion-de-archivos-de-entrada-y-salida.md)
* Paso 2: Desniveles calculados

Use los botones **Siguiente** y **Anterior** para cambiar de paso y modificar los datos o las selecciones.
