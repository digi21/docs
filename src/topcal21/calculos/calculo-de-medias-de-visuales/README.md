# Calcular medias de visuales
<!-- id: calcular-medias-de-visuales -->

Esta herramienta sirve para calcular las visuales medias después de realizar varias visuales a los mismos puntos, visualizando las posibles diferencias que existan entre dichas visuales.

Si se repitieron visuales a los mismos puntos, calcule sus medias antes de calcular los errores sistemáticos del instrumento o de utilizar las visuales en otros cálculos.

La herramienta está estructurada en de tres pasos, que son los siguientes:

* [Paso 1: Selección de visuales](paso-1-seleccion-de-visuales.md)
* [Paso 2: Desviaciones típicas](paso-2-desviaciones-tipicas.md)
* [Paso 3: Configurar salida de datos](paso-3-configurar-salida-de-datos.md)

Use los botones **Siguiente** y **Anterior** para cambiar de paso y modificar los datos o las selecciones.
