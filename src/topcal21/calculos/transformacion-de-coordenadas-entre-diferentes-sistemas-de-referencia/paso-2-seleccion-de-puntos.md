# Paso 2: Selección de puntos
<!-- id: topcal21-transformacion-de-coordenadas-entre-diferentes-sistemas-de-referencia-paso-2-seleccion-de-puntos -->

Este es el segundo paso para el cambio de sistema de referencia, en el que se muestra una pantalla con los puntos con coordenadas almacenados en el fichero actual. Se deberán seleccionar los puntos que se desean transformar.

![Transformación de coordenadas entre diferentes sistemas de referencia — Paso 2](../../../images/cambio-de-sistema-de-referencia-paso2.jpg)

El listado que se muestra contiene los siguientes campos:

* **Número de punto**
* **Coordenadas del punto**
* **Nombre del punto**

Se podrán seleccionar múltiples puntos utilizando la tecla *\[CTRL\]* y pulsando con el botón izquierdo del ratón sobre los puntos deseados. Si se pulsa sobre un punto ya seleccionado, éste se deselecciona.

También se pueden seleccionar puntos dispuestos en rangos, pulsando la tecla *\[MAYÚSCULAS\]* y el botón izquierdo del ratón sobre los puntos límite que definen el rango.

De la misma forma, se pueden utilizar los botones de **Todos** o **Ninguno** para seleccionar o deseleccionar todos los puntos.

Cuando se hayan seleccionado los puntos deseados se puede pulsar el botón **Siguiente** para acceder al [Paso 3: Configurar salida de datos](paso-3-configurar-salida-de-datos.md) o volver al [Paso 1: Selección de los sistemas de referencia](paso-1-seleccion-de-los-sistemas-de-referencia.md) pulsando el botón **Anterior**.
