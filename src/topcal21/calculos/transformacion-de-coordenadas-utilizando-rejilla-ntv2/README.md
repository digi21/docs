# Transformación de coordenadas utilizando rejilla NTV2
<!-- id: transformacion-de-coordenadas-utilizando-rejilla-ntv2 -->

Esta herramienta permite transformar un conjunto de puntos definido en un sistema de coordenadas a otro sistema de coordenadas utilizando un archivo de rejilla en formato NTV2.

El formato NTV2 (desarrollado por el Geodetic Survey Division of Geomatics de Canadá) es utilizado por el IGN para la transformación de coordenadas de diferentes datum, como puede ser la transformación de coordenadas en ED50 a ETRS89 y viceversa. Es una rejilla donde se define en cada punto el desplazamiento en longitud y latitud entre ambos sistemas. Con estos datos el programa interpola el desplazamiento para cada punto, aplicándola y obteniendo las coordenadas en el sistema destino.

La herramienta está estructurada en cuatro pasos, que son los siguientes:

* [Paso 1: Introducir datos de entrada](paso-1-introducir-datos-de-entrada.md)
* [Paso 2: Configurar modo de cálculo](paso-2-configurar-modo-de-calculo.md)
* [Paso 3: Selección de puntos](paso-3-seleccion-de-puntos.md)
* [Paso 4: Configurar salida de datos](paso-4-configurar-salida-de-datos.md)

Use los botones **Siguiente** y **Anterior** para cambiar de paso y modificar los datos o las selecciones.
