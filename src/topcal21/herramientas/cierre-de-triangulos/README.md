# Cierre de triángulos
<!-- id: cierre-de-triangulos -->

Esta herramienta sirve para cerrar triángulos mediante las visuales realizadas entre los puntos. Con ello, se podrán encontrar errores groseros en dichas visuales, ya que los triángulos deberán cerrar en 200 grados centesimales. Sólo se podrán cerrar triángulos si existen lecturas horizontales directas y recíprocas entre los puntos.

La herramienta se estructura en tres pasos que guiarán al usuario en el cálculo:

* [Paso 1: Selección de visuales](paso-1-seleccion-de-visuales.md)
* [Paso 2: Visuales repetidas y sin recíproca](paso-2-visuales-repetidas-y-sin-reciproca.md)
* [Paso 3: Cierres resultantes](paso-3-cierres-resultantes.md)

Use los botones **Siguiente** y **Anterior** para cambiar de paso y modificar los datos o las selecciones.
