# Transformación
<!-- id: transformacion -->

Esta herramienta sirve para transformar las coordenadas de puntos pertenecientes a un sistema de referencia, a otro sistema de referencia a partir del conocimiento de puntos comunes en ambos sistemas.

A partir de estos datos comunes, la aplicación calcula unos parámetros de transformación que aplicará al resto de puntos del fichero para referirlos al nuevo sistema de coordenadas.

La herramienta se estructura en cinco pasos que guiarán al usuario en el cálculo:

* [Paso 1: Seleccionar ficheros de ambos sistemas](paso-1-seleccionar-ficheros-de-ambos-sistemas.md)
* [Paso 2: Puntos comunes a ambos sistemas](paso-2-puntos-comunes-a-ambos-sistemas.md)
* [Paso 3:](paso-3-puntos-transformados-y-residuos.md) Residuos
* [Paso 4: Parámetros de la transformación](paso-4-parametros-de-la-transformacion.md)
* [Paso 5: Puntos transformados y salida de datos](paso-5-puntos-transformados-y-salida-de-datos.md)

Use los botones **Siguiente** y **Anterior** para cambiar de paso y modificar los datos o las selecciones.
