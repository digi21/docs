# Generar libreta de campo
<!-- id: generar-libreta-de-campo -->

Esta herramienta sirve para generar una libreta de campo a partir de un conjunto de puntos con coordenadas conocidas. Es decir, es el paso inverso a la radiación.

La herramienta se estructura en cuatro pasos que guiarán al usuario en el cálculo:

* [Paso 1: Introducir ficheros de datos de entrada](paso-1-introducir-ficheros-de-datos-de-entrada.md)
* [Paso 2: Configuración de la estación](paso-2-configuracion-de-la-estacion.md)
* [Paso 3: Selección de los puntos visados](paso-3-seleccion-de-los-puntos-visados.md)
* [Paso 4: Configurar salida de datos](paso-4-configurar-salida-de-datos.md)

Use los botones **Siguiente** y **Anterior** para cambiar de paso y modificar los datos o las selecciones.
