# Inicio del programa
<!-- id: topcal21-inicio-del-programa -->

El programa de instalación habrá creado un icono de inicio en el escritorio de Windows y una carpeta en el menú *Programas* del *Inicio* de Windows.

Para iniciar TopCal 21:

* Haga doble clic con el ratón sobre el icono del escritorio.
* Seleccione *Inicio* → *Programas* → *Digi21.net* → *TopCal 21* → *TopCal 21*.

> [!NOTE]
> Al iniciarse, Topcal21 comprueba la protección. Si el ordenador tiene una activación de licencias de software, Topcal21 usa esa licencia y no busca ninguna llave. Si el ordenador no tiene una activación, Topcal21 busca una llave de protección. Si no encuentra ni una activación ni una llave, Topcal21 muestra el cuadro **Protección de Topcal21**, con los botones **Activar una licencia de software**, **Seleccionar llave** y **Salir**. Consulta [Licencias de software](../../../licencias-de-software/README.md).

Para iniciar Topcal21 desde la línea de órdenes, consulta [Opciones de la línea de órdenes](../../opciones-de-la-linea-de-ordenes.md).
