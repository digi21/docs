# Requisitos del sistema
<!-- id: topcal21-requisitos-del-sistema -->

TopCal 21 se ejecuta en el sistema operativo Microsoft Windows. Para instalar y empezar a utilizar TopCal 21, es necesario el siguiente hardware y software:

* Un procesador Intel Pentium II (300 Mhz o más), o equivalente, que ejecute Windows 2000 o Windows XP.
* Memoria RAM suficiente para cumplir los requisitos del sistema operativo (recomendable 128 Mb).
* 15 Mb de espacio disponible en disco.
* Unidad de CD-ROM.
* Un monitor color capaz de alcanzar una resolución de 1024 x 768 píxeles y 16 bits, con miles de colores (se recomienda millones de colores).
* Un puerto USB para conectar la llave de protección.
